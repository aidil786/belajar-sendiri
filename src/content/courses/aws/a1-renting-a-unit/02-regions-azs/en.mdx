Build the command that switches on the Malaysia Region.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws', means: 'talk to AWS' }, { text: 'account', means: 'about your account' }, { text: 'enable-region', means: 'switch a Region on' }, { text: '--region-name ap-southeast-5', means: 'the Malaysia Region' }]} decoys={[{ text: '--region us-east-1', means: 'which endpoint to call, not what to switch on' }, { text: 'delete-region', means: 'there is no such command' }]} success="That opens the Malaysia mall for your account." />

<Card id="see-status" type="see">
<Interactive name="Transcript" title="bash" label="enable-region prints nothing when it works. get-region-opt-status then says ENABLING." lines={[{ cmd: 'aws account enable-region --region-name ap-southeast-5' }, { cmd: 'aws account get-region-opt-status --region-name ap-southeast-5' }, { out: '{\n    "RegionName": "ap-southeast-5",\n    "RegionOptStatus": "ENABLING"\n}', color: 'yellow' }]} />

<Card id="deeper" type="deeper">
The letter in `ap-southeast-5a` is a name. The AZ ID (`apse5-az1`) is the real place, the same in every account. In some old Regions, older accounts get their letters shuffled.

Prices differ between Regions. Some services reach new Regions later, so check the service page first.

Real rep: wait for lesson 5. Set your budget alarm before you touch any Region.
</Card>
