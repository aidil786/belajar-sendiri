<Card id="see-split" type="see">
The **<Term id="shared-responsibility">shared responsibility model</Term>** splits the work. AWS guards the building: security *of* the cloud. You guard your unit: security *in* the cloud. Sort the jobs.

<Interactive name="SortCards" buckets={[{ id: 'aws', label: 'AWS (the building)' }, { id: 'you', label: 'You (your unit)' }]} items={[{ label: 'Guards at the data centre doors', bucket: 'aws', why: 'Physical security of the buildings is AWS’s job.' }, { label: 'Power, cooling and the machines', bucket: 'aws', why: 'The hardware under every service is AWS’s.' }, { label: 'Who gets your account’s keys', bucket: 'you', why: 'Your users, passwords and MFA are yours.' }, { label: 'Your unit’s door rules', bucket: 'you', why: 'You set which visitors may come in.' }, { label: 'Your customers’ data', bucket: 'you', why: 'What you store, and who may read it, is yours.' }]} success="AWS guards the building. You guard the unit." />
</Card>

<Card id="try-door" type="try">
Your unit’s door rules are a **security group**. AWS gives you the door; you write the rules. Let the shopper in on HTTPS. Keep the stranger out.

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'You do', correct: true, why: 'On EC2, the system inside the server is yours to update.' }, { label: 'AWS does, automatically', why: 'AWS patches its own machines, not the system you put on top.' }, { label: 'Nobody needs to', why: 'Unpatched systems are a favourite way in for attackers.' }]} />

<Card id="see-line" type="see">
The line moves with the service. A plain server leaves you more jobs. A ready-made service, like S3 storage, leaves you fewer. Which job always stays yours?

<Interactive name="Choice" options={[{ label: 'Choosing who can read your data', correct: true, why: 'Every service, every time: access to your data is yours.' }, { label: 'Patching S3’s computers', why: 'AWS runs S3’s systems. You never see them.' }, { label: 'Fixing a broken disk in the data centre', why: 'Hardware is always AWS’s job.' }]} />
</Card>

<Card id="deeper" type="deeper">
Some jobs are shared but split in two. AWS patches its machines; you patch your system and apps. AWS trains its staff; you train yours.

The rules also depend on your country’s laws and the Regions you pick. World A3 builds real door rules, step by step.
