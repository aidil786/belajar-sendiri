<Card id="see-split" type="see">
**<Term id="shared-responsibility">Model tanggungjawab bersama</Term>** bahagikan kerja. AWS jaga bangunan: keselamatan *bagi* cloud. Anda jaga unit anda: keselamatan *dalam* cloud. Susun kerja-kerja ini.

<Card id="deeper" type="deeper">
Ada kerja yang dikongsi tetapi dibelah dua. AWS patch mesinnya; anda patch sistem dan aplikasi anda. AWS latih stafnya; anda latih staf anda.

Peraturan juga bergantung pada undang-undang negara anda dan Region yang anda pilih. Dunia A3 bina peraturan pintu sebenar, langkah demi langkah.
</Card>
