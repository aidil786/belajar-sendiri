<Card id="hook" type="hook">
Kancil ada dua akaun: satu untuk latihan dan satu untuk kedai sebenar. Dia taip arahan padam. Macam mana `aws` tahu akaun mana yang dimaksudkan?

<Interactive name="Choice" options={[{ label: 'Dari profil yang dia pilih', correct: true, why: 'Profil namakan akaun, role dan Region.' }, { label: 'Ia teka akaun paling baru', why: 'CLI tak pernah meneka. Ia guna profil, atau profil default.' }, { label: 'Ia tanya AWS mana yang lebih selamat', why: 'AWS hanya nampak kunci yang anda hantar. Pilih dengan sengaja.' }]} />
</Card>

<Card id="see-whoami" type="see">
<Interactive name="Transcript" title="bash" label="aws sts get-caller-identity paparkan id pengguna, nombor akaun dan ARN pengguna IAM DevAdmin." lines={[{ cmd: 'aws sts get-caller-identity' }, { out: '{\n    "UserId": "AIDASAMPLEUSERID",\n    "Account": "123456789012",\n    "Arn": "arn:aws:iam::123456789012:user/DevAdmin"\n}', color: 'green' }]} />

Tabiat pertama: tanya "saya siapa?" Baca baris Arn. Ini pengguna DevAdmin, dalam akaun 123456789012.
</Card>

<Card id="see-config" type="see">
**<Term id="cli-profile">Profil</Term>** ialah set tetapan bernama dalam `~/.aws/config`. Ketik baris yang pilih akaun.

<Interactive name="SpotLines" lines={[{ text: '[profile my-dev-profile]' }, { text: 'sso_session = my-sso' }, { text: 'sso_account_id = 123456789011', target: true }, { text: 'sso_role_name = readOnly' }, { text: 'region = us-west-2' }, { text: 'output = json' }, { text: '[sso-session my-sso]' }, { text: 'sso_region = us-east-1' }, { text: 'sso_start_url = https://my-sso-portal.awsapps.com/start' }]} prompt="Ketik baris akaun." success="Nombor itu ialah akaun. Baris role kata pas mana yang dipakai." />
</Card>

<Card id="try-login" type="try">
Bina arahan yang log masuk dengan profil itu.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws', means: 'bercakap dengan AWS' }, { text: 'sso login', means: 'log masuk di kaunter depan' }, { text: '--profile my-dev-profile', means: 'dengan tetapan ini' }]} decoys={[{ text: 'configure set aws_secret_access_key', means: 'simpan kunci jangka panjang: yang kita elakkan' }]} success="Satu log masuk, kemudian pas jangka pendek." />

<Hint>Alat, kemudian sso login, kemudian profil.</Hint>
</Card>

<Card id="see-login" type="see">
<Interactive name="Transcript" title="bash" label="aws sso login buka pelayar, kemudian kata ia sudah log masuk ke start URL." lines={[{ cmd: 'aws sso login --profile my-dev-profile' }, { out: 'SSO authorization page has automatically been opened in your default browser.\nFollow the instructions in the browser to complete this authorization request.' }, { out: 'Successfully logged into Start URL: https://my-sso-portal.awsapps.com/start', color: 'green' }]} />

Pelayar minta anda luluskan, dengan MFA. CLI kemudian simpan pas jangka pendek dalam cache. Tiada kunci disimpan dalam fail.
</Card>

<Card id="predict" type="predict">
Terminal ini ada `AWS_PROFILE=shop`. Kancil jalankan arahan dengan `--profile practice`. Akaun mana yang digunakan?
