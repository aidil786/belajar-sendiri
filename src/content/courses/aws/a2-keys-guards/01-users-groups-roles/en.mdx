<Card id="see-three" type="see">
**IAM** is the mall’s key office. It knows three kinds of keyholder: users, groups and roles. Sort each one.

<Interactive name="SortCards" buckets={[{ id: 'user', label: 'User' }, { id: 'group', label: 'Group' }, { id: 'role', label: 'Role' }]} items={[{ label: 'Aina, with her own sign-in', bucket: 'user', why: 'One person or app, with long-lasting secrets.' }, { label: 'Cashiers: everyone on the till', bucket: 'group', why: 'A list of users that share the same keys.' }, { label: 'A badge trusted people or services borrow', bucket: 'role', why: 'Borrowed for a while, then it expires.' }, { label: 'Cannot sign in by itself', bucket: 'group', why: 'A group only holds users and their keys.' }, { label: 'Hands out temporary keys', bucket: 'role', why: 'No password, no stored keys.' }]} success="User, group, role. Three keyholders, three jobs." />
</Card>

<Card id="deeper" type="deeper">
There is no built-in "everyone" group. If you want one, you make it and add every user yourself.

Real rep: IAM itself is free. Make a group, add your admin user to it, then list it with `aws iam get-group --group-name Cashiers`. Delete the group when done.
</Card>
