<Interactive name="Choice" options={[{ label: 'The badge works for one job, then expires', correct: true, why: 'Nothing long-lived sits in GitHub secrets, so nothing old can leak.' }, { label: 'It is faster to type', why: 'Speed is not the point. <Card id="deeper" type="deeper">
GitHub repos made after 15 July 2026 put ids in the `sub` value, like `repo:kedai-kancil@123/shop@456:…`. Copy the exact format from your repo’s docs.
