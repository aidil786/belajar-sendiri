<Card id="deeper" type="deeper">
Repo GitHub yang dibuat selepas 15 Julai 2026 letak id dalam nilai `sub`, seperti `repo:kedai-kancil@123/shop@456:…`. Salin format tepat dari dokumentasi repo anda.

Latihan sebenar (IAM percuma; pasang penggera bajet dahulu). Senarai bersihkan: role dan provider.
