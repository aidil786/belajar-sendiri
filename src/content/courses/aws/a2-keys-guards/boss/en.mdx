<Card id="predict-login" type="predict">
Room 4: before any push, the workflow must log in to ECR. That needs one more key. Which one?

<Interactive name="Choice" options={[{ label: 'ecr:GetAuthorizationToken, on "*"', correct: true, why: 'The ECR docs list it for pushing. It cannot be narrowed to one shelf.' }, { label: 'ecr:*, on "*"', why: 'That opens every ECR action, deletes included.' }, { label: 'iam:PassRole', why: 'That hands roles to services. Pushing doesn’t need it.' }]} />
</Card>
