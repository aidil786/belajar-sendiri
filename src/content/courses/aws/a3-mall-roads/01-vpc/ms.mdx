<Card id="see-vpc" type="see">
**<Term id="vpc">VPC</Term>** (lot berpagar) ialah lot anda dalam pusat beli-belah. Server dan pangkalan data anda tinggal di dalamnya. Ada servis yang tinggal di luar. Susun mereka.

<Interactive name="SortCards" buckets={[{ id: 'in', label: 'Dalam VPC anda' }, { id: 'out', label: 'Di luar mana-mana VPC' }]} items={[{ label: 'Server web anda (EC2)', bucket: 'in', why: 'Server sentiasa tinggal dalam VPC.' }, { label: 'Pangkalan data anda (RDS)', bucket: 'in', why: 'Ia duduk dalam VPC anda, di bilik belakang.' }, { label: 'Satu bucket S3', bucket: 'out', why: 'S3 ialah stor untuk seluruh Region. Bucket tak pernah duduk dalam VPC.' }, { label: 'Pengguna dan role IAM', bucket: 'out', why: 'IAM untuk seluruh akaun. Ia pegang kunci, bukan unit.' }]} success="Tersusun! Unit tinggal dalam lot anda. Pejabat kunci dan stor tidak." />
</Card>

<Card id="see-cidr" type="see">
Lot anda dapat satu blok alamat, ditulis sebagai **<Term id="cidr">CIDR</Term>**. `10.0.0.0/16` ada 65,536 alamat. Nombor lebih kecil selepas garis miring bermaksud blok lebih besar. Mana paling besar?

<Interactive name="Choice" compact options={[{ label: '/16', correct: true, why: '/16 ialah blok paling besar yang boleh VPC ada.' }, { label: '/24', why: '/24 ada 256 alamat. Itu lebih kecil.' }, { label: '/28', why: '/28 ada 16 sahaja. Paling kecil untuk VPC.' }]} />
</Card>

<Card id="try-plan" type="try">
Lot ini terlalu besar. Jadikan VPC itu /16. Kemudian beri setiap sayap satu baris awam.

<Hint>Taip `10.0.0.0/16` dalam kotak VPC. Kemudian pilih saiz untuk setiap baris.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh pagar lot anda sendiri: VPC dengan blok alamatnya.
</Card>

<Card id="deeper" type="deeper">
Setiap Region beri anda satu VPC lalai, dengan baris awam di setiap sayap. Ia senang untuk berlatih. VPC tiada caj, tetapi ada bahagian di dalamnya yang ada caj. Anda jumpa bahagian itu nanti.

Latihan sebenar (pilihan): dalam akaun ujian, buka halaman VPC. Cari VPC lalai dan CIDRnya. Jangan cipta apa-apa lagi.
</Card>
