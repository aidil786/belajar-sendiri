An **<Term id="ec2">EC2 instance</Term>** is a server you rent by the hour. Launching one is four choices. Put them in order.

<Interactive name="OrderList" items={['Pick the starting disk (an AMI)', 'Pick the size (the instance type)', 'Pick the row and the door guard', 'Launch, and watch it start']} label="First choice at the top" success="Disk, size, row and guard, launch. Every server starts this way." />
</Card>

<Card id="see-size" type="see">
The **<Term id="instance-type">instance type</Term>** sets CPU and memory. Bigger costs more per hour. For practice, pick the smallest that works. Sort these.

<Interactive name="SortCards" buckets={[{ id: 'ok', label: 'Fine for a practice server' }, { id: 'big', label: 'Far too big for practice' }]} items={[{ label: 't3.micro (2 vCPU, 1 GiB)', bucket: 'ok', why: 'Small and cheap. <Card id="try-launch" type="try">
Build the launch command. Use a small size, your public row and your door guard.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws ec2 run-instances', means: 'rent a new server' }, { text: '--image-id ami-0abcdef1234567890', means: 'from this starting disk' }, { text: '--instance-type t3.micro', means: 'a small size' }, { text: '--subnet-id subnet-0e99b93155EXAMPLE', means: 'in your public row' }, { text: '--security-group-ids sg-903004f8', means: 'behind your door guard' }]} decoys={[{ text: '--instance-type m7i.4xlarge', means: 'a very big size' }]} success="That launches one small server in the right row, behind the right guard." />
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'Its disk, and any Elastic IP on it', correct: true, why: 'Compute stops.
