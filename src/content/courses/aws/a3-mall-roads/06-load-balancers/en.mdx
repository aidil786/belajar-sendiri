<Card id="see-lb" type="see">
A **<Term id="load-balancer">load balancer</Term>** is the mall's reception desk. It sends each shopper to a free, healthy counter. AWS has two common kinds. Sort the jobs.

<Interactive name="SortCards" buckets={[{ id: 'alb', label: 'Application Load Balancer (web pages)' }, { id: 'nlb', label: 'Network Load Balancer (any TCP/UDP)' }]} items={[{ label: 'Send /api to one group, the rest to another', bucket: 'alb', why: 'It reads the web address, so it can route by path.' }, { label: 'A website over HTTPS', bucket: 'alb', why: 'It speaks HTTP and HTTPS.' }, { label: 'A game server on UDP', bucket: 'nlb', why: 'It passes raw TCP and UDP, very fast.' }, { label: 'A database port for a partner', bucket: 'nlb', why: 'Plain TCP, no web pages: the network kind.' }]} success="Web pages: application. Anything else on TCP or UDP: network." />
</Card>
