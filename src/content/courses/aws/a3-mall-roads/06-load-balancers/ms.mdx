<Card id="see-lb" type="see">
**<Term id="load-balancer">Load balancer</Term>** (penyambut tetamu) ialah kaunter penyambut pusat beli-belah. Ia hantar setiap pembeli ke kaunter yang lapang dan sihat. AWS ada dua jenis biasa. Susun kerjanya.

<Interactive name="SortCards" buckets={[{ id: 'alb', label: 'Application Load Balancer (laman web)' }, { id: 'nlb', label: 'Network Load Balancer (apa-apa TCP/UDP)' }]} items={[{ label: 'Hantar /api ke satu kumpulan, yang lain ke kumpulan lain', bucket: 'alb', why: 'Ia baca alamat web, jadi ia boleh hala ikut laluan.' }, { label: 'Laman web melalui HTTPS', bucket: 'alb', why: 'Ia faham HTTP dan HTTPS.' }, { label: 'Server permainan guna UDP', bucket: 'nlb', why: 'Ia salurkan TCP dan UDP mentah, sangat laju.' }, { label: 'Port pangkalan data untuk rakan niaga', bucket: 'nlb', why: 'TCP biasa, tiada laman web: jenis rangkaian.' }]} success="Laman web: application. Lain-lain atas TCP atau UDP: network." />
</Card>
