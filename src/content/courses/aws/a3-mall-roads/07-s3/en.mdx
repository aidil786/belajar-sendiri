<Card id="see-bucket" type="see">
An **<Term id="s3-bucket">S3 bucket</Term>** is a storeroom for files. It lives in one Region. Its name must be unique, so pick your own. Watch the official examples.

<Interactive name="Transcript" title="bash" label="aws s3 mb makes the bucket amzn-s3-demo-bucket. aws s3 ls lists two buckets with their dates." lines={[{ cmd: 'aws s3 mb s3://amzn-s3-demo-bucket' }, { out: 'make_bucket: s3://amzn-s3-demo-bucket', color: 'green' }, { cmd: 'aws s3 ls' }, { out: '2013-07-11 17:08:50 amzn-s3-demo-bucket\n2013-07-24 14:55:44 amzn-s3-demo-bucket2' }]} />
</Card>

<Card id="see-lock" type="see">
**<Term id="block-public-access">Block Public Access</Term>** is the storeroom's master lock. New buckets get it on by default. Tap every lock that is on.

<Interactive name="SpotLines" prompt="Tap every setting that is on." success="All four are true: nothing in this bucket can go public." lines={[{ text: '$ aws s3api get-public-access-block --bucket amzn-s3-demo-bucket' }, { text: '"PublicAccessBlockConfiguration": {' }, { text: '    "IgnorePublicAcls": true,', target: true }, { text: '    "BlockPublicPolicy": true,', target: true }, { text: '    "BlockPublicAcls": true,', target: true }, { text: '    "RestrictPublicBuckets": true', target: true }, { text: '}' }]} />
</Card>

<Card id="predict" type="predict">
The master lock is on. Someone adds a bucket policy: "everyone may read". What happens?

<Interactive name="Choice" options={[{ label: 'S3 refuses that policy', correct: true, why: 'BlockPublicPolicy rejects any bucket policy that allows public access.' }, { label: 'The bucket goes public', why: 'Not while the lock is on. That is its whole job.' }, { label: 'Only the photos go public', why: 'The lock looks at the policy, and refuses it whole.' }]} />
</Card>
