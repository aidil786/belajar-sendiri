<Card id="see-bucket" type="see">
**<Term id="s3-bucket">Bucket S3</Term>** (stor fail) ialah stor untuk fail. Ia tinggal dalam satu Region. Namanya mesti unik, jadi pilih nama anda sendiri. Tengok contoh rasmi.

<Interactive name="Transcript" title="bash" label="aws s3 mb buat bucket amzn-s3-demo-bucket. aws s3 ls senaraikan dua bucket dengan tarikhnya." lines={[{ cmd: 'aws s3 mb s3://amzn-s3-demo-bucket' }, { out: 'make_bucket: s3://amzn-s3-demo-bucket', color: 'green' }, { cmd: 'aws s3 ls' }, { out: '2013-07-11 17:08:50 amzn-s3-demo-bucket\n2013-07-24 14:55:44 amzn-s3-demo-bucket2' }]} />
</Card>

<Card id="see-lock" type="see">
**<Term id="block-public-access">Block Public Access</Term>** ialah kunci utama stor. Bucket baru dapat ia hidup secara lalai. Ketik setiap kunci yang hidup.

<Interactive name="SpotLines" prompt="Ketik setiap tetapan yang hidup." success="Keempat-empat true: tiada apa dalam bucket ini boleh jadi awam." lines={[{ text: '$ aws s3api get-public-access-block --bucket amzn-s3-demo-bucket' }, { text: '"PublicAccessBlockConfiguration": {' }, { text: '    "IgnorePublicAcls": true,', target: true }, { text: '    "BlockPublicPolicy": true,', target: true }, { text: '    "BlockPublicAcls": true,', target: true }, { text: '    "RestrictPublicBuckets": true', target: true }, { text: '}' }]} />
</Card>

<Card id="deeper" type="deeper">
Padam bucket: `aws s3 rb s3://amzn-s3-demo-bucket --force` padam setiap fail di dalamnya dahulu. Anggap ia muktamad, dan semak nama dua kali.

Latihan sebenar (pilihan), dalam akaun ujian. Buat satu bucket dan muat naik satu fail. Semak kunci, kemudian kosongkan dan padam.
</Card>
