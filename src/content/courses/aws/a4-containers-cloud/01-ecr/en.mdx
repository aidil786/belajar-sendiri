<Card id="try-login" type="try">
Docker needs a login before it can push. The AWS CLI hands over a short-lived password. Build the safe login.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws ecr get-login-password --region ap-southeast-5', means: 'get a short-lived ECR password' }, { text: '|', means: 'pipe it into the next command' }, { text: 'docker login', means: 'log in with Docker' }, { text: '--username AWS', means: 'ECR’s user name is always AWS' }, { text: '--password-stdin', means: 'read the password from the pipe' }, { text: '111122223333.dkr.ecr.ap-southeast-5.amazonaws.com', means: 'your shelf’s address' }]} decoys={[{ text: '-p MyPassword123', means: 'a password typed on the command line' }]} success="That's the official way: the password never shows on screen." />

<Hint>Same pipe as Docker World D5: the password comes in through `--password-stdin`.</Hint>
</Card>

<Card id="predict" type="predict">
That ECR password is a token. How long does it work?

<Interactive name="Choice" options={[{ label: '12 hours', correct: true, why: 'Then it expires. Run the login again. Nothing old lies around.' }, { label: 'Forever', why: 'Never forever. A leaked token stops working after 12 hours.' }, { label: 'One push only', why: 'It lasts 12 hours, for as many pushes as you like.' }]} />
</Card>

<Card id="check-habits" type="check">
