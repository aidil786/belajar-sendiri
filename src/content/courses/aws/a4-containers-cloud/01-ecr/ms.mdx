<Card id="see-name" type="see">
**<Term id="ecr">ECR</Term>** (rak image) ialah rak peribadi itu: satu <Term id="registry" course="docker">registry</Term>, seperti dalam Dunia Docker D5. Nama imagenya ialah alamat panjang. Susun bahagiannya.

</Card>

<Card id="try-login" type="try">
Docker perlu log masuk sebelum boleh push. AWS CLI beri kata laluan jangka pendek. Bina log masuk yang selamat.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws ecr get-login-password --region ap-southeast-5', means: 'dapatkan kata laluan ECR jangka pendek' }, { text: '|', means: 'salurkan ke arahan seterusnya' }, { text: 'docker login', means: 'log masuk dengan Docker' }, { text: '--username AWS', means: 'nama pengguna ECR sentiasa AWS' }, { text: '--password-stdin', means: 'baca kata laluan dari saluran' }, { text: '111122223333.dkr.ecr.ap-southeast-5.amazonaws.com', means: 'alamat rak anda' }]} decoys={[{ text: '-p MyPassword123', means: 'kata laluan ditaip pada baris arahan' }]} success="Itulah cara rasmi: kata laluan tak pernah muncul di skrin." />

<Hint>Saluran sama seperti Dunia Docker D5: kata laluan masuk melalui `--password-stdin`.</Hint>
</Card>
