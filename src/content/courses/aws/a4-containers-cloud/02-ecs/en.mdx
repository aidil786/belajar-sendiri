<Card id="deeper" type="deeper">
ECS itself has no extra charge. You pay for what tasks run on: Fargate (next lesson) or EC2 servers. A new card version is a revision: `kedai-web:2`. Point the service at it, and ECS rolls new tasks in, old ones out.
</Card>
