<Card id="deeper" type="deeper">
Each Fargate task gets its own private IP, like a pod in [Kubernetes World K3](/en/kubernetes/#world-3). To pull from a private ECR shelf, the task needs a task execution role. That role holds the pull keys.
</Card>
