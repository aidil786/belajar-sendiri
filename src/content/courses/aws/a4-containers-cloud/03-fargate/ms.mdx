<Card id="try-run" type="try">
Mulakan satu task di Fargate, saiz paling kecil, dalam baris awam anda. Bina arahannya.

<Interactive name="CommandBuilder" pieces={[{ text: 'aws ecs run-task', means: 'mulakan task sekali' }, { text: '--cluster kedai', means: 'dalam kluster kedai' }, { text: '--launch-type FARGATE', means: 'di Fargate, tiada server' }, { text: '--task-definition kedai-web:1', means: 'dari kad resepi revision 1' }, { text: '--network-configuration "awsvpcConfiguration={subnets=[subnet-0e99b93155EXAMPLE],securityGroups=[sg-903004f8],assignPublicIp=ENABLED}"', means: 'baris mana, pengawal mana, satu IP awam' }]} decoys={[{ text: '--launch-type EC2', means: 'di server yang anda jaga' }]} success="Satu task kecil, dalam baris anda, di belakang pengawal anda." />

<Hint>Saiz tertulis pada kad resepi: `"cpu": "256"` dan `"memory": "512"`.</Hint>
</Card>

<Card id="check-door" type="check">
Setiap task Fargate dapat pengawal pintunya sendiri. Untuk ujian anda, hanya laptop anda boleh melawat di port 80.

<Interactive name="SecurityGroupGate" edit="sg" forbidOpen={[22]} visitors={[{ id: 'me', label: 'Laptop anda', ip: '203.0.113.9', protocol: 'tcp', port: 80, want: 'in' }, { id: 'stranger', label: 'Orang asing', ip: '192.0.2.77', protocol: 'tcp', port: 80, want: 'out' }, { id: 'ssh', label: 'Orang asing (SSH)', ip: '192.0.2.77', protocol: 'tcp', port: 22, want: 'out' }]} success="Hanya anda boleh nampak kedai ujian." />

<Hint>Satu peraturan: TCP 80 dari 203.0.113.9/32.</Hint>
</Card>
