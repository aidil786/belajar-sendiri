<Card id="deeper" type="deeper">
Deleting a database is careful work. RDS offers a final snapshot first, and deletion protection can block mistakes. Snapshots cost storage too, so delete old test ones. For practice, pick the smallest size, one wing, and delete it the same day.
</Card>
