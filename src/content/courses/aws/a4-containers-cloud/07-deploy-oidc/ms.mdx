<Card id="deeper" type="deeper">
Role penuh juga perlukan hak push ECR, `ecs:RegisterTaskDefinition` dan `iam:PassRole` untuk role task. Panduan GitHub pin langkah ECS kepada commit tepat, seperti di sini. Repo baru mungkin guna format subject lain. Salin yang tepat dari dokumen OIDC GitHub.
