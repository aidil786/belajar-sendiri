<Card id="deeper" type="deeper">
Not every project needs every station. A small static site has no image to scan or publish. Stations can also run side by side. Jobs without `needs:` start at the same time. Jobs with `needs:` wait for the jobs they name.

Real rep (optional): open your own workflow file. Write the station name next to each step as a comment.
</Card>
