<Card id="deeper" type="deeper">
A busy repo can add a merge queue. It tests each pull request with the newest main, then merges it. Each flag adds paths to test. Keep few, and remove old ones. Switching a feature on is a release, not a deploy (World C3).

Real rep (optional): give a test job a matrix with your flag `off` and `on`.
</Card>
