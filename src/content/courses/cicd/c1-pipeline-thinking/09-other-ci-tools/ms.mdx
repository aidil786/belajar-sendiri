<Card id="try-yaml" type="try">
Ini satu job GitLab. Bina job yang sama dalam GitHub Actions.

```yaml
test:
  image: node:24
  script:
    - npm ci
    - npm test
```

<Card id="deeper" type="deeper">
Di mana cerita tak tepat: tali sawat sebenar bawa hidangan satu demi satu. Pipeline boleh jalankan banyak job serentak. Salin build pula percuma, jadi satu pek boleh pergi ke banyak tempat.

Jenkins biasanya jalan pada server pasukan anda sendiri.

Latihan sebenar (pilihan): buka satu projek awam di GitLab. Cari `.gitlab-ci.yml` dan namakan stage-nya.
</Card>
