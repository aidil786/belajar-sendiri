<Card id="see-rules" type="see">
<Interactive name="SpotLines" lines={[{ text: '- id: meta' }, { text: '  uses: docker/metadata-action@v6' }, { text: '  with:' }, { text: '    images: ghcr.io/you/kedai-kancil' }, { text: '    tags: |' }, { text: '      type=ref,event=branch' }, { text: '      type=ref,event=pr' }, { text: '      type=semver,pattern={{version}}' }, { text: '      type=sha', target: true }]} prompt="Tap the rule that writes the batch code: the commit." success="Yes! type=sha adds sha- and the short commit id." />

**<Term id="image-tag">Tags</Term>** are labels on the pack. `docker/metadata-action` writes them for you. Each rule adds a label when it fits the event.
</Card>

<Card id="see-run" type="see">

</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: '`1.3.0-rc.1` and `sha-3f9c2a7`', correct: true, why: 'A pre-release keeps its -rc.1 and never takes latest.' }, { label: '`1.3.0-rc.1`, `sha-3f9c2a7` and `latest`', why: 'latest skips pre-releases. <Card id="check" type="check">
Swipe right if the tag is good for production. Swipe left if it needs work.

<Interactive name="SwipeJudge" cards={[{ text: 'kedai-kancil:1.2.0', good: true, why: 'A version. <Card id="win" type="win">
You can now give every image clear, traceable tags.
</Card>

<Card id="deeper" type="deeper">
Add `type=semver,pattern={{major}}.{{minor}}` to also get `1.2`. Set `flavor: latest=false` to stop `latest`. metadata-action also writes labels: pass `labels: ${{ steps.meta.outputs.labels }}` to the build.
