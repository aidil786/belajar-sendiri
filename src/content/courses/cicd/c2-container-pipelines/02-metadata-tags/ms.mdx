**<Term id="image-tag">Tag</Term>** (label) ialah label pada pek. `docker/metadata-action` tulis untuk anda. Setiap peraturan tambah satu label bila ia sesuai dengan event.
</Card>

<Card id="see-run" type="see">
<Interactive name="ConveyorBelt" scenario="c2-tags" label="Langkah metadata cetak tag untuk event yang anda pilih: push ke main, pull request, atau tag versi." />

Pilih satu event dan tekan Run. Kemudian ketik stesen untuk baca log. Log itu senaraikan tag. Cuba ketiga-tiga event.
</Card>

<Card id="deeper" type="deeper">
Tambah `type=semver,pattern={{major}}.{{minor}}` untuk dapat `1.2` juga. Letak `flavor: latest=false` untuk hentikan `latest`. metadata-action juga tulis label: hantar `labels: ${{ steps.meta.outputs.labels }}` kepada build.
