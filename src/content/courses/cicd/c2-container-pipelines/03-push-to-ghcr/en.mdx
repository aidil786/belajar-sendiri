<Interactive name="ConveyorBelt" scenario="c2-fix-permissions" label="A push to main builds the image, then the push to ghcr.io is denied. The build station turns red." />

Press Run. The pack is built, then stopped at the freezer door: `denied: permission_denied: write_package`. Plain words: this job's key can't put packs in.
</Card>

<Card id="see-ghcr" type="see">
<Interactive name="SpotLines" lines={[{ text: '- uses: docker/login-action@v4' }, { text: '  with:' }, { text: '    registry: ghcr.io' }, { text: '    username: ${{ github.actor }}' }, { text: '    password: ${{ secrets.GITHUB_TOKEN }}', target: true }]} prompt="Tap the line that hands over the job's pass." success="Yes! GITHUB_TOKEN: no secret to make or rotate." />

**<Term id="ghcr">GHCR</Term>** (ghcr.io) is GitHub's own shop freezer. The job logs in with `GITHUB_TOKEN`. It's a pass that ends when the job ends.
</Card>

<Card id="try-sort" type="try">
What does this job's pass need? Give it the least.

<Interactive name="SortCards" buckets={[{ id: 'need', label: 'This job needs it' }, { id: 'off', label: 'Leave it off' }]} items={[{ label: '`contents: read`', bucket: 'need', why: 'The job reads your code.' }, { label: '`packages: write`', bucket: 'need', why: 'This is the freezer key: push to GHCR.' }, { label: '`contents: write`', bucket: 'off', why: 'Pushing an image never changes your code.' }, { label: '`issues: write`', bucket: 'off', why: 'The belt never touches issues.' }]} success="Least privilege: read the code, write the package." />
</Card>

<Card id="try-fix" type="try">

You can now push images to GHCR with only the keys needed.

<Card id="deeper" type="deeper">
A package pushed with `GITHUB_TOKEN` takes its repo's visibility and access rules. Owner names with capitals break `ghcr.io/${{ github.repository }}`. metadata-action makes image names lowercase for you.
