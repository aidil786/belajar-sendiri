The **<Term id="layer-cache">layer cache</Term>** can live in the GitHub Actions cache. `cache-from` reads old layers. `cache-to` saves new ones. `mode=max` keeps middle stages too.
</Card>

<Card id="deeper" type="deeper">
GitHub deletes caches nobody used for a while. Each repo also has a size limit. `type=registry` keeps the cache in GHCR instead. Two images? Give each its own `scope`, like `type=gha,scope=api`.
