**<Term id="layer-cache">Cache layer</Term>** boleh disimpan dalam cache GitHub Actions. `cache-from` baca layer lama. `cache-to` simpan yang baru. `mode=max` simpan peringkat tengah juga.
</Card>

<Card id="deeper" type="deeper">
GitHub padam cache yang lama tak diguna. Setiap repo juga ada had saiz. `type=registry` simpan cache dalam GHCR pula. Dua image? Beri setiap satu `scope` sendiri, contohnya `type=gha,scope=api`.
