**<Term id="multi-arch">Image multi-arch</Term>** ialah satu nama dengan satu pek untuk setiap CPU. Setiap komputer tarik pek yang sesuai dengannya.
</Card>

<Card id="try-fix" type="try">
Tekan Run. Pek arm64 gagal di runner Intel ini. Pilih pembaikan untuk baris kuning.

<Interactive name="ConveyorBelt" scenario="c2-multi-arch" task={{ type: 'green' }} fixes={[

  { label: 'Tambah checkout sebelum Buildx', text: '      - uses: actions/checkout@v7\n      - uses: docker/setup-buildx-action@v4', why: 'Checkout salin kod anda. Masalah CPU masih ada.' }]}

<Card id="deeper" type="deeper">
GitHub juga ada runner Arm, contohnya `ubuntu-24.04-arm`. Ia bina arm64 secara asli, tanpa QEMU, jadi lebih laju. `docker buildx imagetools inspect <image>` senaraikan pek dalam satu nama.

Latihan sebenar (pilihan), dalam repo latihan awam:

<Interactive name="Mission" id="c2-l05-rep" steps={[{ id: 'qemu', text: 'Tambah docker/setup-qemu-action sebelum setup-buildx-action.' }, { id: 'plat', text: 'Tambah platforms: linux/amd64,linux/arm64 pada langkah build.' }, { id: 'look', text: 'Push image itu, kemudian senaraikan peknya.', command: 'docker buildx imagetools inspect ghcr.io/YOUR-NAME/YOUR-REPO:main' }]} success="Image anda kini sesuai untuk dua jenis komputer!" />
</Card>
