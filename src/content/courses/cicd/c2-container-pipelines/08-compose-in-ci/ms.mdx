<Card id="deeper" type="deeper">
Tambah satu langkah dengan `if: failure()` yang jalankan `docker compose logs`. Jadi run merah tunjuk apa kata setiap container. Runner GitHub memang dikosongkan selepas setiap job. `down -v` paling penting di runner anda sendiri.
