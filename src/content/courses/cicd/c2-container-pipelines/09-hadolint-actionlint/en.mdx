<Interactive name="Transcript" title="bash" label="hadolint checks the Dockerfile and warns about DL3007: using latest." lines={[{ cmd: 'hadolint Dockerfile' }, { out: 'Dockerfile:1 DL3007 warning: Using latest is prone to errors if the image will ever update. Pin the version explicitly to a release tag', color: 'yellow' }]} />

Last month `node:latest` jumped a version, and the shop broke overnight. A **<Term id="linter">linter</Term>** would have warned you. Plain words: pin a version, like `node:24-alpine`.
</Card>

<Card id="predict" type="predict">

</Card>

<Card id="see-actionlint" type="see">
<Interactive name="Transcript" title="bash" label="actionlint reads image.yml and finds that job scan needs a job called imgae, which does not exist." lines={[{ cmd: 'docker run --rm -v "$PWD:/repo" -w /repo rhysd/actionlint:1.7.12 .github/workflows/image.yml' }, { out: '.github/workflows/image.yml:14:3: job "scan" needs job "imgae" which does not exist in this workflow [job-needs]\n   |\n14 |   scan:\n   |   ^~~~~', color: 'red' }]} />

actionlint proofreads workflow files. It caught a typo before GitHub did: `imgae`. The official image runs it with no install.
</Card>

<Card id="deeper" type="deeper">
hadolint also checks the shell in `RUN` lines, with ShellCheck. To skip one rule, put `# hadolint ignore=DL3007` above that line. Only do it with a good reason. actionlint checks `run:` scripts too, when ShellCheck is installed.
