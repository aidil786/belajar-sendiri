</Card>

<Card id="deeper" type="deeper">
`ignore-unfixed: true` langkau lubang yang belum ada pembaikan. Docker Scout buat kerja sama dengan `docker/scout-action`. Image lama pun dapat CVE baru. Imbas semula ikut jadual.

Latihan sebenar (pilihan), dengan Trivy yang dipasang ikut dokumen rasminya:

<Interactive name="Mission" id="c2-l10-rep" steps={[{ id: 'scan', text: 'Imbas satu image rasmi yang kecil.', command: 'trivy image --severity CRITICAL --exit-code 1 alpine:3.22' }, { id: 'code', text: 'Semak kod keluar: 0 maksudnya tiada lubang kritikal.', command: 'echo $?' }, { id: 'ci', text: "Tambah langkah Trivy dengan exit-code: '1' dalam repo latihan." }]} success="Anda boleh baca imbasan macam pemeriksa makanan!" />
</Card>
