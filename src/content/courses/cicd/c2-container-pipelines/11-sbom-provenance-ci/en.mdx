<Interactive name="SortCards" buckets={[{ id: 'sbom', label: 'SBOM (what is inside)' }, { id: 'prov', label: 'Provenance (who made it, how)' }]} items={[{ label: 'Every package and its version', bucket: 'sbom', why: 'The ingredients list.' }, { label: 'The commit that was built', bucket: 'prov', why: 'Where the recipe came from.' }, { label: 'The licence of each library', bucket: 'sbom', why: 'It sits next to each ingredient.' }, { label: 'The workflow file that built it', bucket: 'prov', why: 'Which kitchen and which belt.' }]} success="Sorted! <Card id="deeper" type="deeper">
Attestations alone reach SLSA Build Level 2. Building in a reusable workflow can reach Level 3. Public repos log signatures in Sigstore's public log. Private repos use GitHub's own Sigstore. For an SBOM file, `actions/attest` takes `sbom-path`.
