<Card id="win" type="win">
Kini anda boleh hantar SBOM dan provenance bertandatangan dengan setiap image.
</Card>

<Card id="deeper" type="deeper">
Attestation sahaja capai SLSA Build Level 2. Build dalam reusable workflow boleh capai Level 3. Repo awam catat tandatangan dalam log awam Sigstore. Repo peribadi guna Sigstore milik GitHub. Untuk fail SBOM, `actions/attest` terima `sbom-path`.
