<Card id="try-paths" type="try">
A **<Term id="path-filter">path filter</Term>** skips the belt when only some files change. This one says `paths-ignore: ['docs/**', '**.md']`. Sort each push.

<Card id="deeper" type="deeper">
Don't cancel a deploy halfway: `cancel-in-progress: ${{ github.ref != 'refs/heads/main' }}` keeps main safe. Path filters are not checked for tag pushes. Caches nobody uses for a while are deleted.
