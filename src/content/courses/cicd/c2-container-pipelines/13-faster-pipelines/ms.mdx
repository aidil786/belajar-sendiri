<Card id="see-concurrency" type="see">
<Interactive name="ConveyorBelt" scenario="c2-concurrency" label="Push ke menu-page mulakan satu run. Run lama pada branch yang sama dibatalkan dulu. Kemudian ujian berjalan dan lulus." />

**<Term id="concurrency">Concurrency</Term>** letak run dalam satu kumpulan: workflow sama, branch sama. `cancel-in-progress: true` batalkan run yang lama. Tekan Run.
</Card>

<Card id="check-group" type="check">
Anda push ke `main` dan ke `menu-page` serentak. Adakah satu batalkan yang lain?

<Interactive name="Choice" options={[{ label: 'Tidak: branch berbeza, kumpulan berbeza', correct: true, why: 'Nama kumpulan ada github.ref, jadi setiap branch dapat kumpulan sendiri.' }, { label: 'Ya: workflow sama, jadi satu menang', why: 'Kumpulan itu ada nama branch juga. Branch lain, kumpulan lain.' }, { label: 'Kedua-duanya dibatalkan', why: 'Pembatalan hanya kena run lama dalam kumpulan yang sama.' }]} />
</Card>

<Card id="try-paths" type="try">
**<Term id="path-filter">Penapis laluan</Term>** langkau tali sawat bila hanya fail tertentu berubah. Yang ini tulis `paths-ignore: ['docs/**', '**.md']`. Susun setiap push.

<Card id="deeper" type="deeper">
Jangan batalkan deploy separuh jalan: `cancel-in-progress: ${{ github.ref != 'refs/heads/main' }}` jaga main. Penapis laluan tak disemak untuk push tag. Cache yang lama tak diguna akan dipadam.
