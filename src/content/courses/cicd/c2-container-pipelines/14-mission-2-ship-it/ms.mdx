<Card id="try-yaml" type="try">
Bina `ci.yml`: lint dan uji, kemudian bina, imbas dan push kedua-dua image. Anda akan salin fail ini selepas ini.

<Interactive name="YamlBuilder" workflow="Ship it" goal={{ order: ['push', 'pr', 'perms', 'lint', 'test', 'image', 'buildx', 'meta', 'build', 'scan', 'login', 'ship'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'Bila push ke main', yaml: 'push:\n  branches: [main]', means: 'Setiap merge ke main.' },
  { id: 'pr', kind: 'trigger', label: 'Bila ada pull request', yaml: 'pull_request:', means: 'Setiap PR disemak.' },
  { id: 'perms', kind: 'permissions', label: 'Token baca sahaja', yaml: 'contents: read', means: 'Secara lalai, job cuma baca.' },
  { id: 'lint', kind: 'job', label: 'Job: lint', yaml: 'lint:\n  runs-on: ubuntu-latest\n  steps:\n    - uses: actions/checkout@v7\n    - uses: hadolint/hadolint-action@v3.1.0\n      with:\n        dockerfile: Dockerfile\n        recursive: true', means: 'Semak setiap Dockerfile dalam repo.' },
  { id: 'test', kind: 'job', label: 'Job: test', yaml: 'test:\n  runs-on: ubuntu-latest\n  steps:\n    - uses: actions/checkout@v7\n    - run: docker compose up -d --wait\n    - run: docker compose run --rm api npm test', means: 'Hidupkan set hidangan, kemudian jalankan ujian API.' },
  { id: 'image', kind: 'job', label: 'Job: image (web dan api)', yaml: 'image:\n  needs: [lint, test]\n  runs-on: ubuntu-latest\n  permissions:\n    contents: read\n    packages: write\n  strategy:\n    matrix:\n      app: [web, api]', means: 'Hanya selepas lint dan ujian lulus.   { id: 'buildx', kind: 'step', label: 'Sediakan Buildx', yaml: '- uses: docker/setup-buildx-action@v4', means: 'Hidupkan mesin pembungkus.' },
  { id: 'meta', kind: 'step', label: 'Buat tag', yaml: '- id: meta\n  uses: docker/metadata-action@v6\n  with:\n    images: ghcr.io/${{ github.repository }}-${{ matrix.app }}', means: 'Label main, pr-N dan sha-.' },

  { id: 'ship', kind: 'step', label: 'Push (bukan pada PR)', yaml: "- uses: docker/build-push-action@v7\n  with:\n    context: \"{{defaultContext}}:${{ matrix.app }}\"\n    push: ${{ github.event_name != 'pull_request' }}\n    tags: ${{ steps.meta.outputs.tags }}\n    cache-from: type=gha,scope=${{ matrix.app }}", means: 'Image sama dari cache, kini di-push dengan tagnya.' },

  { id: 'echo', kind: 'step', label: 'Cetak token untuk semak', yaml: '- run: echo ${{ secrets.GITHUB_TOKEN }}', means: 'Tunjuk token dalam log.', why: 'Jangan sesekali cetak secret, walaupun untuk semak.' }]}
  success="Talian hijau anda dah siap. Pilih YAML itu dan salin." />

<Hint>Bila, token, kemudian tiga job: lint, test, image. Dalam image: Buildx, tag, build, imbas, log masuk, push.</Hint>

<Card id="deeper" type="deeper">
Di mana cerita ini tak tepat. Tali sawat sebenar gerakkan satu pek pada satu masa. Pipeline jalankan banyak job serentak. Setiap pekerja lupa semuanya selepas job. Dan tag tak melekat kekal: ia boleh beralih ke pek lain. Hanya digest (`sha256:…`) yang tak pernah berubah.
</Card>
