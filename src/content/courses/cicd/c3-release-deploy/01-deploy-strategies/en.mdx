Way 1: **<Term id="recreate">recreate</Term>**. Close the stall, swap the menu, open again. The old version stops, then the new one starts. What do customers see in between?

<Interactive name="Choice" options={[{ label: 'A closed sign, for a short while', correct: true, why: 'Nothing serves between stop and start. </Card>

<Card id="see-rolling" type="see">
Way 2: **<Term id="rolling-update">rolling update</Term>**. Swap the cooks one at a time. The stall never closes. Put the steps in order.

<Interactive name="OrderList" items={['Start one copy of version 2', 'Check that it is healthy', 'Stop one copy of version 1', 'Repeat until every copy is version 2']} label="First step at the top" success="Yes! No closed sign. For a while, old and new serve side by side." />
</Card>

<Card id="try-bluegreen" type="try">
Way 3: **<Term id="blue-green">blue/green</Term>**. Two full kitchens. Version 2 waits next to version 1. Test it, then switch everyone. Trouble? Switch back.

<Interactive name="TrafficDial" mode="bluegreen" newErrorRate={0.1} task={{ type: 'rollback' }} success="Safe! Version 1 kept serving while you checked." />

<Hint>Test version 2 first. If it shows errors, keep version 1 live.</Hint>
</Card>

<Card id="see-canary" type="see">
Way 4: **<Term id="canary">canary</Term>**. A few customers taste the new dish first. All good? Serve more people. Sort each fact.

<Interactive name="SortCards" buckets={[{ id: 'bluegreen', label: 'Blue/green' }, { id: 'canary', label: 'Canary' }]} items={[{ label: 'Needs two full copies running', bucket: 'bluegreen', why: 'Two whole kitchens cost more, for a short time.' }, { label: 'Moves users in small steps: 5%, 25%, 50%', bucket: 'canary', why: 'Each step waits and watches the errors.' }, { label: 'One switch moves everyone', bucket: 'bluegreen', why: 'The sign flips for all customers at once.' }, { label: 'Only a few users meet a new bug', bucket: 'canary', why: 'If 5% get version 2, a bug hurts only 5%.' }]} success="Sorted! <Card id="deeper" type="deeper">
Kubernetes does rolling updates by default (World K2). Cloudflare Workers can run a canary for you, called a gradual deployment. Upload a version with no traffic, then choose its share.

<Interactive name="Transcript" title="bash" label="Two Wrangler commands: upload a new version, then split traffic between versions." lines={[{ cmd: 'npx wrangler versions upload' }, { cmd: 'npx wrangler versions deploy' }]} />

Real rep (optional): use a free test Worker, not your team's. Send 10% to the new version, then roll back.
</Card>
