<Card id="see-rolling" type="see">

<Interactive name="OrderList" items={['Mulakan satu salinan versi 2', 'Semak salinan itu sihat', 'Hentikan satu salinan versi 1', 'Ulang sampai semua salinan jadi versi 2']} label="Langkah pertama di atas" success="Ya! Tiada papan Tutup. Buat seketika, versi lama dan baharu melayan bersama." />

Cara 3: **<Term id="blue-green">blue/green</Term>**. Dua dapur penuh. Versi 2 menunggu di sebelah versi 1. Uji dulu, kemudian alihkan semua orang. Ada masalah? Alih balik.

<Card id="see-canary" type="see">
Cara 4: **<Term id="canary">canary</Term>**. Beberapa pelanggan rasa hidangan baharu dulu. Semua okey? Hidang kepada lebih ramai. Susun setiap fakta.

<Interactive name="SortCards" buckets={[{ id: 'bluegreen', label: 'Blue/green' }, { id: 'canary', label: 'Canary' }]} items={[{ label: 'Perlu dua salinan penuh berjalan', bucket: 'bluegreen', why: 'Dua dapur penuh lebih mahal, untuk sekejap.' }, { label: 'Alih pengguna sikit demi sikit: 5%, 25%, 50%', bucket: 'canary', why: 'Setiap langkah tunggu dan perhati ralat.' }, { label: 'Satu suis alihkan semua orang', bucket: 'bluegreen', why: 'Papan tanda bertukar untuk semua pelanggan serentak.' }, { label: 'Hanya sedikit pengguna jumpa bug baharu', bucket: 'canary', why: 'Kalau 5% dapat versi 2, bug hanya kena 5%.' }]} success="Siap! </Card>

<Card id="deeper" type="deeper">
Kubernetes guna rolling update secara lalai (Dunia K2). Cloudflare Workers boleh buat canary untuk anda, dipanggil gradual deployment. Muat naik versi tanpa trafik, kemudian pilih bahagiannya.

<Interactive name="Transcript" title="bash" label="Dua arahan Wrangler: muat naik versi baharu, kemudian bahagikan trafik antara versi." lines={[{ cmd: 'npx wrangler versions upload' }, { cmd: 'npx wrangler versions deploy' }]} />

Latihan sebenar (pilihan): cuba pada Worker ujian percuma, bukan milik pasukan anda. Hantar 10% ke versi baharu, kemudian rollback.
</Card>
