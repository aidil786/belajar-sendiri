<Card id="try-yaml" type="try">
Now build it. A job joins an environment with one key: `environment`.

<Interactive name="YamlBuilder" workflow="Deploy" goal={{ order: ['push', 'perms', 'job', 'ready', 'deploy'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'On push to main', yaml: 'push:\n  branches: [main]', means: 'Run when main gets new commits.' },
  { id: 'pr', kind: 'trigger', label: 'On every pull request', yaml: 'pull_request:', means: 'Run for every pull request.', why: 'Deploy what lands on main, not every pull request.' },
  { id: 'perms', kind: 'permissions', label: 'Read-only token', yaml: 'contents: read', means: 'The token can only read the code.' },
  { id: 'bare', kind: 'job', label: 'Job: deploy (no environment)', yaml: 'deploy:\n  runs-on: ubuntu-latest', means: 'A runner that deploys.', why: 'No environment means no reviewer and no guard.' },
  { id: 'job', kind: 'job', label: 'Job: deploy (production)', yaml: 'deploy:\n  runs-on: ubuntu-latest\n  environment:\n    name: production\n    url: https://shop.example.com', means: 'Deploy to production. Its rules apply first.' },
  { id: 'ready', kind: 'step', label: 'Get ready', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Copy the code. Install packages.' },

<Card id="deeper" type="deeper">
Up to six people or teams can be reviewers. One approval is enough. Turn on "prevent self-review" so nobody approves their own deploy. A wait timer can pause up to 30 days. On private repos, required reviewers need GitHub Enterprise.

Real rep (optional): in a public test repo, make a `production` environment. Add yourself as its reviewer.
</Card>
