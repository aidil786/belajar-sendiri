<Card id="win" type="win">
Kini anda boleh letak pintu manusia di depan production.
</Card>

<Card id="deeper" type="deeper">
Sehingga enam orang atau pasukan boleh jadi penyemak. Satu kelulusan sudah cukup. Hidupkan "prevent self-review" supaya tiada siapa lulus deploy sendiri. Pemasa tunggu boleh tahan sehingga 30 hari. Untuk repo peribadi, penyemak wajib perlukan GitHub Enterprise.

Latihan sebenar (pilihan): dalam repo ujian awam, buat environment `production`. Tambah diri anda sebagai penyemak.
</Card>
