<Card id="see-bump" type="see">
Mesej yang jelas pilih nombor seterusnya. Peraturannya ialah **<Term id="semantic-versioning" course="git">SemVer</Term>**: MAJOR.MINOR.PATCH. Anda di 1.4.2. Susun setiap commit ikut versi yang dihasilkannya.

<Interactive name="SortCards" buckets={[{ id: 'patch', label: '1.4.3 (patch)' }, { id: 'minor', label: '1.5.0 (minor)' }, { id: 'major', label: '2.0.0 (major)' }]} items={[{ label: '`fix: typo on the menu`', bucket: 'patch', why: 'Pembaikan naikkan nombor terakhir.' }, { label: '`feat: add a search box`', bucket: 'minor', why: 'Ciri baharu naikkan nombor tengah.' }, { label: '`feat!: remove the old cart API`', bucket: 'major', why: 'Perubahan yang memecahkan naikkan nombor pertama.' }, { label: '`fix: crash on an empty cart`', bucket: 'patch', why: 'Satu lagi pembaikan. <Card id="try-yaml" type="try">
Bina workflow robot itu. Ia jalan pada setiap push ke main.

<Interactive name="YamlBuilder" workflow="Release Please" goal={{ order: ['push', 'job', 'perms', 'robot'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'Bila push ke main', yaml: 'push:\n  branches: [main]', means: 'Setiap merge ke main kejutkan robot.' },
  { id: 'job', kind: 'job', label: 'Job: release-please', yaml: 'release-please:\n  runs-on: ubuntu-latest', means: 'Runner Linux yang baharu.' },
  { id: 'perms', kind: 'permissions', label: 'Tulis tag, PR dan issue', yaml: 'contents: write\npull-requests: write\nissues: write', means: 'Buat tag dan release. Buka PR. Tambah label.' },
  { id: 'pkgs', kind: 'permissions', label: 'Tulis pakej', yaml: 'packages: write', means: 'Push image ke GHCR.', why: 'Job ini tak terbitkan image. Beri apa yang perlu sahaja.' },

<Card id="deeper" type="deeper">
semantic-release buat kerja yang sama tanpa release PR. Ia release pada setiap push ke main. Satu perangkap: tag yang dibuat dengan `GITHUB_TOKEN` tak mulakan workflow lain. Jadi deploy dalam workflow yang sama, selepas release-please lapor ada release.

Latihan sebenar (pilihan): tambah workflow ini pada repo ujian. Merge commit `feat:` dan lihat release PR muncul.
</Card>
