<Card id="try-yaml" type="try">
Now build this site's pipeline, in short. Check everything. Deploy only from main.

<Interactive name="YamlBuilder" workflow="CI" goal={{ order: ['push', 'pr', 'perms', 'check', 'ready1', 'test', 'deploy', 'ready2', 'ship'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'On every push', yaml: 'push:', means: 'Run for a push to any branch.' },
  { id: 'pr', kind: 'trigger', label: 'On every pull request', yaml: 'pull_request:', means: 'Run for pull requests too.' },
  { id: 'perms', kind: 'permissions', label: 'Read-only token', yaml: 'contents: read', means: 'The token can only read the code.' },
  { id: 'check', kind: 'job', label: 'Job: check', yaml: 'check:\n  runs-on: ubuntu-latest', means: 'A runner that tests everything.' },
  { id: 'ready1', kind: 'step', label: 'Get ready (check job)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Copy the code. Install packages.' },
  { id: 'test', kind: 'step', label: 'Run the tests', yaml: '- run: npm test', means: 'Every test must pass.' },
  { id: 'always', kind: 'job', label: 'Job: deploy (every event)', yaml: 'deploy:\n  needs: check\n  runs-on: ubuntu-latest', means: 'Deploy after the checks.', why: 'Then every pull request would go live. Deploy from main only.' },
  { id: 'deploy', kind: 'job', label: 'Job: deploy (main only, never cut short)', yaml: "deploy:\n  needs: check\n  if: github.event_name == 'push' && github.ref == 'refs/heads/main'\n  runs-on: ubuntu-latest\n  concurrency:\n    group: deploy-production\n    cancel-in-progress: false", means: 'Wait for check. Only pushes to main. Never stop a deploy halfway.' },
  { id: 'ready2', kind: 'step', label: 'Get ready (deploy job)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'A new runner needs the code again.' },
  { id: 'ship', kind: 'step', label: 'Build and deploy', yaml: '- run: npm run deploy\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}\n    CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}', means: 'Build, then wrangler deploy, with keys from secrets.' }]}
  success="That is the shape of this site's real pipeline." />

<Hint>Both triggers, permissions, the check job and its steps. Then the main-only deploy job and its steps.</Hint>
</Card>

<Card id="deeper" type="deeper">
This site's real file is `.github/workflows/ci.yml`. Its deploy job waits for two jobs: check and workflows. Containers can pull from Cloudflare's registry, Docker Hub, Amazon ECR or Google's registry. A GHCR image? Push it to Cloudflare's registry first.

Real rep (optional): run `npx wrangler deploy --dry-run` in a small Worker project.
</Card>
