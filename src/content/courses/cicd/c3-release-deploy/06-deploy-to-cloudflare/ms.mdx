<Card id="try-yaml" type="try">
Sekarang bina pipeline laman ini, versi ringkas. Semak semua. Deploy dari main sahaja.

<Interactive name="YamlBuilder" workflow="CI" goal={{ order: ['push', 'pr', 'perms', 'check', 'ready1', 'test', 'deploy', 'ready2', 'ship'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'Pada setiap push', yaml: 'push:', means: 'Jalan untuk push ke mana-mana branch.' },
  { id: 'pr', kind: 'trigger', label: 'Pada setiap pull request', yaml: 'pull_request:', means: 'Jalan untuk pull request juga.' },
  { id: 'perms', kind: 'permissions', label: 'Token baca sahaja', yaml: 'contents: read', means: 'Token hanya boleh baca kod.' },
  { id: 'check', kind: 'job', label: 'Job: check', yaml: 'check:\n  runs-on: ubuntu-latest', means: 'Runner yang uji semuanya.' },
  { id: 'ready1', kind: 'step', label: 'Bersedia (job check)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Salin kod. Pasang pakej.' },
  { id: 'test', kind: 'step', label: 'Jalankan ujian', yaml: '- run: npm test', means: 'Setiap ujian mesti lulus.' },
  { id: 'always', kind: 'job', label: 'Job: deploy (setiap acara)', yaml: 'deploy:\n  needs: check\n  runs-on: ubuntu-latest', means: 'Deploy selepas semakan.', why: 'Nanti setiap pull request jadi live. Deploy dari main sahaja.' },
  { id: 'deploy', kind: 'job', label: 'Job: deploy (main sahaja, jangan dipotong)', yaml: "deploy:\n  needs: check\n  if: github.event_name == 'push' && github.ref == 'refs/heads/main'\n  runs-on: ubuntu-latest\n  concurrency:\n    group: deploy-production\n    cancel-in-progress: false", means: 'Tunggu check. Push ke main sahaja. Jangan hentikan deploy separuh jalan.' },
  { id: 'ready2', kind: 'step', label: 'Bersedia (job deploy)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Runner baharu perlukan kod sekali lagi.' },
  { id: 'ship', kind: 'step', label: 'Build dan deploy', yaml: '- run: npm run deploy\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}\n    CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}', means: 'Build, kemudian wrangler deploy, dengan kunci dari secrets.' }]}
  success="Itulah bentuk pipeline sebenar laman ini." />

<Hint>Kedua-dua trigger, permissions, job check dan langkahnya. Kemudian job deploy main sahaja dan langkahnya.</Hint>
</Card>

<Card id="deeper" type="deeper">
Fail sebenar laman ini ialah `.github/workflows/ci.yml`. Job deploy-nya tunggu dua job: check dan workflows. Containers tarik image dari registry Cloudflare, Docker Hub, Amazon ECR atau Google. Image GHCR? Push ke registry Cloudflare dulu.

Latihan sebenar (pilihan): jalankan `npx wrangler deploy --dry-run` dalam projek Worker kecil.
</Card>
