<Card id="deeper" type="deeper">
Runner self-hosted juga boleh baca environment secret. Kawal ia baik-baik (Dunia C4). Untuk repo peribadi, environment secret perlukan GitHub Pro, Team atau Enterprise.

Latihan sebenar (pilihan): dalam repo ujian awam, buat environment staging dan production. Beri setiap satu token ujian sendiri dengan `gh secret set CLOUDFLARE_API_TOKEN --env staging`.
</Card>
