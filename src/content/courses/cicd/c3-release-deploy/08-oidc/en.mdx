<Card id="see-badge" type="see">
**<Term id="oidc">OIDC</Term>** swaps the stored key for a visitor badge. The badge works for one job, then melts. Put the steps in order.

<Interactive name="OrderList" items={['The job asks GitHub for an ID token', 'It shows the token to the cloud', 'The cloud checks the repo and environment', 'The cloud lends a short-lived key', 'The key expires when the job ends']} label="First step at the top" success="Yes! Nothing is stored, so nothing old can leak." />
</Card>

<Card id="try-yaml" type="try">
Build an OIDC deploy to AWS. No keys in secrets.

<Interactive name="YamlBuilder" workflow="Deploy to AWS" goal={{ order: ['push', 'perms', 'job', 'checkout', 'build', 'login', 'upload'] }} blocks={[

  { id: 'perms', kind: 'permissions', label: 'Ask for a badge, read the code', yaml: 'id-token: write\ncontents: read', means: 'Allow the job to ask for an ID token. Read the code.' },
  { id: 'readonly', kind: 'permissions', label: 'Read the code only', yaml: 'contents: read', means: 'The token can only read the code.', why: 'Without id-token: write, the job cannot ask for a badge.' },
  { id: 'job', kind: 'job', label: 'Job: deploy (production)', yaml: 'deploy:\n  runs-on: ubuntu-latest\n  environment: production', means: 'Deploy to production. The cloud can check this name.' },
  { id: 'checkout', kind: 'step', label: 'Check out code', yaml: '- uses: actions/checkout@v7', means: 'Copy the code onto the runner.' },

  { id: 'login', kind: 'step', label: 'Log in to AWS with the badge', yaml: '- uses: aws-actions/configure-aws-credentials@v6\n  with:\n    role-to-assume: arn:aws:iam::123456789012:role/shop-deploy\n    aws-region: ap-southeast-5', means: 'Swap the badge for a short-lived role.' },
  { id: 'keys', kind: 'step', label: 'Log in to AWS with stored keys', yaml: '- uses: aws-actions/configure-aws-credentials@v6\n  with:\n    aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}\n    aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}\n    aws-region: ap-southeast-5', means: 'Log in with keys saved in secrets.', why: 'Those are the long-lived keys we want gone.' },
  { id: 'upload', kind: 'step', label: 'Upload the site', yaml: '- run: aws s3 sync ./dist s3://kedai-kancil-shop', means: 'Copy the built files to cloud storage.' }]}

<Card id="deeper" type="deeper">
The cloud reads claims inside the badge. The subject names the repo and environment, like `repo:you/shop:environment:production`. Repos made after 15 July 2026 use a newer format with ids. So copy the exact rule your cloud's docs show.

Real rep (optional): follow your cloud's GitHub OIDC guide on a test account.
</Card>
