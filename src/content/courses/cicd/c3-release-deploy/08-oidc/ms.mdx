<Card id="deeper" type="deeper">
Cloud baca claim di dalam pas itu. Subject menamakan repo dan environment, contohnya `repo:you/shop:environment:production`. Repo yang dibuat selepas 15 Julai 2026 guna format baharu dengan id. Jadi salin peraturan tepat dari dokumentasi cloud anda.

Latihan sebenar (pilihan): ikut panduan GitHub OIDC cloud anda pada akaun ujian.
</Card>
