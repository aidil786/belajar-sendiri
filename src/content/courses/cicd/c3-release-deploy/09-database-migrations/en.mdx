<Card id="deeper" type="deeper">
Run each migration as its own step, before the code that needs it. Some changes lock a big table while they run. Read your database's docs first. And remember: a rollback swaps code, not data. Cloudflare's rollback leaves databases and other bindings as they are.

Real rep (optional): try these steps on a throwaway database: `docker run --rm -e POSTGRES_PASSWORD=test postgres:18-alpine`.
</Card>
