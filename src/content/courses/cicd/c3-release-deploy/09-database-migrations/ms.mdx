<Card id="win" type="win">

<Card id="deeper" type="deeper">
Jalankan setiap migration sebagai langkah sendiri, sebelum kod yang memerlukannya. Sesetengah perubahan mengunci jadual besar semasa berjalan. Baca dokumentasi pangkalan data anda dulu. Ingat: rollback tukar kod, bukan data. Rollback Cloudflare biarkan pangkalan data dan binding lain seperti asal.

Latihan sebenar (pilihan): cuba langkah ini pada pangkalan data pakai buang: `docker run --rm -e POSTGRES_PASSWORD=test postgres:18-alpine`.
</Card>
