<Card id="try-yaml" type="try">
Build it yourself: deploy, taste, and roll back on failure.

<Interactive name="YamlBuilder" workflow="Deploy" goal={{ order: ['push', 'perms', 'deploy', 'ready1', 'ship', 'smoke', 'rollback', 'ready2', 'undo'] }} blocks={[
  { id: 'push', kind: 'trigger', label: 'On push to main', yaml: 'push:\n  branches: [main]', means: 'Run when main gets new commits.' },
  { id: 'perms', kind: 'permissions', label: 'Read-only token', yaml: 'contents: read', means: 'The token can only read the code.' },
  { id: 'deploy', kind: 'job', label: 'Job: deploy (production)', yaml: 'deploy:\n  runs-on: ubuntu-latest\n  environment: production', means: 'Deploy with the production keys.' },
  { id: 'ready1', kind: 'step', label: 'Get ready (deploy job)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Copy the code. Install packages.' },
  { id: 'ship', kind: 'step', label: 'Deploy', yaml: '- run: npx wrangler deploy\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}', means: 'Upload the new version.' },
  { id: 'smoke', kind: 'step', label: 'Smoke test', yaml: '- run: curl --fail --silent https://shop.example.com/health', means: 'One quick taste. An error page fails the job.' },
  { id: 'always', kind: 'job', label: 'Job: rollback (always)', yaml: 'rollback:\n  needs: deploy\n  if: always()\n  runs-on: ubuntu-latest\n  environment: production', means: 'Roll back after every deploy.', why: 'always() would undo good releases too.' },
  { id: 'rollback', kind: 'job', label: 'Job: rollback (only on failure)', yaml: 'rollback:\n  needs: deploy\n  if: failure()\n  runs-on: ubuntu-latest\n  environment: production', means: 'Runs only when the deploy job failed.' },
  { id: 'ready2', kind: 'step', label: 'Get ready (rollback job)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'A new runner needs the code and Wrangler.' },
  { id: 'undo', kind: 'step', label: 'Roll back', yaml: '- run: npx wrangler rollback --message "Smoke test failed"\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}', means: 'Go back to the version before this one.' }]}
  success="Your pipeline can now undo a bad deploy by itself." />

<Hint>The deploy job with its three steps. Then the rollback job that runs only on failure.</Hint>
</Card>

<Interactive name="Choice" options={[{ label: 'It is skipped: nothing failed', correct: true, why: 'failure() is false, so the job never starts.' }, { label: 'It rolls back anyway', why: 'Only always() would do that. failure() waits for a failure.' }, { label: 'It fails', why: 'A skipped job is not a failed job.' }]} />

<Card id="deeper" type="deeper">
`wrangler rollback` swaps the code, not the data. Databases and other bindings stay as they are. Pair it with expand and contract. Want to taste before any user does? Deploy a version at 0%, then call it with the `Cloudflare-Workers-Version-Overrides` header.

Real rep (optional): give a test Worker a `/health` page and a curl check.
</Card>
