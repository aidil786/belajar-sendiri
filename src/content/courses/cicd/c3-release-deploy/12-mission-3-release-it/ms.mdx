Misi 3: Lancarkan. Kedai Kancil dah uji dan build dirinya sendiri. Sekarang jadikan release selamat. Matlamat anda: release teruk yang ditangkap dan diundur oleh pipeline. Run untuk lihat matlamatnya.
</Card>

<Card id="try-setup" type="try">
Langkah 1: dua dapur. Bahagian depan web kedai anda masuk ke pelan Workers percuma Cloudflare. Tambah ini dalam `wrangler.jsonc`:

```jsonc
"account_id": "YOUR_ACCOUNT_ID",
"env": { "staging": {}, "production": {} }
```

<Interactive name="Mission" id="cicd-m3-setup" steps={[
  { id: 'token', text: 'Buat token API Cloudflare daripada templat "Edit Cloudflare Workers". Hadkan kepada satu akaun anda.' },
  { id: 'health', text: 'Pastikan laman yang dibina menjawab /health dengan ok. Fail health.html dalam folder build pun boleh.' },
  { id: 'staging', text: 'Buat environment staging dalam repo anda.', command: 'gh api --method PUT "repos/{owner}/{repo}/environments/staging"' },
  { id: 'production', text: 'Buat production juga. Kemudian, dalam tetapannya, tambah diri anda sebagai penyemak wajib.', command: 'gh api --method PUT "repos/{owner}/{repo}/environments/production"' },
  { id: 'secret-staging', text: 'Simpan token dalam staging. Ia minta anda tampal nilainya.', command: 'gh secret set CLOUDFLARE_API_TOKEN --env staging' },
  { id: 'secret-production', text: 'Simpan token dalam production juga.', command: 'gh secret set CLOUDFLARE_API_TOKEN --env production' },
  { id: 'vars', text: 'Simpan alamat staging anda sebagai pemboleh ubah repo. Buat yang sama untuk SITE_URL.', command: 'gh variable set STAGING_URL --body "https://kedai-kancil-staging.YOUR-SUBDOMAIN.workers.dev"' }]}
  success="Kedua-dua dapur dah sedia, masing-masing dengan kotak rempah berkunci sendiri." />
</Card>

<Card id="try-build" type="try">
Langkah 2: bina `release.yml`. Canary dulu. Production selepasnya, dengan kelulusan anda. Rollback hanya kalau canary gagal.

<Interactive name="YamlBuilder" workflow="Release" goal={{ order: ['tag', 'perms', 'canary', 'ready1', 'stage', 'smoke', 'prod', 'ready2', 'ship', 'rollback', 'ready3', 'undo'] }} blocks={[
  { id: 'tag', kind: 'trigger', label: 'Bila ada tag versi', yaml: "push:\n  tags: ['v*']", means: 'Jalan bila anda push tag seperti v1.0.0.' },
  { id: 'perms', kind: 'permissions', label: 'Token baca sahaja', yaml: 'contents: read', means: 'Token hanya boleh baca kod.' },
  { id: 'canary', kind: 'job', label: 'Job: canary (staging)', yaml: 'canary:\n  runs-on: ubuntu-latest\n  environment: staging', means: 'Cuba versi baharu pada staging dulu.' },
  { id: 'ready1', kind: 'step', label: 'Bersedia (canary)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Salin kod. Pasang pakej.' },
  { id: 'stage', kind: 'step', label: 'Deploy ke staging', yaml: '- run: npx wrangler deploy --env staging\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}', means: 'Muat naik ke Worker kedai-kancil-staging.' },
  { id: 'smoke', kind: 'step', label: 'Smoke test staging', yaml: '- run: curl --fail --silent "$STAGING_URL/health"\n  env:\n    STAGING_URL: ${{ vars.STAGING_URL }}', means: 'Satu rasa pantas. Halaman ralat hentikan talian.' },
  { id: 'loose', kind: 'job', label: 'Job: production (tanpa needs)', yaml: 'production:\n  runs-on: ubuntu-latest\n  environment: production', means: 'Deploy ke production.', why: 'Tanpa needs: canary, production tak tunggu canary.' },
  { id: 'prod', kind: 'job', label: 'Job: production (selepas canary)', yaml: 'production:\n  needs: canary\n  runs-on: ubuntu-latest\n  environment:\n    name: production\n    url: ${{ vars.SITE_URL }}', means: 'Hanya selepas canary hijau, dan kelulusan anda.' },
  { id: 'ready2', kind: 'step', label: 'Bersedia (production)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Runner baharu perlukan kod sekali lagi.' },
  { id: 'ship', kind: 'step', label: 'Deploy ke production', yaml: '- run: npx wrangler deploy --env production\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}', means: 'Muat naik ke Worker kedai-kancil-production.' },
  { id: 'rollback', kind: 'job', label: 'Job: rollback (canary gagal)', yaml: 'rollback:\n  needs: canary\n  if: failure()\n  runs-on: ubuntu-latest\n  environment: staging', means: 'Jalan hanya bila canary gagal.' },
  { id: 'ready3', kind: 'step', label: 'Bersedia (rollback)', yaml: '- uses: actions/checkout@v7\n- run: npm ci', means: 'Wrangler dan tetapannya, sekali lagi.' },
  { id: 'undo', kind: 'step', label: 'Rollback staging', yaml: '- run: npx wrangler rollback --env staging --message "Canary failed"\n  env:\n    CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}', means: 'Kembalikan versi elok yang terakhir pada staging.' }]}
  success="Itulah release.yml anda. Simpan dalam .github/workflows/." />

<Hint>Tiga job, setiap satu dengan langkahnya: canary, kemudian production, kemudian rollback.</Hint>
</Card>
