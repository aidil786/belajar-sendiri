<Card id="hook" type="hook">
Friday, 4:55 pm. Version 2.3.0 of the shop is tagged. Your lead is on a plane, and you are on call. Boss mission: ship it safely, or undo it fast. How do you ship it?

<Interactive name="Choice" options={[{ label: 'A canary: 5% of users first', correct: true, why: 'If it is bad, only a few users meet it.' }, { label: 'Everyone at once. It is Friday!', why: 'One bug would hit every customer before the weekend.' }, { label: 'Close the shop, then swap', why: 'That is recreate. Downtime is not needed here.' }]} />
</Card>

<Card id="try-ship" type="try">

<Card id="try-dial" type="try">
Room 2: the canary is live at 5%. Watch the graph. Move up only while the version 2 line stays calm. Roll back before 150 users hit a bug.

<Interactive name="TrafficDial" scenario="c3-boss-canary" task={{ type: 'rollback', maxHurt: 150 }} success="Rolled back! Most users never saw the bug." />

</Card>

<Card id="check-why" type="check">
The smoke test passed, yet users hit errors. Why?

<Interactive name="Choice" options={[{ label: 'It only tasted /health. The bug is in checkout.', correct: true, why: 'One spoon cannot taste every dish. The canary caught the rest.' }, { label: 'The smoke test was broken', why: 'It did its job: /health really was fine.' }, { label: 'Canaries always miss bugs', why: 'Your canary caught it, with only 5% of users.' }]} />
</Card>

<Card id="try-rollback" type="try">
Room 3: make the undo stick. The rollback workflow, run by hand, is red. Read the real error. Fix the yellow line.

<Interactive name="ConveyorBelt" scenario="c3-boss-rollback" task={{ type: 'green' }} fixes={[
  { label: 'Add environment: production', text: '    runs-on: ubuntu-latest\n    environment: production' },
  { label: 'Paste the token into the file', text: '    runs-on: ubuntu-latest\n    env:\n      CLOUDFLARE_API_TOKEN: paste-token-here', why: 'Never put a key in a file. And the step still reads the empty secret.' },
  { label: 'Add permissions: write-all', text: '    runs-on: ubuntu-latest\n    permissions: write-all', why: 'Token permissions are not secrets. The spice box stays locked.' }]}
  success="Green! Version 2.2 serves everyone again, and /health is happy." />

<Hint>Remember lesson 7: secrets reach only jobs that name their environment.</Hint>
</Card>

<Card id="deeper" type="deeper">
On Cloudflare, a canary is a gradual deployment. These commands do it by hand. Wrangler prints each version id when you upload.

<Interactive name="Transcript" title="bash" label="Upload a version, send it 5% of traffic, then roll back to the previous version." lines={[{ cmd: 'npx wrangler versions upload' }, { cmd: 'npx wrangler versions deploy NEW_ID@5% OLD_ID@95%' }, { cmd: 'npx wrangler rollback --message "Bad Friday"' }]} />

Real rep (optional): practise on a free test Worker, never on your team's.
</Card>
