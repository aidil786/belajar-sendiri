Di Cloudflare, canary ialah gradual deployment. Arahan ini buatnya secara manual. Wrangler cetak id setiap versi bila anda muat naik.

<Interactive name="Transcript" title="bash" label="Muat naik versi, beri 5% trafik, kemudian rollback ke versi sebelumnya." lines={[{ cmd: 'npx wrangler versions upload' }, { cmd: 'npx wrangler versions deploy NEW_ID@5% OLD_ID@95%' }, { cmd: 'npx wrangler rollback --message "Bad Friday"' }]} />
