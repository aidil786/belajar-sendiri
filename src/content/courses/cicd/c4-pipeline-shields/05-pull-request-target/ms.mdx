<Card id="hook" type="hook">
Orang asing fork (buat salinan) repo kedai anda dan buka PR. Job pratonton anda perlukan token Cloudflare anda. Patutkah kod mereka dapat token itu?

<Interactive name="Choice" options={[{ label: 'Tak: kod mereka boleh salin token itu', correct: true, why: 'Token di tangan orang asing boleh deploy apa sahaja.' }, { label: 'Patut: pratonton perlukannya', why: 'Pratonton memang bagus. Token anda lebih berharga.' }, { label: 'Hanya jika PR mereka nampak mesra', why: 'Kod yang nampak mesra pun boleh mencuri. Anda tak boleh baca setiap baris.' }]} />
</Card>

<Card id="see-prt" type="see">
Sesetengah pasukan mahu pratonton untuk fork juga. Jadi mereka tukar ke **<Term id="pull-request-target">pull_request_target</Term>**. Ia jalan dengan secret anda dan kunci tulis, walaupun untuk fork. Susun dua pencetus ini.

<Interactive name="SortCards" buckets={[{ id: 'pr', label: 'pull_request' }, { id: 'prt', label: 'pull_request_target' }]} items={[{ label: 'Guna fail workflow dari kod PR itu sendiri', bucket: 'pr', why: 'PR boleh ubah workflow, tapi fork tak dapat secret.' }, { label: 'Guna fail workflow dari branch lalai anda', bucket: 'prt', why: 'Orang asing tak boleh ubahnya. Sebab itu ia dipercayai dengan kunci.' }, { label: 'PR fork: tiada secret, kunci baca sahaja', bucket: 'pr', why: 'Pilihan lalai yang selamat untuk kod orang asing.' }, { label: 'PR fork: secret anda dan kunci tulis', bucket: 'prt', why: 'Berkuasa, jadi ia tak boleh sekali-kali jalankan kod mereka.' }]} success="Siap! Satu selamat untuk kod asing. Satu pegang kunci anda." />
</Card>

<Card id="predict" type="predict">
Pratonton ini tukar ke `pull_request_target`. Ia juga check out kod PR itu sendiri. PR fork orang asing sampai. Apa jadi?

<Interactive name="Choice" options={[{ label: 'Ia jalan hijau, dan kod mereka pegang token anda', correct: true, why: 'Hijau tak bermaksud selamat. Tengok pada kad seterusnya.' }, { label: 'Ia berhenti: fork tak dapat secret', why: 'Itu pull_request. Pencetus ini serahkan secret anda.' }, { label: 'GitHub sekat checkout itu', why: 'Checkout ambil apa sahaja ref yang anda minta.' }]} />
</Card>

<Card id="see-green" type="see">
<Interactive name="ConveyorBelt" scenario="c4-prt-preview" label="PR orang asing pada pull_request_target. Setiap stesen jadi hijau, dengan token anda dalam job." />

Okey pada `pull_request_target`, atau perangkap? Leret setiap job.

<Card id="deeper" type="deeper">
Corak lebih selamat: uji kod fork dengan `pull_request`. Perlukan secret selepas itu? Guna workflow berasingan pada `workflow_run`, dan anggap artifaknya tak dipercayai. Penyumbang kali pertama mungkin perlu kelulusan penyelenggara untuk run mereka. Latihan sebenar: cari `pull_request_target` dalam repo anda dan semak setiap satu.
</Card>
