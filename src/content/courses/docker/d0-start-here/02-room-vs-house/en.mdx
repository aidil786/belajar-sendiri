<Card id="deeper" type="deeper">
A VM has stronger walls, because each house has its own kernel. Rooms are lighter, but they share one kernel. So many clouds run containers inside VMs: rooms inside houses.

Real rep (optional): once Docker is installed, run `docker run --rm alpine:3.22 uname -a` and `uname -a`. Same kernel? On a Mac or Windows, you see the small Linux VM's kernel.
</Card>
