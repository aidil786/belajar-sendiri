**<Term id="virtual-machine">Virtual machine</Term>** (mesin maya, VM) ialah sebuah rumah penuh. Container ialah sebuah bilik dalam rumah. Tekan setiap satu untuk bandingkan.
</Card>

<Card id="see-kernel" type="see">
<Interactive name="KitchenReplay" scenario="d0-rooms" commands={['cat /etc/os-release', 'docker run --rm alpine:3.22 cat /etc/os-release', 'uname -a', 'docker run --rm alpine:3.22 uname -a']} label="Laptop kata Ubuntu, container kata Alpine Linux. Kemudian uname tunjuk kernel yang sama, 6.18.44, pada kedua-duanya." />

Bilik ada fail sendiri: Alpine di dalam, Ubuntu di luar. Tapi kedua-duanya tunjuk **<Term id="kernel">kernel</Term>** yang sama. Kernel ialah elektrik rumah. Ia jalankan setiap program, di setiap bilik.
</Card>

<Card id="deeper" type="deeper">
VM ada dinding lebih kukuh, sebab setiap rumah ada kernel sendiri. Bilik lebih ringan, tapi kongsi satu kernel. Sebab itu banyak cloud jalankan container di dalam VM: bilik di dalam rumah.

Latihan sebenar (pilihan): selepas Docker dipasang, jalankan `docker run --rm alpine:3.22 uname -a` dan `uname -a`. Kernel sama? Di Mac atau Windows, anda nampak kernel VM Linux kecil itu.
