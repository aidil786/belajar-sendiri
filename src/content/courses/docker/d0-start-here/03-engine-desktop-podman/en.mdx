<Card id="deeper" type="deeper">
Docker Engine is open source (Apache 2.0). The licence rules on docs.docker.com are for Docker Desktop. Podman also has a free app, Podman Desktop. All three run the same images, because images follow one open standard (OCI).

Real rep (optional): open the [Docker Desktop licence page](https://docs.docker.com/subscription/desktop-license/). Find the two numbers for “small business”.
