<Card id="deeper" type="deeper">
Docker Engine ialah sumber terbuka (Apache 2.0). Peraturan lesen di docs.docker.com untuk Docker Desktop. Podman pun ada aplikasi percuma, Podman Desktop. Ketiga-tiganya jalankan image yang sama, sebab image ikut satu standard terbuka (OCI).

Latihan sebenar (pilihan): buka [halaman lesen Docker Desktop](https://docs.docker.com/subscription/desktop-license/). Cari dua nombor untuk “small business”.
</Card>
