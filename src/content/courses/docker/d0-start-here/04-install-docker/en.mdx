<Card id="deeper" type="deeper">
On Linux, start a sleeping engine with `sudo systemctl start docker`. Joining the `docker` group skips sudo, but it gives root-level power. Do it only on your own machine.

No good computer? Killercoda gives you a free Linux terminal in your browser. Type `docker version` there to see if Docker is ready.
