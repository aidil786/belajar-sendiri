<Card id="deeper" type="deeper">
Di Linux, hidupkan enjin yang tidur dengan `sudo systemctl start docker`. Masuk kumpulan `docker` boleh langkau sudo, tapi ia beri kuasa setaraf root. Buat hanya di mesin anda sendiri.

Tiada komputer yang sesuai? Killercoda beri terminal Linux percuma dalam pelayar. Taip `docker version` di sana untuk tengok Docker dah sedia atau belum.
</Card>
