<Card id="deeper" type="deeper">
`docker info` shows more: how many containers and images you have. `docker --version` prints just the client version on one line. The client can even send orders to an engine on another computer.

Real rep (optional): run `docker version` on your own computer. Do both halves show the same version number?
</Card>
