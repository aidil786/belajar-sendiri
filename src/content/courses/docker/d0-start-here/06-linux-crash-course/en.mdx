<Card id="see-path" type="see">
Linux keeps files in folders inside folders, like jars on shelves. A file’s full address is its **<Term id="path">path</Term>**. Build the path to the menu, from the top down.

<Interactive name="OrderList" items={['/ (the top folder)', 'home', 'you', 'kitchen', 'menu.txt']} label="Top folder first" success="/home/you/kitchen/menu.txt. That is a path!" />
</Card>

<Card id="try-chmod" type="try">
Every file has **<Term id="permissions">permissions</Term>**: `r` read, `w` write, `x` run. `ls -l` shows them. `chmod +x cook.sh` adds the run permission. Do it, then run `./cook.sh`.

<Interactive name="KitchenSim" scenario="d0-linux" picture={false} keys={['ls', '-l', 'chmod', '+x', './', 'Tab', '↑']} goal={{ fileMode: { '/home/you/kitchen/cook.sh': 'x' }, lastTyped: '^\\./cook\\.sh', lastExit: 0 }} hints={['Type ls -l first. cook.sh has no x yet.', 'Type chmod +x cook.sh, then ./cook.sh']} success="Nasi lemak is ready! cook.sh may run now." />

<Hint>`chmod +x cook.sh`, then `./cook.sh`.</Hint>
</Card>

<Card id="see-process" type="see">
A file just sits on the shelf. A program that is running is a **<Term id="process">process</Term>**. Each one gets a number, its PID. File or process? Sort them.

<Interactive name="SortCards" buckets={[{ id: 'file', label: 'File (sits still)' }, { id: 'process', label: 'Process (running now)' }]} items={[{ label: 'menu.txt on the shelf', bucket: 'file', why: 'It just sits there until someone reads it.' }, { label: 'cook.sh, waiting on the disk', bucket: 'file', why: 'A script is a file until you run it.' }, { label: 'cook.sh while it runs', bucket: 'process', why: 'Running it makes a process with its own PID.' }, { label: 'dockerd, the engine', bucket: 'process', why: 'The daemon runs all the time, so it is a process.' }, { label: 'A container that is up', bucket: 'process', why: 'A running container is a process on the laptop.' }]} success="Files sit still. Processes run." />
</Card>

<Card id="try-env" type="try">
An **<Term id="environment-variable">environment variable</Term>** is a sticky note on the kitchen wall. Every program you start can read it. Stick one up with `export`. Read it with `echo`.

<Interactive name="KitchenSim" scenario="d0-linux" picture={false} keys={['export', 'echo', '$', '=', 'Tab', '↑']} goal={{ envVar: { CHEF: 'Kancil' }, lastTyped: '^echo\\s+.*\\$\\{?CHEF' }} hints={['Type export CHEF=Kancil', 'Then type echo $CHEF']} success="The note says Kancil. Programs you start can read it too." />

<Hint>`export CHEF=Kancil`, then `echo $CHEF`.</Hint>
</Card>

<Card id="see-exit" type="see">
Every process ends with a number: its **<Term id="exit-code">exit code</Term>**. 0 means all good. Anything else means trouble. `echo $?` shows the last one. Tap every exit code.

<Interactive name="SpotLines" lines={[{ text: '$ cat menu.txt' }, { text: 'nasi lemak' }, { text: 'laksa' }, { text: 'satay' }, { text: '$ echo $?' }, { text: '0', color: 'green', target: true }, { text: '$ cat nope.txt' }, { text: 'cat: nope.txt: No such file or directory', color: 'red' }, { text: '$ echo $?' }, { text: '1', color: 'yellow', target: true }]} prompt="Tap the two exit codes." success="0 after the menu: fine. 1 after nope.txt: trouble." />
</Card>
