<Card id="see-path" type="see">
Linux simpan fail dalam folder di dalam folder, macam balang atas rak. Alamat penuh sesuatu fail ialah **<Term id="path">path</Term>** (laluan). Bina path ke menu, dari atas ke bawah.

<Interactive name="OrderList" items={['/ (folder paling atas)', 'home', 'you', 'kitchen', 'menu.txt']} label="Folder paling atas dulu" success="/home/you/kitchen/menu.txt. Itulah path!" />
</Card>

<Card id="try-chmod" type="try">
Setiap fail ada **<Term id="permissions">permissions</Term>** (kebenaran): `r` baca, `w` tulis, `x` jalankan. `ls -l` tunjukkannya. `chmod +x cook.sh` tambah kebenaran jalankan. Buat, kemudian jalankan `./cook.sh`.

<Interactive name="KitchenSim" scenario="d0-linux" picture={false} keys={['ls', '-l', 'chmod', '+x', './', 'Tab', '↑']} goal={{ fileMode: { '/home/you/kitchen/cook.sh': 'x' }, lastTyped: '^\\./cook\\.sh', lastExit: 0 }} hints={['Taip ls -l dulu. cook.sh belum ada x.', 'Taip chmod +x cook.sh, kemudian ./cook.sh']} success="Nasi lemak is ready! cook.sh dah boleh berjalan." />

<Hint>`chmod +x cook.sh`, kemudian `./cook.sh`.</Hint>
</Card>

<Card id="see-process" type="see">
Fail cuma duduk atas rak. Program yang sedang berjalan ialah **<Term id="process">process</Term>** (proses). Setiap satu dapat nombor, iaitu PID. Fail atau process? Susun.

<Interactive name="SortCards" buckets={[{ id: 'file', label: 'Fail (duduk diam)' }, { id: 'process', label: 'Process (sedang berjalan)' }]} items={[{ label: 'menu.txt atas rak', bucket: 'file', why: 'Ia cuma duduk sampai seseorang membacanya.' }, { label: 'cook.sh, menunggu dalam cakera', bucket: 'file', why: 'Skrip ialah fail sehingga anda jalankannya.' }, { label: 'cook.sh semasa ia berjalan', bucket: 'process', why: 'Menjalankannya cipta process dengan PID sendiri.' }, { label: 'dockerd, enjin itu', bucket: 'process', why: 'Daemon berjalan sepanjang masa, jadi ia process.' }, { label: 'Container yang sedang hidup', bucket: 'process', why: 'Container yang berjalan ialah process dalam laptop.' }]} success="Fail duduk diam. Process berjalan." />
</Card>

<Card id="try-env" type="try">
**<Term id="environment-variable">Environment variable</Term>** (pemboleh ubah persekitaran) ialah nota lekat di dinding dapur. Setiap program yang anda mulakan boleh membacanya. Lekat satu dengan `export`. Baca dengan `echo`.

<Interactive name="KitchenSim" scenario="d0-linux" picture={false} keys={['export', 'echo', '$', '=', 'Tab', '↑']} goal={{ envVar: { CHEF: 'Kancil' }, lastTyped: '^echo\\s+.*\\$\\{?CHEF' }} hints={['Taip export CHEF=Kancil', 'Kemudian taip echo $CHEF']} success="Nota itu tulis Kancil. Program yang anda mulakan pun boleh membacanya." />

<Hint>`export CHEF=Kancil`, kemudian `echo $CHEF`.</Hint>
</Card>

<Card id="see-exit" type="see">
Setiap process tamat dengan satu nombor: **<Term id="exit-code">exit code</Term>** (kod keluar). 0 bermaksud semua okey. Nombor lain bermaksud ada masalah. `echo $?` tunjuk yang terakhir. Tekan setiap exit code.

<Interactive name="SpotLines" lines={[{ text: '$ cat menu.txt' }, { text: 'nasi lemak' }, { text: 'laksa' }, { text: 'satay' }, { text: '$ echo $?' }, { text: '0', color: 'green', target: true }, { text: '$ cat nope.txt' }, { text: 'cat: nope.txt: No such file or directory', color: 'red' }, { text: '$ echo $?' }, { text: '1', color: 'yellow', target: true }]} prompt="Tekan dua exit code itu." success="0 selepas menu: okey. 1 selepas nope.txt: ada masalah." />
</Card>
