<Card id="try-localhost" type="try">
**<Term id="localhost">localhost</Term>** bermaksud “komputer ini, di sini”. Kedai dibuka di tingkap 8080. `curl` ambil satu laman, macam pelayar kecil. Taip `curl localhost:8080`.

<Interactive name="KitchenSim" scenario="d0-net" keys={['curl', '-I', 'localhost:8080', '127.0.0.1', 'Tab', '↑']} goal={{ lastTyped: '^curl\\b.*(localhost|127\\.0\\.0\\.1):8080', lastExit: 0 }} hints={['Taip curl localhost:8080 dan tekan Enter.']} success="Kedai menjawab dari laptop anda sendiri. localhost ialah anda!" />

<Hint>`curl localhost:8080`: tiada ruang di sekeliling titik bertindih.</Hint>
</Card>

**<Term id="dns">DNS</Term>** ialah buku telefon: ia tukar nama kepada IP address. Laptop anda pun simpan buku telefon kecil, /etc/hosts. Tiada siapa senaraikan kedai-kancil, jadi curl mengalah.

<Card id="try-codes" type="try">
Bila server menjawab, ia mula dengan **<Term id="http-status-code">HTTP status code</Term>** (kod status HTTP). 2xx: nah, ambil. 4xx: pesanan anda tak kena. 5xx: dapur bermasalah. Susun semua ini.

<Card id="deeper" type="deeper">
`127.0.0.1` ialah nombor localhost sendiri. Dalam output Docker, `0.0.0.0:8080` bermaksud “port 8080 pada setiap alamat laptop ini”. Pelayar di http://localhost:8080 bertanya sama macam curl.

Latihan sebenar (pilihan): selepas Docker dipasang, jalankan `docker run -d --name web -p 8080:80 nginx:1.30-alpine`. Buka http://localhost:8080 dalam pelayar. Kemas dengan `docker rm -f web`.
</Card>
