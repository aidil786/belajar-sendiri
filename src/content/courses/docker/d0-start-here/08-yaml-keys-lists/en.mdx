<Card id="deeper" type="deeper">
A line that starts with `#` is a comment: computers skip it. A short list can sit on one line: `sides: [sambal, egg]`. YAML files end in `.yaml` or `.yml`.

Real rep (optional): open any `compose.yaml` or workflow file on GitHub. Find one key and one list.
