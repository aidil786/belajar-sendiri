<Card id="deeper" type="deeper">
`docker run` ialah tiga arahan dalam satu: `docker pull`, `docker create` dan `docker start`. Setiap run buat bekas baru, dengan nama rawak seperti `vibrant_ritchie`. Pelajaran 3 tunjuk cara pilih nama sendiri.
