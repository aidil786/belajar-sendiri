<Card id="see-rm" type="see">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker run --rm alpine:3.22 echo hi', 'docker ps -a']} label="docker run --rm alpine:3.22 echo hi prints hi. Then docker ps -a shows an empty list: the box threw itself away." />

**--rm** throws the box away when its job ends. `docker ps -a` shows nothing left. Perfect for one-off jobs.
</Card>

<Card id="check-conflict" type="check">
<Interactive name="KitchenReplay" scenario="d1-web" commands={['docker run -d --name web nginx:1.30-alpine']} fails={['docker run -d --name web nginx:1.30-alpine']} label="A box called web already runs. docker run --name web answers with a Conflict error: the name is already in use." />

The real error says the name `"/web" is already in use`. Plain words: one name, one box. Remove the old box, or pick a new name.
</Card>

You can now run, name and tidy up boxes with three flags.

<Card id="deeper" type="deeper">
`-d` and `--rm` work together: a background box that cleans up when it stops. `docker rename web shop` changes a name. `-it` gives you a keyboard inside a box; that comes in lesson 6.
