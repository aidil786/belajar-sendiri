<Card id="see-follow" type="see">
<Interactive name="KitchenReplay" scenario="d1-logs" commands={['curl -s localhost:8080 | grep title', 'docker logs --tail 1 web']} label="curl lawat web. Kemudian docker logs --tail 1 web tunjuk satu baris baru: permintaan GET dengan status 200." />

Setiap lawatan ke web tambah satu baris. `--tail 1` tunjuk yang terakhir sahaja. Tambah **-f** (follow) untuk tengok baris baru secara langsung. Ctrl+C berhenti menengok.
</Card>

<Card id="try-follow" type="try">

</Card>

<Card id="win" type="win">
Kini anda boleh baca log container untuk cari punca masalah.
</Card>

<Card id="deeper" type="deeper">
Log ialah apa yang aplikasi paparkan ke skrin (stdout dan stderr). Image nginx hantar fail lognya ke situ juga. Pilihan berguna: `--tail 20`, `--since 10m`, dan `-t` untuk masa. Log hilang bila anda buang bekas.
