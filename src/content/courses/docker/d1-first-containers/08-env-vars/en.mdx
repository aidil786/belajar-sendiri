<Card id="see-e" type="see">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker run --rm -e NAME=Aina alpine:3.22 printenv NAME']} label="docker run with -e NAME=Aina starts a box. Inside, printenv NAME prints Aina." />

`-e` sticks a note on the lunchbox lid. The note is an **environment variable**: `NAME=Aina` sets NAME to Aina. The app inside reads it.
</Card>

<Card id="try-build" type="try">

<Card id="check" type="check">

<Card id="win" type="win">
You can now hand a container its settings with -e.
</Card>

<Card id="deeper" type="deeper">
`docker inspect -f '{{.Config.Env}}' db` lists every note on a box. Anyone who can run Docker can read them. So keep real passwords out of `-e` on shared machines. World D3 shows safer ways. `-e NAME` with no value copies NAME from your laptop.
