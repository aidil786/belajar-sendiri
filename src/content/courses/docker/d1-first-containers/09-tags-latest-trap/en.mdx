<Card id="see-tag" type="see">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker pull nginx', 'docker images']} label="docker pull nginx prints Using default tag: latest, then pulls nginx:latest. docker images now lists nginx:1.30-alpine and nginx:latest side by side." />

A **<Term id="tag">tag</Term>** is the label after the colon, like `1.30-alpine`. No tag? Docker says `Using default tag: latest`.
</Card>

<Card id="try-sort" type="try">
Which labels could suddenly give you a new version?

<Card id="predict" type="predict">
Is <Term id="latest-tag">latest</Term> always the newest, safest version?

<Interactive name="Choice" options={[{ label: 'No. It is just a name its makers can move.', correct: true, why: 'Docker does not check it. For nginx today, latest is 1.31, not the stable 1.30 line.' }, { label: 'Yes. Docker checks it every day.', why: 'Docker never checks latest. It is only the default name.' }, { label: 'Yes. latest always means stable.', why: 'For nginx, latest follows the newest line (1.31), not the stable 1.30.' }]} />
</Card>

<Card id="check-versions" type="check">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker run -d --name pinned -p 8080:80 nginx:1.30-alpine', 'docker run -d --name newest -p 8081:80 nginx', 'curl -sI localhost:8080 | grep Server', 'curl -sI localhost:8081 | grep Server']} label="Two boxes, both nginx. pinned answers Server: nginx/1.30.6. newest, from latest, answers Server: nginx/1.31.8." />

Two boxes, both "nginx". One answers 1.30.6, the other 1.31.8. You tested one, but production got the other. That is the **latest trap**.
</Card>

<Card id="check-typo" type="check">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker pull nginx:9.9']} fails={['docker pull nginx:9.9']} label="docker pull nginx:9.9 fails: failed to resolve reference, nginx:9.9 not found." />

A tag that doesn't exist? The real error ends with `nginx:9.9: not found`. Plain words: the freezer has no pack with that label.
</Card>

<Card id="win" type="win">
You can now pick tags on purpose and dodge the latest trap.
</Card>

<Card id="deeper" type="deeper">
Even `1.30-alpine` gets small fixes, so the pack can still change a little. To freeze one exact pack, use its digest: `nginx@sha256:…`. World D5 covers digests. One rule for now: never `latest` in production.
