<Card id="check-versions" type="check">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker run -d --name pinned -p 8080:80 nginx:1.30-alpine', 'docker run -d --name newest -p 8081:80 nginx', 'curl -sI localhost:8080 | grep Server', 'curl -sI localhost:8081 | grep Server']} label="Dua bekas, kedua-duanya nginx. pinned jawab Server: nginx/1.30.6. newest, daripada latest, jawab Server: nginx/1.31.8." />

Dua bekas, kedua-duanya "nginx". Satu jawab 1.30.6, satu lagi 1.31.8. Anda uji yang satu, tapi produksi dapat yang lain. Itulah **perangkap latest**.
</Card>

<Card id="check-typo" type="check">
<Interactive name="KitchenReplay" scenario="d1-kitchen" commands={['docker pull nginx:9.9']} fails={['docker pull nginx:9.9']} label="docker pull nginx:9.9 gagal: failed to resolve reference, nginx:9.9 not found." />

Tag yang tak wujud? Ralat sebenar berakhir dengan `nginx:9.9: not found`. Maksudnya: peti sejuk tiada pek dengan label itu.
</Card>

<Card id="win" type="win">
Kini anda boleh pilih tag dengan sengaja dan elak perangkap latest.
</Card>

<Card id="deeper" type="deeper">
`1.30-alpine` pun dapat pembaikan kecil, jadi pek itu masih boleh berubah sedikit. Untuk bekukan satu pek yang tepat, guna digest: `nginx@sha256:…`. Dunia D5 terangkan digest. Satu peraturan buat masa ini: jangan guna `latest` dalam produksi.
