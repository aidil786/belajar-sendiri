<Card id="try-rm" type="try">
**docker rm** throws away a stopped box, and the files inside it. Remove old1 and old2. Keep web.

<Interactive name="KitchenSim" scenario="d1-messy" goal={{ notExists: ['old1', 'old2'], running: ['web'] }} hints={['See every box: docker ps -a', 'Then: docker rm old1 old2']} success="Two old boxes gone. web is still serving." />

<Hint>`docker rm old1 old2`</Hint>
</Card>

<Card id="see-rmi" type="see">
<Interactive name="KitchenReplay" scenario="d1-messy" commands={['docker rmi redis:8-alpine', 'docker rmi hello-world']} fails={['docker rmi hello-world']} label="docker rmi redis:8-alpine removes the unused redis pack. docker rmi hello-world is refused: container old2 is using its referenced image." />

`docker rmi` removes a meal pack. redis goes. hello-world is refused: the real error says a container `is using its referenced image`. Plain words: remove the box first.
</Card>

<Card id="predict" type="predict">

</Card>

<Card id="see-prune" type="see">
<Interactive name="KitchenReplay" scenario="d1-messy" commands={['docker system prune', 'y', 'docker ps -a']} label="docker system prune prints a warning list and asks to continue. The answer y deletes the stopped boxes old1 and old2. docker ps -a now shows only web." />

**<Term id="prune">Prune</Term>** sweeps up everything unused. It always asks first. `y` deletes, and there is no undo. `N` keeps it all.
</Card>

<Card id="try-prune" type="try">
Sweep up every stopped box in one go. Read the warning before you answer.

<Interactive name="KitchenSim" scenario="d1-messy" goal={{ notExists: ['old1', 'old2'], running: ['web'], typed: 'prune' }} hints={['Type docker container prune', 'Read the warning. Then type y.']} success="Swept! web still runs. Prune only takes what nothing uses." />

<Hint>`docker container prune`, then `y`.</Hint>

<Card id="deeper" type="deeper">
Where the story breaks: you cook a real meal pack once. A Docker image is never used up: one pack fills endless boxes. Packs also share layers, so `rmi` may free less than you expect. Careful: `docker volume prune -a` deletes saved data (World D3).
