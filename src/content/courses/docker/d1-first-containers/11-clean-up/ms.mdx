<Card id="deeper" type="deeper">
Di mana cerita ini tak tepat: pek makanan sebenar habis bila dimasak. Image Docker tak pernah habis: satu pek isi bekas tanpa had. Pek juga kongsi layer, jadi `rmi` mungkin kosongkan kurang daripada jangkaan. Hati-hati: `docker volume prune -a` padam data yang disimpan (Dunia D3).
