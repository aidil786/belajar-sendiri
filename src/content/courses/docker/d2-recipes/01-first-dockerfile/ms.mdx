<Card id="see-recipe" type="see">
<Interactive name="KitchenReplay" scenario="d2-l01" commands={['cat Dockerfile']} label="cat tunjuk Dockerfile tiga baris: FROM node:24-alpine, COPY hello.js /hello.js, CMD node /hello.js." />

**<Term id="dockerfile">Dockerfile</Term>** ialah resepi untuk image. `FROM` pilih pek beku asas. `COPY` masukkan makanan anda. `CMD` beritahu apa nak buat bila bekas dibuka.
</Card>

<Card id="try-order" type="try">
Susun resepi ini. Baris paling atas jalan dulu.

<Interactive name="OrderList" items={['FROM node:24-alpine', 'COPY hello.js /hello.js', 'CMD ["node", "/hello.js"]']} label="Baris pertama di atas" success="Asas dulu, kemudian makanan, kemudian apa nak dijalankan." />

<Hint>Anda perlu pek asas dulu sebelum boleh tambah makanan.</Hint>
</Card>

<Card id="see-build" type="see">
<Interactive name="KitchenReplay" scenario="d2-l01" commands={['docker build -t hello:1.0 .', 'docker images hello']} label="docker build bakar dua langkah: FROM node:24-alpine, kemudian COPY hello.js. docker images kini senaraikan hello:1.0." />

`docker build -t hello:1.0 .` bakar resepi menjadi image. `-t` beri nama dan tag. Titik itu maksudnya "guna folder ini".
</Card>

<Card id="try-build" type="try">
Giliran anda. Bina image itu, kemudian jalankan sekali.

<Interactive name="KitchenSim" scenario="d2-l01" goal={{ imageExists: 'hello:1.0', lastTyped: '^docker run\\b.*hello:1\\.0' }} hints={['Bina dulu: docker build -t hello:1.0 .', 'Kemudian jalankan: docker run --rm hello:1.0']} success="Image buatan sendiri yang pertama sudah bercakap!" />

<Hint>Taip `docker build -t hello:1.0 .` dulu. Kemudian `docker run --rm hello:1.0`.</Hint>
</Card>
