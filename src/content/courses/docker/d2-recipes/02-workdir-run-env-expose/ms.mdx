<Card id="hook" type="hook">
Satu resepi tulis `COPY server.js .` sahaja. Asas node tak tetapkan folder kerja. Di mana `server.js` mendarat?

<Interactive name="Choice" options={[{ label: 'Di /, folder paling atas', correct: true, why: 'Tanpa folder kerja, titik itu maksudnya /. Fail anda duduk sebelah folder sistem. Bersepah!' }, { label: 'Di /app', why: 'Hanya jika ada baris WORKDIR /app dulu.' }, { label: 'Di laptop anda', why: 'COPY sentiasa letak fail di dalam image.' }]} />
</Card>

<Card id="see-workdir" type="see">
<Interactive name="KitchenReplay" scenario="d2-l02" commands={['cat Dockerfile', 'docker build -t api:1.0 .', 'docker run --rm api:1.0 pwd']} label="Resepi ada WORKDIR /app, COPY fail pakej, RUN npm ci, COPY server.js, ENV PORT=3000, EXPOSE 3000 dan CMD. Selepas build, pwd di dalam container cetak /app." />

**WORKDIR** `/app` ialah kaunter kerja anda. Semua baris selepasnya bekerja di situ. `RUN` memasak semasa membakar: di sini ia pasang pakej. `pwd` cetak kaunter itu: `/app`.
</Card>

<Card id="try-sort" type="try">
Sesetengah baris bakar satu layer (lapisan). Yang lain cuma tampal nota pada pek. Asingkan mereka.

<Interactive name="SortCards" buckets={[{ id: 'layer', label: 'Bakar satu layer' }, { id: 'note', label: 'Nota sahaja' }]} items={[{ label: 'WORKDIR /app', bucket: 'layer', why: 'Ia buat folder. Itu langkah build yang bernombor.' }, { label: 'RUN npm ci --omit=dev', bucket: 'layer', why: 'RUN memasak sesuatu. Hasilnya layer baharu.' }, { label: 'COPY server.js .', bucket: 'layer', why: 'Fail baharu masuk ke layer baharu.' }, { label: 'ENV PORT=3000', bucket: 'note', why: 'Tetapan untuk nanti. Tiada fail berubah.' }, { label: 'EXPOSE 3000', bucket: 'note', why: 'Nota sahaja: "saya dengar di 3000".' }, { label: 'CMD ["node", "server.js"]', bucket: 'note', why: 'Ia cuma beritahu apa nak dijalankan bila bekas dibuka.' }]} success="Betul! Hanya WORKDIR, RUN dan COPY jadi langkah bernombor." />
</Card>

<Card id="try-run" type="try">
Image sudah dibina. Jalankan dengan tingkap 3000 terbuka, kemudian ketuk dengan `curl`.

<Interactive name="KitchenSim" scenario="d2-l02" intro={['docker build -t api:1.0 .']} goal={{ running: ['api'], portMapped: { api: '3000:3000' }, lastTyped: '^curl\\b.*localhost:3000' }} hints={['Taip docker run -d --name api -p 3000:3000 api:1.0', 'Kemudian taip curl localhost:3000']} success="API menjawab melalui tingkap 3000." />

</Card>

<Card id="predict" type="predict">
Resepi tulis `EXPOSE 3000`. Anda jalankan image tanpa `-p`. Boleh laptop anda capai port 3000?

<Interactive name="Choice" options={[{ label: 'Tak. EXPOSE cuma nota', correct: true, why: 'EXPOSE beritahu orang port mana aplikasi guna. Hanya -p buka tingkap.' }, { label: 'Boleh. EXPOSE buka tingkap', why: 'Ramai sangka begitu! EXPOSE tak buka apa-apa.' }, { label: 'Boleh, tapi dengan curl -s sahaja', why: 'Pilihan curl tak boleh buka tingkap yang tertutup.' }]} />
</Card>

<Card id="check-expose" type="check">
<Interactive name="KitchenReplay" scenario="d2-l02" commands={['docker build -t api:1.0 .', 'docker run -d --name api api:1.0', 'curl localhost:3000', 'docker ps']} fails={['curl localhost:3000']} label="Container api berjalan tanpa -p. curl localhost:3000 jawab: Failed to connect to localhost port 3000: Couldn't connect to server. docker ps tunjuk 3000/tcp tanpa port laptop." />

Ralat sebenar: `Couldn't connect to server`. Maksudnya: tiada tingkap terbuka. `docker ps` tunjuk `3000/tcp` tanpa anak panah.
</Card>

<Card id="try-env" type="try">
`ENV PORT=3000` cuma nilai asal. Bina arahan yang jalankan API di port 4000.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker run -d', means: 'mula di belakang' }, { text: '--name api', means: 'namakan bekas itu api' }, { text: '-e PORT=4000', means: 'tukar tetapan PORT' }, { text: '-p 4000:4000', means: 'buka tingkap 4000' }, { text: 'api:1.0', means: 'dari image ini' }]} decoys={[{ text: '--build-arg PORT=4000', means: 'hanya berfungsi semasa build' }]} success="ENV beri nilai asal. -e tukar untuk bekas ini." />
</Card>

<Card id="win" type="win">
Kini anda boleh guna WORKDIR, RUN, ENV dan EXPOSE.
</Card>

<Card id="deeper" type="deeper">
Gabungkan arahan berkaitan dalam satu `RUN` dengan `&&`. Satu RUN, satu layer. `EXPOSE` juga bantu `docker run -P`, yang buka setiap port yang di-expose pada port laptop rawak.
