<Interactive name="Choice" options={[{ label: 'Hai', correct: true, why: 'Words after the image name replace CMD completely.' }, { label: 'Selamat datang!', why: 'That is only the default. <Card id="see-cmd" type="see">
<Interactive name="KitchenReplay" scenario="d2-l03" commands={['cat sayer/Dockerfile', 'docker run --rm say:1.0', 'docker run --rm say:1.0 echo Hai']} label="say:1.0 prints Selamat datang! by itself. With echo Hai after the image name, it prints only Hai." />

`CMD` is the default order, like "the usual, please". Say something else after the image name, and your order replaces it.
</Card>

<Card id="try-entry" type="try">
`greet:1.0` uses **<Term id="entrypoint">ENTRYPOINT</Term>**: a fixed first part. Run it. Then run it again with a place name at the end.

<Hint>Put your words after `greet:1.0`, like `Pasar Seni`.</Hint>
</Card>

<Card id="check-warning" type="check">
<Interactive name="KitchenReplay" scenario="d2-l03" commands={['cat shouter/Dockerfile', 'docker build -t shout:1.0 shouter']} label="The shout recipe writes CMD without brackets. The build works but shows a yellow warning: JSONArgsRecommended." />

Real warning: `JSONArgsRecommended`. Plain words: write CMD as a list in brackets. Without brackets, a shell runs your app. A stop signal may not reach it.
</Card>

<Card id="win" type="win">
You can now choose between CMD and ENTRYPOINT.
</Card>

<Card id="deeper" type="deeper">
`docker run --entrypoint whoami greet:1.0` swaps the fixed part for one run. The bracket form is called exec form. It runs your app as process 1, so `docker stop` reaches it quickly.
