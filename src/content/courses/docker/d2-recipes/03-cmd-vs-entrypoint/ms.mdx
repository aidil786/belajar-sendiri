</Card>

<Card id="see-cmd" type="see">
<Interactive name="KitchenReplay" scenario="d2-l03" commands={['cat sayer/Dockerfile', 'docker run --rm say:1.0', 'docker run --rm say:1.0 echo Hai']} label="say:1.0 cetak Selamat datang! dengan sendirinya. Dengan echo Hai selepas nama image, ia cetak Hai sahaja." />

<Card id="check-warning" type="check">
<Interactive name="KitchenReplay" scenario="d2-l03" commands={['cat shouter/Dockerfile', 'docker build -t shout:1.0 shouter']} label="Resepi shout tulis CMD tanpa kurungan. Build berjaya tapi tunjuk amaran kuning: JSONArgsRecommended." />

Amaran sebenar: `JSONArgsRecommended`. Maksudnya: tulis CMD sebagai senarai dalam kurungan. Tanpa kurungan, shell yang jalankan aplikasi. Isyarat berhenti mungkin tak sampai.

<Card id="win" type="win">
Kini anda boleh pilih antara CMD dan ENTRYPOINT.
</Card>

<Card id="deeper" type="deeper">
`docker run --entrypoint whoami greet:1.0` tukar bahagian tetap untuk satu kali jalan. Bentuk berkurungan dipanggil exec form. Aplikasi anda jadi proses 1, jadi `docker stop` sampai dengan cepat.
