<Card id="see-layers" type="see">
<Interactive name="KitchenReplay" scenario="d2-diary-dockerfile" commands={['docker build -t diary:1.0 .', 'echo "body { color: hotpink; }" > style.css', 'docker build -t diary:1.1 .']} label="Build kedua tukar style.css. WORKDIR dan COPY index.html tulis CACHED. COPY style.css dibakar semula." />

Setiap baris resepi bakar satu **<Term id="layer">layer (lapisan)</Term>**, macam kek lapis. Docker simpan layer lama. Tukar `style.css`: hanya layernya dan layer di atasnya dibakar semula. Yang lain tulis CACHED.
</Card>

<Card id="try-cake" type="try">
Resepi ini bakar `npm ci` semula selepas setiap perubahan kod. Alihkan baris supaya ia kekal CACHED bila `server.js` berubah.

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'COPY fail pakej, npm ci, dan setiap layer di atasnya', correct: true, why: 'Layer itu berubah, jadi setiap layer di atasnya dibakar semula.' }, { label: 'COPY . . sahaja', why: 'Fail pakej berubah di bahagian bawah kek. <Card id="win" type="win">

<Card id="deeper" type="deeper">
`docker history api:1.1` senaraikan layer, yang terbaru di atas, dengan saiznya. Baris seperti `ENV` dan `CMD` tunjuk `0B`: nota, bukan layer. Padam fail dalam layer kemudian cuma sembunyikannya. Image tak jadi kecil.
