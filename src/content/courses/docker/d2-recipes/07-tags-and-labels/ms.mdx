<Card id="see-tags" type="see">
<Interactive name="KitchenReplay" scenario="d2-l07" commands={['docker build -t diary:1.2.0 -t diary:sha-3f2a9c1 .', 'docker images diary']} label="Satu binaan dapat dua tag, diary:1.2.0 dan diary:sha-3f2a9c1. docker images tunjuk IMAGE ID yang sama untuk kedua-duanya." />

Satu pek, dua pelekat. `1.2.0` ialah tag <Term id="semantic-versioning" course="git">SemVer</Term> untuk manusia. `sha-3f2a9c1` namakan commit Git yang tepat. ID sama: tiada apa disalin.
</Card>

<Card id="predict-semver" type="predict">
SemVer ialah MAJOR.MINOR.PATCH. Anda baiki salah ejaan di laman diari. `1.2.0` jadi apa?

<Interactive name="Choice" options={[{ label: '1.2.1', correct: true, why: 'PATCH: pembaikan kecil yang tak ubah benda lain.' }, { label: '1.3.0', why: 'MINOR untuk ciri baharu, contohnya laman baharu.' }, { label: '2.0.0', why: 'MAJOR untuk perubahan yang pecahkan cara lama menggunakannya.' }]} />
</Card>

<Card id="try-build" type="try">
Bina arahan untuk versi 1.2.1. Tag juga dengan id pendek commit anda.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker build', means: 'bakar satu image' }, { text: '-t diary:1.2.1', means: 'versi untuk manusia' }, { text: '-t diary:sha-$(git rev-parse --short HEAD)', means: 'id commit untuk mesin' }, { text: '.', means: 'folder ini' }]} decoys={[{ text: '-t diary:final', means: 'final tak beritahu binaan mana' }]} success="Dua nama yang jelas, satu image." />

<Hint>`git rev-parse --short HEAD` cetak id pendek commit semasa anda.</Hint>
</Card>

<Card id="see-labels" type="see">
<Interactive name="KitchenReplay" scenario="d2-l07" commands={['cat Dockerfile', 'docker build --label org.opencontainers.image.version=1.2.0 -t diary:1.2.0 .', 'docker inspect --format "{{json .Config.Labels}}" diary:1.2.0']} label="Resepi ada baris LABEL dengan tajuk. Build tambah label versi. docker inspect cetak semua label, termasuk label maintainer nginx." />

**<Term id="image-label">Label</Term>** ialah fakta yang dilekat pada pek. Nama piawai bermula dengan `org.opencontainers.image.`, contohnya title, version dan source. `docker inspect` membacanya.
</Card>

<Card id="deeper" type="deeper">
`docker tag diary:1.2.0 diary:1.2` tambah pelekat ketiga yang boleh dialih ke 1.2.1 nanti. Dalam Dunia C2, pipeline buat tag ini untuk anda. Label dari `--label` dan `LABEL` masuk ke senarai yang sama.
