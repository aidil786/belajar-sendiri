<Card id="see-secret" type="see">
<Interactive name="SpotLines" lines={[{ text: 'FROM node:24-alpine' }, { text: 'WORKDIR /app' }, { text: 'COPY package.json package-lock.json .npmrc ./' }, { text: 'RUN --mount=type=secret,id=npm_token,env=NPM_TOKEN,required=true npm ci', target: true }]} prompt="Tap the line that borrows the key." success="Yes! The key is lent to npm ci only." />

A **<Term id="build-secret">build secret</Term>** is a key lent to one RUN step. When the step ends, the key goes back. No layer keeps it.
</Card>

<Card id="try-secret" type="try">
Build the safe recipe as `api:1.0`. Try it plain first and read the error. Then lend the key from `token.txt`.

<Interactive name="KitchenSim" scenario="d2-l12" goal={{ imageExists: 'api:1.0', typed: '--secret id=npm_token' }} hints={['The error says: secret npm_token: not found. Lend it with --secret.', 'Type docker build --secret id=npm_token,src=token.txt -t api:1.0 .']} success="Built, and the key went back in its box." />

<Hint>`--secret id=npm_token,src=token.txt` lends the file's text as the secret.</Hint>
</Card>

<Card id="try-cache" type="try">
Downloads are slow too. A **<Term id="cache-mount">cache mount</Term>** is a pantry shelf BuildKit keeps between builds. It is not in the image. Build the RUN line that uses it.

<Interactive name="CommandBuilder" pieces={[{ text: 'RUN', means: 'cook while baking' }, { text: '--mount=type=cache,target=/root/.npm', means: "keep npm's downloads on a shelf" }, { text: 'npm ci', means: 'install the packages' }]} decoys={[{ text: '--no-cache', means: 'a docker build flag: bake everything again' }]} success="Next time package.json changes, npm finds most downloads on the shelf." />
</Card>

<Card id="deeper" type="deeper">
Without `env=`, the secret is a file at `/run/secrets/<id>`. Leave out `required=true`, and a missing secret is simply not there. Secrets do not change the cache: a new token does not bake again. Use test tokens only while practising.
