**<Term id="build-secret">Rahsia binaan</Term>** ialah kunci yang dipinjamkan kepada satu langkah RUN. Bila langkah itu tamat, kunci itu dipulangkan. Tiada layer (lapisan) yang menyimpannya.
</Card>

<Card id="try-secret" type="try">
Bina resepi selamat ini sebagai `api:1.0`. Cuba cara biasa dulu dan baca ralatnya. Kemudian pinjamkan kunci dari `token.txt`.

<Interactive name="KitchenSim" scenario="d2-l12" goal={{ imageExists: 'api:1.0', typed: '--secret id=npm_token' }} hints={['Ralat itu kata: secret npm_token: not found. Pinjamkan dengan --secret.', 'Taip docker build --secret id=npm_token,src=token.txt -t api:1.0 .']} success="Siap dibina, dan kunci sudah kembali ke kotaknya." />

<Hint>`--secret id=npm_token,src=token.txt` pinjamkan isi fail itu sebagai rahsia.</Hint>
</Card>

<Card id="try-cache" type="try">
Muat turun pun lambat. **<Term id="cache-mount">Cache mount</Term>** ialah rak dapur yang BuildKit simpan antara build. Ia tiada dalam image. Bina baris RUN yang menggunakannya.

<Interactive name="CommandBuilder" pieces={[{ text: 'RUN', means: 'masak semasa membakar' }, { text: '--mount=type=cache,target=/root/.npm', means: 'simpan muat turun npm di rak' }, { text: 'npm ci', means: 'pasang pakej' }]} decoys={[{ text: '--no-cache', means: 'pilihan docker build: bakar semua semula' }]} success="Lain kali package.json berubah, npm jumpa kebanyakan muat turun di rak." />
</Card>

<Card id="check-history" type="check">
<Interactive name="KitchenReplay" scenario="d2-l12" commands={['docker build --secret id=npm_token,src=token.txt -t api:1.0 .', 'docker history --format "{{.CreatedBy}}" api:1.0']} label="Build guna secret mount. docker history senaraikan RUN /bin/sh -c npm ci tanpa token di mana-mana." />

Tiada token di mana-mana. Layer RUN cuma tulis `npm ci`. `token.txt` ada dalam `.dockerignore` juga, jadi ia tak pernah sampai ke dapur.
</Card>

<Card id="deeper" type="deeper">
Tanpa `env=`, rahsia itu jadi fail di `/run/secrets/<id>`. Tanpa `required=true`, rahsia yang tiada cuma tak muncul. Rahsia tak ubah cache: token baharu tak bakar semula. Guna token ujian sahaja semasa berlatih.
