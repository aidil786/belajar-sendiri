`buildx` bakes for two platforms in one go. Each step runs twice, once per CPU. Both packs share one name.

<Card id="deeper" type="deeper">
To run steps for another CPU, Docker can use an emulator called QEMU. It is slow, so big teams often build each platform on its own machine.

Where the story breaks: a cook gets the same cake from the same recipe. A Dockerfile may not. `RUN apk add curl` can fetch a newer curl next month. Pin versions to keep the taste.
