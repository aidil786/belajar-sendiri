Aina bakar pek itu di Mac yang guna cip Apple. Server pula guna cip Intel. Ia terus berhenti. Ralat sebenar: `exec format error`. Maksudnya: dimasak untuk jenis CPU lain.

<Card id="deeper" type="deeper">
Untuk jalankan langkah bagi CPU lain, Docker boleh guna emulator bernama QEMU. Ia perlahan, jadi pasukan besar selalu bina setiap platform di mesinnya sendiri.

Di mana cerita ini tak tepat: tukang masak dapat kek sama dari resepi sama. Dockerfile mungkin tidak. `RUN apk add curl` boleh ambil curl yang lebih baharu bulan depan. Tetapkan versi untuk kekalkan rasa.
