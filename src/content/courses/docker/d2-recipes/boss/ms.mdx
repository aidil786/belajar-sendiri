<Card id="try-shrink" type="try">
Peringkat 3: kecilkan betul-betul. Tinggalkan `notes.txt` di rumah, dan bina `diary:2.0` atas `nginx:1.30-alpine`.

<Interactive name="KitchenSim" scenario="d2-boss-pack" goal={{ fileContains: { 'diary/.dockerignore': 'notes.txt' }, imageExists: 'diary:2.0', imageMaxSize: { 'diary:2.0': '100MB' } }} hints={['Dulu: echo "notes.txt" > .dockerignore', 'Kemudian pilih asas dengan argumen build: docker build --build-arg BASE=nginx:1.30-alpine -t diary:2.0 .']} success="Bawah 100MB, dan nota kekal di rumah." />

<Hint>Resepi bermula dengan `ARG BASE`. `--build-arg BASE=...` tukar asasnya.</Hint>

<Card id="predict" type="predict">
Anda tambah `USER nginx` sahaja pada resepi. Apa jadi bila bekas itu mula?

<Interactive name="Choice" options={[{ label: 'nginx berhenti: ia tak boleh tulis folder cache', correct: true, why: 'Log sebenar: mkdir() "/var/cache/nginx/client_temp" failed (13: Permission denied). root yang memiliki folder itu.' }, { label: 'Ia jalan sama macam biasa', why: 'nginx perlu tulis di beberapa tempat. </Card>

<Card id="try-nonroot" type="try">

<Card id="win" type="win">
Kini anda boleh bungkus laman sebenar: kecil, selamat dan bukan root.
</Card>

<Card id="deeper" type="deeper">
Kenapa ada baris `chown`? nginx tulis cache ke `/var/cache/nginx` dan id prosesnya ke `/run/nginx.pid`. Sebagai root, boleh. Sebagai `nginx`, hanya jika ia pemiliknya. Sesetengah platform halang port rendah untuk pengguna biasa. Ramai pasukan guna 8080.
