`docker diff` senaraikan apa yang berubah dalam writable layer. `A` maksudnya ditambah, `C` diubah, `D` dipadam.

<Interactive name="Transcript" title="bash" label="docker diff pada container alpine baru tunjuk satu fail ditambah: A /orders.txt." lines={[{ cmd: 'docker run -d --name box alpine:3.22 sleep 600' }, { cmd: 'docker exec box sh -c "echo nasi lemak > /orders.txt"' }, { cmd: 'docker diff box' }, { out: 'A /orders.txt', color: 'green' }]} />
