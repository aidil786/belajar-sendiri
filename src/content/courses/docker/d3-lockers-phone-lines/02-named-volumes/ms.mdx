<Card id="see-volume" type="see">
**<Term id="volume">Volume</Term>** (loker data) ialah loker di luar bekas. Docker simpan loker itu sampai anda padam. Tekan kepingan untuk bina pangkalan data yang ada loker.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker run -d', means: 'Mulakan bekas di belakang' }, { text: '--name db', means: 'Namakan ia db' }, { text: '-e POSTGRES_PASSWORD=secret', means: 'Postgres perlukan kata laluan' }, { text: '-v pgdata:/var/lib/postgresql', means: 'Loker pgdata, dibuka di folder data' }, { text: 'postgres:18-alpine', means: 'Pek beku yang digunakan' }]} decoys={[{ text: '-v pgdata:/var/lib/postgresql/data', means: 'Folder Postgres versi lama. Postgres 18 menolaknya.' }]} success="Betul! -v nama:folder beri bekas itu satu loker." />
</Card>

<Card id="check" type="check">
Arahan mana yang padam pesanan buat selamanya?

<Interactive name="Choice" options={[{ label: '`docker rm -f db`', why: 'Bekas dibuang. Loker pgdata kekal.' }, { label: '`docker volume rm pgdata`', correct: true, why: 'Ya. <Card id="deeper" type="deeper">
Ralat sebenar: `volume is in use`. Maksudnya: buang bekas itu dulu. Tanpa `-v`, Postgres dapat loker tanpa nama. Bekas baru dapat loker baru, jadi `docker volume ls` kumpul sisa.

<Interactive name="KitchenReplay" scenario="d3-pg-orders" commands={['docker volume ls', 'docker volume rm pgdata']} fails={['docker volume rm pgdata']} label="docker volume ls senaraikan pgdata. docker volume rm pgdata ditolak: volume itu sedang digunakan oleh container db." />
