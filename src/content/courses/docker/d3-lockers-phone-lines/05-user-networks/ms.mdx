</Card>

<Card id="try-network" type="try">
Buat talian shopnet. Sambungkan web dan db kepadanya.

<Interactive name="KitchenSim" scenario="d3-bridge" goal={{ networkHas: { shopnet: ['web', 'db'] } }} hints={['Taip docker network create shopnet', 'Taip docker network connect shopnet web', 'Taip docker network connect shopnet db']} success="Kedua-dua bekas di satu talian. <Hint>`docker network connect shopnet web` sambungkan bekas yang sedang berjalan.</Hint>
</Card>

<Card id="predict" type="predict">
cache dimulakan dengan `docker run` biasa, tanpa `--network`. Boleh ia hubungi menu, yang ada di shopnet?

<Interactive name="Choice" options={[{ label: 'Tak boleh: cache di talian asal', correct: true, why: 'Setiap rangkaian ialah talian sendiri. cache tiada di shopnet.' }, { label: 'Boleh: semua bekas kongsi satu talian', why: 'Hanya bekas dalam rangkaian yang sama boleh berbual.' }, { label: 'Hanya selepas restart', why: 'Restart kekalkan talian yang sama. network connect tambah talian.' }]} />
</Card>

<Card id="see-connect" type="see">
<Interactive name="KitchenReplay" scenario="d3-shopnet" commands={['docker exec cache wget -qO- http://menu', 'docker network connect shopnet cache', 'docker exec cache sh -c "wget -qO- http://menu | grep title"']} fails={['docker exec cache wget -qO- http://menu']} label="cache tak jumpa menu. Selepas docker network connect shopnet cache, tajuk halaman menu sampai." />

`docker network connect` sambungkan bekas yang sedang berjalan ke satu talian. Tak perlu restart. Kini cache boleh hubungi menu.
</Card>

<Card id="check" type="check">
db ada di shopnet. Bekas mana boleh panggil db ikut nama?

<Interactive name="SortCards" buckets={[{ id: 'yes', label: 'Boleh panggil db' }, { id: 'no', label: 'Tak boleh panggil db' }]} items={[{ label: 'Dimulakan dengan --network shopnet', bucket: 'yes', why: 'Talian sama, buku telefon sama.' }, { label: 'Dimulakan dengan docker run biasa', bucket: 'no', why: 'Ia di bridge asal, yang tiada nama.' }, { label: 'Disambung kemudian dengan network connect', bucket: 'yes', why: 'Sambung kemudian pun boleh.' }, { label: 'Dimulakan dengan --network none', bucket: 'no', why: 'none maksudnya tiada talian langsung.' }]} success="Talian sama, buku telefon sama." />

<Card id="win" type="win">
Kini anda boleh beri container anda talian telefon sendiri.
</Card>

<Card id="deeper" type="deeper">
Bridge asal tiada nama, dan semua bekas masuk ke situ. Rangkaian sendiri ada nama, dan hanya bekas yang dijemput. `docker network inspect shopnet` senaraikan siapa yang bersambung. `docker network disconnect` putuskan satu bekas.
