<Card id="see-dns" type="see">

Dalam talian sendiri, Docker simpan buku telefon. Sebut nama bekas, dapat alamatnya. Inilah **<Term id="container-dns">container DNS</Term>**.
</Card>

<Card id="try-call" type="try">

</Card>

</Card>

<Card id="check-port" type="check">
<Interactive name="KitchenReplay" scenario="d3-shopnet" commands={['docker run --rm --network shopnet alpine:3.22 wget -qO- http://menu:8080']} fails={['docker run --rm --network shopnet alpine:3.22 wget -qO- http://menu:8080']} label="wget ke menu di port 8080 gagal: can't connect to remote host, Connection refused." />

`menu:8080` pun ditolak. nginx dengar di port 80 dalam bekas. 8080 cuma tingkap di laptop anda.
</Card>

Nama kekal.' }, { text: 'MENU_URL=http://menu:80', good: true, why: 'Nama, ditambah port dalam bekas.' }, { text: 'MENU_URL=http://menu:8080', good: false, why: '8080 ialah tingkap di laptop. <Card id="win" type="win">

<Card id="deeper" type="deeper">
Buku telefon Docker ada di 127.0.0.11 dalam setiap bekas di rangkaian sendiri. `--network-alias` tambah nama kedua. Compose letak semua servis dalam satu rangkaian dan namakan untuk anda (Dunia D4).
