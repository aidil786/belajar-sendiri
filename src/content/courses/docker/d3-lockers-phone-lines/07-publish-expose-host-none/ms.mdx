<Card id="check-host-none" type="check">
<Interactive name="KitchenReplay" scenario="d3-expose" commands={['docker run -d --name hostbox --network host -p 8082:80 alpine:3.22 sleep 300', 'docker run --rm --network none alpine:3.22 ping -c 1 8.8.8.8']} fails={['docker run --rm --network none alpine:3.22 ping -c 1 8.8.8.8']} label="Mod host cetak: WARNING: Published ports are discarded when using host network mode. Kata-kata sebenar Docker: mod host buang `-p`. Dengan none, `Network unreachable`: bekas itu tiada talian keluar.
</Card>

<Card id="win" type="win">

</Card>

<Card id="deeper" type="deeper">
`-p 8080:80` dengar di semua kad rangkaian, jadi jiran Wi-Fi mungkin boleh capai. `-p 127.0.0.1:8080:80` simpan tingkap untuk laptop anda sahaja. `-P` buka tingkap rawak untuk setiap port expose. Di Docker Desktop, mod host perlukan versi baru; semak docs.
