<Card id="deeper" type="deeper">
Baris yang ada `NAMA` sahaja salin nilai itu dari laptop anda, kalau ada. Compose baca fail `.env` dengan peraturannya sendiri: Dunia D4. Fail env anda ada kata laluan? Jauhkan dari Git: masukkan dalam `.gitignore`.

Latihan sebenar (pilihan):

<Interactive name="Mission" id="d3-l08-rep" steps={[{ id: 'card', text: 'Tulis satu kad tetapan.', command: 'printf "SHOP_NAME=Kedai Kancil\\nTZ=Asia/Kuala_Lumpur\\n" > shop.env' }, { id: 'use', text: 'Serahkan kepada bekas.', command: 'docker run --rm --env-file shop.env alpine:3.22 env' }, { id: 'ignore', text: 'Jauhkan fail env dari Git.', command: 'echo "*.env" >> .gitignore' }]} success="Satu kad, banyak tetapan, tiada apa dalam Git." />
