<Card id="check-path" type="check">
Room 2 starts Postgres 18. Where must the pgdata locker open?

<Interactive name="Choice" options={[{ label: '`/var/lib/postgresql`', correct: true, why: 'Postgres 18 keeps its data under this folder.' }, { label: '`/var/lib/postgresql/data`', why: 'That is the old folder. <Card id="try-room2" type="try">
Room 2: start db on shopnet, with the pgdata locker. Then make an orders table.

<Interactive name="KitchenSim" scenario="d3-boss-locker" goal={{ running: ['db'], networkHas: { shopnet: ['db'] }, containerEnv: { db: ['POSTGRES_PASSWORD'] }, tableInVolume: { pgdata: 'orders' } }} hints={['Type docker run -d --name db --network shopnet -e POSTGRES_PASSWORD=secret -v pgdata:/var/lib/postgresql postgres:18-alpine', 'Type docker exec db psql -U postgres -c "create table orders (id int, dish text)"']} success="Room 2 cleared! The orders table lives in the locker." />

<Hint>You need `--network shopnet`, `-e POSTGRES_PASSWORD=…` and `-v pgdata:/var/lib/postgresql`.</Hint>
