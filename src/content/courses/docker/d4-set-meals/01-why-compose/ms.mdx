<Card id="deeper" type="deeper">
`docker compose` ialah plugin untuk arahan `docker`. Ia cari `compose.yaml` dalam folder anda. Nama folder jadi nama projek. Sebab itu bekasnya bernama `kedai-kancil-web-1`.

Latihan sebenar (pilihan), di mesin anda sendiri:
