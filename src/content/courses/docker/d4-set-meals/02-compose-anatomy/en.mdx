<Card id="predict" type="predict">
The locker is named twice: on the dish, and at the bottom. What if you delete the bottom block?

```yaml
  db:
    image: postgres:18-alpine
    volumes:
      - db-data:/var/lib/postgresql

volumes:
  db-data:
```

<Card id="deeper" type="deeper">
Want two phone lines? List them under a top `networks:` block, like `front` and `back`. Then db can sit on `back` only. A top line `name: kedai` sets the project name. `compose.yaml` is the preferred file name; `docker-compose.yml` still works.

Real rep (optional): in your `hello-set` folder, run `docker compose config`. Compare it with your file.
</Card>
