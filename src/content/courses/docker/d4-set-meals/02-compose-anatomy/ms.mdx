<Card id="predict" type="predict">
Loker disebut dua kali: pada hidangan, dan di bawah sekali. Apa jadi kalau anda padam blok bawah?

```yaml
  db:
    image: postgres:18-alpine
    volumes:
      - db-data:/var/lib/postgresql

volumes:
  db-data:
```

<Card id="deeper" type="deeper">
Mahu dua talian telefon? Senaraikan di bawah blok `networks:` paling atas, contohnya `front` dan `back`. Kemudian db boleh duduk di `back` sahaja. Baris atas `name: kedai` tetapkan nama projek. `compose.yaml` ialah nama fail pilihan; `docker-compose.yml` masih boleh.

Latihan sebenar (pilihan): dalam folder `hello-set`, jalankan `docker compose config`. Bandingkan dengan fail anda.
</Card>
