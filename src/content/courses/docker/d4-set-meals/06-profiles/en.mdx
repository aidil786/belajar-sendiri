The cache is right there in `compose.yaml`. You ran `docker compose up -d`. So why is it not running?
</Card>

<Card id="see-profile" type="see">
```yaml
  cache:
    image: redis:8-alpine
    profiles: [cache]
```

A side dish comes only when you ask for it. That is a **<Term id="compose-profile">profile</Term>**. A dish with a profile stays off. You turn it on when you need it. Sort the dishes.

<Interactive name="SortCards" buckets={[{ id: 'plain', label: 'Starts with plain up -d' }, { id: 'side', label: 'Only with --profile cache' }]} items={[{ label: 'web', bucket: 'plain', why: 'No profiles line: always on.' }, { label: 'api', bucket: 'plain', why: 'No profiles line: always on.' }, { label: 'db', bucket: 'plain', why: 'No profiles line: always on.' }, { label: 'cache', bucket: 'side', why: 'profiles: [cache] keeps it off by default.' }]} success="Only cache waits to be asked for." />
</Card>

<Card id="try-profile" type="try">

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'The cache starts', correct: true, why: 'Naming a dish turns its profile on, just for that command.' }, { label: 'Nothing: the profile is off', why: 'Naming the dish is enough to order it.' }, { label: 'Every profile starts', why: 'Only the dish you named (and what it depends on) starts.' }]} />

<Card id="check-down" type="check">
<Interactive name="KitchenReplay" scenario="d4-profiles" commands={['docker compose --profile cache up -d', 'docker compose down', 'docker compose ps']} label="Plain down removes web, api and db. The cache keeps running, and so does its phone line." />

Careful at closing time. Plain `down` only clears dishes without a profile. Add `--profile cache` to clear the side dish too.
</Card>

<Card id="win" type="win">
You can now keep extra dishes off until you ask for them.
</Card>

<Card id="deeper" type="deeper">
`COMPOSE_PROFILES=cache docker compose up -d` does the same as the flag. Turn on two with `--profile cache --profile debug`. Good side dishes: debug tools, an admin page, a job that loads test data. Profile names use letters, digits, `_`, `.` and `-`.
