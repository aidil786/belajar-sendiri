<Interactive name="KitchenReplay" scenario="d4-profiles" commands={['docker compose up -d', 'docker compose ps']} label="web, api dan db hidup. Cache dalam fail yang sama tidak." />

Cache ada dalam `compose.yaml`. Anda dah jalankan `docker compose up -d`. Jadi kenapa ia tak berjalan?
</Card>

<Card id="see-profile" type="see">
```yaml
  cache:
    image: redis:8-alpine
    profiles: [cache]
```

Lauk tambahan datang hanya bila anda minta. Itulah **<Term id="compose-profile">profile</Term>**. Hidangan yang ada profile kekal tutup. Anda hidupkannya bila perlu. Susun hidangan ini.

<Interactive name="SortCards" buckets={[{ id: 'plain', label: 'Hidup dengan up -d biasa' }, { id: 'side', label: 'Hanya dengan --profile cache' }]} items={[{ label: 'web', bucket: 'plain', why: 'Tiada baris profiles: sentiasa hidup.' }, { label: 'api', bucket: 'plain', why: 'Tiada baris profiles: sentiasa hidup.' }, { label: 'db', bucket: 'plain', why: 'Tiada baris profiles: sentiasa hidup.' }, { label: 'cache', bucket: 'side', why: 'profiles: [cache] buat ia tutup secara lalai.' }]} success="Hanya cache yang tunggu diminta." />
</Card>

<Card id="try-profile" type="try">
Pesan lauk tambahan juga. Hidupkan profile cache.

</Card>

<Card id="predict" type="predict">

<Card id="check-down" type="check">
<Interactive name="KitchenReplay" scenario="d4-profiles" commands={['docker compose --profile cache up -d', 'docker compose down', 'docker compose ps']} label="down biasa buang web, api dan db. Cache masih berjalan, begitu juga talian telefonnya." />

Hati-hati masa tutup kedai. `down` biasa hanya kemas hidangan tanpa profile. Tambah `--profile cache` untuk kemas lauk tambahan juga.
</Card>

<Card id="win" type="win">
Kini anda boleh biarkan hidangan tambahan tutup sampai anda memintanya.
</Card>

<Card id="deeper" type="deeper">
`COMPOSE_PROFILES=cache docker compose up -d` buat perkara sama seperti pilihan itu. Hidupkan dua dengan `--profile cache --profile debug`. Lauk tambahan yang sesuai: alat debug, laman admin, kerja yang muatkan data ujian. Nama profile guna huruf, nombor, `_`, `.` dan `-`.
