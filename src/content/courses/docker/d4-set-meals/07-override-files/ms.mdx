<Card id="see-override" type="see">
```yaml
# compose.override.yaml
services:
  web:
    volumes:
      - ./web:/usr/share/nginx/html:ro
```

<Interactive name="KitchenReplay" scenario="d4-override" commands={['docker compose up -d', 'echo "<h1>Kedai Kancil: new menu</h1>" > web/index.html', 'curl -s localhost:8080']} label="Folder web di laptop dipasang ke dalam web, jadi menu baru terus nampak." />

Benda yang dikongsi kekal dalam `compose.yaml`. Tambahan laptop masuk ke `compose.override.yaml`. Compose baca **<Term id="compose-override">fail override</Term>** ini sendiri dan letak di atas.
</Card>

<Card id="predict" type="predict">
Dua fail tetapkan kunci yang sama. Fail pertama kata satu nilai, fail kemudian kata nilai lain. Mana yang menang?

<Interactive name="Choice" options={[{ label: 'Fail yang kemudian', correct: true, why: 'Fail bertindan ikut urutan. Fail kemudian mengubahnya.' }, { label: 'Compose berhenti dengan ralat', why: 'Tukar nilai memang tujuannya. Compose gabungkan fail-fail itu.' }]} />
</Card>

<Card id="try-prod" type="try">
Hidupkan versi server: `compose.yaml` dengan `compose.prod.yaml`. Namakan kedua-dua fail dengan `-f`, asas dulu.

<Interactive name="KitchenSim" scenario="d4-override" keys="compose" goal={{ composeUp: 'kedai-kancil', restartPolicy: { 'kedai-kancil-web-1': 'unless-stopped' }, typed: '-f compose\\.prod\\.yaml' }} hints={['Dua pilihan -f: mula-mula compose.yaml, kemudian compose.prod.yaml.', 'Taip docker compose -f compose.yaml -f compose.prod.yaml up -d']} success="Campuran prod sedang berjalan. Setiap hidangan kini hidup semula sendiri." />

<Hint>`docker compose -f compose.yaml -f compose.prod.yaml up -d`</Hint>
</Card>

<Card id="check-prod" type="check">
<Interactive name="KitchenReplay" scenario="d4-override" commands={['docker compose -f compose.yaml -f compose.prod.yaml up -d', 'echo "<h1>Kedai Kancil: new menu</h1>" > web/index.html', 'curl -s localhost:8080']} label="Dengan -f, override dev dilangkau. Suntingan laptop tak sampai ke server: laman lama yang keluar." />

Kenapa laman lama? Dengan `-f`, Compose baca fail yang anda namakan sahaja. Tiada pasangan folder dev, jadi laman datang dari image.
</Card>

<Card id="win" type="win">
Kini anda boleh jalankan satu aplikasi dua cara: dev dan prod.
</Card>

<Card id="deeper" type="deeper">
Cara fail bergabung: satu nilai (seperti `image`) diganti. Senarai seperti `ports` ditambah bersama. `environment` bergabung ikut nama. `volumes` bergabung ikut laluan di dalam bekas. Buat larian kering dulu: `docker compose -f compose.yaml -f compose.prod.yaml config`.
