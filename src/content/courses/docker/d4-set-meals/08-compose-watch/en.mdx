<Card id="see-watch" type="see">
```yaml
  web:
    build: ./web
    develop:
      watch:
        - action: sync
          path: ./web
          target: /usr/share/nginx/html
```

<Interactive name="Transcript" title="bash" label="docker compose watch starts the shop (its build lines are left out here), then says Watch enabled. You save web/index.html in your editor. Watch copies it in: Syncing service web after 1 changes were detected." lines={[{ cmd: 'docker compose watch' }, { out: 'Watch enabled' }, { out: 'Syncing service "web" after 1 changes were detected', color: 'green' }]} />

**<Term id="compose-watch">compose watch</Term>** watches your folder. When you save, it copies the file into the running box. No bake, no restart.
</Card>

<Card id="deeper" type="deeper">
`docker compose up --watch` starts and watches in one go, with logs mixed in. The box needs `stat`, `mkdir` and `rmdir`, and its user must be allowed to write the target. `ignore:` skips folders like `node_modules/`. A rebuild prints `Rebuilding service(s) ["api"] after changes were detected...`.
