<Card id="see-watch" type="see">

```yaml
  web:
    build: ./web
    develop:
      watch:
        - action: sync
          path: ./web
          target: /usr/share/nginx/html
```

<Card id="deeper" type="deeper">
`docker compose up --watch` hidupkan dan perhati sekali gus, dengan log bercampur. Bekas perlukan `stat`, `mkdir` dan `rmdir`, dan penggunanya mesti boleh tulis ke sasaran. `ignore:` langkau folder seperti `node_modules/`. Bina semula paparkan `Rebuilding service(s) ["api"] after changes were detected...`.
