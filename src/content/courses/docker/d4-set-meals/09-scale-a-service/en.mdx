<Card id="deeper" type="deeper">
`deploy: replicas: 3` in the file does the same as the flag. Asking for `api` on the phone line now finds all three boxes. Docker doesn't truly share the work between them. A proxy does that, or Kubernetes in Part 3. Compose runs on one machine only.

Real rep (optional): in a project with an api service and no ports, run `docker compose up -d --scale api=3`, then `docker compose ps`.
</Card>
