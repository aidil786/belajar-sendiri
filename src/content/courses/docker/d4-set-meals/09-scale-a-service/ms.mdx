**<Term id="compose-scale">Scale</Term>** (skala) satu service bermaksud jalankan lebih banyak salinannya. `--scale api=3` minta tiga. Compose beri nombor: `api-1`, `api-2`, `api-3`.
</Card>

<Card id="deeper" type="deeper">
`deploy: replicas: 3` dalam fail buat perkara sama seperti pilihan itu. Panggil `api` pada talian telefon kini jumpa ketiga-tiga bekas. Docker tak betul-betul bahagikan kerja antara mereka. Proxy yang buat begitu, atau Kubernetes dalam Bahagian 3. Compose jalan di satu mesin sahaja.

Latihan sebenar (pilihan): dalam projek yang ada service api tanpa ports, jalankan `docker compose up -d --scale api=3`, kemudian `docker compose ps`.
</Card>
