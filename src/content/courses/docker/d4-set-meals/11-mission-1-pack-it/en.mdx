<Card id="see-api-code" type="see">
The API code is below: `api/server.js`, then `api/package.json`. Its recipe will have no `npm ci` step. Why is that fine?

<Interactive name="Choice" options={[{ label: 'There are no packages to install', correct: true, why: 'server.js only uses node:http, which comes with Node.' }, { label: 'npm ci runs by itself', why: 'Nothing runs unless the recipe says so.' }, { label: 'Compose installs packages', why: 'Compose only builds what the Dockerfile says.' }]} />

```js
const http = require('node:http');
const port = process.env.PORT || 3000;
http.createServer((req, res) => {
  res.setHeader('Content-Type', 'application/json');
  res.end(JSON.stringify({ ok: true, shop: 'Kedai Kancil' }));
}).listen(port, () => console.log(`API listening on port ${port}`));
```

```json
{
  "name": "kedai-api",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "start": "node server.js",
    "test": "node --test"
  }
}
```
</Card>

<Card id="see-api-recipe" type="see">
```dockerfile
FROM node:24-alpine
WORKDIR /app
COPY package.json server.js ./
USER node
EXPOSE 3000
CMD ["node", "server.js"]
```

<Interactive name="KitchenReplay" scenario="d4-mission" commands={['docker build -t api-check ./api', 'docker run -d --name apicheck -p 3000:3000 api-check', 'curl -s localhost:3000']} label="The API recipe bakes, runs on hatch 3000 and answers with JSON." />

This is `api/Dockerfile`. `USER node` runs the API as a normal user, not root.
</Card>
