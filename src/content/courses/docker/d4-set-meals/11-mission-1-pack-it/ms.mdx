<Card id="see-api-code" type="see">
Kod API ada di bawah: `api/server.js`, kemudian `api/package.json`. Resepinya nanti tiada langkah `npm ci`. Kenapa tak apa?

<Interactive name="Choice" options={[{ label: 'Tiada pakej untuk dipasang', correct: true, why: 'server.js cuma guna node:http, yang memang datang dengan Node.' }, { label: 'npm ci jalan sendiri', why: 'Tiada apa yang jalan kecuali resepi menyuruhnya.' }, { label: 'Compose pasang pakej', why: 'Compose cuma bina apa yang Dockerfile sebut.' }]} />

```js
const http = require('node:http');
const port = process.env.PORT || 3000;
http.createServer((req, res) => {
  res.setHeader('Content-Type', 'application/json');
  res.end(JSON.stringify({ ok: true, shop: 'Kedai Kancil' }));
}).listen(port, () => console.log(`API listening on port ${port}`));
```

```json
{
  "name": "kedai-api",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "start": "node server.js",
    "test": "node --test"
  }
}
```
</Card>

<Card id="see-api-recipe" type="see">
```dockerfile
FROM node:24-alpine
WORKDIR /app
COPY package.json server.js ./
USER node
EXPOSE 3000
CMD ["node", "server.js"]
```

<Interactive name="KitchenReplay" scenario="d4-mission" commands={['docker build -t api-check ./api', 'docker run -d --name apicheck -p 3000:3000 api-check', 'curl -s localhost:3000']} label="Resepi API dibakar, jalan di tingkap 3000 dan jawab dengan JSON." />

Ini `api/Dockerfile`. `USER node` jalankan API sebagai pengguna biasa, bukan root.
</Card>
