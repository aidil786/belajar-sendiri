<Card id="see-freezer" type="see">
A **<Term id="registry">registry</Term>** is a shop freezer for image packs. You push a pack in. Anyone allowed can pull it out. Which of these are freezers?

<Interactive name="SortCards" buckets={[{ id: 'freezer', label: 'A registry (shop freezer)' }, { id: 'not', label: 'Not a registry' }]} items={[{ label: 'Docker Hub (docker.io)', bucket: 'freezer', why: 'The default freezer. <Card id="deeper" type="deeper">
Private packs need a login to pull, too. Clouds have freezers too: Amazon ECR, Google Artifact Registry, Azure Container Registry. The commands stay the same: `docker tag`, `docker push`, `docker pull`.

Real rep (optional), with a free Docker Hub account. A new repository can be public, so never push secrets.
