<Card id="see-stdin" type="see">
The token waits in `$DOCKER_TOKEN`. `--password-stdin` reads it from a pipe, so it never shows on screen. Build the safe login.

<Interactive name="CommandBuilder" pieces={[{ text: 'echo', means: 'print…' }, { text: '$DOCKER_TOKEN', means: 'the token in this variable' }, { text: '|', means: 'pipe it into the next command' }, { text: 'docker login', means: 'log in to Docker Hub' }, { text: '-u you', means: 'your user name' }, { text: '--password-stdin', means: 'read the secret from the pipe' }]} decoys={[{ text: '-p rahsia123', means: 'a password on the command line' }]} success="That's the safe login." />
</Card>

<Card id="deeper" type="deeper">
Docker saves your login in `~/.docker/config.json`. Without a credential helper, it is not encrypted, and Docker warns you. Docker Desktop uses your system's keychain. `docker logout` removes the login. To push to GHCR, use a GitHub personal access token (classic) with `write:packages`.
