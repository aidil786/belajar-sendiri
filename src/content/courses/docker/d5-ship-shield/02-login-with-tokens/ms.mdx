<Card id="deeper" type="deeper">
Docker simpan log masuk anda dalam `~/.docker/config.json`. Tanpa credential helper, ia tak disulitkan, dan Docker beri amaran. Docker Desktop guna keychain sistem anda. `docker logout` buang log masuk itu. Untuk push ke GHCR, guna personal access token (classic) GitHub dengan `write:packages`.

Latihan sebenar (pilihan), di komputer anda:
