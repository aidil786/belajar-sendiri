Your recipe says `FROM node:24-alpine`. Next month, the same line gives you a different base. How?

<Interactive name="Choice" options={[{ label: 'The publisher moved the tag to a newer image', correct: true, why: 'Tags can move. <Card id="see-digest" type="see">
<Interactive name="KitchenReplay" scenario="d5-digest-pull" commands={["docker pull node:24-alpine"]} label="docker pull node:24-alpine downloads its layers, then prints Digest: sha256 and 64 letters and numbers." />

Look at the `Digest:` line. A **<Term id="digest">digest</Term>** is the pack's fingerprint, made from every byte inside. Change one byte, and the digest changes.
</Card>

<Card id="try-run" type="try">
`$PIN` holds node's digest. Run `node --version` from exactly that pack: put `@$PIN` after the image name.

<Interactive name="KitchenSim" scenario="d5-digest" goal={{ lastTyped: '@(\\$PIN|sha256:)', lastExit: 0 }} hints={['Add @$PIN right after node:24-alpine.', 'Type docker run --rm node:24-alpine@$PIN node --version']} success="Pinned! Same fingerprint, same pack, every time." />

<Hint>`docker run --rm node:24-alpine@$PIN node --version`</Hint>
</Card>

<Card id="predict" type="predict">
Someone moves `node:24-alpine` to a new image. Your recipe says `node:24-alpine@sha256:8a32…`. What do you build on?

<Interactive name="Choice" options={[{ label: 'The same old base: the digest wins', correct: true, why: 'With both, Docker uses only the digest. </Card>

</Card>

<Card id="deeper" type="deeper">
Pinning has a cost: you also pin old bugs. Let a robot bump it. Dependabot opens a pull request when the base changes ([Git World 7](/en/git/#world-7)). A wrong digest gets `not found`. A multi-platform image has one digest for the whole list, and one per platform.
