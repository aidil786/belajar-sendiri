<Card id="try-run" type="try">
`$PIN` simpan digest node. Jalankan `node --version` daripada pek yang tepat itu: letak `@$PIN` selepas nama image.

<Interactive name="KitchenSim" scenario="d5-digest" goal={{ lastTyped: '@(\\$PIN|sha256:)', lastExit: 0 }} hints={['Tambah @$PIN terus selepas node:24-alpine.', 'Taip docker run --rm node:24-alpine@$PIN node --version']} success="Sudah dipin! Cap jari sama, pek sama, setiap kali." />

<Card id="deeper" type="deeper">
Pin ada kosnya: anda juga pin pepijat lama. Biar robot kemas kininya. Dependabot buka pull request bila base berubah ([Dunia Git 7](/ms/git/#world-7)). Digest yang salah dapat `not found`. Image pelbagai platform ada satu digest untuk senarai, dan satu untuk setiap platform.
