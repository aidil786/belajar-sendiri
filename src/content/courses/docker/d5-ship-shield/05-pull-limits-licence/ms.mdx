Ralat sebenar: `429 Too Many Requests`. Maksudnya: Docker Hub kira pull anda, dan anda sudah guna semuanya.
</Card>

<Card id="see-limits" type="see">
Docker Hub ada **<Term id="pull-limit">had tarikan</Term>**: sekian banyak pull setiap 6 jam. Pull tanpa log masuk kongsi satu kiraan bagi setiap alamat internet. Susun, paling sedikit dulu.

<Interactive name="OrderList" items={['Tanpa log masuk: 100 setiap alamat', 'Akaun percuma, sudah log masuk: 200', 'Pelan berbayar: tiada had']} label="Paling sedikit di atas" success="Log masuk gandakan had anda, percuma." />
</Card>

<Card id="try-login" type="try">
Token anda dalam `$DOCKER_TOKEN`. Log masuk, kemudian pull `redis:8-alpine` sekali lagi.

<Interactive name="KitchenSim" scenario="d5-pull-limit" goal={{ loggedIn: 'you', imageExists: 'redis:8-alpine' }} hints={['Log masuk dulu: echo $DOCKER_TOKEN | docker login -u you --password-stdin', 'Kemudian taip docker pull redis:8-alpine']} success="Sudah log masuk, dan peti sejuk dibuka semula." />

<Hint>Log masuk selamat dari pelajaran 2, kemudian `docker pull redis:8-alpine`.</Hint>
</Card>

<Card id="deeper" type="deeper">
Pakej percuma boleh berubah, jadi semak docs.docker.com sebelum merancang. Satu pull dikira bila anda ambil manifest image. Permintaan HEAD, yang cuma mengintai, tak dikira. Dalam CI, log masuk, atau simpan salinan dalam registry sendiri. Podman, dan Docker Engine di Linux, juga pilihan percuma.
