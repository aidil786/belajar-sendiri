<Card id="deeper" type="deeper">
Scout needs a Docker account and checks your local images. Trivy is open source and needs no account. Both read the packages in the image, so neither finds bugs in code you wrote. `docker scout cves --exit-code` returns 2 when it finds holes. Trivy's `--ignore-unfixed` hides holes with no fix yet.
