<Interactive name="Transcript" title="bash" label="docker buildx imagetools inspect reads the SBOM of ghcr.io/you/kedai-api:1.0. grep picks four packages: kedai-api 1.0.0, musl 1.2.6-r3, node 24.22.2 and npm 11.19.1." lines={[{ cmd: "docker buildx imagetools inspect ghcr.io/you/kedai-api:1.0 --format '{{ range .SBOM.SPDX.packages }}{{ .name }} {{ .versionInfo }}{{ \"\\n\" }}{{ end }}' | grep -E '^(node|npm|musl|kedai-api) '" }, { out: 'kedai-api 1.0.0\nmusl 1.2.6-r3\nnode 24.22.2\nnpm 11.19.1' }]} />

An **<Term id="sbom" course="cicd">SBOM</Term>** is the ingredients list: every package and its version. This image lists 168. Yes, `musl` is in it.
</Card>

<Card id="try-build" type="try">
**<Term id="provenance" course="cicd">Provenance</Term>** is the "made here" record: which recipe, which inputs, how. BuildKit can add both labels as it builds. Build that command.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker buildx build', means: 'build with BuildKit' }, { text: '--sbom=true', means: 'add the ingredients list' }, { text: '--provenance=mode=max', means: 'add the full "made here" record' }, { text: '-t ghcr.io/you/kedai-api:1.0', means: 'the full name' }, { text: '--push', means: 'send it to the freezer' }, { text: '.', means: 'this folder is the kitchen' }]} decoys={[{ text: '--sbom=false', means: 'no ingredients list' }]} success="Pack, list and record travel together." />
</Card>

<Card id="deeper" type="deeper">
BuildKit adds a small provenance record by default (`mode=min`). Attestations need the containerd image store, the default for new Docker 29 installs. Keyless signing uses your GitHub or Google login. It writes to a public log. [Part 2, World C2](/en/cicd/#world-2) signs in CI with `actions/attest`.
