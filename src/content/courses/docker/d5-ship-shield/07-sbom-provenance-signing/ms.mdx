<Card id="try-build" type="try">
**<Term id="provenance" course="cicd">Provenance</Term>** (rekod asal usul) ialah rekod "dibuat di sini": resepi mana, bahan apa, bagaimana. BuildKit boleh tambah kedua-dua label semasa membina. Bina arahan itu.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker buildx build', means: 'bina dengan BuildKit' }, { text: '--sbom=true', means: 'tambah senarai bahan' }, { text: '--provenance=mode=max', means: 'tambah rekod "dibuat di sini" yang penuh' }, { text: '-t ghcr.io/you/kedai-api:1.0', means: 'nama penuh' }, { text: '--push', means: 'hantar ke peti sejuk' }, { text: '.', means: 'folder ini ialah dapurnya' }]} decoys={[{ text: '--sbom=false', means: 'tiada senarai bahan' }]} success="Pek, senarai dan rekod bergerak bersama." />
</Card>

<Card id="deeper" type="deeper">
BuildKit tambah rekod provenance kecil secara lalai (`mode=min`). Attestation perlukan containerd image store, iaitu lalai untuk pemasangan baru Docker 29. Tandatangan tanpa kunci guna log masuk GitHub atau Google anda. Ia tulis ke log awam. [Bahagian 2, Dunia C2](/ms/cicd/#world-2) tandatangan dalam CI dengan `actions/attest`.

Latihan sebenar (pilihan), selepas log masuk ke GHCR (pelajaran 2):
