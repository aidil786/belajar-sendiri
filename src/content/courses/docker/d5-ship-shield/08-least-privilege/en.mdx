You can now lock a container down: non-root, read-only, no extra powers.
</Card>

<Card id="deeper" type="deeper">
By default Docker keeps 14 capabilities, like `CHOWN` and `NET_BIND_SERVICE`. Add back only what you need: `--cap-add CHOWN`. `--security-opt no-new-privileges` stops a program from gaining more power. Never use `--privileged`, and never mount the Docker socket: both hand over the whole host. Compose has `user`, `read_only` and `cap_drop`.
