Ralat sebenar, maksud mudah. `Read-only file system`: penutupnya dimeterai. `Operation not permitted`: pisau itu, satu <Term id="capability">capability</Term> (kuasa khas), sudah disimpan.

<Card id="win" type="win">
Kini anda boleh kunci container: bukan root, baca sahaja, tanpa kuasa lebih.
</Card>

<Card id="deeper" type="deeper">
Secara lalai Docker kekalkan 14 capability, contohnya `CHOWN` dan `NET_BIND_SERVICE`. Tambah semula yang perlu sahaja: `--cap-add CHOWN`. `--security-opt no-new-privileges` halang program dapat kuasa lebih. Jangan guna `--privileged`, dan jangan mount soket Docker: kedua-duanya serahkan seluruh host. Compose ada `user`, `read_only` dan `cap_drop`.
