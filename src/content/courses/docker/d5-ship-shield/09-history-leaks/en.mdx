<Card id="predict-rm" type="predict">
Line 3 of a recipe copies `.env` in. Line 4 runs `rm .env`. Is the secret in the image?

<Interactive name="Choice" options={[{ label: 'Yes: it stays in the layer from line 3', correct: true, why: 'Each line bakes a layer. A later rm only hides the file on top.' }, { label: 'No: rm deleted it', why: 'rm hides it in a new layer. The old layer still holds it.' }, { label: 'Only if the image is public', why: 'Anyone who gets the image can dig it out, public or not.' }]} />
</Card>

<Card id="see-fix" type="see">
A **<Term id="build-secret">build secret</Term>** is lent to one `RUN` step, then taken back. It never lands in a layer.

<Interactive name="SpotLines" lines={[{ text: 'FROM alpine:3.22' }, { text: 'RUN --mount=type=secret,id=shop_token,env=SHOP_TOKEN test -n "$SHOP_TOKEN"', target: true }, { text: 'COPY menu.txt /app/menu.txt' }, { text: 'CMD ["cat", "/app/menu.txt"]' }]} prompt="Tap the line that borrows the secret." success="Yes! --mount=type=secret lends it to that step only." />
</Card>

<Card id="check-history" type="check">
<Interactive name="Transcript" title="bash" label="Build with --secret id=shop_token,env=SHOP_TOKEN, then docker history: the RUN row shows test -n with no token value." lines={[{ cmd: 'docker build --secret id=shop_token,env=SHOP_TOKEN -t menu:1.1 .' }, { out: '…', color: 'dim' }, { cmd: "docker history --no-trunc --format '{{.CreatedBy}}' menu:1.1" }, { out: 'CMD ["cat" "/app/menu.txt"]\nCOPY menu.txt /app/menu.txt # buildkit\nRUN /bin/sh -c test -n "$SHOP_TOKEN" # buildkit\nCMD ["/bin/sh"]\nADD alpine-minirootfs-3.22.7-x86_64.tar.gz / # buildkit' }]} />

Real output. The `RUN` row names the variable, never its value. The token stayed in your locked spice box.
</Card>

<Card id="win" type="win">
You can now find leaked secrets and keep them out of your images.
</Card>

<Card id="deeper" type="deeper">
Leaked one? Cancel the token first: it is public now. Then fix the recipe, rebuild and delete the old tags. BuildKit warns you with `SecretsUsedInArgOrEnv`.

**Where the story breaks:** a real freezer holds one pack. A registry hands out perfect copies forever, and they never thaw. But packs still go off: new holes are found in old images.
