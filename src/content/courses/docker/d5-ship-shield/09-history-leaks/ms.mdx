<Card id="see-fix" type="see">
**<Term id="build-secret">Build secret</Term>** (rahsia binaan) dipinjamkan kepada satu langkah `RUN`, kemudian diambil balik. Ia tak pernah masuk ke dalam layer.

<Interactive name="SpotLines" lines={[{ text: 'FROM alpine:3.22' }, { text: 'RUN --mount=type=secret,id=shop_token,env=SHOP_TOKEN test -n "$SHOP_TOKEN"', target: true }, { text: 'COPY menu.txt /app/menu.txt' }, { text: 'CMD ["cat", "/app/menu.txt"]' }]} prompt="Tekan baris yang meminjam rahsia itu." success="Ya! --mount=type=secret pinjamkannya kepada langkah itu sahaja." />
</Card>

<Card id="deeper" type="deeper">
Ada yang bocor? Batalkan token dulu: ia sudah awam. Kemudian baiki resepi, bina semula dan padam tag lama. BuildKit beri amaran `SecretsUsedInArgOrEnv`.

**Di mana cerita ini tak tepat:** peti sejuk sebenar simpan satu pek. Registry beri salinan sempurna selamanya, dan ia tak pernah cair. Tapi pek tetap boleh basi: lubang baru dijumpai dalam image lama.
