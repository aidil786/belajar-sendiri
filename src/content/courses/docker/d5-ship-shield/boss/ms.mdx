<Card id="try-root" type="try">

<Interactive name="KitchenSim" scenario="d5-boss-root" goal={{ imageUser: { 'kedai-api:1.0': 'nonroot' } }} hints={['Tambah satu baris di hujung Dockerfile dengan echo dan >>.', 'Taip echo "USER node" >> Dockerfile, kemudian docker build -t kedai-api:1.0 .']} success="Bilik 1 selesai! Pek itu kini jalan sebagai node." />

<Hint>`echo "USER node" >> Dockerfile`, kemudian `docker build -t kedai-api:1.0 .`</Hint>
</Card>

<Card id="check-scan" type="check">
Bilik 2: peraturan anda ialah sifar CRITICAL. Asingkan setiap penemuan daripada imbasan semalam.

<Interactive name="SortCards" buckets={[{ id: 'stop', label: 'Hentikan keluaran' }, { id: 'plan', label: 'Hantar, dan rancang pembaikan' }]} items={[{ label: 'CRITICAL, pembaikan ada', bucket: 'stop', why: 'Naik taraf pakej atau base, kemudian imbas semula.' }, { label: 'CRITICAL, belum ada pembaikan', bucket: 'stop', why: 'Sifar bermaksud sifar. Tukar base, atau buang pakej itu.' }, { label: 'HIGH, pembaikan ada', bucket: 'plan', why: 'Bukan penghalang ikut peraturan anda. Baiki segera.' }, { label: 'LOW, belum ada pembaikan', bucket: 'plan', why: 'Catat. Imbas semula minggu depan.' }]} success="Bilik 2 selesai! Peraturan jelas, keputusan jelas." />
</Card>

<Card id="see-clean" type="see">
<Interactive name="Transcript" title="bash" label="Trivy semak kedai-api:1.0 untuk lubang CRITICAL dan keluar dengan 0: tiada yang dijumpai." lines={[{ cmd: 'trivy image --severity CRITICAL --exit-code 1 kedai-api:1.0' }, { out: '…', color: 'dim' }, { cmd: 'echo $?' }, { out: '0', color: 'green' }]} />

Pek API anda, diimbas betul-betul. Kod keluar 0: sifar lubang CRITICAL. Peraturan 3 dipenuhi.
</Card>

<Card id="try-push" type="try">
Bilik 3: hantar ke GHCR. Token GitHub anda ada dalam `$CR_PAT`. Log masuk dengannya, kemudian tag dan push.

<Interactive name="KitchenSim" scenario="d5-boss-push" goal={{ pushed: ['ghcr.io/you/kedai-api:1.0'], typed: 'password-stdin' }} hints={['Log masuk: echo $CR_PAT | docker login ghcr.io -u you --password-stdin', 'Kemudian docker tag kedai-api:1.0 ghcr.io/you/kedai-api:1.0, kemudian docker push ghcr.io/you/kedai-api:1.0']} success="Bilik 3 selesai! Pek anda dalam peti sejuk GitHub." />

<Hint>Log masuk dengan token dulu (`--password-stdin`), kemudian `docker tag` dan `docker push`.</Hint>
</Card>

<Card id="check-sbom" type="check">
Bilik 4: pek itu mesti bawa senarai bahannya. Bina satu arahan yang bina, labelkan dan push.

<Interactive name="CommandBuilder" pieces={[{ text: 'docker buildx build', means: 'bina dengan BuildKit' }, { text: '--sbom=true', means: 'tambah senarai bahan' }, { text: '-t ghcr.io/you/kedai-api:1.0', means: 'peti sejuk, pemilik, pek, label' }, { text: '--push', means: 'hantar ke GHCR' }, { text: '.', means: 'folder ini' }]} decoys={[{ text: '-t kedai-api:latest', means: 'label yang berpindah, dan tiada peti sejuk' }]} success="Semua bilik boss selesai! Sekarang buat betul-betul." />
</Card>

<Card id="mission" type="try">

<Interactive name="Mission" id="d5-boss-real" steps={[{ id: 'pat', text: 'Buat personal access token (classic) GitHub dengan write:packages.
