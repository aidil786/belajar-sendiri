<Card id="see-uts" type="see">
<Interactive name="KitchenReplay" scenario="d6-web" commands={['hostname', 'docker exec web hostname']} label="hostname on the laptop prints laptop. Inside web, hostname prints the container's short id." />

Two different names! Each switch is a <Term id="linux-namespace">namespace</Term>. A **namespace** is a pair of blinkers. It hides one thing, like the laptop's hostname.
</Card>

<Card id="deeper" type="deeper">
Linux has 8 kinds: cgroup, IPC, network, mount, PID, time, user and UTS. Docker turns on PID, mount, network, UTS and IPC (plus cgroup on cgroup v2). The user one stays off by default (lesson 6). A Kubernetes namespace is a different idea: a zone of the food court.

Real rep (optional, Linux): make your own namespaces.
