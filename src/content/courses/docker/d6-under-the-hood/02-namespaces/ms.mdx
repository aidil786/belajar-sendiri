<Card id="deeper" type="deeper">
Linux ada 8 jenis: cgroup, IPC, network, mount, PID, time, user dan UTS. Docker hidupkan PID, mount, network, UTS dan IPC (dan cgroup pada cgroup v2). Yang user kekal mati secara lalai (pelajaran 6). Namespace Kubernetes ialah idea lain: satu zon medan selera.

Latihan sebenar (pilihan, Linux): buat namespace sendiri.
