</Card>

<Card id="deeper" type="deeper">
Docker always puts a container in its own cgroup, but sets no cap unless asked. With cgroup v2, caps live in files: `memory.max`, `cpu.max`, `pids.max`. A CPU cap only slows a box down. It never kills it. Only use `tail /dev/zero` with a memory cap!
