<Card id="deeper" type="deeper">
Docker sentiasa letak container dalam cgroup sendiri, tapi tiada had kecuali diminta. Dengan cgroup v2, had disimpan dalam fail: `memory.max`, `cpu.max`, `pids.max`. Had CPU cuma lambatkan bekas. Ia tak pernah bunuhnya. Guna `tail /dev/zero` hanya dengan had memori!

<Interactive name="Mission" id="d6-l03-limits" steps={[{ id: 'run', text: 'Mulakan nginx dengan tiga had.', command: 'docker run -d --name web --memory 256m --cpus 0.5 --pids-limit 100 nginx:1.30-alpine' }, { id: 'stats', text: 'Lihat had memori dan PID-nya.', command: 'docker stats --no-stream web' }, { id: 'rm', text: 'Kemas semula.', command: 'docker rm -f web' }]} success="Tiga catuan, satu bekas." />
