<Card id="see-stack" type="see">
<Interactive name="KitchenReplay" scenario="d6-two-boxes" commands={['docker ps', 'docker system df']} label="Dua bekas berjalan, box1 dan box2, dari satu image alpine. docker system df tunjuk satu image 12.9MB dan dua container yang guna 8.192kB sahaja." />

Satu image, dua bekas, ruang tambahan yang kecil. Lapisan image ialah kek lapis baca sahaja. Setiap bekas dapat plastik lutsinar di atas. Susunan itu ialah **<Term id="overlay-filesystem">overlay filesystem</Term>** (sistem fail overlay).
</Card>

<Card id="try-note" type="try">

<Interactive name="KitchenSim" scenario="d6-two-boxes" intro={['docker exec box1 sh -c "echo hi > /root/note.txt"']} goal={{ lastTyped: '^docker exec box2 (cat|ls)' }} hints={['Taip docker exec box2 cat /root/note.txt']} success="Tiada fail itu! Nota itu ada pada plastik box1 sahaja." />

<Hint>`docker exec box2 cat /root/note.txt` baca fail itu di dalam box2.</Hint>
</Card>

<Card id="predict" type="predict">
box1 ubah `/etc/profile`, satu fail dari image. Ke mana perubahan itu pergi?

<Interactive name="Choice" options={[{ label: 'Satu salinan masuk ke plastik box1. Kalau tidak, semua bekas nampak perubahan itu.' }, { label: 'Tak ke mana. Tulisan itu gagal.', why: 'Bekas boleh menulis. Ia tulis pada plastiknya sendiri.' }]} />
</Card>

<Card id="check-diff" type="check">
<Interactive name="Transcript" title="bash" label="Output sebenar pada Docker 29: satu bekas tambah nota, padam /etc/motd dan ubah /etc/profile. docker diff senaraikan baris C, A dan D." lines={[{ cmd: "docker run --name box alpine:3.22 sh -c 'echo hi > /root/note.txt; rm /etc/motd; echo hi >> /etc/profile'" }, { cmd: 'docker diff box' }, { out: 'C /etc\nC /etc/profile\nD /etc/motd\nC /root\nA /root/note.txt' }]} />

`docker diff` baca plastik atas. A = ditambah, C = diubah, D = dipadam. Padam tinggalkan pelekat penyorok, dipanggil **whiteout**. Image masih ada fail itu.
</Card>

<Card id="deeper" type="deeper">
Dalam istilah OverlayFS: lapisan image ialah `lowerdir`, plastik ialah `upperdir`, dan bekas nampak `merged`. Pemasangan baharu Docker Engine 29 guna stor image containerd dengan snapshotter `overlayfs`. Pemasangan lama yang dinaik taraf mungkin tunjuk `overlay2`. Semak dengan `docker info`.
