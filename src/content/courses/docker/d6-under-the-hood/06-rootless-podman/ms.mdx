Root di dalam kini jadi uid 100000 di luar. Itulah **<Term id="user-namespace">user namespace</Term>** (namespace pengguna). Docker biarkannya mati kecuali anda minta.

<Card id="see-rootless" type="see">
<Interactive name="Transcript" title="bash" label="Dari dokumentasi Docker: alat persediaan rootless, dijalankan sebagai pengguna biasa, cipta konteks CLI bernama rootless dan tukar kepadanya." lines={[{ cmd: 'dockerd-rootless-setuptool.sh install' }, { out: '[INFO] Creating CLI context "rootless"\nSuccessfully created context "rootless"\n[INFO] Using CLI context "rootless"\nCurrent context is now "rootless"', color: 'green' }]} />

**<Term id="rootless-mode">Rootless mode</Term>** (mod tanpa root) pergi lebih jauh. Daemon Docker sendiri berjalan sebagai anda, dalam user namespace. Kalau terlepas, ia dapat hak anda sahaja.
</Card>

<Card id="deeper" type="deeper">
Rootless perlukan `newuidmap` dan `newgidmap` (pakej `uidmap`) serta 65,536 id ganti dalam `/etc/subuid` dan `/etc/subgid`. Had seperti `--memory` perlukan cgroup v2 dengan systemd. Port rendah: lihat halaman tips. Untuk Podman, `alias docker=podman` cukup untuk kebanyakan arahan.
