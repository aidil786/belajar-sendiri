<Card id="see-vm" type="see">
<Interactive name="Transcript" title="zsh" prompt="%" label="On a Mac with Docker Desktop: the docker command is a macOS program (darwin), and the engine it talks to runs Linux." lines={[{ cmd: "docker version --format '{{.Client.Os}} / {{.Server.Os}}'" }, { out: 'darwin / linux' }]} />

Containers borrow a Linux kernel, and macOS has a different one. So Docker Desktop starts a small **<Term id="linux-vm">Linux VM</Term>**. The engine lives there.
