<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w00-l04-log" commands={['git log -n 1']} label="git log shows the newest commit. The Author line says: You, you@example.com." />

Every commit is signed with a name and an email. This one just says "You". Git can't guess who you are.
</Card>

<Card id="see-config" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global user.name "Aiman Hakim"', 'git config --global user.name']} label="The first command saves the name Aiman Hakim. The second one prints it back." />

`git config` changes Git's settings, called **<Term id="config">config</Term>**. This one saves your name. `--global` means: for all your projects.
</Card>

<Card id="try-sim" type="try">
Now set your own name and email here.

<Interactive name="Sim" scenario="w00-l04" panels={[]} prefill="git config --global user.name " goal={{ configSet: ['user.name', 'user.email'], typed: 'user\\.email\\s+\\S' }} hints={['Type git config --global user.name "Your Name" and press Enter.', 'Now type git config --global user.email "you@example.com".']} success="Git knows you now. Your email shows on every commit. Use one you are happy to share.

<Hint>Put your name in quotes, like `"Aiman Hakim"`.</Hint>
</Card>

<Card id="see-branch" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global init.defaultBranch main', 'git init diary']} label="After setting init.defaultBranch to main, git init makes a new project called diary." />

Each project starts with one **<Term id="branch">branch</Term>**, a line of save points. This setting names it `main`. `git init diary` makes a new project to test it.
</Card>

<Card id="see-editor" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global core.editor "code --wait"', 'git config --global --list']} label="core.editor is set to code --wait. The list shows every setting." />

Sometimes Git opens an **editor** for you to type in. This picks VS Code. `--wait` makes Git wait until you close it. `--list` shows all your settings.
</Card>

<Card id="predict-levels" type="predict">
Settings have three levels: system, global and **local**. Local is for one project. Your global email is `home@example.com`. One project sets a local email: `work@example.com`. Which one does that project use?

<Interactive name="Choice" options={[{ label: '`work@example.com`', correct: true, why: 'Local beats global. The closest setting wins.' }, { label: '`home@example.com`', why: 'Global is the backup. Inside that project, local wins.' }, { label: 'Both emails', why: 'A commit has one email. Here, the local one wins.' }]} />
</Card>

<Card id="deeper" type="deeper">
`git config --list --show-origin` shows each setting and the file it lives in. `--system` changes settings for everyone on the computer. On a Mac, `code --wait` needs the `code` command. Add it from VS Code's Command Palette.
</Card>
