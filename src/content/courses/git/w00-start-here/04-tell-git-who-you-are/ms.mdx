<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w00-l04-log" commands={['git log -n 1']} label="git log tunjuk commit terbaru. Baris Author tertulis: You, you@example.com." />

Setiap commit (titik simpan) ditandatangani dengan nama dan e-mel. Yang ini cuma tulis "You". Git tak boleh teka siapa anda.
</Card>

<Card id="see-config" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global user.name "Aiman Hakim"', 'git config --global user.name']} label="Arahan pertama simpan nama Aiman Hakim. Arahan kedua paparkan semula nama itu." />

`git config` tukar tetapan Git, dipanggil **<Term id="config">config</Term>** (tetapan). Yang ini simpan nama anda. `--global` maksudnya: untuk semua projek anda.
</Card>

<Card id="see-branch" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global init.defaultBranch main', 'git init diary']} label="Selepas init.defaultBranch ditetapkan kepada main, git init buat projek baru bernama diary." />

Setiap projek bermula dengan satu **<Term id="branch">branch</Term>** (jalan cerita), iaitu barisan titik simpan. Tetapan ini namakannya `main`. `git init diary` buat projek baru untuk mengujinya.
</Card>

<Card id="see-editor" type="see">
<Interactive name="TermReplay" scenario="w00-l04" commands={['git config --global core.editor "code --wait"', 'git config --global --list']} label="core.editor ditetapkan kepada code --wait. Senarai itu tunjuk semua tetapan." />

Kadang-kadang Git buka **editor** (penyunting) untuk anda menaip. Tetapan ini pilih VS Code. `--wait` buat Git tunggu sampai anda tutupnya. `--list` tunjuk semua tetapan anda.
</Card>

<Card id="predict-levels" type="predict">
Tetapan ada tiga peringkat: system, global dan **local**. Local untuk satu projek sahaja. E-mel global anda `home@example.com`. Satu projek ada e-mel local: `work@example.com`. Projek itu guna yang mana?

<Interactive name="Choice" options={[{ label: '`work@example.com`', correct: true, why: 'Local menang lawan global. Tetapan paling dekat yang menang.' }, { label: '`home@example.com`', why: 'Global cuma sandaran. Dalam projek itu, local yang menang.' }, { label: 'Kedua-dua e-mel', why: 'Satu commit ada satu e-mel sahaja. Di sini, yang local menang.' }]} />
</Card>

<Card id="deeper" type="deeper">
`git config --list --show-origin` tunjuk setiap tetapan dan fail tempat ia disimpan. `--system` tukar tetapan untuk semua orang dalam komputer itu. Di Mac, `code --wait` perlukan arahan `code`. Tambahnya dari Command Palette dalam VS Code.
</Card>
