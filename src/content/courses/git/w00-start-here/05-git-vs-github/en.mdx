<Card id="hook" type="hook">
One friend says: put it on Git. Another says: it's on GitHub. Are they the same thing? Not quite!
</Card>

<Card id="see-git" type="see">
<Interactive name="TermReplay" scenario="w00-l05" commands={['git log --oneline']} label="git log --oneline lists two commits, right on this computer." />

**<Term id="git">Git</Term>** is a tool on your computer. It saves your versions. It works with no internet at all.
</Card>

<Card id="see-github" type="see">
**<Term id="github">GitHub</Term>** is a website. It keeps a copy of your Git projects online. Friends and teams can share and review work there.
</Card>
