Seorang kawan kata: letak dalam Git. Seorang lagi kata: ada dalam GitHub. Benda yang sama ke? Sebenarnya tak!
</Card>

<Card id="see-git" type="see">
<Interactive name="TermReplay" scenario="w00-l05" commands={['git log --oneline']} label="git log --oneline senaraikan dua commit, terus dalam komputer ini." />

**<Term id="git">Git</Term>** ialah alat dalam komputer anda. Ia simpan versi-versi kerja anda. Ia boleh jalan tanpa internet langsung.
</Card>

<Card id="see-github" type="see">
**<Term id="github">GitHub</Term>** ialah laman web. Ia simpan salinan projek Git anda secara dalam talian. Kawan dan pasukan boleh kongsi dan semak kerja di situ.
</Card>
