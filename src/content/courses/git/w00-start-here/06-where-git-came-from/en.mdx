<Card id="hook" type="hook">
Thousands of people build Linux together. In 2005, they lost their free version control tool. What now?
</Card>

<Card id="see-linus" type="see">
**Linus Torvalds** made Linux. So in April 2005, he started writing a new tool himself. He called it Git.
</Card>

<Card id="see-name" type="see">
Why the name **Git**? In British slang, a "git" is an annoying person. Linus joked that he names his projects after himself.
</Card>

<Card id="deeper" type="deeper">
Before 2005, the Linux team used a tool called BitKeeper. Its free licence ended, so Linus built Git instead. He wanted Git to be fast. He also wanted it to work without one central server.
</Card>
