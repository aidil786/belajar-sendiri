<Card id="hook" type="hook">
You forgot how a command works. It happens to everyone, even experts. Where do you look?
</Card>

<Card id="see-h" type="see">
<Interactive name="TermReplay" scenario="w00-l08" commands={['git commit -h']} label="git commit -h prints a short list of options, like -m for the message." />

Add `-h` to a command for a **short help**. `git commit -h` lists the options for commit, right here in the terminal.
</Card>

<Card id="see-manual" type="see">
<Interactive name="TermReplay" scenario="w00-l08" commands={['git help commit']} label="git help commit shows the help page for commit, with a link to the full manual." />

`git help commit` opens the full **manual** for commit. It explains every option. On a Mac or Linux, press `q` to close it.
</Card>

<Card id="predict-quick" type="predict">
You only forgot the option for a commit message. Which help is fastest?

<Interactive name="Choice" compact options={[{ label: '`git commit -h`', correct: true, why: 'Short and quick. The `-m` option is right there.' }, { label: '`git help commit`', why: 'That works too, but it is long. `-h` is quicker.' }]} />
</Card>

<Card id="predict-deep" type="predict">
You want to learn everything `git log` can do. Which help fits best?

<Interactive name="Choice" compact options={[{ label: '`git help log`', correct: true, why: 'The manual explains every option in detail.' }, { label: '`git log -h`', why: 'That is only a short list. The manual has the full story.' }]} />
</Card>

<Card id="try-help" type="try">
Ask Git for help with `add`. Pick either way.

<Interactive name="Sim" scenario="w00-l08" panels={[]} goal={{ typed: '^git\\s+(add\\s+(-h|--help)|help\\s+add)\\s*$' }} hints={['Type git add -h and press Enter.']} success="That's how pros remember things. They look it up!" />

<Hint>Try `git add -h`. Or `git help add`.</Hint>
</Card>

<Card id="deeper" type="deeper">
The full manual also lives online at git-scm.com/docs. `git help -a` lists every Git command. `git help git` explains Git itself. On Windows, `git help` opens the manual in your web browser.
</Card>
