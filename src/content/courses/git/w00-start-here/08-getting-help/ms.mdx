<Card id="hook" type="hook">
Anda lupa cara guna satu arahan. Semua orang pernah lupa, pakar pun sama. Di mana nak cari?
</Card>

<Card id="see-h" type="see">
<Interactive name="TermReplay" scenario="w00-l08" commands={['git commit -h']} label="git commit -h paparkan senarai pendek pilihan, contohnya -m untuk mesej." />

Tambah `-h` pada arahan untuk dapat **bantuan ringkas**. `git commit -h` senaraikan pilihan untuk commit (titik simpan), terus dalam terminal.
</Card>

<Card id="see-manual" type="see">
<Interactive name="TermReplay" scenario="w00-l08" commands={['git help commit']} label="git help commit tunjuk halaman bantuan untuk commit, dengan pautan ke manual penuh." />

`git help commit` buka **manual** penuh untuk commit. Ia terangkan setiap pilihan. Di Mac atau Linux, tekan `q` untuk tutup.
</Card>

<Card id="predict-quick" type="predict">
Anda cuma lupa pilihan untuk mesej commit. Bantuan mana yang paling cepat?

<Interactive name="Choice" compact options={[{ label: '`git commit -h`', correct: true, why: 'Pendek dan cepat. Pilihan `-m` ada di situ.' }, { label: '`git help commit`', why: 'Itu pun boleh, tapi panjang. `-h` lagi cepat.' }]} />
</Card>

<Card id="predict-deep" type="predict">

<Interactive name="Choice" compact options={[{ label: '`git help log`', correct: true, why: 'Manual terangkan setiap pilihan dengan terperinci.' }, { label: '`git log -h`', why: 'Itu cuma senarai pendek. Manual ada cerita penuh.' }]} />
</Card>

<Card id="try-help" type="try">
Minta bantuan Git untuk `add`. Pilih mana-mana cara.

Manual penuh juga ada dalam talian di git-scm.com/docs. `git help -a` senaraikan semua arahan Git. `git help git` terangkan Git sendiri. Di Windows, `git help` buka manual dalam pelayar web anda.
