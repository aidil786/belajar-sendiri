<Interactive name="AreasScene" zones={['working']} effect="wobble" label="index.html wobbles in the working folder with a changed tag." frames={[{ working: [{ name: 'index.html', tag: 'changed' }] }]} />

You pressed save in your editor. So Git saved it too, right? Not yet! Your work can sit in three places.
</Card>

<Card id="see-working" type="see">
<Interactive name="AreasScene" label="The blue working folder glows. It holds index.html and style.css. The box and the repository are empty." frames={[{ working: [{ name: 'index.html', glow: true }, { name: 'style.css', glow: true }], staging: [], repo: [] }]} />

Place 1 is the **working folder**. These are your normal files. You edit them here.
</Card>

<Card id="see-staging" type="see">
<Interactive name="AreasScene" command="git add index.html" label="The command git add index.html types itself. index.html slides from the working folder into the amber box." frames={[{ working: [{ name: 'index.html', tick: true }, 'style.css'] }, { working: ['style.css'], staging: [{ name: 'index.html', tick: true }] }]} />

Place 2 is the **staging area**, a box. `git add` puts ready changes in the box.
</Card>

<Card id="see-repo" type="see">
<Interactive name="AreasScene" command='git commit -m "Add home page"' effect="flash" label="Camera flash. The box empties, and a new commit called Add home page lands in the green repository." frames={[{ working: ['style.css'], staging: ['index.html'], repo: [{ name: 'Add README', kind: 'commit' }] }, { working: ['style.css'], staging: [], repo: [{ name: 'Add README', kind: 'commit' }, { name: 'Add home page', kind: 'commit' }] }]} />

Place 3 is the **repository**. `git commit` takes a photo of the box and keeps it here, safe.
</Card>

</Card>

<Card id="deeper" type="deeper">
You will meet other names for these places. The working folder is also called the working tree. The staging area is also called the index. The repository lives inside the hidden `.git` folder.
</Card>
