<Interactive name="AreasScene" zones={['working']} effect="wobble" label="index.html bergoyang dalam folder kerja dengan tanda berubah." frames={[{ working: [{ name: 'index.html', tag: 'changed' }] }]} />

Anda tekan simpan dalam editor. Jadi Git pun dah simpan, kan? Belum lagi! Kerja anda boleh berada di tiga tempat.
</Card>

<Card id="see-working" type="see">
<Interactive name="AreasScene" label="Folder kerja biru bercahaya. Ia ada index.html dan style.css. Kotak dan repository kosong." frames={[{ working: [{ name: 'index.html', glow: true }, { name: 'style.css', glow: true }], staging: [], repo: [] }]} />

Tempat 1 ialah **folder kerja** (working folder). Ini fail biasa anda. Anda ubah fail di sini.
</Card>

<Card id="see-staging" type="see">
<Interactive name="AreasScene" command="git add index.html" label="Arahan git add index.html menaip sendiri. index.html meluncur dari folder kerja ke dalam kotak kuning." frames={[{ working: [{ name: 'index.html', tick: true }, 'style.css'] }, { working: ['style.css'], staging: [{ name: 'index.html', tick: true }] }]} />

Tempat 2 ialah **kawasan staging**, iaitu sebuah kotak. `git add` masukkan perubahan yang siap ke dalam kotak.
</Card>

<Card id="see-repo" type="see">
<Interactive name="AreasScene" command='git commit -m "Add home page"' effect="flash" label="Kilat kamera. Kotak jadi kosong, dan commit baru bernama Add home page masuk ke repository hijau." frames={[{ working: ['style.css'], staging: ['index.html'], repo: [{ name: 'Add README', kind: 'commit' }] }, { working: ['style.css'], staging: [], repo: [{ name: 'Add README', kind: 'commit' }, { name: 'Add home page', kind: 'commit' }] }]} />

Tempat 3 ialah **repository** (stor sejarah projek). `git commit` ambil gambar isi kotak dan simpan di sini dengan selamat.
</Card>
