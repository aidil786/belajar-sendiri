<Card id="hook" type="hook">
<Interactive name="AreasScene" zones={['working', 'repo']} effect="wobble" label="index.html has a green tick in the working folder. The repository holds only one commit: Add README." frames={[{ working: [{ name: 'index.html', tick: true }], repo: [{ name: 'Add README', kind: 'commit' }] }]} />

Tonight your home page works. Tomorrow you might break it. Can you get tonight's version back? Only with a save point.
</Card>

<Card id="see-commit" type="see">
<Interactive name="AreasScene" command='git commit -m "Add home page"' effect="flash" label="Camera flash. index.html leaves the box and a new commit, Add home page, lands in the repository." frames={[{ staging: [{ name: 'index.html', tick: true }], repo: [{ name: 'Add README', kind: 'commit' }] }, { staging: [], repo: [{ name: 'Add README', kind: 'commit' }, { name: 'Add home page', kind: 'commit' }] }]} />

`git commit` takes a **snapshot**: a full photo of the box, right now. The words after `-m` are a short note about it.
</Card>

<Card id="try-commit" type="try">
Save `index.html` as a new commit.

<Interactive name="Sim" scenario="w01-l05" panels={['areas', 'graph']} goal={{ commits: 2, lastCommitHas: ['index.html'] }} hints={['First put it in the box: git add index.html', 'Then save the box: git commit -m "Add home page"']} success="Saved! See the new dot on your timeline?" />

<Hint>Two steps: `git add index.html`, then `git commit -m "Add home page"`.</Hint>
</Card>

<Card id="see-log" type="see">
<Interactive name="TermReplay" scenario="w01-l05-saved" commands={['git log']} label="git log shows two commits, newest first. Each has a long code, an author, a date and a message." />

`git log` lists your commits, newest first. The long code after "commit" is the **hash**. It is that commit's unique name.
</Card>

<Card id="see-parent" type="see">
<Interactive name="GraphScene" scenario="w01-l05" commands={['git add index.html', 'git commit -m "Add home page"']} label="A new commit dot appears on the timeline. A line links it back to the older Add README dot." />

Each new commit points back to the one before it. That older commit is its **parent**. Together they make your timeline.
</Card>
