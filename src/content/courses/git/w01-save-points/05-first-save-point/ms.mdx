<Card id="see-log" type="see">
<Interactive name="TermReplay" scenario="w01-l05-saved" commands={['git log']} label="git log tunjuk dua commit, yang terbaru dulu. Setiap satu ada kod panjang, pengarang, tarikh dan mesej." />

`git log` senaraikan commit anda, yang terbaru dulu. Kod panjang selepas "commit" ialah **hash** (id commit). Itu nama unik commit tersebut.
</Card>

<Card id="see-parent" type="see">
<Interactive name="GraphScene" scenario="w01-l05" commands={['git add index.html', 'git commit -m "Add home page"']} label="Titik commit baru muncul pada garis masa. Satu garis menyambungnya kembali ke titik Add README yang lebih lama." />

Setiap commit baru tunjuk balik ke commit sebelumnya. Commit lama itu ialah **parent** (induk). Bersama, ia jadi garis masa anda.
</Card>
