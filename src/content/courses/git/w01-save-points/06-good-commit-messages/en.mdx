A good **commit message** says what changed. Keep it short: aim for 50 characters or less.
</Card>

<Card id="see-action" type="see">
<Interactive name="AreasScene" zones={['repo']} label="Added header. becomes Add header. Fixing typos becomes Fix typos." frames={[{ repo: [{ name: 'Added header.', kind: 'commit' }, { name: 'Fixing typos', kind: 'commit' }] }, { repo: [{ name: 'Add header', kind: 'commit' }, { name: 'Fix typos', kind: 'commit' }] }]} />

Start with an **action word**, like an order: Add, Fix, Remove. It should finish the sentence "This commit will…". Skip the full stop.
</Card>

<Card id="try-swipe" type="try">
Judge each message. Swipe right if it is good, left if it needs work.

<Interactive name="SwipeJudge" cards={[{ text: 'Add contact form', good: true, why: 'Starts with an action word and says what changed.' }, { text: 'stuff', good: false, why: 'What stuff? </Card>

<Card id="see-conventional" type="see">
<Interactive name="AreasScene" zones={['repo']} label="Three commits get a label in front: feat: add contact form, fix: correct typo on about page, docs: add setup steps to README." frames={[{ repo: [{ name: 'Add contact form', kind: 'commit' }, { name: 'Correct typo on about page', kind: 'commit' }, { name: 'Add setup steps to README', kind: 'commit' }] }, { repo: [{ name: 'feat: add contact form', kind: 'commit' }, { name: 'fix: correct typo on about page', kind: 'commit' }, { name: 'docs: add setup steps to README', kind: 'commit' }] }]} />

Many teams add a label in front. `feat:` is a new feature. `fix:` repairs a bug. `docs:` is for writing. This style is called **Conventional Commits**.
</Card>

<Card id="deeper" type="deeper">
More labels you will see: `style:`, `refactor:`, `test:` and `chore:`. Need more detail? Add a second `-m` for a longer body. Teams pick one language for messages. English is common, but Malay is fine too.

<Interactive name="TermReplay" scenario="w01-l06" commands={['git add about.html', 'git commit -m "feat: add about page" -m "It lists my favourite food."', 'git log -n 1']} label="A commit with a title and a body. git log -n 1 shows both." />
</Card>
