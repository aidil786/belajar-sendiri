<Card id="see-conventional" type="see">
<Interactive name="AreasScene" zones={['repo']} label="Tiga commit dapat label di depan: feat: add contact form, fix: correct typo on about page, docs: add setup steps to README." frames={[{ repo: [{ name: 'Add contact form', kind: 'commit' }, { name: 'Correct typo on about page', kind: 'commit' }, { name: 'Add setup steps to README', kind: 'commit' }] }, { repo: [{ name: 'feat: add contact form', kind: 'commit' }, { name: 'fix: correct typo on about page', kind: 'commit' }, { name: 'docs: add setup steps to README', kind: 'commit' }] }]} />

Banyak pasukan letak label di depan. `feat:` untuk ciri baru. `fix:` baiki pepijat. `docs:` untuk penulisan. Gaya ini dipanggil **Conventional Commits** (gaya mesej berlabel).
</Card>

<Card id="deeper" type="deeper">
Label lain yang anda akan jumpa: `style:`, `refactor:`, `test:` dan `chore:`. Perlu lebih butiran? Tambah `-m` kedua untuk isi yang lebih panjang. Pasukan pilih satu bahasa untuk mesej. Bahasa Inggeris biasa digunakan, tapi Bahasa Melayu pun boleh.

</Card>
