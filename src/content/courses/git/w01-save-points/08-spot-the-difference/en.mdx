<Card id="see-staged" type="see">
<Interactive name="TermReplay" scenario="w01-l08" commands={['git add index.html', 'git diff', 'git diff --staged']} label="After git add, git diff prints nothing. git diff --staged prints the same changes again." />

Plain `git diff` is empty now. To see what is in the box, add `--staged`. It compares the box with your **last commit**.
</Card>

<Card id="see-commits" type="see">
<Interactive name="TermReplay" scenario="w01-l08" commands={['git log --oneline', 'git diff 5ba4c72 e1ef438']} label="git log --oneline shows three hashes. git diff between the two older commits shows TODO: write day 2 replaced by Day 2." />

You can also compare two **save points**. Give `git diff` two hashes, older first. It shows what changed between them.
</Card>

<Card id="try-staged" type="try">
Put `index.html` in the box. Then show the diff of the box.

<Interactive name="Sim" scenario="w01-l08" panels={['areas']} goal={{ staged: ['index.html'], typed: '^git diff (--staged|--cached)' }} hints={['First: git add index.html', 'Then: git diff --staged']} success="That is exactly what your next commit will save." />

<Hint>`git add index.html`, then `git diff --staged`.</Hint>

<Card id="win" type="win">
You can now spot every change before you save it.
</Card>

<Card id="deeper" type="deeper">
`--cached` means the same as `--staged`. `git diff --name-only` lists only the names of changed files. Add a file name to see only that file, like `git diff index.html`.

<Interactive name="TermReplay" scenario="w01-l08" commands={['git diff --name-only']} label="git diff --name-only prints just one name: index.html." />
</Card>
