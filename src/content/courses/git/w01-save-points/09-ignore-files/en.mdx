Your folder fills up with junk: logs, downloads, even `.env` with your passwords. One careless `git add .` grabs it all.
</Card>

<Card id="see-gitignore" type="see">
<Interactive name="TermReplay" scenario="w01-l09" commands={['git status -s', 'echo "*.log" > .gitignore', 'git status -s']} label="Before: git status -s lists debug.log and error.log. After writing *.log into .gitignore, only .gitignore is listed." />

A **.gitignore** file lists names Git should skip. One line, `*.log`, and both log files vanish from `git status`.
</Card>

<Card id="see-patterns" type="see">
<Interactive name="TermReplay" scenario="w01-l09" commands={['echo "node_modules/" > .gitignore', 'echo ".env" >> .gitignore', 'echo "*.log" >> .gitignore', 'cat .gitignore']} label="Three echo commands build a .gitignore. cat shows its three lines: node_modules/, .env and *.log." />

Each line is a **pattern**. A name ending in `/` means a folder. `*` means "anything". `>` writes a new file, `>>` adds a line.
</Card>

<Card id="deeper" type="deeper">
Commit your `.gitignore`, so your whole team uses it. A line starting with `!` brings a file back, like `!keep.log`. `git add .` skips ignored files without a word.
