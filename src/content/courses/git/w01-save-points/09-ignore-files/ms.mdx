Folder anda penuh sampah: log, muat turun, malah `.env` berisi kata laluan. Satu `git add .` yang cuai akan ambil semuanya.
</Card>

<Card id="see-gitignore" type="see">
<Interactive name="TermReplay" scenario="w01-l09" commands={['git status -s', 'echo "*.log" > .gitignore', 'git status -s']} label="Sebelum: git status -s senaraikan debug.log dan error.log. Selepas *.log ditulis dalam .gitignore, hanya .gitignore disenaraikan." />

Fail **.gitignore** (senarai benda untuk diabaikan) beritahu Git apa yang perlu dilangkau. Satu baris, `*.log`, dan kedua-dua fail log hilang dari `git status`.
</Card>

<Card id="see-patterns" type="see">
<Interactive name="TermReplay" scenario="w01-l09" commands={['echo "node_modules/" > .gitignore', 'echo ".env" >> .gitignore', 'echo "*.log" >> .gitignore', 'cat .gitignore']} label="Tiga arahan echo bina .gitignore. cat tunjuk tiga barisnya: node_modules/, .env dan *.log." />

Setiap baris ialah satu **corak** (pattern). Nama yang berakhir dengan `/` maksudnya folder. `*` maksudnya "apa-apa sahaja". `>` tulis fail baru, `>>` tambah satu baris.
</Card>

<Card id="try-write" type="try">
Sorokkan fail log daripada Git. Kemudian masukkan `.gitignore` ke dalam kotak.

<Interactive name="Sim" scenario="w01-l09" panels={['areas']} goal={{ fileContains: { '.gitignore': '*.log' }, staged: ['.gitignore'], notStaged: ['debug.log', 'error.log'], noUntracked: true }} hints={['Tulis peraturannya: echo "*.log" > .gitignore', 'Sekarang masukkan ke dalam kotak: git add .gitignore']} success="Log dah disorok, dan peraturan anda sedia untuk commit." />

<Hint>Taip `echo "*.log" > .gitignore`. Kemudian `git add .gitignore`.</Hint>
</Card>

<Card id="deeper" type="deeper">
Commit `.gitignore` anda, supaya seluruh pasukan guna peraturan yang sama. Baris yang bermula dengan `!` bawa balik satu fail, contohnya `!keep.log`. `git add .` langkau fail yang diabaikan tanpa sebarang amaran.
