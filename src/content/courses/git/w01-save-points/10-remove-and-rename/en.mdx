<Card id="predict" type="predict">
You run `git rm --cached debug.log`. Is `debug.log` still in your folder?

<Interactive name="Choice" options={[{ label: 'Yes. Git just stops tracking it.', correct: true, why: '--cached only takes it out of Git. The file stays.' }, { label: 'No, it is deleted', why: 'That is plain git rm. --cached keeps the file.' }, { label: 'It moves into the box', why: 'Only its deletion goes in the box. The file stays in your folder.' }]} />
</Card>

<Card id="see-cached" type="see">
<Interactive name="TermReplay" scenario="w01-l10" commands={['git rm --cached debug.log', 'git status -s', 'ls']} pulse label="git rm --cached debug.log. Status shows a green D for debug.log, but ls still lists debug.log in the folder." />

`git rm --cached` means: **stop tracking**, but keep the file. Perfect for things you saved by mistake. Your `.gitignore` keeps it hidden after.
</Card>

<Card id="see-mv" type="see">
<Interactive name="TermReplay" scenario="w01-l10" commands={['git mv aboutme.html about.html', 'git status -s']} pulse label="git mv aboutme.html about.html. Status shows R aboutme.html -> about.html in green." />

`git mv` renames a file and tells Git in one step. The `R` in status means **renamed**.
</Card>

<Card id="try-mv" type="try">
Rename `aboutme.html` to `about.html`. Then commit it.

<Interactive name="Sim" scenario="w01-l10" panels={['areas', 'graph']} goal={{ filesExist: ['about.html'], filesMissing: ['aboutme.html'], lastCommitHas: ['about.html'], lastCommitLacks: ['aboutme.html'] }} hints={['Type git mv aboutme.html about.html', 'Now save it: git commit -m "Rename about page"']} success="Renamed and saved. <Card id="win" type="win">
You can now delete, untrack and rename files without confusing Git.
</Card>

<Card id="deeper" type="deeper">
Deleted or renamed a file without Git? No problem. Run `git add -A`. Git puts the deletion in the box. It usually spots a rename too. For a whole folder, use `git rm -r` and the folder name.
</Card>
