`git rm` padam fail dan masukkan **pemadaman** itu ke dalam kotak. Commit (titik simpan) seterusnya akan simpan fail itu sebagai dah tiada.

<Card id="see-cached" type="see">
<Interactive name="TermReplay" scenario="w01-l10" commands={['git rm --cached debug.log', 'git status -s', 'ls']} pulse label="git rm --cached debug.log. Status tunjuk D hijau untuk debug.log, tapi ls masih senaraikan debug.log dalam folder." />

`git rm --cached` maksudnya: **berhenti jejak**, tapi simpan fail itu. Sesuai untuk benda yang tersimpan secara tak sengaja. `.gitignore` anda akan terus sorokkannya.
</Card>

<Card id="see-mv" type="see">
<Interactive name="TermReplay" scenario="w01-l10" commands={['git mv aboutme.html about.html', 'git status -s']} pulse label="git mv aboutme.html about.html. Status tunjuk R aboutme.html -> about.html berwarna hijau." />

`git mv` tukar nama fail dan beritahu Git dalam satu langkah. Huruf `R` dalam status maksudnya **renamed** (ditukar nama).
</Card>

</Card>

<Card id="deeper" type="deeper">
Terpadam atau tertukar nama fail tanpa Git? Tak apa. Jalankan `git add -A`. Git masukkan pemadaman ke dalam kotak. Biasanya ia kenal pasti pertukaran nama juga. Untuk satu folder penuh, guna `git rm -r` dengan nama folder itu.
</Card>
