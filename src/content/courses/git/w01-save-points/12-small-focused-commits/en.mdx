<Card id="see-small" type="see">
<Interactive name="AreasScene" zones={['repo']} label="One big commit called Fix typo and add day 4 splits into two small commits: Fix title typo, and Add day 4 entry." frames={[{ repo: [{ name: 'Add README', kind: 'commit' }, { name: 'Fix typo and add day 4', kind: 'commit' }] }, { repo: [{ name: 'Add README', kind: 'commit' }, { name: 'Fix title typo', kind: 'commit' }, { name: 'Add day 4 entry', kind: 'commit' }] }]} />

Good commits are small: **one change per commit**. Then every message tells the whole truth. And you can undo one change without losing the other.
</Card>

<Card id="see-hunk" type="see">
<Interactive name="TermReplay" scenario="w01-l12" commands={['git diff']} pulse label="git diff for index.html shows two separate pieces. The first fixes the title. The second adds Day 4." />

`git diff` shows two separate pieces of change. Each piece is a **hunk**. Git can save one hunk and leave the other.
</Card>

<Card id="try-pick" type="try">
This commit will be "Add day 4 entry". Pick only the pieces that belong.

<Interactive name="HunkPicker" file="index.html" hunks={[{ lines: ['-<title>My Dairy</title>', '+<title>My Diary</title>'], take: false, why: 'A typo fix is a different change. <Card id="try-addp" type="try">
Type `git add -p`. Answer `n` for the typo fix, and `y` for Day 4.

<Interactive name="Sim" scenario="w01-l12" panels={['areas']} goal={{ stagedContains: { 'index.html': 'Day 4' }, stagedNotContains: { 'index.html': '<title>My Diary' }, modified: ['index.html'], typed: '^git add (-p|--patch)' }} hints={['Type git add -p and press Enter.', 'The first piece is the typo fix: type n. <Hint>`-p` means patch: Git asks about each hunk. `y` is yes, `n` is no.</Hint>

<Card id="deeper" type="deeper">
More answers for `git add -p`:

- `q` quits.
- `a` takes this hunk and the rest of the file.
- `d` skips the rest of the file.
- `?` shows help.

Real Git has even more, like `s` to split a big hunk.
</Card>
