Commit yang bagus itu kecil: **satu perubahan bagi setiap commit**. Jadi setiap mesej tepat dengan isinya. Anda juga boleh undur satu perubahan tanpa hilang yang lain.
</Card>

<Card id="see-hunk" type="see">
<Interactive name="TermReplay" scenario="w01-l12" commands={['git diff']} pulse label="git diff untuk index.html tunjuk dua bahagian berasingan. Yang pertama baiki tajuk. Yang kedua tambah Day 4." />

`git diff` tunjuk dua cebisan perubahan yang berasingan. Setiap cebisan ialah satu **hunk** (cebisan perubahan). Git boleh simpan satu hunk dan tinggalkan yang lain.
</Card>

<Card id="try-addp" type="try">
Taip `git add -p`. Jawab `n` untuk baiki salah taip, dan `y` untuk Day 4.

<Interactive name="Sim" scenario="w01-l12" panels={['areas']} goal={{ stagedContains: { 'index.html': 'Day 4' }, stagedNotContains: { 'index.html': '<title>My Diary' }, modified: ['index.html'], typed: '^git add (-p|--patch)' }} hints={['Taip git add -p dan tekan Enter.', 'Cebisan pertama ialah baiki salah taip: taip n. <Card id="deeper" type="deeper">
Jawapan lain untuk `git add -p`:

- `q` berhenti.
- `a` ambil hunk ini dan yang selebihnya dalam fail itu.
- `d` langkau yang selebihnya dalam fail itu.
- `?` tunjuk bantuan.

Git sebenar ada lebih banyak, contohnya `s` untuk pecahkan hunk besar.
</Card>
