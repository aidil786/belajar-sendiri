<Card id="deeper" type="deeper">
`git restore` copies from the box. If you staged the file, you get the staged version. `git restore .` restores every tracked file. Old guides use `git checkout -- index.html`. It does the same job.

<Interactive name="TermReplay" scenario="w02-l01" commands={['git status -s', 'git checkout -- index.html', 'git status -s']} label="The old way: git checkout -- index.html also throws away the change to index.html." />
