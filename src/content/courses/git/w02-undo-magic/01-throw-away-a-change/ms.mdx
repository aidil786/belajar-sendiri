<Card id="deeper" type="deeper">
`git restore` salin dari kotak. Kalau fail itu dah di-stage, anda dapat versi dalam kotak. `git restore .` pulihkan semua fail yang dijejak. Panduan lama guna `git checkout -- index.html`. Hasilnya sama.

<Interactive name="TermReplay" scenario="w02-l01" commands={['git status -s', 'git checkout -- index.html', 'git status -s']} label="Cara lama: git checkout -- index.html juga buang perubahan pada index.html." />
</Card>
