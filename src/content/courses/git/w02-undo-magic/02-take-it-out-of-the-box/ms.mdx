<Card id="hook" type="hook">
<Interactive name="AreasScene" zones={['working', 'staging']} effect="wobble" label="Dua fail bergoyang dalam kotak: index.html dengan tanda hijau, dan style.css bertanda belum siap." frames={[{ working: [], staging: [{ name: 'index.html', tick: true }, { name: 'style.css', tag: 'notReady' }] }]} />

Anda taip `git add .` terlalu cepat. Fail yang separuh siap pun masuk ke dalam kotak. Macam mana nak keluarkan?
</Card>

<Card id="see-unstage" type="see">
<Interactive name="AreasScene" zones={['working', 'staging']} command="git restore --staged style.css" label="Arahan git restore --staged style.css menaip sendiri. style.css meluncur keluar dari kotak, balik ke folder kerja. index.html kekal dalam kotak." frames={[{ working: [], staging: [{ name: 'index.html', tick: true }, { name: 'style.css', tag: 'notReady', glow: true }] }, { working: [{ name: 'style.css', tag: 'notReady' }], staging: [{ name: 'index.html', tick: true }] }]} />

`git restore --staged style.css` keluarkan fail itu dari kotak. Ini dipanggil **unstage** (keluarkan dari kotak).
</Card>

<Card id="try-drag" type="try">
Seret fail yang separuh siap keluar dari kotak.

</Card>

<Card id="try-type" type="try">

<Interactive name="Sim" scenario="w02-l02" panels={['areas']} goal={{ staged: ['index.html'], notStaged: ['style.css'], modified: ['style.css'] }} hints={['Taip git restore --staged style.css dan tekan Enter.', 'Jangan buang --staged. <Hint>Taip `git restore --staged style.css`, kemudian tekan Enter.</Hint>
</Card>

<Card id="predict" type="predict">
Anda baru unstage style.css. Di mana perubahan anda sekarang?

<Interactive name="Choice" options={[{ label: 'Masih dalam folder kerja', correct: true, why: 'Unstage cuma kosongkan kotak. Isi kotak cuma berkurang.' }]} />
</Card>

<Card id="check-status" type="check">
<Interactive name="TermReplay" scenario="w02-l02" commands={['git status']} pulse label="git status senaraikan index.html dan style.css dalam kotak. Satu baris petunjuk sebut: guna git restore --staged untuk unstage." />

Lupa arahannya? `git status` akan beritahu. Cari petunjuk yang sebut "to unstage".
</Card>

<Card id="win" type="win">
Kini anda boleh keluarkan fail dari kotak dengan selamat.
</Card>
