<Card id="see-amend" type="see">
<Interactive name="AreasScene" zones={['repo']} effect="flash" command={'git commit --amend -m "Add day 2 page"'} label="The amend command types itself. `git commit --amend` swaps your last commit for a fixed one. **<Term id="amend">Amend</Term>** means "fix". Add `-m` with the new message.
</Card>

<Card id="try-build" type="try">
Build the command that fixes the typo.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Talk to Git' }, { text: 'commit', means: 'make a commit' }, { text: '--amend', means: 'replace the last one' }, { text: '-m', means: 'here is the message' }, { text: '"Add day 2 page"', means: 'the fixed message' }]} decoys={[{ text: '--no-edit', means: 'keep the old message' }, { text: '"Add day 2 pgae"', means: 'the old typo' }]} success="That's it! <Card id="see-forgot" type="see">
<Interactive name="AreasScene" zones={['staging', 'repo']} effect="flash" command="git commit --amend --no-edit" label="day2.css waits in the box. Flash: it joins the last commit, Add day 2 page. The box is empty again." frames={[{ staging: [{ name: 'day2.css', glow: true }], repo: [{ name: 'Add day 2 page', kind: 'commit' }] }, { staging: [], repo: [{ name: 'Add day 2 page', kind: 'commit', tick: true }] }]} />

Forgot a file? Put it in the box with `git add day2.css`. Then run `git commit --amend --no-edit`. `--no-edit` keeps the same message.
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'No, it gets a new hash', correct: true, why: 'Amend makes a brand new commit. </Card>

<Card id="see-pushed" type="see">
<Interactive name="GraphScene" scenario="w02-l03" commands={['git commit --amend -m "Add day 2 page"']} label="The newest commit is swapped for a new commit with a different hash. The older commits stay the same." />

⚠️ **Careful**: amend swaps in a new commit. Never amend a commit you already pushed to GitHub. Your team may have the old one.
</Card>

<Card id="win" type="win">
You can now fix your last commit: the message or the files.
</Card>

<Card id="deeper" type="deeper">
Without `-m`, `git commit --amend` opens your editor with the old message. Change it, save and close. Amend only fixes the *last* commit. Older commits need interactive rebase, in World 3.
