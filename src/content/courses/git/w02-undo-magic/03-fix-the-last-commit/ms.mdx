Terlupa satu fail? Masukkan ke dalam kotak dengan `git add day2.css`. Kemudian jalankan `git commit --amend --no-edit`. `--no-edit` kekalkan mesej yang sama.
</Card>

<Card id="deeper" type="deeper">
Tanpa `-m`, `git commit --amend` buka editor anda dengan mesej lama. Ubah, simpan dan tutup. Amend hanya baiki commit *terakhir*. Commit yang lebih lama perlukan rebase interaktif, dalam World 3.
