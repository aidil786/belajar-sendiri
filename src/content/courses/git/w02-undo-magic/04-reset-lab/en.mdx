**<Term id="reset">Reset</Term>** moves your branch back. `HEAD~1` means "one commit before HEAD". The mode decides where the undone changes go.
</Card>

<Card id="try-lab" type="try">
Try all three modes. Watch where the changes land.

<Interactive name="ResetLab" scenario="w02-l04" />

<Hint>Soft, then mixed, then hard. Each one runs `git reset --<mode> HEAD~1`.</Hint>
</Card>

<Card id="predict-soft" type="predict">
You want to redo the commit. The changes should stay in the box. Which mode?

<Interactive name="Choice" compact options={[{ label: '`--soft`', correct: true, why: 'Soft only moves the branch. The changes wait in the box.' }, { label: '`--mixed`', why: 'Mixed empties the box. The changes go back to your folder.' }, { label: '`--hard`', why: 'Hard wipes the changes. Not what you want here!' }]} />
</Card>

<Card id="see-hard" type="see">
<Interactive name="AreasScene" command="git reset --hard HEAD~1" label="Before: index.html has an unsaved change, and Add day 2 entry is the newest commit. After: the commit and the change are both gone." frames={[{ working: [{ name: 'index.html', tag: 'changed' }], staging: [], repo: [{ name: 'Add style', kind: 'commit' }, { name: 'Add day 2 entry', kind: 'commit', glow: true }] }, { working: ['index.html'], staging: [], repo: [{ name: 'Add style', kind: 'commit' }] }]} />

⚠️ **Danger**: `--hard` wipes the changes from your files too. Edits you never committed are lost for good. Use it only when you're sure.
</Card>

<Card id="check-default" type="check">

<Interactive name="Choice" options={[{ label: 'Back to the working folder', correct: true, why: '--mixed is the default. <Card id="deeper" type="deeper">
`HEAD~2` goes back two commits. You can also reset to a hash from `git log --oneline`. Reset rewrites history. Only reset commits that are still just on your computer. Shared commits need revert (next lesson).
