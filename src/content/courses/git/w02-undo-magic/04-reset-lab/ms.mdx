**<Term id="reset">Reset</Term>** (undur) gerakkan branch (jalan cerita) anda ke belakang. `HEAD~1` maksudnya "satu commit sebelum HEAD". Mod yang anda pilih tentukan ke mana perubahan pergi.
</Card>

<Card id="try-lab" type="try">
Cuba ketiga-tiga mod. Tengok ke mana perubahan pergi.

<Interactive name="ResetLab" scenario="w02-l04" />

<Hint>Soft, kemudian mixed, kemudian hard. Setiap satu jalankan `git reset --<mode> HEAD~1`.</Hint>
</Card>

<Card id="predict-soft" type="predict">
Anda mahu buat semula commit itu. Perubahan patut kekal dalam kotak. Mod mana?

<Interactive name="Choice" compact options={[{ label: '`--soft`', correct: true, why: 'Soft cuma gerakkan branch. Perubahan menunggu dalam kotak.' }, { label: '`--mixed`', why: 'Mixed kosongkan kotak. Perubahan balik ke folder anda.' }, { label: '`--hard`', why: 'Hard padam perubahan. Bukan itu yang anda mahu!' }]} />
</Card>

<Card id="see-hard" type="see">
<Interactive name="AreasScene" command="git reset --hard HEAD~1" label="Sebelum: index.html ada perubahan yang belum disimpan, dan Add day 2 entry ialah commit terbaru. Selepas: commit dan perubahan itu dua-dua hilang." frames={[{ working: [{ name: 'index.html', tag: 'changed' }], staging: [], repo: [{ name: 'Add style', kind: 'commit' }, { name: 'Add day 2 entry', kind: 'commit', glow: true }] }, { working: ['index.html'], staging: [], repo: [{ name: 'Add style', kind: 'commit' }] }]} />

⚠️ **Bahaya**: `--hard` padam perubahan dalam fail anda juga. Suntingan yang belum di-commit hilang terus. Guna hanya bila anda pasti.
</Card>

<Card id="deeper" type="deeper">
`HEAD~2` undur dua commit. Anda juga boleh reset ke satu hash dari `git log --oneline`. Reset tulis semula sejarah. Reset hanya commit yang masih dalam komputer anda. Commit yang dikongsi perlukan revert (pelajaran seterusnya).
