<Card id="check" type="check">

<Interactive name="Choice" options={[{ label: '`git revert`', correct: true, why: 'It adds an undo commit. <Card id="win" type="win">

</Card>

<Card id="deeper" type="deeper">
In real Git, `git revert` opens your editor with a ready message. Save and close it. `--no-edit` skips the editor. Did later commits change the same lines? Then you get a conflict. Conflicts come in World 3.

<Interactive name="TermReplay" scenario="w02-l05" commands={['git revert --no-edit HEAD~1', 'git log --oneline']} label="git revert --no-edit HEAD~1 makes the undo commit without opening an editor." />
</Card>
