<Card id="deeper" type="deeper">
Dalam Git sebenar, `git revert` buka editor dengan mesej yang dah siap. Simpan dan tutup. `--no-edit` langkau editor itu. Commit kemudian ubah baris yang sama? Anda akan dapat konflik. Konflik ada dalam World 3.
