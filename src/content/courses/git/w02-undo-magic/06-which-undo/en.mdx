<Card id="deeper" type="deeper">
A quick map. Pick by where the mistake lives.

```
Not committed      → git restore <file>
In the box         → git restore --staged <file>
Last commit, typo  → git commit --amend
Only on my laptop  → git reset HEAD~1
Already shared     → git revert <commit>
```
</Card>
