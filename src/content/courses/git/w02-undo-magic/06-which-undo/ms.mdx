<Card id="deeper" type="deeper">
Peta ringkas. Pilih ikut di mana kesilapan itu berada.

```
Belum di-commit         → git restore <fail>
Dalam kotak             → git restore --staged <fail>
Commit terakhir, typo   → git commit --amend
Hanya dalam laptop      → git reset HEAD~1
Dah dikongsi            → git revert <commit>
```
</Card>
