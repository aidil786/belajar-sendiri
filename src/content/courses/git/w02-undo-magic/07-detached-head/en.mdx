`git switch --detach HEAD~2` visits an old commit. HEAD now points at a commit, not a branch. This is a **<Term id="detached-head">detached HEAD</Term>**.

<Card id="see-checkout" type="see">

<Card id="predict" type="predict">
You are on a detached HEAD. You commit, then switch to main. What happens to that commit?

<Interactive name="Choice" options={[{ label: 'It is left behind', correct: true, why: 'No branch points at it. Git even warns you when you leave.' }, { label: 'It joins main', why: 'main only moves when you commit while on main.' }, { label: 'Git deletes it at once', why: 'It stays for a while. The reflog remembers it (lesson 9).' }]} />
</Card>

<Card id="try-back" type="try">
You are visiting day 1. Get back to your branch.

<Interactive name="Sim" scenario="w02-l07b" panels={['graph']} goal={{ headDetached: false, headAtMessage: '^Add day 2 entry$' }} hints={['Type git switch main and press Enter.', 'main is your branch. Switching to it puts HEAD back on it.']} success="HEAD is back on main. Welcome home!" />

<Hint>Type `git switch main`, then press Enter.</Hint>
</Card>

<Card id="win" type="win">
You can now visit old commits and come back safely.
</Card>

<Card id="deeper" type="deeper">
`git switch -` jumps back to where you were before. Made commits while detached? Give them a branch before you leave, or they get left behind. Making branches comes in World 3. `git checkout` still works in Git 3.0, next to `git switch`.

<Interactive name="TermReplay" scenario="w02-l07" commands={['git switch --detach HEAD~2', 'git switch -']} label="git switch --detach HEAD~2 visits day 1. git switch - goes straight back to main." />
</Card>
