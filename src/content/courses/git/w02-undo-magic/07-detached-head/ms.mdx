`git switch --detach HEAD~2` lawat commit (titik simpan) lama. Kini HEAD tunjuk ke commit, bukan branch (jalan cerita). Ini dipanggil **<Term id="detached-head">detached HEAD</Term>** (HEAD terlerai).

<Card id="deeper" type="deeper">
`git switch -` lompat balik ke tempat anda tadi. Ada buat commit semasa terlerai? Beri ia satu branch sebelum pergi, atau ia akan ditinggalkan. Cara buat branch ada dalam World 3. `git checkout` masih ada dalam Git 3.0, bersama `git switch`.
