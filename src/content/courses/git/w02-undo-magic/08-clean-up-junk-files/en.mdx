`git clean -f` deletes <Term id="untracked">untracked</Term> files: new files Git never saved. This is called **<Term id="clean">clean</Term>**. Tracked files stay safe.
</Card>

<Card id="see-danger" type="see">
<Interactive name="AreasScene" zones={['working']} effect="wobble" label="test.html and index-copy.html are marked deleted. There is no bin to get them back from." frames={[{ working: [{ name: 'test.html', tag: 'deleted' }, { name: 'index-copy.html', tag: 'deleted' }] }]} />

⚠️ **Danger**: clean deletes for good. There is no bin and no undo. So always preview first with `git clean -n`.
</Card>

<Card id="deeper" type="deeper">
Plain `git clean` refuses to delete anything without `-f`. That is Git being careful. `-x` deletes ignored files too, like `.env` or log files. Be very careful with it. This practice terminal blocks `-x`. `git clean -i` asks about each file.
</Card>
