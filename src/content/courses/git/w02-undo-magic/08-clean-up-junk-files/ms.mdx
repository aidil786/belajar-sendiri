<Card id="deeper" type="deeper">
`git clean` biasa tak akan padam apa-apa tanpa `-f`. Itu cara Git berhati-hati. `-x` padam fail yang diabaikan juga, contohnya `.env` atau fail log. Guna dengan sangat berhati-hati. Terminal latihan ini sekat `-x`. `git clean -i` tanya tentang setiap fail.
</Card>
