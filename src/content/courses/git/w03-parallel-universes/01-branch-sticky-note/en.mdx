<Card id="deeper" type="deeper">
`git branch -v` shows the commit under each note. `git branch -m dark-mode night-mode` renames one. Branch names can't have spaces. Teams use `-` and `/`, like `feature/dark-mode`. Why are branches so cheap? Inside Git, a branch is just a name holding one commit id.

<Interactive name="TermReplay" scenario="w03-l01" commands={['git branch dark-mode', 'git branch -v']} label="git branch -v shows dark-mode and main, each with a short hash and the message Add style." />
</Card>
