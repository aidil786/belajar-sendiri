<Card id="deeper" type="deeper">
`git branch -v` tunjuk commit di bawah setiap nota. `git branch -m dark-mode night-mode` tukar namanya. Nama branch tak boleh ada ruang kosong. Pasukan guna `-` dan `/`, contohnya `feature/dark-mode`. Kenapa branch murah sangat? Dalam Git, branch cuma nama yang memegang satu id commit.

<Interactive name="TermReplay" scenario="w03-l01" commands={['git branch dark-mode', 'git branch -v']} label="git branch -v tunjuk dark-mode dan main, masing-masing dengan hash pendek dan mesej Add style." />
</Card>
