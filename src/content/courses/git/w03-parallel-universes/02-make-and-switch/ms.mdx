<Card id="deeper" type="deeper">
`git switch -` lompat balik ke branch tadi. Ada fail berubah tapi belum commit? Git bawa perubahan itu bersama kalau selamat. Kalau perubahan boleh hilang, Git berhenti dan beritahu anda. Pelajaran 9 tunjuk caranya: stash.
