<Card id="deeper" type="deeper">
`git checkout` does two jobs: branches and files. That mix confused people. So Git 2.23 added `git switch` for branches and `git restore` for files. Careful: `git checkout -- file` throws away your changes, like `git restore`. Prefer the new commands. They say what they do.
</Card>
