<Card id="deeper" type="deeper">
`git checkout` buat dua kerja: branch dan fail. Campuran itu mengelirukan orang. Jadi Git 2.23 tambah `git switch` untuk branch dan `git restore` untuk fail. Hati-hati: `git checkout -- file` buang perubahan anda, macam `git restore`. Lebih baik guna arahan baru. Namanya sendiri terangkan kerjanya.
</Card>
