<Card id="deeper" type="deeper">
`git merge --ff-only about` merges only if it can fast-forward. If not, it stops safely. `git merge --no-ff about` always makes a merge commit. Some teams like that, so the branch shows up in history.

<Interactive name="TermReplay" scenario="w03-l04" commands={['git merge --no-ff about', 'git log --oneline --graph']} label="With --no-ff, Git makes a merge commit, Merge branch 'about', even though it could fast-forward." />
</Card>
