<Card id="deeper" type="deeper">
`git merge --ff-only about` hanya merge kalau boleh fast-forward. Kalau tak boleh, ia berhenti dengan selamat. `git merge --no-ff about` sentiasa buat merge commit. Ada pasukan suka cara itu, supaya branch nampak dalam sejarah.

<Interactive name="TermReplay" scenario="w03-l04" commands={['git merge --no-ff about', 'git log --oneline --graph']} label="Dengan --no-ff, Git buat merge commit, Merge branch 'about', walaupun boleh fast-forward." />
</Card>
