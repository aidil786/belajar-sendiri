<Card id="see-merge" type="see">
<Interactive name="GraphScene" scenario="w03-l05" commands={['git merge about']} label="A new commit appears on main. Two lines run into it: one from main, one from about." />

Git makes a new **<Term id="merge-commit">merge commit</Term>**. It has two parents, one from each branch. Both stories join here.
</Card>

<Card id="try-base" type="try">
Git compares three commits: your tip, their tip, and where they split. That spot is the <Term id="merge-base">merge base</Term>. Find it.

<Interactive name="GraphPick" scenario="w03-l05" answer="^Add style$" prompt="Tap the last commit both branches share." why="Add style is where the two branches split." />
</Card>

<Card id="see-three" type="see">
<Interactive name="TermReplay" scenario="w03-l05" commands={['git merge about']} label="git merge about prints: Merge made by the 'ort' strategy. Then about.html with 2 new lines." />

Base, yours and theirs: three commits go in. That's a **<Term id="three-way-merge">three-way merge</Term>**. The word ort is the name of Git's merge engine.
</Card>
