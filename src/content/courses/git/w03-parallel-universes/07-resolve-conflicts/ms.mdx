<Card id="deeper" type="deeper">
Merge Editor dalam VS Code tunjuk anda, mereka dan hasilnya sebelah-menyebelah. Dari terminal, `git mergetool` buka alat merge yang anda tetapkan. `git merge --abort` berfungsi sehingga anda commit merge itu. Selepas itu, undur macam commit biasa.
</Card>
