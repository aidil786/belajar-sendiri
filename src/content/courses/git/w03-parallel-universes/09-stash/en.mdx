<Card id="deeper" type="deeper">
`git stash -u` also takes new, untracked files. `git stash push -m "note"` adds a label. `git stash apply` puts work back but keeps a copy in the drawer. `git stash drop` throws one away for good. A pop can clash with newer changes. Then the markers say Updated upstream and Stashed changes.
</Card>
