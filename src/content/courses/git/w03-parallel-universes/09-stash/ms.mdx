`git stash` simpan perubahan yang belum siap dalam laci. Folder anda bersih semula, jadi anda boleh tukar branch. Laci itu ialah **<Term id="stash">stash</Term>** (simpanan sementara).
</Card>

<Card id="see-pop" type="see">
<Interactive name="TermReplay" scenario="w03-l09" commands={['git stash', 'git stash pop']} label="git stash simpan kerja. git stash pop kembalikannya: style.css ditunjuk sebagai modified, dan entri stash dibuang." />

Dah siap pembaikan? `git stash pop` keluarkan kerja paling baru dari laci. Ia kembali ke folder anda.
</Card>

<Card id="deeper" type="deeper">
`git stash -u` ambil juga fail baru yang belum dijejak. `git stash push -m "nota"` tambah label. `git stash apply` kembalikan kerja tapi simpan salinan dalam laci. `git stash drop` buang satu entri terus. Pop boleh bertembung dengan perubahan baru. Masa itu, penanda tertulis Updated upstream dan Stashed changes.
</Card>
