`git rebase -i main` opens a to-do list of your commits, oldest on top. Change the word in front, and Git replays the list. That's an **<Term id="interactive-rebase">interactive rebase</Term>**.
</Card>

<Card id="see-actions" type="see">
<Interactive name="AreasScene" zones={['repo']} zoneLabels={{ repo: 'gallery' }} label="Three commits: Add gallery page, fix typo, captions. fix typo melts into Add gallery page. captions gets a new name: Add photo captions." frames={[{ repo: [{ name: 'Add gallery page', kind: 'commit' }, { name: 'fix typo', kind: 'commit', glow: true }, { name: 'captions', kind: 'commit' }] }, { repo: [{ name: 'Add gallery page', kind: 'commit' }, { name: 'Add photo captions', kind: 'commit' }] }]} />

The words: pick keeps a commit. reword gives it a new message. <Term id="squash">squash</Term> joins it into the one above. <Term id="fixup">fixup</Term> joins it and drops its message. drop deletes it.
</Card>

<Card id="deeper" type="deeper">
In a real terminal, `git rebase -i main` opens this list in your editor. Edit the words, save and close. Got lost? `git rebase --abort`. Tip: `git commit --fixup <commit>` marks a fix early. Later, `git rebase -i --autosquash main` puts it in place for you.
</Card>
