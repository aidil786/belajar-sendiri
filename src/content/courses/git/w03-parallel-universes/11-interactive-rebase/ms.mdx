`git rebase -i main` buka senarai tugasan berisi commit anda, yang paling lama di atas. Tukar perkataan di depan, dan Git main semula senarai itu. Itulah **<Term id="interactive-rebase">rebase interaktif</Term>**.
</Card>

<Interactive name="AreasScene" zones={['repo']} zoneLabels={{ repo: 'gallery' }} label="Tiga commit: Add gallery page, fix typo, captions. fix typo cair masuk ke Add gallery page. captions dapat nama baru: Add photo captions." frames={[{ repo: [{ name: 'Add gallery page', kind: 'commit' }, { name: 'fix typo', kind: 'commit', glow: true }, { name: 'captions', kind: 'commit' }] }, { repo: [{ name: 'Add gallery page', kind: 'commit' }, { name: 'Add photo captions', kind: 'commit' }] }]} />

Perkataannya: pick simpan commit. reword beri mesej baru. <Term id="squash">squash</Term> gabungkan ke commit atas. <Term id="fixup">fixup</Term> gabungkan dan buang mesejnya. drop padam commit itu.
</Card>

<Card id="deeper" type="deeper">
Dalam terminal sebenar, `git rebase -i main` buka senarai ini dalam editor anda. Ubah perkataannya, simpan dan tutup. Sesat? `git rebase --abort`. Tip: `git commit --fixup <commit>` tanda pembaikan awal-awal. Kemudian, `git rebase -i --autosquash main` letakkannya di tempat yang betul untuk anda.
</Card>
