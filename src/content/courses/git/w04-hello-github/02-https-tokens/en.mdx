<Card id="see-https" type="see">
<Interactive name="Transcript" title="bash" label="git push asks for a username, then a password. The password stays hidden while you type." lines={[{ cmd: 'git push' }, { out: "Username for 'https://github.com': you" }, { out: "Password for 'https://you@github.com':", color: 'dim' }]} />

Your remote address starts with `https://`. So Git talks to GitHub over **HTTPS**. Git asks who you are. The password you type stays hidden.
</Card>

<Card id="see-token" type="see">
Which key would you lend a plumber?

<Interactive name="Choice" options={[{ label: 'A key that opens only the kitchen', correct: true, why: 'Small access, small risk. A fine-grained token works like that.' }, { label: 'The master key for every door', why: 'Lose it, and every door is open.' }]} />

A **<Term id="personal-access-token">personal access token</Term>** is a key for Git. Paste it at that Password prompt. A fine-grained token opens only the repos you pick.
</Card>

<Card id="try-order" type="try">
Make a fine-grained token for your diary. Put the steps in order.

<Interactive name="OrderList" items={['Open Settings, then Developer settings', 'Pick Fine-grained tokens. Generate a new one.', 'Give it a name and an end date', 'Choose only the diary repo', 'Allow Contents: Read and write', 'Generate it and copy it once']} label="First step at the top" success="That's it! GitHub shows the token only once, so save it right away." />

<Hint>You need a token page before you can fill it in.</Hint>
</Card>

<Card id="see-gcm" type="see">
<Interactive name="TimelineTap" events={[{ when: '1', title: 'You push', text: 'Git needs to know who you are.' }, { when: '2', title: 'A browser opens', text: 'You sign in to GitHub there, with 2FA.' }, { when: '3', title: 'It remembers', text: 'The login is stored safely. Copying tokens is a chore. **<Term id="credential-manager">Git Credential Manager</Term>** signs you in with your browser instead. It comes with Git for Windows.
</Card>

<Card id="deeper" type="deeper">
Classic tokens still exist, but they can reach every repo you own. GitHub suggests fine-grained ones. On macOS and Linux, install Git Credential Manager yourself. `git config --global credential.helper` shows which helper Git uses. The GitHub CLI can sign Git in too: next lesson!
</Card>
