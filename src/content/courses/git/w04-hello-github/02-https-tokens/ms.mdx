Anda push ke GitHub. Git minta kata laluan. Anda taip kata laluan GitHub anda. Apa jadi?

<Interactive name="Choice" options={[{ label: 'Gagal. GitHub mahu token atau pembantu log masuk.', correct: true, why: 'Sejak 2021, GitHub tak terima kata laluan akaun untuk Git. </Card>

<Card id="see-https" type="see">
<Interactive name="Transcript" title="bash" label="git push minta username, kemudian kata laluan. Kata laluan tersembunyi semasa ditaip." lines={[{ cmd: 'git push' }, { out: "Username for 'https://github.com': you" }, { out: "Password for 'https://you@github.com':", color: 'dim' }]} />

Alamat remote anda bermula dengan `https://`. Jadi Git bercakap dengan GitHub melalui **HTTPS**. Git tanya siapa anda. Kata laluan yang ditaip tak kelihatan.
</Card>

<Card id="see-token" type="see">
Kunci mana yang anda pinjamkan kepada tukang paip?

<Interactive name="Choice" options={[{ label: 'Kunci yang buka dapur sahaja', correct: true, why: 'Akses kecil, risiko kecil. Token fine-grained macam itu.' }, { label: 'Kunci induk untuk semua pintu', why: 'Kalau hilang, semua pintu terbuka.' }]} />

**<Term id="personal-access-token">Token akses peribadi</Term>** ialah kunci untuk Git. Tampal di ruang Password tadi. Token fine-grained hanya buka repo yang anda pilih.
</Card>

</Card>

<Card id="deeper" type="deeper">
Token klasik masih ada, tapi ia boleh capai semua repo anda. GitHub cadangkan token fine-grained. Di macOS dan Linux, pasang Git Credential Manager sendiri. `git config --global credential.helper` tunjuk pembantu yang Git guna. GitHub CLI pun boleh log masuk Git: pelajaran seterusnya!
</Card>
