You push many times a day. Can your laptop prove it's you, with nothing to type?

<Interactive name="Choice" options={[{ label: 'Yes, with a key pair saved on it', correct: true, why: 'That is SSH. </Card>

<Card id="see-pair" type="see">
Think of a padlock and its key. Give GitHub the padlock. Keep the key. An **<Term id="ssh-key">SSH key</Term>** works the same way. Sort the two halves.

<Interactive name="SortCards" buckets={[{ id: 'keep', label: 'Keep it secret' }, { id: 'give', label: 'Give it to GitHub' }]} items={[{ label: 'id_ed25519', bucket: 'keep', why: 'No .pub: this is the private key. It never leaves your computer.' }, { label: 'id_ed25519.pub', bucket: 'give', why: '.pub means public. This is the padlock.' }, { label: 'The public key (the padlock)', bucket: 'give', why: 'GitHub uses it to check your private key.' }, { label: 'The private key (the key)', bucket: 'keep', why: 'Whoever has it can push as you.' }]} success="Right! The .pub file goes to GitHub. The other one stays home." />

<Hint>.pub means public. Public is the padlock.</Hint>
</Card>

<Card id="try-build" type="try">
Build the command that makes a new key pair.

<Interactive name="CommandBuilder" pieces={[{ text: 'ssh-keygen', means: 'Make a key pair' }, { text: '-t', means: 'of this type' }, { text: 'ed25519', means: 'a modern, strong type' }, { text: '-C', means: 'with a label' }, { text: '"you@example.com"', means: 'your email as the label' }]} decoys={[{ text: 'git', means: 'Git does not make SSH keys' }, { text: '--force', means: 'not an ssh-keygen option here' }]} success="That's the command GitHub's guide uses too." />

<Hint>The tool is ssh-keygen. The type is ed25519.</Hint>
</Card>

<Card id="see-keygen" type="see">
<Interactive name="Transcript" title="bash" label="ssh-keygen starts making an ed25519 key pair. Then cat shows the public key: one long line that ends with your email. The key here is a fake example." lines={[{ cmd: 'ssh-keygen -t ed25519 -C "you@example.com"' }, { out: 'Generating public/private ed25519 key pair.' }, { cmd: 'cat ~/.ssh/id_ed25519.pub' }, { out: 'ssh-ed25519 AAAA...FAKE-EXAMPLE-KEY... you@example.com', color: 'cyan' }]} />

It asks where to save. Press Enter for the usual place. Then pick a passphrase: a password for the key itself. `cat` prints the public key to copy.
</Card>

<Card id="predict" type="predict">

<Card id="see-test" type="see">
<Interactive name="Transcript" title="bash" label="ssh -T git@github.com answers: Hi you! Paste the `.pub` key in GitHub: Settings, then SSH and GPG keys. Then test it. "Hi you!" means the padlock fits.
</Card>

<Card id="see-gh" type="see">
<Interactive name="Transcript" title="bash" label="The command gh auth login. It asks a few questions and signs you in with your browser." lines={[{ cmd: 'gh auth login' }]} />

Shortcut: the **<Term id="github-cli">GitHub CLI</Term>**. Run `gh auth login`. Pick GitHub.com, then HTTPS or SSH. Sign in with your browser. It can set up Git for you too.
</Card>

<Card id="deeper" type="deeper">
Already have an HTTPS remote? Switch it: `git remote set-url origin git@github.com:you/diary.git`. The ssh-agent can remember your passphrase for a whole session. The first SSH test asks you to trust github.com. Check its fingerprint on docs.github.com first.
</Card>
