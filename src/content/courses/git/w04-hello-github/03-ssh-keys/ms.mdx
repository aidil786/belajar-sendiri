<Card id="try-build" type="try">
Bina arahan untuk buat sepasang kunci baru.

<Interactive name="CommandBuilder" pieces={[{ text: 'ssh-keygen', means: 'Buat sepasang kunci' }, { text: '-t', means: 'jenis ini' }, { text: 'ed25519', means: 'jenis moden yang kuat' }, { text: '-C', means: 'dengan label' }, { text: '"you@example.com"', means: 'e-mel anda sebagai label' }]} decoys={[{ text: 'git', means: 'Git tak buat kunci SSH' }, { text: '--force', means: 'bukan pilihan ssh-keygen di sini' }]} success="Itulah arahan yang panduan GitHub guna juga." />

<Hint>Alatnya ssh-keygen. Jenisnya ed25519.</Hint>
</Card>

<Card id="see-keygen" type="see">
<Interactive name="Transcript" title="bash" label="ssh-keygen mula membuat sepasang kunci ed25519. Kemudian cat papar kunci awam: satu baris panjang yang berakhir dengan e-mel anda. Kunci di sini hanya contoh palsu." lines={[{ cmd: 'ssh-keygen -t ed25519 -C "you@example.com"' }, { out: 'Generating public/private ed25519 key pair.' }, { cmd: 'cat ~/.ssh/id_ed25519.pub' }, { out: 'ssh-ed25519 AAAA...FAKE-EXAMPLE-KEY... you@example.com', color: 'cyan' }]} />

Ia tanya mana nak simpan. Tekan Enter untuk tempat biasa. Kemudian pilih passphrase: kata laluan untuk kunci itu. `cat` papar kunci awam untuk disalin.
</Card>

<Card id="deeper" type="deeper">
Dah ada remote HTTPS? Tukar: `git remote set-url origin git@github.com:you/diary.git`. ssh-agent boleh ingat passphrase, jadi anda taip sekali sahaja setiap sesi. Ujian SSH pertama minta anda percaya github.com. Semak cap jarinya di docs.github.com dulu.
</Card>
