<Card id="hook" type="hook">
Your empty diary repo on GitHub has a long web address. Must you type it on every push?

<Interactive name="Choice" options={[{ label: 'No. Save it once under a short name.', correct: true, why: 'Git keeps a little address book. You tell it once.' }]} />
</Card>

<Card id="see-remote" type="see">
<Interactive name="TermReplay" scenario="w04-l04" commands={['git remote add origin https://github.com/you/diary.git', 'git remote -v']} label="git remote add saves the GitHub address as origin. git remote -v lists origin twice: once for fetch, once for push." />

A **<Term id="remote">remote</Term>** is a contact in Git's address book. `git remote add origin <url>` saves GitHub as `origin`. `git remote -v` lists your contacts.
</Card>

<Card id="deeper" type="deeper">
Typo in the address? `git remote set-url origin <new-url>` fixes it. `git remote rename` and `git remote remove` exist too. Removing a remote only deletes the contact. The repo on GitHub stays.

<Interactive name="TermReplay" scenario="w04-l04" commands={['git remote add origin https://github.com/you/diry.git', 'git remote set-url origin https://github.com/you/diary.git', 'git remote -v']} label="A remote with a typo in the address gets fixed with git remote set-url." />
</Card>
