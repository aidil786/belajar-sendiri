**<Term id="remote">Remote</Term>** (salinan dalam talian) ialah kenalan dalam buku alamat Git. `git remote add origin <url>` simpan GitHub sebagai `origin`. `git remote -v` senaraikan kenalan anda.
</Card>

<Card id="deeper" type="deeper">
Salah taip alamat? `git remote set-url origin <url-baru>` membaikinya. `git remote rename` dan `git remote remove` pun ada. Buang remote hanya padam kenalan itu. Repo di GitHub kekal.

<Interactive name="TermReplay" scenario="w04-l04" commands={['git remote add origin https://github.com/you/diry.git', 'git remote set-url origin https://github.com/you/diary.git', 'git remote -v']} label="Remote dengan alamat tersalah taip dibaiki dengan git remote set-url." />
