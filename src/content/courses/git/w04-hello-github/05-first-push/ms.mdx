<Card id="hook" type="hook">
Diari anda ada 3 commit. Repo GitHub anda kosong. Apa yang bawa commit itu ke sana?

<Interactive name="Choice" options={[{ label: '`git push`', correct: true, why: 'Push hantar commit ke remote. Tengok di kad seterusnya.' }, { label: '`git commit`', why: 'Commit simpan dalam laptop anda sahaja.' }, { label: 'GitHub salin sendiri', why: 'GitHub tak nampak laptop anda. Anda yang hantar.' }]} />
</Card>

<Card id="see-push" type="see">
<Interactive name="Courier" scenario="w04-l05" commands={['git push -u origin main']} label="Seorang kurier bawa tiga commit dari laptop anda ke repo GitHub yang kosong. Kini main di GitHub sama dengan main anda, dan laptop anda tunjuk origin/main." />

**<Term id="push">Push</Term>** (hantar) ialah kurier. Ia bawa commit baru anda naik ke GitHub. `git push -u origin main` hantar main ke origin.
</Card>

<Card id="see-upstream" type="see">
<Interactive name="TermReplay" scenario="w04-l05" commands={['git push -u origin main', 'git status']} label="Push itu kata main kini menjejak origin/main. Kemudian git status kata: Your branch is up to date with origin/main." />

`-u` tetapkan **<Term id="upstream">upstream</Term>**: main kini ikut `origin/main`. Lepas ini, `git push` sahaja dah tahu ke mana.
</Card>

<Card id="try-courier" type="try">
Giliran anda. Tekan satu arahan dan tengok kurier itu.

<Interactive name="Courier" scenario="w04-l05" actions={[{ cmd: 'git push' }, { cmd: 'git push -u origin main' }]} goal={{ pushed: ['main'], upstream: { main: 'origin/main' } }} hints={['Push yang pertama sekali perlukan -u, remote dan branch.']} success="Sampai! GitHub ada diari anda, dan main ikut origin/main." />

<Hint>Cuba yang pendek dulu. Baca apa Git kata.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh push commit anda ke GitHub.
</Card>

<Card id="deeper" type="deeper">
`git config --global push.autoSetupRemote true` buat `git push` biasa tetapkan upstream untuk branch baru juga. `git push origin --delete old-branch` padam branch di GitHub. Push branch baru buat GitHub papar pautan untuk pull request.
</Card>
