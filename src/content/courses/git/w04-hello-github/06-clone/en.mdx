<Card id="hook" type="hook">
Your laptop broke. The new one is empty. Luckily, your diary is safe on GitHub. How do you get it back?

<Interactive name="Choice" options={[{ label: 'Clone it from the GitHub address', correct: true, why: 'One command brings back every file and every commit.' }, { label: 'git init, then type it all again', why: 'No need! Your history waits on GitHub.' }, { label: 'Download each file from the website', why: 'You would get the files, but no history.' }]} />
</Card>

<Card id="see-clone" type="see">
<Interactive name="TermReplay" scenario="w04-l06" commands={['git clone https://github.com/you/diary.git', 'cd diary', 'git log --oneline']} label="git clone makes a diary folder. Inside, git log shows all three commits, with origin/main next to main." />

**<Term id="clone">Clone</Term>** copies the whole project: every file and every commit. It even saves the address as `origin` for you.
</Card>

</Card>

<Card id="deeper" type="deeper">
`git clone <url> my-diary` picks the folder name. With an SSH key, clone the SSH address instead. Cloning someone else's public repo works too. To change it, you'll need a fork (lesson 12).
</Card>
