<Card id="deeper" type="deeper">
`git clone <url> diari-saya` pilih nama folder. Kalau guna kunci SSH, clone alamat SSH. Clone repo awam orang lain pun boleh. Untuk mengubahnya, anda perlukan fork (pelajaran 12).
</Card>
