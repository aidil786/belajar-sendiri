<Card id="see-tracking" type="see">
<Interactive name="GraphScene" scenario="w04-l07" commands={['git fetch']} label="After git fetch, a purple commit appears with the origin/main label on it. The main label stays one commit behind." />

`origin/main` is a **<Term id="remote-tracking-branch">remote-tracking branch</Term>**. It is your laptop's memory of GitHub. It moves only when you fetch, pull or push.
</Card>

<Card id="deeper" type="deeper">
`git pull` is `git fetch` plus a merge (or a rebase: next lesson). After a fetch, `git log --oneline main..origin/main` lists what is new. `git fetch --prune` forgets remote branches that were deleted on GitHub.
</Card>
