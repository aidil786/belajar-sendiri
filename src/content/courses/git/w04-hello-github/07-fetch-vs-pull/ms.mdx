<Card id="deeper" type="deeper">
`git pull` ialah `git fetch` dan merge (atau rebase: pelajaran seterusnya). Selepas fetch, `git log --oneline main..origin/main` senaraikan apa yang baru. `git fetch --prune` lupakan branch remote yang dah dipadam di GitHub.
</Card>
