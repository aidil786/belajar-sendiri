<Card id="deeper" type="deeper">
`git config --global pull.ff only` makes pull refuse anything but a fast-forward. A rebase can stop on a conflict, like a merge. Fix the file, `git add` it, then `git rebase --continue`. Or run `git rebase --abort` to go back.
</Card>
