<Card id="deeper" type="deeper">
`git config --global pull.ff only` buat pull tolak semua kecuali fast-forward. Rebase boleh berhenti kerana konflik, macam merge. Baiki fail, `git add`, kemudian `git rebase --continue`. Atau `git rebase --abort` untuk undur.
</Card>
