<Card id="see-why" type="see">
GitHub ada commit baru Aisyah. Commit anda tak dibina di atasnya. Jadi GitHub tolak, untuk jaga kerja Aisyah. Tekan baris penolakan, dan baris cara membaikinya.

<Card id="deeper" type="deeper">
Dah fetch, tapi belum pull? Git akan kata "non-fast-forward", bukan "fetch first". Caranya sama: pull, kemudian push. Push juga boleh ditolak oleh peraturan branch di GitHub. Itu Dunia 5.
</Card>
