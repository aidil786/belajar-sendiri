**<Term id="force-push">Force push</Term>** (push paksa) paksa GitHub jadi sama tepat dengan main anda. Aisyah push selepas fetch terakhir anda. Commitnya baru sahaja lesap.
</Card>

<Card id="try-build" type="try">
Bina force push yang lebih selamat.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Bercakap dengan Git' }, { text: 'push', means: 'hantar ke GitHub' }, { text: '--force-with-lease', means: 'paksa, tapi hanya jika GitHub masih di tempat saya nampak tadi' }]} decoys={[{ text: '--force', means: 'paksa tanpa semakan langsung' }, { text: '--tags', means: 'hantar tag; bukan kali ini' }]} success="Itulah force push yang sopan." />

<Hint>Cari yang ada lease.</Hint>
</Card>

<Card id="see-lease" type="see">
<Interactive name="Courier" scenario="w04-l10-team" commands={['git push --force-with-lease']} label="git push --force-with-lease semak GitHub dulu. GitHub dah berubah sejak fetch terakhir anda, jadi push berhenti dan bungkusan dipulangkan. Commit Aisyah kekal." />

`--force-with-lease` semak dulu. Adakah GitHub masih seperti fetch terakhir saya? Aisyah dah push, jadi ia berhenti. Kerjanya selamat.
</Card>

<Card id="win" type="win">
Kini anda boleh force push hanya bila selamat, dengan --force-with-lease.
</Card>

<Card id="deeper" type="deeper">
Lease percaya pada `origin/main` anda. Sesetengah editor fetch secara senyap, jadi ia dikemas kini. Lease mungkin lepas tanpa anda nampak commit baru. `--force-if-includes` tambah satu lagi semakan untuk itu. Kesilapan dikongsi pada main? Guna `git revert` sahaja.
</Card>
