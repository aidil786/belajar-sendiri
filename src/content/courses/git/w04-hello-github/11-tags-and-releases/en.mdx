<Card id="deeper" type="deeper">
`git tag v1.0.0` without `-a` makes a lightweight tag: just a name, no note. `git push origin v1.0.0` sends one tag. `git push --follow-tags` sends your annotated tags with the commits. Versions like 0.3.0 mean "still early: things may change".
</Card>
