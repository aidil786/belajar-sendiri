<Card id="deeper" type="deeper">
`git tag v1.0.0` tanpa `-a` buat tag ringan: nama sahaja, tiada nota. `git push origin v1.0.0` hantar satu tag. `git push --follow-tags` hantar tag beranotasi bersama commit. Versi macam 0.3.0 bermaksud "masih awal: mungkin berubah".
</Card>
