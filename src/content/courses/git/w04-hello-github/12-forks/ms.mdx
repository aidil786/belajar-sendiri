<Card id="deeper" type="deeper">
GitHub CLI pun boleh. `gh repo fork --clone` fork dan clone sekali gus. `gh repo sync` kemas kini fork daripada repo induknya. Fork ingat repo asalnya, jadi pull request tahu arah tujunya.
</Card>
