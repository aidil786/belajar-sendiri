<Card id="see-buttons" type="see">
Three buttons sit near the top. **Star** saves a repo like a bookmark. Watch sends you news about it. Fork makes your own copy.

Which one keeps you posted on new issues?

<Interactive name="Choice" compact options={[{ label: 'Watch', correct: true, why: 'Watching sends you notifications about the repo.' }, { label: 'Star', why: 'A star is a bookmark. It sends no news.' }, { label: 'Fork', why: 'A fork is your own copy. It sends no news.' }]} />
</Card>
