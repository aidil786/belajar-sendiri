Same file, on GitHub. It reads the signs and draws a neat page. This way of writing is called **<Term id="markdown">Markdown</Term>**.

<Card id="try-heading" type="try">
A **heading** starts with #. One # makes the biggest. Make "Code Club" a big title. Make "What we do" a smaller one.

<Interactive name="MarkdownPlayground" initial={'Code Club\n\nWe meet every Friday.\n\nWhat we do\n\nWe build fun websites.\n'} prompt="Put # before Code Club. Put ## before What we do." goal={{ mustMatch: ['^#\\s+Code Club', '^##\\s+What we do'], hint: ['Type # and a space before Code Club.', 'Type ## and a space before What we do.'] }} success="Two headings! Big title, smaller section." />

<Hint>Leave a space after the # signs.</Hint>
</Card>

<Card id="predict" type="predict">
You type `**Friday**`. How does it look on the page?

<Interactive name="Choice" options={[{ label: 'Bold, like **this**', correct: true, why: 'Two stars on each side make it bold. GitHub hides the stars.' }, { label: 'Slanted (italic)', why: 'Italic uses one star on each side.' }, { label: 'With the stars showing', why: 'GitHub hides the stars and makes the word bold.' }]} />
</Card>

<Card id="try-list" type="try">
A dash and a space start a list item. Turn the two plain lines into a **list**.

<Interactive name="MarkdownPlayground" initial={'# Code Club\n\nThings we need:\n\nLaptops\nSnacks\n'} prompt="Start each of the last two lines with a dash and a space." goal={{ mustMatch: ['^- Laptops', '^- Snacks'], hint: ['Type - and a space before Laptops.', 'Type - and a space before Snacks.'] }} success="A real list! See the dots in the preview?" />

<Hint>Type `- ` before each line.</Hint>
</Card>

<Card id="check-swipe" type="check">
A **link** is `[text](address)`. Code goes between backticks. Good Markdown, or needs work?

<Interactive name="SwipeJudge" cards={[{ text: '[How to help](CONTRIBUTING.md)', good: true, why: 'Square brackets for the text, round ones for the address.' }, { text: '(How to help)[CONTRIBUTING.md]', good: false, why: 'The brackets are swapped. Square ones go first.' }, { text: 'Run `git status` first.', good: true, why: 'Backticks show git status as code.' }, { text: 'Run "git status" first.', good: false, why: 'Quotes do not make code. Use backticks.' }]} />
</Card>

<Card id="win" type="win">
You can now write headings, lists, links and code in Markdown.
</Card>

<Card id="deeper" type="deeper">
One star on each side makes *italic*. Two tildes make ~~strikethrough~~. A line starting with `>` makes a quote. Three backticks on their own lines make a code block. Type `@name` to mention someone, or `#12` to link issue 12. With two or more headings, GitHub builds an outline menu for the file.
</Card>
