<Card id="try-heading" type="try">
**Tajuk** (heading) bermula dengan #. Satu # paling besar. Jadikan "Kelab Kod" tajuk besar. Jadikan "Apa kami buat" tajuk kecil.

<Interactive name="MarkdownPlayground" initial={'Kelab Kod\n\nKami berjumpa setiap Jumaat.\n\nApa kami buat\n\nKami bina laman web yang seronok.\n'} prompt="Letak # sebelum Kelab Kod. Letak ## sebelum Apa kami buat." goal={{ mustMatch: ['^#\\s+Kelab Kod', '^##\\s+Apa kami buat'], hint: ['Taip # dan satu jarak sebelum Kelab Kod.', 'Taip ## dan satu jarak sebelum Apa kami buat.'] }} success="Dua tajuk! Tajuk besar, bahagian kecil." />

<Hint>Tinggalkan satu jarak selepas tanda #.</Hint>
</Card>

<Card id="try-list" type="try">
Sengkang dan satu jarak mulakan item senarai. Tukar dua baris biasa itu jadi **senarai**.

<Interactive name="MarkdownPlayground" initial={'# Kelab Kod\n\nBarang yang kami perlu:\n\nLaptop\nSnek\n'} prompt="Mulakan dua baris terakhir dengan sengkang dan satu jarak." goal={{ mustMatch: ['^- Laptop', '^- Snek'], hint: ['Taip - dan satu jarak sebelum Laptop.', 'Taip - dan satu jarak sebelum Snek.'] }} success="Senarai sebenar! <Hint>Taip `- ` sebelum setiap baris.</Hint>
</Card>

<Card id="deeper" type="deeper">
Satu bintang di setiap sisi buat *italik*. Dua tilde buat ~~garis potong~~. Baris yang bermula dengan `>` jadi petikan. Tiga backtick pada baris sendiri buat blok kod. Taip `@nama` untuk sebut seseorang, atau `#12` untuk pautkan issue 12. Dengan dua tajuk atau lebih, GitHub bina menu rangka untuk fail itu.
</Card>
