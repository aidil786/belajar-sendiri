<Card id="try-order" type="try">
A great **<Term id="readme">README</Term>** answers five questions. Put them in a good order.

<Interactive name="OrderList" items={['What does the project do?', 'Why is it useful?', 'How do I get started?', 'Where can I get help?', 'Who keeps it going?']} label="First question at the top" success="Yes! That's the order GitHub's own guide suggests." />

<Hint>Start with what it is. End with the people behind it.</Hint>
</Card>

<Card id="try-write" type="try">
Fix Sam's README. Add a line that says what the game does. Then add a Get started section with a command in backticks.

<Interactive name="MarkdownPlayground" initial={'# Quiz Game\n'} prompt="Add a short description, a ## Get started heading and one command in backticks." goal={{ mustMatch: ['^(?![#>\\-\\s])\\S+([ \\t]+\\S+){2,}', '^##\\s+[Gg]et [Ss]tarted', '\\x60[^\\x60\\n]+\\x60'], hint: ['Under the title, write one line, like: A quick maths quiz for your browser.', 'Start a line with ## Get started', 'Put a command between backticks, like `open index.html`.'] }} success="Now a stranger knows what it is and how to start." />

<Hint>Need ideas? A quick maths quiz you play in your browser.</Hint>
</Card>

<Card id="deeper" type="deeper">
GitHub shows the README from `.github/`, the top folder or `docs/`. It checks them in that order. Add pictures with alt text, so everyone knows what they show. Use relative links like `[Help](CONTRIBUTING.md)`: they work in every copy of the repo. A profile README comes in World 12.
</Card>
