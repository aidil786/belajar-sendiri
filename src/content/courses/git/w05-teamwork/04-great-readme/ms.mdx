<Card id="try-order" type="try">
**<Term id="readme">README</Term>** yang hebat jawab lima soalan. Susun soalan itu ikut urutan yang baik.

<Interactive name="OrderList" items={['Projek ini buat apa?', 'Kenapa ia berguna?', 'Macam mana nak mula?', 'Di mana nak dapat bantuan?', 'Siapa yang jaga projek ini?']} label="Soalan pertama di atas" success="Betul! Itu urutan yang panduan GitHub sendiri cadangkan." />

<Hint>Mula dengan apa benda ini. Tamatkan dengan orang di sebaliknya.</Hint>
</Card>

<Card id="try-write" type="try">
Baiki README Sam. Tambah satu baris tentang fungsi permainan itu. Kemudian tambah bahagian Mula di sini, dengan satu arahan dalam backtick.

<Interactive name="MarkdownPlayground" initial={'# Permainan Kuiz\n'} prompt="Tambah penerangan pendek, tajuk ## Mula di sini dan satu arahan dalam backtick." goal={{ mustMatch: ['^(?![#>\\-\\s])\\S+([ \\t]+\\S+){2,}', '^##\\s+[Mm]ula di sini', '\\x60[^\\x60\\n]+\\x60'], hint: ['Di bawah tajuk, tulis satu baris, contohnya: Kuiz matematik pantas dalam pelayar.', 'Mulakan satu baris dengan ## Mula di sini', 'Letak satu arahan antara backtick, contohnya `open index.html`.'] }} success="Sekarang orang asing tahu apa benda ini dan cara mula." />

<Hint>Perlukan idea? Kuiz matematik pantas yang anda main dalam pelayar.</Hint>
</Card>

<Card id="deeper" type="deeper">
GitHub tunjuk README dari `.github/`, folder atas atau `docs/`. Ia semak ikut urutan itu. Tambah gambar dengan teks alt, supaya semua orang tahu isinya. Guna pautan relatif macam `[Bantu](CONTRIBUTING.md)`: ia berfungsi dalam setiap salinan repo. README profil datang dalam Dunia 12.
</Card>
