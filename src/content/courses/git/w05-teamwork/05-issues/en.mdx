<Card id="try-issue" type="try">
An **<Term id="issue">issue</Term>** is a to-do note on the repo. The team can read it, talk and close it when done. Tell Aina you will fix #14.

<Interactive name="PracticeRepo" screen="issue" at={14} repo={{ owner: 'kelab-kod', name: 'club-site', readme: '# Club Site\n\nThe website for our school code club.\n' }} issues={[{ number: 14, title: 'Sign-up button does nothing', body: 'On the home page, I tap **Sign up** and nothing happens.\n\nPhone: Android, Chrome.', state: 'open', author: 'ravi', labels: ['bug'], milestone: 'Open Day', comments: [{ author: 'aina', body: 'Thanks Ravi! Who can take this one?' }] }, { number: 15, title: 'Logo looks squashed on phones', body: 'The logo is too thin on small screens.', state: 'open', author: 'sam', milestone: 'Open Day' }]} task={{ type: 'comment', issue: 14 }} success="Now everyone knows you are on it." />

<Hint>Write something like "I can fix this!" and press Comment.</Hint>
</Card>

<Card id="deeper" type="deeper">
Assign an issue to a person, so everyone knows who is on it. Type `#14` anywhere to link that issue. Use filters like `is:open label:bug` to find issues fast. New repos start with a few labels, but you can make your own. Milestones can have a due date too.
</Card>
