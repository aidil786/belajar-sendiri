<Card id="deeper" type="deeper">
Tetapkan issue kepada seseorang, supaya semua tahu siapa yang uruskan. Taip `#14` di mana-mana untuk pautkan issue itu. Guna penapis seperti `is:open label:bug` untuk cari issue dengan cepat. Repo baru mula dengan beberapa label, tapi anda boleh buat sendiri. Milestone boleh ada tarikh akhir juga.
</Card>
