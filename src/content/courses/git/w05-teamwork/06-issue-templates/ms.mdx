**<Term id="issue-template">Templat issue</Term>** ialah borang dengan ruang kosong. Ia tinggal dalam `.github/ISSUE_TEMPLATE/`. Setiap laporan pepijat baru bermula dengan soalan-soalan ini.

<Card id="deeper" type="deeper">
Templat juga boleh jadi borang issue: fail `.yml` dengan ruang borang sebenar. Fail `config.yml` dalam folder yang sama sediakan pemilih templat. Templat pull request (`pull_request_template.md`) isi penerangan PR baru. Sub-issue boleh ada sub-issue sendiri. Jenis issue disediakan dalam tetapan organisasi.
</Card>
