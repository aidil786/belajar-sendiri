<Card id="deeper" type="deeper">
You can turn a PR back into a draft at any time. Drafts do not ask code owners to review. Marking one ready does. You can open PRs on the website, from your editor, or with `gh pr create` (World 9). A pull request template fills in the description for you.
</Card>
