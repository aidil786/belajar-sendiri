<Card id="deeper" type="deeper">
Anda boleh tukar PR jadi draf semula bila-bila masa. Draf tak minta code owner buat review. Bila ditanda sedia, barulah ia minta. Anda boleh buka PR di laman web, dari editor, atau dengan `gh pr create` (Dunia 9). Templat pull request isi penerangan untuk anda.
</Card>
