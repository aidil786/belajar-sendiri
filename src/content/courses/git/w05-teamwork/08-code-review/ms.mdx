Di laman sebenar, anda boleh mula satu review dan tambah banyak komen baris. Semuanya dihantar serentak bila anda hantar review. Selepas membaiki, penulis boleh minta anda review semula. Sesetengah repo buang kelulusan lama bila commit baru masuk. Peraturan emas: semak kod, jangan serang orangnya.
