<Card id="see-keyword" type="see">
A **<Term id="closing-keyword">closing keyword</Term>** goes in the PR description. When the PR merges into main, the issue closes by itself. Tap the magic line.

</Card>

<Card id="deeper" type="deeper">
All nine keywords: close, closes, closed, fix, fixes, fixed, resolve, resolves, resolved. For an issue in another repo, write `Fixes owner/repo#100`. For several issues, repeat the keyword: `Closes #10, closes #11`. A keyword in a commit message works too, once it reaches the default branch.
</Card>
