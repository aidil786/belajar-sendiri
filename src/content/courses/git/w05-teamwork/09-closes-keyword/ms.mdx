Kini anda boleh pautkan PR ke issue, supaya ia tutup dengan sendiri.
</Card>

<Card id="deeper" type="deeper">
Kesemua sembilan kata kunci: close, closes, closed, fix, fixes, fixed, resolve, resolves, resolved. Untuk issue dalam repo lain, tulis `Fixes owner/repo#100`. Untuk beberapa issue, ulang kata kunci: `Closes #10, closes #11`. Kata kunci dalam mesej commit pun berfungsi, bila commit itu sampai ke branch utama.
</Card>
