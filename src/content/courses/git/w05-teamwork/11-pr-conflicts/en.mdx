<Card id="try-spot" type="try">
Git marks the clash with **<Term id="conflict-markers">conflict markers</Term>**. Your line sits on top. Main's line sits below. Tap the three marker lines.

<Interactive name="SpotLines" lines={[{ text: '# Club Site' }, { text: '<<<<<<< my-tagline', target: true }, { text: 'Code, snacks and friends. </Card>

<Card id="try-fix" type="try">
Now fix it. Keep the words you want. Delete all three marker lines.

<Interactive name="MarkdownPlayground" initial={'# Club Site\n<<<<<<< my-tagline\nCode, snacks and friends. <Card id="deeper" type="deeper">
On GitHub, fixing a conflict makes a merge commit. It merges main into your PR branch. Not just the clashing lines: all of main comes in. On your computer, switch to your branch and merge main into it. Fix the files, then `git add` and `git commit`. Push, and the PR updates. World 3 shows merging in detail.
</Card>
