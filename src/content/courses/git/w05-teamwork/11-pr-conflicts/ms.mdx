<Card id="try-spot" type="try">
Git tandakan pertembungan dengan **<Term id="conflict-markers">penanda konflik</Term>**. Baris anda di atas. Baris main di bawah. Tekan tiga baris penanda itu.

<Card id="win" type="win">
Kini anda boleh baiki konflik dalam pull request tanpa panik.
</Card>

<Card id="deeper" type="deeper">
Di GitHub, membaiki konflik buat satu merge commit. Ia merge main ke dalam branch PR anda. Bukan baris yang bertembung sahaja: seluruh main masuk. Di komputer anda, tukar ke branch anda dan merge main ke dalamnya. Baiki fail, kemudian `git add` dan `git commit`. Push, dan PR itu dikemas kini. Dunia 3 terangkan merge dengan lebih lanjut.
</Card>
