<Card id="deeper" type="deeper">
Rules can also require code owner reviews, resolved comments or signed commits. Force pushes and deleting a protected branch are blocked by default. Code owners need write access to the repo. The CODEOWNERS file can live in `.github/`, the top folder or `docs/`. Rulesets can let chosen people or apps skip a rule.
</Card>
