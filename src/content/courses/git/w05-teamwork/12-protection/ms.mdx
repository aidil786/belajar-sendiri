<Card id="deeper" type="deeper">
Peraturan juga boleh perlukan review code owner, komen yang selesai atau commit bertandatangan. Force push dan padam branch yang dilindungi disekat secara lalai. Code owner perlukan akses tulis ke repo. Fail CODEOWNERS boleh duduk dalam `.github/`, folder atas atau `docs/`. Ruleset boleh benarkan orang atau aplikasi terpilih langkau satu peraturan.
</Card>
