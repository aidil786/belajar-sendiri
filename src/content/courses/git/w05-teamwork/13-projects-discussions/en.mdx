<Card id="try-board" type="try">

<Card id="see-discussions" type="see">
**<Term id="discussions">Discussions</Term>** is a forum inside the repo. It holds questions, ideas, news and polls. In a Q&A, the asker can mark the best reply as the answer. Put a Q&A in order.

<Interactive name="OrderList" items={['Ravi asks how to run the site', 'Mei replies with the steps', "Ravi marks Mei's reply as the answer", 'Later, others find the answer fast']} label="First at the top" success="Questions answered once help everyone after." />
</Card>

<Card id="predict-wiki" type="predict">
A **<Term id="wiki">wiki</Term>** holds long guides on many pages, next to the code. Your wiki explains how to set up the club laptops. Who can edit it, at first?

<Interactive name="Choice" options={[{ label: 'People with write access to the repo', correct: true, why: 'That is the default. Owners of public repos can open it to more people.' }, { label: 'Anyone on the internet', why: 'Not by default. The owner must allow that.' }, { label: 'Only the repo owner', why: 'Everyone with write access can edit it too.' }]} />
</Card>

<Card id="check-gist" type="check">
A **<Term id="gist">gist</Term>** is a tiny repo for sharing a snippet. Secret gists hide from search. But anyone with the link can see them. Safe in a secret gist?

<Interactive name="SwipeJudge" prose cards={[{ text: 'A handy CSS snippet', good: true, why: 'Snippets are what gists are for.' }, { text: 'Your password', good: false, why: 'Secret gists are not private. Anyone with the link sees it.' }, { text: 'A short script to share with the club', good: true, why: 'Easy to share with one link.' }, { text: 'An API key', good: false, why: 'Keys never go in gists. Remember World 8!' }]} />
</Card>

<Card id="deeper" type="deeper">
Projects can also be a table or a roadmap with dates. Add your own fields, like priority. A project belongs to you or to an organization. You can turn an issue into a discussion. Every gist is a Git repo, so people can fork and clone it. A secret gist can turn public later, not back.
</Card>
