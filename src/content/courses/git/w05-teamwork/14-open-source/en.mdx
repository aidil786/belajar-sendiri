<Card id="try-roles" type="try">
An **<Term id="organization">organization</Term>** is a shared account for a group, like our club. Members form teams. Each team gets a role. Order the roles from least to most power.

<Interactive name="OrderList" items={['Read: view and comment', 'Triage: sort issues and PRs', 'Write: push code', 'Maintain: run the repo', 'Admin: full control']} label="Least power at the top" success="Give each team only the power it needs." />

<Hint>Read can only look. Admin can even delete the repo.</Hint>
</Card>

<Card id="predict" type="predict">
A **<Term id="license">licence</Term>** says what others may do with the code. A public repo has no licence file. Can you copy its code into your app?

<Interactive name="Choice" options={[{ label: 'Not really. Without a licence, the author keeps all rights', correct: true, why: 'You may look and fork on GitHub. A licence says you may reuse it.' }, { label: 'Yes, if you star it first', why: 'A star is a bookmark. It gives you no rights.' }]} />
</Card>

<Card id="deeper" type="deeper">
choosealicense.com helps you pick a licence. MIT is short: people may do almost anything, if they keep your notice. GPL asks people who share changed versions to share their code too. Put the licence in a `LICENSE` file at the top of the repo. In World 12 you make a real open source PR.
</Card>
