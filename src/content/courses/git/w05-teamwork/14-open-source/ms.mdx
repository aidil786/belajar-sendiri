<Card id="try-roles" type="try">
**<Term id="organization">Organisasi</Term>** (organization) ialah akaun yang dikongsi satu kumpulan, macam kelab kita. Ahli membentuk pasukan. Setiap pasukan dapat satu peranan. Susun peranan dari kuasa paling sedikit ke paling banyak.

<Interactive name="OrderList" items={['Read: tengok dan komen', 'Triage: susun issue dan PR', 'Write: push kod', 'Maintain: urus repo', 'Admin: kawalan penuh']} label="Kuasa paling sedikit di atas" success="Beri setiap pasukan kuasa yang ia perlu sahaja." />

<Hint>Read cuma boleh tengok. Admin boleh padam repo pun.</Hint>
</Card>

<Card id="see-path" type="see">
Kod **<Term id="open-source">sumber terbuka</Term>** (open source) terbuka untuk sesiapa baca, guna dan baiki. Tekan setiap langkah sumbangan pertama.

<Interactive name="TimelineTap" events={[{ when: '1', title: 'Pilih satu issue', text: 'Pilih yang projek itu perlukan bantuan.' }, { when: '2', title: 'Fork', text: 'Buat salinan repo anda sendiri.' }, { when: '3', title: 'Branch dan commit', text: 'Baiki dalam salinan anda, dalam branch baru.' }, { when: '4', title: 'Push dan buka PR', text: 'Minta projek itu tarik masuk pembaikan anda.' }, { when: '5', title: 'Review dan merge', text: 'Baiki apa yang reviewer minta. Kemudian mereka merge.' }]} />
</Card>

<Card id="predict" type="predict">
**<Term id="license">Lesen</Term>** (licence) beritahu apa orang lain boleh buat dengan kod itu. Satu repo awam tiada fail lesen. Bolehkah anda salin kodnya ke dalam aplikasi anda?

<Interactive name="Choice" options={[{ label: 'Tak boleh sebenarnya. Tanpa lesen, penulis simpan semua hak', correct: true, why: 'Anda boleh tengok dan fork di GitHub. Guna semula perlukan lesen.' }, { label: 'Boleh. Awam bermaksud bebas digunakan', why: 'Awam bermaksud anda boleh nampak. Lesen pula beri izin guna semula.' }, { label: 'Boleh, kalau anda star dulu', why: 'Star cuma penanda buku. Ia tak beri apa-apa hak.' }]} />
</Card>

<Card id="deeper" type="deeper">
choosealicense.com bantu anda pilih lesen. MIT ringkas: orang boleh buat hampir apa sahaja, asalkan notis anda dikekalkan. GPL minta sesiapa yang kongsi versi ubahan supaya kongsi kodnya juga. Letak lesen dalam fail `LICENSE` di folder atas repo. Dalam Dunia 12, anda buat PR sumber terbuka yang sebenar.
</Card>
