**<Term id="git-flow">Git Flow</Term>** sebarkan kerja ke lima jenis branch (cabang). Dua kekal selamanya: main dan develop. Yang lain datang dan pergi. Ketik untuk ikut versi 2.1.
</Card>

Ciri dah siap? Mulakan **<Term id="release-branch">release branch</Term>** dari develop. Penguji semak di situ. Kemudian ia merge ke main, dengan tag versi.
</Card>
