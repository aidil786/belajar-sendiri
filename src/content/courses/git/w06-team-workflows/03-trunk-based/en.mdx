<Card id="deeper" type="deeper">
Very small teams may commit straight to main. Bigger teams use tiny branches and quick PRs. A merge queue helps busy repos. It tests each PR with the latest main, then merges it. Flags can also switch a feature on for a few users first.
</Card>
