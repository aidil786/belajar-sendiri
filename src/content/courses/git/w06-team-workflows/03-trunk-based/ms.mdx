<Card id="deeper" type="deeper">
Pasukan yang sangat kecil mungkin commit terus ke main. Pasukan lebih besar guna branch kecil dan PR yang cepat. Merge queue bantu repo yang sibuk. Ia uji setiap PR dengan main terkini, kemudian merge. Flag juga boleh hidupkan ciri untuk segelintir pengguna dulu.
</Card>
