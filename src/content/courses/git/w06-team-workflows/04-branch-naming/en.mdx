</Card>

<Card id="deeper" type="deeper">
Many teams add the issue number, like `fix/42-login-typo`. Some add a name, like `aiman/fix-login`. Agree on one style. Write it in CONTRIBUTING.md. Git also refuses `~ ^ : ? * [` and a backslash. A branch name cannot start with a dash.
</Card>
