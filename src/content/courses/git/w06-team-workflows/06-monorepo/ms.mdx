<Card id="deeper" type="deeper">
Monorepo yang sangat besar boleh jadi perlahan. Git ada pembantu. `git sparse-checkout` isi folder yang anda perlu sahaja. Partial clone langkau versi fail lama sampai anda perlukannya. Fail CODEOWNERS boleh namakan pemilik setiap folder. World 10 terangkan lebih lanjut.
</Card>
