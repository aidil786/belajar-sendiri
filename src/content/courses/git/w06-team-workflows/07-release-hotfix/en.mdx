<Card id="deeper" type="deeper">
In Git Flow, merge the hotfix into develop too. If not, the bug comes back next release. Trunk-based teams fix main first. Then they copy the fix to the release branch with `git cherry-pick`. On GitHub, a Release adds notes to a tag. GitHub can draft those notes for you.
</Card>
