<Card id="deeper" type="deeper">
Dalam Git Flow, merge hotfix ke develop juga. Kalau tidak, bug itu kembali dalam release seterusnya. Pasukan berasaskan trunk baiki main dulu. Kemudian mereka salin pembaikan ke release branch dengan `git cherry-pick`. Di GitHub, Release tambah nota pada tag. GitHub boleh draf nota itu untuk anda.
</Card>
