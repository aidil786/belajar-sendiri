<Card id="pasar-pick" type="check">
Pasar Besar has 150 developers. They merge into main many times a day. Strong automatic tests guard main. Big features take months. Which workflow fits?

<Interactive name="Choice" options={[{ label: 'Trunk-based, with feature flags', correct: true, why: 'Tiny daily merges avoid huge conflicts. <Card id="deeper" type="deeper">
Real teams mix and match. Many web teams use GitHub Flow with feature flags. Some app teams merge to main daily. Then they cut a release branch from it. Pick what fits your team. Then write it down, so everyone works the same way.
</Card>
