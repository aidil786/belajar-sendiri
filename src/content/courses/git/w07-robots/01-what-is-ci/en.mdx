<Card id="see-ci" type="see">

<Card id="deeper" type="deeper">
CD comes in two flavours. Continuous delivery: every change is ready, and a person presses ship. Continuous deployment: it ships by itself when the checks pass. Many tools do CI. This world uses GitHub Actions.
</Card>
