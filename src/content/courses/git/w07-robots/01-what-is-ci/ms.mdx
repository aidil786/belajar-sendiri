<Card id="deeper" type="deeper">
CD ada dua jenis. Continuous delivery: setiap perubahan sedia dihantar, dan manusia tekan butang. Continuous deployment: ia dihantar sendiri bila semua semakan lulus. Banyak alat boleh buat CI. Dunia ini guna GitHub Actions.
</Card>
