<Card id="see-on" type="see">
<Interactive name="SpotLines" lines={[{ text: 'name: CI' }, { text: 'on: push', target: true }, { text: 'jobs:' }, { text: '  test:' }, { text: '    runs-on: ubuntu-latest' }, { text: '    steps:' }, { text: '      - uses: actions/checkout@v7' }, { text: '      - run: npm test' }]} prompt="Ketik baris yang beritahu bila robot bangun." success="Ya! on: push maksudnya setiap push kejutkan robot." />

Bila: `on:` menamakan **<Term id="trigger">trigger</Term>** (pencetus). Ia beritahu bila workflow berjalan. Di sini, pada setiap push.
</Card>

<Interactive name="Choice" options={[{ label: 'Komputer Linux baru dari GitHub', correct: true, why: 'GitHub pinjamkan komputer bersih untuk setiap job. </Card>

<Card id="see-steps" type="see">

<Interactive name="SortCards" buckets={[{ id: 'uses', label: 'uses: action siap pakai' }, { id: 'run', label: 'run: satu arahan' }]} items={[{ label: '`actions/checkout@v7`', bucket: 'uses', why: 'owner/nama@versi ialah action. </Card>
