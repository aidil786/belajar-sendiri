<Card id="see-push-pr" type="see">
<Interactive name="SpotLines" lines={[{ text: 'on:' }, { text: '  push:' }, { text: '    branches: [main]' }, { text: '  pull_request:', target: true }]} prompt="Tap the line that checks pull requests." success="Yes! Every new PR, and every new commit on it, gets checked." />

Each start is an **<Term id="trigger">event</Term>**. `push` fires when commits land. `branches: [main]` keeps it to main. `pull_request` fires when a PR opens or changes.
</Card>

<Card id="see-schedule" type="see">
`schedule` is an alarm clock. It uses **<Term id="cron">cron</Term>**: minute, hour, day, month, weekday. By default, times are in UTC. When does `cron: '30 1 * * 1'` ring?

<Interactive name="Choice" options={[{ label: '01:30 UTC every Monday', correct: true, why: 'Minute 30, hour 1, any day, any month, weekday 1 (Monday). </Card>

<Card id="deeper" type="deeper">
`paths:` runs a workflow only when certain files change. `types: [opened]` narrows `pull_request` to new PRs only. Busy times can delay scheduled runs. The top of the hour is busiest. So pick a minute like 30, not 0.
</Card>
