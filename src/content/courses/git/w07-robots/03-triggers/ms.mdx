<Card id="see-push-pr" type="see">
<Interactive name="SpotLines" lines={[{ text: 'on:' }, { text: '  push:' }, { text: '    branches: [main]' }, { text: '  pull_request:', target: true }]} prompt="Ketik baris yang semak pull request." success="Ya! Setiap PR baru, dan setiap commit baru di dalamnya, akan disemak." />

Setiap permulaan ialah satu **<Term id="trigger">event</Term>** (peristiwa). `push` berlaku bila commit sampai. `branches: [main]` hadkan kepada main. `pull_request` berlaku bila PR dibuka atau berubah.
</Card>

<Card id="see-schedule" type="see">
`schedule` ialah jam loceng. Ia guna **<Term id="cron">cron</Term>**: minit, jam, hari, bulan, hari minggu. Secara lalai, masa dalam UTC. Bila `cron: '30 1 * * 1'` berbunyi?

<Interactive name="Choice" options={[{ label: '01:30 UTC setiap Isnin', correct: true, why: 'Minit 30, jam 1, mana-mana hari, mana-mana bulan, hari minggu 1 (Isnin). Di sini ia `*`, mana-mana hari.' }]} />
</Card>

<Card id="deeper" type="deeper">
`paths:` jalankan workflow hanya bila fail tertentu berubah. `types: [opened]` hadkan `pull_request` kepada PR baru sahaja. Waktu sibuk boleh lambatkan larian berjadual. Awal jam paling sibuk. Jadi pilih minit macam 30, bukan 0.
</Card>
