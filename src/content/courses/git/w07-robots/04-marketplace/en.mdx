An **<Term id="action">action</Term>** is a ready-made step, like a Lego brick. `uses: owner/name@version` borrows one.

<Card id="see-marketplace" type="see">
The **<Term id="marketplace">GitHub Marketplace</Term>** is a shop of shared actions. Anyone can publish there. So check before you borrow. Trust it? Swipe each clue.

<Interactive name="SwipeJudge" prose cards={[{ text: 'Made by a creator GitHub verified, used by thousands', good: true, why: 'A known maker and many users are good signs.' }, { text: 'Last update six years ago, many open bug reports', good: false, why: 'Nobody looks after it. </Card>

<Card id="see-tag" type="see">
<Interactive name="TimelineTap" events={[{ when: 'Day 1', title: 'v7 is fine', text: 'You write `uses: some-dev/tool@v7`. It works.' }, { when: 'Day 30', title: 'The tag moves', text: "An attacker breaks into the tool's repo. `@v7` is a **tag**: a sticky note on one commit. Sticky notes can be moved. Tap through the story.
</Card>

<Card id="see-pin" type="see">
<Interactive name="SpotLines" lines={[{ text: '- uses: some-dev/tool@main' }, { text: '- uses: some-dev/tool@v7' }, { text: '- uses: some-dev/tool@a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0 # v7.0.1', target: true }]} prompt="Tap the line that can never change under you." success="Yes! A full SHA always means the same code." />

A full commit SHA can never point at other code. Using it is called **<Term id="pinning">pinning</Term>**. Add the version as a comment, for humans. (That SHA is a made-up example.)
</Card>

<Card id="try-sort" type="try">
Can it move, or never? Sort each version.

<Interactive name="SortCards" buckets={[{ id: 'moves', label: 'Can move' }, { id: 'fixed', label: 'Never moves' }]} items={[{ label: '`@main` (a branch)', bucket: 'moves', why: 'A branch moves with every new commit.' }, { label: '`@v7` (a tag)', bucket: 'moves', why: 'A tag is a sticky note. It can be moved.' }, { label: '`@v7.0.1` (a tag too)', bucket: 'moves', why: 'It looks exact, but it is still a tag.' }, { label: 'A full 40-character commit SHA', bucket: 'fixed', why: "A SHA is the code's fingerprint. New code means a new SHA." }]} success="Only the SHA stays put." />
</Card>

<Card id="predict" type="predict">

<Card id="deeper" type="deeper">
Actions under `actions/` are made by GitHub. GitHub's own advice: pin third-party actions to a full SHA. Copy the SHA from the action's own repo, never from a fork. A branch like `@main` is the riskiest: you run whatever lands there next.
</Card>
