`@v7` ialah **tag**: nota pelekat pada satu commit. Nota pelekat boleh dialih. Ketik sepanjang cerita ini.
</Card>

<Card id="see-pin" type="see">
<Interactive name="SpotLines" lines={[{ text: '- uses: some-dev/tool@main' }, { text: '- uses: some-dev/tool@v7' }, { text: '- uses: some-dev/tool@a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0 # v7.0.1', target: true }]} prompt="Ketik baris yang tak boleh berubah senyap-senyap." success="Ya! SHA penuh sentiasa bermaksud kod yang sama." />

SHA commit penuh tak boleh tunjuk ke kod lain. Guna SHA dipanggil **<Term id="pinning">pinning</Term>** (sematkan). Tambah versi sebagai komen, untuk manusia. (SHA itu contoh rekaan.)
</Card>

<Card id="deeper" type="deeper">
Action di bawah `actions/` dibuat oleh GitHub. Nasihat GitHub sendiri: sematkan action pihak ketiga pada SHA penuh. Salin SHA dari repo asal action itu, bukan dari fork. Branch seperti `@main` paling berisiko. Anda jalankan apa sahaja yang masuk ke situ nanti.
</Card>
