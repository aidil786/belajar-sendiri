**<Term id="secret">Secret</Term>** (rahsia) duduk berkunci dalam tetapan repo anda. Workflow baca ikut nama, contohnya `${{ secrets.MY_TOKEN }}`. Tercetak tanpa sengaja? Log tunjuk `***`. Namun, jangan sekali-kali cetak.
</Card>

<Card id="see-variable" type="see">

<Card id="see-env" type="see">
**<Term id="environment">Environment</Term>** (persekitaran) ialah tempat bernama untuk deploy, contohnya `production`. Ia boleh simpan rahsia sendiri. Ia boleh tunggu kelulusan seseorang. Susun deploy yang dikawal ini.

<Interactive name="OrderList" items={['Job deploy bermula, kemudian menunggu', 'Penyemak semak dan luluskan', 'Job dapat rahsia production', 'Laman baru dah live']} label="Langkah pertama di atas" success="Ya! Tiada kelulusan, tiada rahsia, tiada deploy." />
</Card>

<Card id="deeper" type="deeper">
Rahsia ada tiga peringkat: organisasi, repo dan environment. Rahsia environment hanya sampai kepada job yang guna environment itu. Peraturan environment boleh hadkan deploy kepada `main` sahaja. Pada pelan percuma GitHub, environment hanya berfungsi dalam repo awam.
</Card>
