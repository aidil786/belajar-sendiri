**<Term id="matrix">Matrix</Term>** ialah satu resipi job dan satu senarai. GitHub jalankan satu salinan untuk setiap item. `${{ matrix.node }}` ialah item untuk salinan itu.

**<Term id="cache">Cache</Term>** ialah almari dapur. Larian pertama membeli dan menyimpan. Larian seterusnya ambil dari rak. `cache: npm` dalam setup-node hidupkannya.
</Card>

<Card id="see-artifact" type="see">
<Interactive name="SpotLines" lines={[{ text: '- uses: actions/upload-artifact@v7' }, { text: '  with:' }, { text: '    name: site' }, { text: '    path: dist/', target: true }]} prompt="Ketik baris yang beritahu folder mana nak disimpan." success="Betul! Semua dalam dist/ masuk ke dalam bekas." />

**<Term id="artifact">Artifact</Term>** (artifak) ialah bekas bungkus. Job masukkan fail ke dalamnya. Selepas larian, anda boleh muat turun fail itu. Secara lalai, GitHub simpan 90 hari.
</Card>

<Card id="deeper" type="deeper">
Bila satu job matrix gagal, GitHub batalkan yang lain. Tetapkan `fail-fast: false` untuk lihat setiap keputusan. Untuk folder lain, `actions/cache@v6` ambil `path` dan `key`. GitHub buang entri cache yang tiada siapa guna selama 7 hari.
</Card>
