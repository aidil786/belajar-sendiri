<Card id="see-call" type="see">
Write the recipe once, in one shared repo. Other workflows call it. That is a **<Term id="reusable-workflow">reusable workflow</Term>**. Which trigger makes it callable?

<Interactive name="Choice" compact options={[{ label: '`workflow_call`', correct: true, why: 'Call me! It turns the file into a recipe others can use.' }, { label: '`workflow_dispatch`', why: 'That adds a Run button for people. Workflows need workflow_call.' }, { label: '`push`', why: 'push runs on new commits. Nobody can call it.' }]} />
</Card>

<Card id="see-use" type="see">
<Interactive name="SpotLines" lines={[{ text: 'on: push' }, { text: 'jobs:' }, { text: '  test:' }, { text: '    uses: aina-codes/shared/.github/workflows/test.yml@v1', target: true }, { text: '    with:' }, { text: '      node-version: 24' }]} prompt="Tap the line that calls the shared workflow." success="Yes! The job points at the recipe, then lets it cook." />

To call it, a job says `uses:` with the file's path. It goes in a **job**, not a step. The caller job has no `runs-on` and no steps.
</Card>

<Card id="deeper" type="deeper">
A composite action is a smaller cousin. It bundles steps, and you use it as a step. A reusable workflow bundles whole jobs. Its file must sit right in `.github/workflows/`, not in a subfolder. In the same repo, call it as `./.github/workflows/test.yml`.
</Card>
