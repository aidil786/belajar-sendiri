<Card id="deeper" type="deeper">
`interval` boleh jadi daily, weekly, monthly dan lain-lain. Version update tengok branch lalai anda. Terlalu banyak PR kecil? `groups:` himpunkan banyak kemas kini dalam satu PR. PR Dependabot jalankan CI anda, sama macam PR kawan sepasukan.
</Card>
