<Card id="deeper" type="deeper">
Text from strangers, like a PR title, can sneak commands into `run:`. Put it in `env:` first, then use `"$TITLE"` in the script. `persist-credentials: false` on checkout keeps the key out of the repo's Git config. This course's own workflow does that.
</Card>
