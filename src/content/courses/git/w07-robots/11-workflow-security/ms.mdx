<Card id="deeper" type="deeper">
Teks dari orang asing, contohnya tajuk PR, boleh selitkan arahan ke dalam `run:`. Letak dalam `env:` dulu, kemudian guna `"$TITLE"` dalam skrip. `persist-credentials: false` pada checkout simpan kunci itu di luar config Git repo. Workflow kursus ini sendiri buat begitu.
</Card>
