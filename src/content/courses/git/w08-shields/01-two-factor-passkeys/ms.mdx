**<Term id="two-factor">2FA</Term>** (pengesahan dua faktor) minta dua bukti. Mula-mula kata laluan anda. Kemudian kod atau ketukan dari benda milik anda.
</Card>

<Hint>Tanya diri: saya ingat benda ini, atau saya pegang benda ini?</Hint>

<Card id="see-passkey" type="see">
**<Term id="passkey">Passkey</Term>** (kunci tanpa kata laluan) tinggal dalam peranti anda. Contohnya telefon, laptop atau pengurus kata laluan. Anda buka dengan muka, cap jari atau PIN. Tiada kata laluan untuk ditaip. Satu langkah, dan ia dikira sebagai 2FA juga.
</Card>

GitHub wajibkan 2FA untuk sesiapa yang menyumbang kod di github.com. Hilang telefon dan kod pemulihan sekali? GitHub Support tak boleh bawa anda masuk semula. Jadi jaga kod itu baik-baik. Passkey boleh diselaraskan ke semua peranti anda. Atau ia kekal dalam satu kunci keselamatan.
