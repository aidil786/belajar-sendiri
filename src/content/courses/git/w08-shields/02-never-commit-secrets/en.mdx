<Card id="deeper" type="deeper">
A `.env.example` file lists the key names with empty values, like `API_KEY=`. Teammates copy it to `.env` and add their own keys. Ignore `.env` before your very first commit. Then a careless `git add .` can never grab it.

</Card>
