**<Term id="secret">Rahsia</Term>** (secret) macam kunci rumah. Kunci API, kata laluan dan token semuanya rahsia. `git add .` ambil semua benda, rahsia sekali.
</Card>

<Card id="see-ignore" type="see">
<Interactive name="TermReplay" scenario="w08-l02" commands={['echo ".env" >> .gitignore', 'git status -s']} label="Baris .env ditambah ke .gitignore. Sekarang git status -s senaraikan .gitignore dan app.js. .env dah hilang dari senarai." />

Tambah satu baris dalam **<Term id="gitignore">.gitignore</Term>** anda. Sekarang Git buat-buat `.env` tak wujud. Dua anak panah, `>>`, tambah satu baris dan kekalkan baris lama.
</Card>

<Card id="check-code" type="check">

<Interactive name="SwipeJudge" prose cards={[{ text: '`const key = process.env.API_KEY;`', good: true, why: 'Ia baca kunci dari .env. <Card id="win" type="win">
Kini anda boleh jauhkan rahsia dari commit anda.
</Card>

<Card id="deeper" type="deeper">
Fail `.env.example` senaraikan nama kunci dengan nilai kosong, contohnya `API_KEY=`. Rakan sepasukan salin ke `.env` dan isi kunci sendiri. Abaikan `.env` sebelum commit pertama anda. Jadi `git add .` yang cuai tak akan dapat menangkapnya.
