<Card id="see-scanning" type="see">
GitHub has a guard called **<Term id="secret-scanning">secret scanning</Term>**. It reads your repo, old commits too, looking for keys. Found one? It raises an alert, so you can act. Public repos get it for free.
</Card>

<Card id="see-push-protection" type="see">
**<Term id="push-protection">Push protection</Term>** checks your push before it lands. Spots a key? GitHub blocks the push and shows where the key is. The secret never reaches the repo.
</Card>

<Card id="win" type="win">
You can now let GitHub's guards catch leaked keys for you.
</Card>

<Card id="deeper" type="deeper">
Some services team up with GitHub. If their key leaks in a public repo, GitHub tells them. They can cancel the key fast. Your own pushes to public repos get push protection by default. Tools like gitleaks can even check before you commit.
</Card>
