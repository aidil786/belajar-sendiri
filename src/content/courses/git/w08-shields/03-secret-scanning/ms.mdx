<Card id="see-push-protection" type="see">
**<Term id="push-protection">Push protection</Term>** (perlindungan push) semak push anda sebelum ia sampai. Nampak kunci? GitHub sekat push itu dan tunjuk di mana kunci itu. Rahsia tak pernah sampai ke repo.
</Card>

<Card id="deeper" type="deeper">
Sesetengah servis bekerjasama dengan GitHub. Jika kunci mereka bocor dalam repo awam, GitHub beritahu mereka. Mereka boleh batalkan kunci itu dengan cepat. Push anda ke repo awam dapat push protection secara lalai. Alat seperti gitleaks boleh semak sebelum anda commit lagi.
</Card>
