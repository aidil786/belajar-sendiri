<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w08-l05" commands={['cat package.json']} label="package.json lists two packages your diary uses: example-date-lib 1.0.0 and example-weather-lib 2.4.1." />

Your diary uses packages other people wrote. One day, one of them gets a security hole. Would you even know?
</Card>

<Card id="see-dependabot" type="see">
**<Term id="dependabot">Dependabot</Term>** is GitHub's helper robot. It checks your <Term id="dependency">dependencies</Term> against a big list of known holes. Finds a match? You get an alert.
</Card>

<Card id="try-spot" type="try">
Here is an alert. Tap the line that tells you the fix.

<Interactive name="SpotLines" lines={[{ text: 'Alert: example-date-lib' }, { text: 'How bad: High' }, { text: 'Your version: 1.0.0' }, { text: 'Fixed in: 1.0.3', target: true }, { text: 'Found in: package.json' }]} prompt="Tap the line that tells you the fix." success="Yes! Move to 1.0.3 or newer, and the hole is gone." />
</Card>

<Card id="see-update" type="see">
Dependabot can even do the fix. A **security update** is a pull request it opens for you. It moves the package to the fixed version. You check it, then merge.
</Card>

<Card id="try-order" type="try">
An alert arrives. Put your steps in order, first at the top.

<Interactive name="OrderList" items={['Read the alert: which package, how bad', 'Open the update pull request', 'Check that your tests still pass', 'Merge it to close the hole']} label="First step at the top" success="Calm and in order. That's how pros do it." />
</Card>

<Card id="predict" type="predict">
The alert says the fix is in 1.0.3. Which version should you move to?

<Interactive name="Choice" options={[{ label: '1.0.3 or a later one', correct: true, why: 'The fixed version, or a newer one.' }, { label: '0.9.0', why: 'Older versions most likely still have the hole.' }, { label: 'Stay on 1.0.0 for now', why: 'The hole stays open while you wait.' }]} />
</Card>

<Card id="win" type="win">
You can now act on a Dependabot alert.
</Card>

<Card id="deeper" type="deeper">
Alerts come from the GitHub Advisory Database. It is a big public list of known <Term id="vulnerability">vulnerabilities</Term>. Dependabot watches your default branch. Version updates are different: they keep packages fresh, holes or not. World 7 shows those.
</Card>
