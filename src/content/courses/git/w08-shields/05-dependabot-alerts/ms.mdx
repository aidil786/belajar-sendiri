Diari anda guna pakej tulisan orang lain. Satu hari, salah satunya ada lubang keselamatan. Adakah anda akan tahu?

<Card id="see-dependabot" type="see">
**<Term id="dependabot">Dependabot</Term>** ialah robot pembantu GitHub. Ia semak <Term id="dependency">dependency</Term> (pakej yang anda guna). Ia cari padanan dalam senarai besar lubang yang diketahui. Ada padanan? Anda dapat amaran.
</Card>

<Card id="try-spot" type="try">
Ini satu amaran. Ketik baris yang beritahu cara baikinya.

<Interactive name="SpotLines" lines={[{ text: 'Amaran: example-date-lib' }, { text: 'Tahap bahaya: Tinggi' }, { text: 'Versi anda: 1.0.0' }, { text: 'Dibaiki dalam: 1.0.3', target: true }, { text: 'Dijumpai dalam: package.json' }]} prompt="Ketik baris yang beritahu cara baikinya." success="Ya! Tukar ke 1.0.3 atau lebih baru, dan lubang itu hilang." />
</Card>

<Card id="see-update" type="see">
Dependabot boleh baiki untuk anda juga. Ia buka pull request bernama **security update** (kemas kini keselamatan). Ia tukar pakej ke versi yang dah dibaiki. Anda semak, kemudian merge.
</Card>

<Card id="try-order" type="try">
Satu amaran sampai. Susun langkah anda, yang pertama di atas.

<Interactive name="OrderList" items={['Baca amaran: pakej mana, seteruk mana', 'Buka pull request kemas kini itu', 'Semak ujian anda masih lulus', 'Merge untuk tutup lubang itu']} label="Langkah pertama di atas" success="Tenang dan teratur. Begitulah cara pakar buat." />
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: '1.0.3 atau yang lebih baru', correct: true, why: 'Versi yang dah dibaiki, atau yang lebih baru.' }, { label: '0.9.0', why: 'Versi lebih lama berkemungkinan besar masih ada lubang itu.' }, { label: 'Kekal di 1.0.0 dulu', why: 'Lubang itu terus terbuka selama anda tunggu.' }]} />

<Card id="deeper" type="deeper">
Amaran datang dari GitHub Advisory Database. Itu senarai awam yang besar tentang <Term id="vulnerability">kelemahan keselamatan</Term>. Dependabot jaga branch lalai anda. Version updates pula lain. Ia pastikan pakej sentiasa baru, ada lubang atau tidak. Dunia 7 tunjuk yang itu.
</Card>
