<Card id="hook" type="hook">
Laman log masuk anda berfungsi. Ujian pun lulus. Tapi satu baris benarkan penipu baca data setiap pengguna. Bolehkah anda jumpa baris itu dalam 500 fail?
</Card>

<Card id="see-codeql" type="see">
**<Term id="codeql">CodeQL</Term>** ialah detektif kod dari GitHub. Ia jadikan kod anda sebagai data. Kemudian ia tanya soalan. Contohnya: "bolehkah teks yang ditaip sampai ke pangkalan data?"
</Card>

<Card id="try-spot" type="try">
Jadi detektif. Ketik baris yang lekatkan teks ditaip terus ke soalan pangkalan data.

<Interactive name="SpotLines" lines={[{ text: 'const name = form.name;' }, { text: 'db.ask("name = " + name);', target: true }, { text: 'db.ask("name = ?", [name]);' }, { text: 'showWelcome(name);' }]} prompt="Ketik baris yang lekatkan teks ditaip ke dalam query." success="Jumpa! Baris dengan ? ialah cara selamat. CodeQL memburu jenis yang berisiko." />

<Hint>Cari tanda + yang lekatkan nama itu pada soalan.</Hint>
</Card>

<Card id="see-scanning" type="see">
CodeQL berjalan sebagai **<Term id="code-scanning">code scanning</Term>** (imbasan kod). Hidupkan, dan GitHub Actions semak kod anda setiap push dan pull request. Masalah muncul sebagai amaran pada baris yang tepat.
</Card>

Kini anda boleh biar CodeQL memburu kod berisiko.
</Card>

<Card id="deeper" type="deeper">
Pepijat dalam kad detektif tadi dipanggil SQL injection. CodeQL faham banyak bahasa, contohnya JavaScript, Python, Java, Go, C# dan Ruby. Default setup pilih tetapan untuk anda. Advanced setup tambah fail workflow yang anda boleh ubah.
</Card>
