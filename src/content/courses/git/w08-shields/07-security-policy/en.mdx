<Card id="hook" type="hook">
You find a bug in a popular project. It leaks passwords. Do you post it in a public issue? Attackers read issues too.
</Card>

<Card id="see-policy" type="see">
<Interactive name="TermReplay" scenario="w08-l07-policy" commands={['cat SECURITY.md']} label="cat SECURITY.md shows a short policy: please do not open a public issue; use private vulnerability reporting; we will reply within 7 days." />

A **<Term id="security-policy">SECURITY.md</Term>** file tells people how to report security bugs privately. It's like a README, just for security.
</Card>

<Card id="try-write" type="try">
Give your diary a security policy. Write `SECURITY.md`, then commit it.

<Interactive name="Sim" scenario="w08-l07" panels={['areas']} goal={{ lastCommitHas: ['SECURITY.md'], clean: true }} hints={['Write the file: echo "Report bugs privately" > SECURITY.md', 'Put it in the box: git add SECURITY.md', 'Save it: git commit -m "Add security policy"']} success="Your repo now tells people how to report bugs safely." />

<Hint>Start with `echo "Report bugs privately" > SECURITY.md`.</Hint>
</Card>

<Card id="see-advisory" type="see">
A report comes in. Now the maintainers open a **<Term id="security-advisory">security advisory</Term>**. It's a private room. They talk, fix the bug, then publish a warning for everyone.
</Card>

<Card id="try-order" type="try">
Put the safe way to handle a security bug in order. First at the top.

<Interactive name="OrderList" items={['Someone reports the bug privately', 'Maintainers open a draft advisory', 'They fix it in private', 'They release the fixed version', 'They publish the advisory']} label="First step at the top" success="Fix first, tell everyone after. That's called coordinated disclosure." />
</Card>

</Card>

<Card id="deeper" type="deeper">
Repo owners can turn on private vulnerability reporting. Then anyone can report straight into a draft advisory. Maintainers can fix the bug in a temporary private fork. They can also ask GitHub for a CVE id. That's a worldwide name for the bug.
</Card>
