</Card>

Fail **<Term id="security-policy">SECURITY.md</Term>** (dasar keselamatan) beritahu cara melaporkan pepijat keselamatan secara sulit. Ia macam README, tapi khas untuk keselamatan.
</Card>

<Card id="try-write" type="try">
Beri diari anda dasar keselamatan. Tulis `SECURITY.md`, kemudian commit.

<Interactive name="Sim" scenario="w08-l07" panels={['areas']} goal={{ lastCommitHas: ['SECURITY.md'], clean: true }} hints={['Tulis fail itu: echo "Report bugs privately" > SECURITY.md', 'Masukkan ke dalam kotak: git add SECURITY.md', 'Simpan: git commit -m "Add security policy"']} success="Repo anda kini beritahu cara melaporkan pepijat dengan selamat." />

<Hint>Mula dengan `echo "Report bugs privately" > SECURITY.md`.</Hint>
</Card>

<Card id="see-advisory" type="see">
Satu laporan sampai. Kini penyelenggara buka **<Term id="security-advisory">security advisory</Term>** (nasihat keselamatan). Ia macam bilik sulit. Mereka berbincang, baiki pepijat, kemudian terbitkan amaran untuk semua.
</Card>

<Card id="try-order" type="try">
Susun cara selamat untuk urus pepijat keselamatan. Yang pertama di atas.

<Interactive name="OrderList" items={['Seseorang laporkan pepijat secara sulit', 'Penyelenggara buka draf advisory', 'Mereka baiki secara sulit', 'Mereka keluarkan versi yang dibaiki', 'Mereka terbitkan advisory itu']} label="Langkah pertama di atas" success="Baiki dulu, beritahu semua kemudian. </Card>

<Card id="win" type="win">
Kini anda boleh urus pepijat keselamatan dengan cara selamat.
</Card>

<Card id="deeper" type="deeper">
Pemilik repo boleh hidupkan private vulnerability reporting. Kemudian sesiapa pun boleh lapor terus ke dalam draf advisory. Penyelenggara boleh baiki pepijat dalam fork sulit sementara. Mereka juga boleh minta id CVE dari GitHub. Itu nama sedunia untuk pepijat itu.
</Card>
