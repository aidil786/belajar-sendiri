<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w08-l08" commands={['git config --global user.name "Siti"', 'git commit -m "Add footer"', 'git log -n 1']} label="One config command sets the name to Siti. The new commit says Author: Siti, even though anyone could have typed it." />

Git trusts any name you type. Anyone can make commits that say "Siti". So how can people trust a commit is really yours?
</Card>

<Card id="see-signed" type="see">
A **<Term id="signed-commit">signed commit</Term>** carries your digital signature. Only your private key can make it. GitHub checks it with your public key, like a key in its lock.
</Card>

<Card id="see-verified" type="see">
Signature checks out? GitHub shows a **<Term id="verified-badge">Verified</Term>** badge next to the commit. Signed, but GitHub can't check it? It says Unverified. Not signed? No badge at all.
</Card>

<Card id="try-build" type="try">
Git can sign with an SSH key, like your key from World 4. Build the setting that picks SSH.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Talk to Git' }, { text: 'config', means: 'change a setting' }, { text: '--global', means: 'for all your projects' }, { text: 'gpg.format', means: 'which kind of key signs' }, { text: 'ssh', means: 'use an SSH key' }]} decoys={[{ text: 'openpgp', means: 'use a GPG key (the default)' }, { text: 'user.name', means: 'your name' }]} success="Yes! Git will now sign with SSH." />
</Card>

<Card id="try-sim" type="try">
Now set up signing here. You need three settings: the format, your key, and "sign every commit".

<Interactive name="Sim" scenario="w08-l08" panels={[]} prefill="git config --global gpg.format ssh" goal={{ config: { 'gpg.format': 'ssh', 'commit.gpgsign': 'true' }, configSet: ['user.signingkey'] }} hints={['Press Enter to run the first setting.', 'Your key: git config --global user.signingkey ~/.ssh/id_ed25519.pub', 'Sign every commit: git config --global commit.gpgsign true']} success="Done! Every new commit will carry your signature." />

<Hint>Point `user.signingkey` at your public key, the file that ends in `.pub`.</Hint>
</Card>

<Card id="deeper" type="deeper">
GPG keys work too. That's the default format, `openpgp`. SSH signing needs Git 2.34 or newer. Turn on vigilant mode, and your unsigned commits show as Unverified. `git log --show-signature` shows signatures on your computer. For SSH, Git first needs `gpg.ssh.allowedSignersFile`.
</Card>
