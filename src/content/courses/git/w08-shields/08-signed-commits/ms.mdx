<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w08-l08" commands={['git config --global user.name "Siti"', 'git commit -m "Add footer"', 'git log -n 1']} label="Satu arahan config tukar nama kepada Siti. Commit baru tulis Author: Siti, walaupun sesiapa pun boleh taip begitu." />

Git percaya apa saja nama yang anda taip. Sesiapa pun boleh buat commit yang tulis "Siti". Jadi macam mana orang nak percaya commit itu betul-betul anda punya?
</Card>

<Card id="see-signed" type="see">
**<Term id="signed-commit">Commit bertandatangan</Term>** (signed commit) bawa tandatangan digital anda. Hanya kunci peribadi anda boleh buat tandatangan itu. GitHub semak dengan kunci awam anda, macam padankan kunci dengan mangganya.
</Card>

<Card id="see-verified" type="see">
Tandatangan sah? GitHub tunjuk lencana **<Term id="verified-badge">Verified</Term>** di sebelah commit itu. Bertandatangan, tapi GitHub tak dapat semak? Ia tulis Unverified. Tak bertandatangan? Tiada lencana langsung.
</Card>

<Card id="try-build" type="try">
Git boleh tandatangan dengan kunci SSH, macam kunci anda dari Dunia 4. Bina tetapan yang pilih SSH.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Bercakap dengan Git' }, { text: 'config', means: 'ubah tetapan' }, { text: '--global', means: 'untuk semua projek anda' }, { text: 'gpg.format', means: 'jenis kunci yang menandatangani' }, { text: 'ssh', means: 'guna kunci SSH' }]} decoys={[{ text: 'openpgp', means: 'guna kunci GPG (lalai)' }, { text: 'user.name', means: 'nama anda' }]} success="Ya! Git akan tandatangan dengan SSH sekarang." />
</Card>

<Card id="try-sim" type="try">
Sekarang sediakan tandatangan di sini. Anda perlu tiga tetapan: format, kunci anda, dan "tandatangan setiap commit".

<Interactive name="Sim" scenario="w08-l08" panels={[]} prefill="git config --global gpg.format ssh" goal={{ config: { 'gpg.format': 'ssh', 'commit.gpgsign': 'true' }, configSet: ['user.signingkey'] }} hints={['Tekan Enter untuk jalankan tetapan pertama.', 'Kunci anda: git config --global user.signingkey ~/.ssh/id_ed25519.pub', 'Tandatangan setiap commit: git config --global commit.gpgsign true']} success="Siap! Setiap commit baru akan bawa tandatangan anda." />

<Hint>Halakan `user.signingkey` kepada kunci awam anda, fail yang berakhir dengan `.pub`.</Hint>
</Card>

<Card id="deeper" type="deeper">
Kunci GPG pun boleh. Itu format lalai, `openpgp`. Tandatangan SSH perlukan Git 2.34 atau lebih baru. Hidupkan vigilant mode, dan commit anda yang tak bertandatangan akan tunjuk Unverified. `git log --show-signature` tunjuk tandatangan di komputer anda. Untuk SSH, Git perlukan `gpg.ssh.allowedSignersFile` dulu.
</Card>
