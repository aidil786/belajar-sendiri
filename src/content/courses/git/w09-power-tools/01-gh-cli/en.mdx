<Card id="deeper" type="deeper">
`gh browse` opens the current repo in your browser. `gh repo fork --clone` makes a fork and copies it in one go. `gh api` can ask GitHub for almost anything. Get gh from cli.github.com. It works on Windows, macOS and Linux.
</Card>
