<Card id="deeper" type="deeper">
`gh browse` buka repo semasa dalam pelayar anda. `gh repo fork --clone` buat fork dan salin ke komputer sekali gus. `gh api` boleh tanya GitHub hampir apa sahaja. Dapatkan gh dari cli.github.com. Ia berfungsi di Windows, macOS dan Linux.
</Card>
