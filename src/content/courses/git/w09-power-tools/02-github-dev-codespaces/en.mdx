<Card id="see-codespace" type="see">
<Interactive name="Transcript" title="bash" label="Two commands. gh codespace create makes a Codespace for the diary repo. gh codespace code --web opens it in the browser." lines={[{ cmd: 'gh codespace create --repo aina-codes/diary' }, { cmd: 'gh codespace code --web' }]} />

github.dev has no terminal, so it can't run code. Need that? Open a **<Term id="codespace">Codespace</Term>**: a cloud computer, set up for your repo. It needs a GitHub account and has usage limits.
</Card>

<Card id="deeper" type="deeper">
Press `>` instead of `.` to open github.dev in a new tab. Or change github.com to github.dev in the address bar. A Codespace can set itself up from a dev container file. Idle Codespaces stop by themselves after a while.
</Card>
