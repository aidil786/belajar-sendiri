<Card id="see-codespace" type="see">
<Interactive name="Transcript" title="bash" label="Dua arahan. gh codespace create buat Codespace untuk repo diary. gh codespace code --web buka Codespace itu dalam pelayar." lines={[{ cmd: 'gh codespace create --repo aina-codes/diary' }, { cmd: 'gh codespace code --web' }]} />

github.dev tiada terminal, jadi ia tak boleh jalankan kod. Perlukan itu? Buka **<Term id="codespace">Codespace</Term>**: komputer di awan yang siap untuk repo anda. Ia perlukan akaun GitHub dan ada had penggunaan.
</Card>

<Card id="deeper" type="deeper">
Tekan `>` dan bukan `.` untuk buka github.dev dalam tab baru. Atau tukar github.com kepada github.dev di bar alamat. Codespace boleh siapkan dirinya dari fail dev container dalam repo anda. Codespace yang terbiar akan berhenti sendiri selepas beberapa ketika.
</Card>
