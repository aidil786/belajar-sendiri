<Card id="see-pages" type="see">
<Interactive name="TimelineTap" events={[{ when: 'Step 1', title: 'You push', text: 'Your HTML, CSS and JavaScript land on GitHub.' }, { when: 'Step 2', title: 'Pages publishes', text: 'GitHub turns those files into a website.' }, { when: 'Step 3', title: 'It is live', text: 'Anyone with the link can open it.' }]} />

**<Term id="github-pages">GitHub Pages</Term>** turns files in your repo into a website. It hosts plain files only: HTML, CSS and JavaScript. No server code, no database.
</Card>

<Card id="try-order" type="try">
Switch Pages on. Put the steps in order.

<Interactive name="OrderList" items={['Open your repo on GitHub', 'Go to Settings, then Pages', 'Pick Deploy from a branch', 'Choose main and the root folder', 'Click Save, then wait a few minutes']} label="First step at the top" success="That's how! Every push to main now updates the site." />

<Hint>You can't pick a branch before you open the Pages settings.</Hint>
</Card>

<Card id="deeper" type="deeper">
Name a repo `your-name.github.io`, and it becomes your main site, at the root. Pages looks for `index.html`, `index.md` or `README.md` first. You can also publish with a GitHub Actions workflow. Custom domains work too. Changes can take up to 10 minutes to show.
</Card>
