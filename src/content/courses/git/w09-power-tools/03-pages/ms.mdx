Namakan repo `nama-anda.github.io`, dan ia jadi laman utama anda, di akar. Pages cari `index.html`, `index.md` atau `README.md` dulu. Anda juga boleh terbitkan dengan workflow GitHub Actions. Domain sendiri pun boleh. Perubahan boleh ambil masa sehingga 10 minit untuk muncul.
