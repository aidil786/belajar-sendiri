GitHub Desktop ialah perisian sumber terbuka. Ia juga boleh tunjuk diff dan checkout pull request. Tetap belajar arahannya. Pelayan dan terminal Codespace tiada butang. Bila aplikasi tunjuk ralat, arahan di sebaliknya bantu anda faham.
