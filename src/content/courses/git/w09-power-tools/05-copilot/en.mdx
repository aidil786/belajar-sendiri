<Card id="deeper" type="deeper">
Copilot changes fast. Check docs.github.com for what you can use today. Your school or company may switch some parts off. Copilot can also review a pull request when asked. By default, its review does not count as an approval. Look at `wordCount("")` in that pull request. It returns 1, not 0. A test would catch that!
</Card>
