<Card id="deeper" type="deeper">
Copilot cepat berubah. Semak docs.github.com untuk apa yang anda boleh guna hari ini. Sekolah atau syarikat anda mungkin matikan sesetengah bahagian. Copilot juga boleh semak pull request bila diminta. Secara lalai, semakannya tak dikira sebagai kelulusan. Tengok `wordCount("")` dalam pull request tadi. Ia pulangkan 1, bukan 0. Ujian akan tangkap itu!
