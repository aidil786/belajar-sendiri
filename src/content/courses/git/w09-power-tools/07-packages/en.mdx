A **<Term id="package">package</Term>** is code with a name and a version. It sits on a <Term id="registry">registry</Term>, like a shop shelf. GitHub Packages is a shelf on GitHub, right next to your code.
</Card>

<Card id="deeper" type="deeper">
On GitHub Packages, npm names need your scope, like `@aina-codes`. You also tell npm to use GitHub's registry. Container images live at `ghcr.io`. Publishing from your laptop needs a personal access token (classic). In Actions, `GITHUB_TOKEN` works. Public packages are free.
</Card>
