**<Term id="package">Pakej</Term>** (package) ialah kod dengan nama dan versi. Ia duduk di <Term id="registry">registry</Term>, macam rak kedai. GitHub Packages ialah rak di GitHub, betul-betul di sebelah kod anda.
</Card>

<Card id="deeper" type="deeper">
Di GitHub Packages, nama npm perlukan skop anda, contohnya `@aina-codes`. Anda juga perlu suruh npm guna registry GitHub. Imej container tinggal di `ghcr.io`. Terbitkan dari laptop perlukan personal access token (classic). Dalam Actions, `GITHUB_TOKEN` boleh digunakan. Pakej awam adalah percuma.
</Card>
