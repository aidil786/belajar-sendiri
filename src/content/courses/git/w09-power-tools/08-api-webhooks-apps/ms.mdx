**<Term id="api">API</Term>** ialah kaunter khas untuk program. Program tanya satu soalan. GitHub jawab dengan data. `gh api` biar anda bertanya dari terminal.

**<Term id="webhook">Webhook</Term>** ialah loceng pintu. Bila sesuatu berlaku, GitHub panggil alamat web anda. Tiada siapa perlu asyik bertanya.
</Card>

<Card id="see-app" type="see">
**<Term id="github-app">GitHub App</Term>** ialah pembantu robot. Anda pasang ia pada repo pilihan anda. Sebelum pasang, anda nampak apa yang ia boleh buat. Bot yang label issue atau semak pull request selalunya App.
</Card>

<Card id="deeper" type="deeper">
GitHub ada REST API dan GraphQL API. Anda boleh baca data awam tanpa log masuk, tapi hadnya lebih rendah. Semakan misi Belajar Sendiri buat begitu. Webhook boleh dipasang pada repo, organisasi atau App. App guna token jangka pendek, jadi kebocoran kurang memudaratkan.
</Card>
