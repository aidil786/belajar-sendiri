**<Term id="code-search">Code search</Term>** looks through code across GitHub. Type in the search box at the top of any page. Sign in first: code search needs an account. Then add filters to zoom in.

<Card id="deeper" type="deeper">
Only the default branch is searched. Put a regex between slashes: `/fetch.*Weather/`. Use NOT to skip things: `log4j NOT is:fork`. In the terminal, `gh search code` works too. But it uses GitHub's older search engine, so results can differ.
</Card>
