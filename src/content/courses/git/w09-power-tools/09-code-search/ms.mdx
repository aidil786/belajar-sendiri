Hanya branch lalai yang dicari. Letak regex di antara garis condong: `/fetch.*Weather/`. Guna NOT untuk langkau sesuatu: `log4j NOT is:fork`. Dalam terminal, `gh search code` pun boleh. Tapi ia guna enjin carian GitHub yang lama, jadi hasilnya mungkin berbeza.
