<Card id="deeper" type="deeper">
Happy with it? Merge from the terminal with `gh pr merge`. Once your work is pushed, `gh codespace delete` removes the Codespace. No Codespace? Press `.` on your repo for github.dev. Commit to a new branch there. Then open the pull request in the browser.
</Card>
