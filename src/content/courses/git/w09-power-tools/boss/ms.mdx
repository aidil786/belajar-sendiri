<Card id="deeper" type="deeper">
Puas hati? Merge dari terminal dengan `gh pr merge`. Bila semua kerja dah di-push, `gh codespace delete` buang Codespace itu. Tiada Codespace? Tekan `.` pada repo anda untuk github.dev. Commit ke branch baru di sana, kemudian buka pull request dalam pelayar.
</Card>
