<Card id="hook" type="hook">
Your shop has 3 commits. `style.css` never changed. Does Git store it 3 times?

<Interactive name="Choice" options={[{ label: 'No. Same content is kept once', correct: true, why: 'Git names content by a fingerprint. Same content, same name, one copy.' }, { label: 'Yes, one copy per commit', why: 'That would waste space. Git shares content that did not change.' }, { label: 'Git keeps only the newest copy', why: 'Git keeps every version you commit. It just never stores one twice.' }]} />
</Card>

<Card id="see-commit" type="see">
<Interactive name="TermReplay" scenario="w10-objects" commands={['git cat-file -p HEAD']} label="git cat-file -p HEAD prints the newest commit: a tree id, a parent id, the author, the committer and the message Add opening hours." />

Git keeps everything as **<Term id="object">objects</Term>**. `git cat-file -p HEAD` opens the newest commit. It points to a <Term id="tree">tree</Term> (the files). Its parent is the commit before.
</Card>

<Interactive name="SortCards" buckets={[{ id: 'blob', label: 'blob' }, { id: 'tree', label: 'tree' }, { id: 'commit', label: 'commit' }]} items={[{ label: 'The text inside index.html', bucket: 'blob', why: 'A blob is pure content. </Card>

<Card id="see-hash" type="see">
<Interactive name="TermReplay" scenario="w10-objects" commands={['git rev-parse HEAD', 'git log --oneline -1']} label="git rev-parse HEAD prints the full 40-character id 9e8ddf8fb3a185e7920bc21542abe85b09f07e21. git log --oneline -1 shows the short id 9e8ddf8 and Add opening hours." />

Each object's name is a **<Term id="sha-1">SHA-1</Term>** <Term id="hash">hash</Term>. It has 40 characters, made from the content. The short id is just the start.
</Card>

<Card id="deeper" type="deeper">
Annotated tags (`git tag -a`) are objects. Lightweight tags are only refs. Git compresses each object and keeps it in `.git/objects`. `git cat-file -t` prints an object's type. `git cat-file -s` prints its size. Git 3.0 plans SHA-256 ids for new repos.

<Interactive name="TermReplay" scenario="w10-objects" commands={['git cat-file -t HEAD', 'git cat-file -t HEAD^{tree}', 'git cat-file -t v1.0']} label="cat-file -t prints commit for HEAD, tree for HEAD's tree, and tag for v1.0." />
</Card>
