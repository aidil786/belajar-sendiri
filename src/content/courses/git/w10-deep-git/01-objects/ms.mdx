<Card id="see-commit" type="see">
<Interactive name="TermReplay" scenario="w10-objects" commands={['git cat-file -p HEAD']} label="git cat-file -p HEAD cetak commit terbaru: id tree, id parent, pengarang, committer dan mesej Add opening hours." />

Git simpan semuanya sebagai **<Term id="object">objek</Term>** (object). `git cat-file -p HEAD` buka commit terbaru. Ia tunjuk ke satu <Term id="tree">tree</Term> (senarai fail) dan satu parent (commit sebelumnya).
</Card>

<Card id="see-hash" type="see">
<Interactive name="TermReplay" scenario="w10-objects" commands={['git rev-parse HEAD', 'git log --oneline -1']} label="git rev-parse HEAD cetak id penuh 40 aksara 9e8ddf8fb3a185e7920bc21542abe85b09f07e21. git log --oneline -1 tunjuk id pendek 9e8ddf8 dan Add opening hours." />

Nama setiap objek ialah <Term id="hash">hash</Term> **<Term id="sha-1">SHA-1</Term>**. Ia ada 40 aksara, dibuat daripada isinya. Id pendek cuma permulaannya.

<Card id="deeper" type="deeper">
Tag beranotasi (`git tag -a`) ialah objek. Tag ringan cuma ref. Git mampatkan setiap objek dan simpan dalam `.git/objects`. `git cat-file -t` cetak jenis objek. `git cat-file -s` cetak saiznya. Git 3.0 merancang id SHA-256 untuk repo baru.

<Interactive name="TermReplay" scenario="w10-objects" commands={['git cat-file -t HEAD', 'git cat-file -t HEAD^{tree}', 'git cat-file -t v1.0']} label="cat-file -t cetak commit untuk HEAD, tree untuk tree HEAD, dan tag untuk v1.0." />
</Card>
