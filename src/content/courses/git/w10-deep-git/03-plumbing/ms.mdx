<Card id="see-hash-object" type="see">
<Interactive name="TermReplay" scenario="w10-plumbing" commands={['git hash-object index.html', 'git rev-parse HEAD:index.html']} label="git hash-object index.html dan git rev-parse HEAD:index.html cetak id yang sama, 6b62adb46423f92b1c925e6fdcc9ec947097a1d4." />

`git hash-object` cetak id yang Git akan beri kepada sesuatu fail. Ia sama dengan blob yang dah ada dalam commit. Isi sama, id sama.
</Card>

<Card id="try-write" type="try">
`notes.txt` belum ada dalam Git. Simpan isinya sebagai blob, tanpa commit. Kemudian baca semula blob itu.

<Interactive name="Sim" scenario="w10-plumbing" panels={[]} goal={{ objectsWritten: ['17e284d'], lastTyped: 'cat-file -p' }} hints={['Tambah -w untuk simpan: git hash-object -w notes.txt', 'Kemudian taip git cat-file -p dan id yang dicetak']} success="Disimpan dan dibaca semula! Git simpan isi itu tanpa sebarang commit." />

<Hint>Taip `git hash-object -w notes.txt`. Kemudian `git cat-file -p` dengan id yang dicetak.</Hint>
</Card>

<Card id="deeper" type="deeper">
Output porcelain mungkin berubah antara versi Git. Output plumbing kekal stabil. Perlukan status dalam skrip? `git status --porcelain` beri format yang dijanji kekal sama. `git ls-tree -r --name-only HEAD` senaraikan setiap fail dalam satu commit.
