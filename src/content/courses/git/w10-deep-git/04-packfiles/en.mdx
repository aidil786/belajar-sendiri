<Card id="deeper" type="deeper">
Packfiles live in `.git/objects/pack`. `git gc --prune=now` drops unreachable objects at once, with no grace time. `git maintenance stop` turns the background jobs off. `git maintenance run --task=gc` runs one job now. Git 3.0 removes the old `git pack-redundant` command.
</Card>
