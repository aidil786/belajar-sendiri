<Card id="see-gc" type="see">
<Interactive name="Transcript" title="bash" label="Dua arahan: git gc, kemudian git count-objects -vH." lines={[{ cmd: 'git gc' }, { cmd: 'git count-objects -vH' }]} />

`git gc` ialah **<Term id="garbage-collection">kutipan sampah</Term>** (garbage collection). Ia padatkan objek dan buang sampah yang tiada siapa boleh capai. `git count-objects -vH` tunjuk saiznya. Git juga mengemas sedikit sendiri.
</Card>

<Card id="deeper" type="deeper">
Packfile tinggal dalam `.git/objects/pack`. `git gc --prune=now` buang objek yang tak boleh dicapai serta-merta, tanpa tempoh tangguh. `git maintenance stop` matikan kerja di belakang tabir. `git maintenance run --task=gc` jalankan satu kerja sekarang. Git 3.0 buang arahan lama `git pack-redundant`.
</Card>
