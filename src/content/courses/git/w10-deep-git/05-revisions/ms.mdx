**<Term id="revision">Revision</Term>** ialah apa-apa cara untuk namakan commit. `HEAD~2` maksudnya dua langkah ke belakang dari HEAD. Setiap langkah ikut parent pertama.
</Card>

<Hint>Merge itu ada dua parent. `~` sentiasa ambil yang pertama, di main.</Hint>

<Card id="see-two-dots" type="see">
<Interactive name="TermReplay" scenario="w10-revisions" commands={['git log --oneline main..prices', 'git log --oneline prices..main']} label="main..prices senaraikan Add a price. prices..main senaraikan Add about page." />

`A..B` (dua titik) senaraikan commit dalam B yang tiada dalam A. Tukar sisinya, dan anda nampak kerja tambahan sisi lain.
</Card>

<Card id="try-three-dots" type="try">
`A...B` (tiga titik) senaraikan commit di mana-mana sisi, tapi bukan kedua-duanya. `--left-right` tandakan sisi: `<` untuk A, `>` untuk B.

<Interactive name="SpotLines" scenario="w10-revisions" commands={['git log --oneline --left-right main...prices']} targets="^>" prompt="Ketik commit yang hanya ada dalam prices." success="Ya! Tanda > ialah sisi kanan: prices." />
</Card>

<Card id="check" type="check">
Sebelum merge, anda semak apa yang `prices` akan bawa masuk ke `main`. Arahan mana?

<Interactive name="Choice" options={[{ label: '`git log main..prices`', correct: true, why: 'Commit dalam prices yang main belum ada.' }, { label: '`git log prices..main`', why: 'Itu arah sebaliknya: apa yang main ada tapi prices tiada.' }, { label: '`git log main...prices`', why: 'Tiga titik juga tunjuk commit baru di main.' }]} />
</Card>

<Card id="win" type="win">
Kini anda boleh namakan mana-mana commit tanpa salin idnya.
</Card>

<Card id="deeper" type="deeper">
`HEAD^` sama dengan `HEAD~1`. `HEAD@{1}` ialah tempat HEAD berada satu langkah tadi, daripada reflog. `v1.0^{}` ialah commit yang tag tunjuk. `git rev-parse` tukar mana-mana revision kepada id penuh. `git diff main...prices` tunjuk apa yang prices ubah sejak ia berpecah.

<Interactive name="TermReplay" scenario="w10-revisions" commands={['git rev-parse --short HEAD~2^2', 'git diff main...prices']} label="rev-parse cetak id pendek Add onde-onde. git diff main...prices tunjuk satu baris dalam menu.html dapat RM1." />
</Card>
