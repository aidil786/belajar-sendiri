<Card id="see-grep" type="see">
`git grep` searches the files Git tracks, as they are now. `-n` adds line numbers.

<Interactive name="SpotLines" scenario="w10-search" commands={['git grep -n footer']} targets="^style\.css" prompt="Tap the match inside the stylesheet." success="Yes! style.css line 1 says footer." />
</Card>

<Card id="see-blame" type="see">
<Interactive name="TermReplay" scenario="w10-search" commands={['git blame index.html']} label="git blame index.html: line 1 from You, line 2 from Aisyah, line 3 from Aisyah. Each line has a commit id and a date." />

`git blame` shows who last changed each line, and in which commit. It is for finding context, not for blaming people!
</Card>

<Card id="see-shortlog" type="see">

<Card id="deeper" type="deeper">
`git log -G "regex"` matches any changed line, not just added or removed text. `git log --author=Ben` shows one person's commits. `git log --grep=footer` searches the messages. Add `-p` to see each change. `git blame -L 2,3 file` looks at lines 2 to 3 only.

<Interactive name="TermReplay" scenario="w10-search" commands={['git log --author=Ben --oneline', 'git log --grep=footer --oneline']} label="Ben made Style the footer and Add a footer. Three commit messages mention footer." />
</Card>
