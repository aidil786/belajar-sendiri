<Card id="deeper" type="deeper">
`git log -G "regex"` padankan mana-mana baris yang berubah, bukan sekadar teks yang ditambah atau dibuang. `git log --author=Ben` tunjuk commit seorang sahaja. `git log --grep=footer` cari dalam mesej. Tambah `-p` untuk tengok setiap perubahan. `git blame -L 2,3 fail` tengok baris 2 hingga 3 sahaja.

<Interactive name="TermReplay" scenario="w10-search" commands={['git log --author=Ben --oneline', 'git log --grep=footer --oneline']} label="Ben buat Style the footer dan Add a footer. Tiga mesej commit sebut footer." />
</Card>
