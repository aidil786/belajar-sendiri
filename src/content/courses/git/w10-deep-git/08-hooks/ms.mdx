<Card id="see-moments" type="see">
**<Term id="hook">Hook</Term>** (cangkuk) ialah skrip yang Git jalankan sendiri pada saat tertentu. Hook tinggal dalam `.git/hooks`. Ketik setiap saat.

<Interactive name="TimelineTap" events={[{ when: 'Sebelum commit', title: 'pre-commit', text: 'Semak perubahan dalam kotak. Kalau gagal, tiada commit dibuat.' }, { when: 'Selepas mesej', title: 'commit-msg', text: 'Semak mesej commit. Kalau gagal, tiada commit dibuat.' }, { when: 'Sebelum push', title: 'pre-push', text: 'Semakan terakhir sebelum apa-apa keluar dari komputer anda.' }]} />
</Card>

<Card id="see-pre-commit" type="see">
<Interactive name="Transcript" title="bash" label="Hook pre-commit: kalau baris dalam kotak tambah console.log, ia cetak Please remove console.log first dan keluar dengan 1. Selepas chmod +x, git commit berhenti dengan mesej itu." lines={[{ cmd: 'cat .git/hooks/pre-commit' }, { out: '#!/bin/sh\n# Stop the commit if a staged line adds console.log\nif git diff --cached | grep -q "^+.*console.log"; then\n  echo "Please remove console.log first."\n  exit 1\nfi' }, { cmd: 'chmod +x .git/hooks/pre-commit' }, { cmd: 'git commit -m "Add menu"' }, { out: 'Please remove console.log first.', color: 'yellow' }]} />

Hook mesti boleh dilaksanakan: `chmod +x`. Kalau ia tamat dengan `exit 1`, Git hentikan commit. `exit 0` benarkan ia lalu.
</Card>

<Card id="try-order" type="try">
Susun kitaran hidup hook pre-commit.

<Interactive name="OrderList" items={['Tulis skrip dalam .git/hooks/pre-commit', 'Jadikan ia boleh dilaksanakan dengan chmod +x', 'Jalankan git commit', 'Git jalankan hook dulu', 'Hook keluar dengan 0, jadi commit dibuat']} label="Langkah pertama di atas" success="Betul! Git jalankan hook sebelum setiap commit." />
</Card>

<Card id="see-commit-msg" type="see">
<Interactive name="Transcript" title="bash" label="Hook commit-msg: kalau fail mesej tak bermula dengan feat, fix atau docs, ia cetak tip dan keluar dengan 1. git commit -m stuff berhenti dengan tip itu." lines={[{ cmd: 'cat .git/hooks/commit-msg' }, { out: '#!/bin/sh\n# $1 is the file that holds the message\nif ! grep -qE "^(feat|fix|docs): " "$1"; then\n  echo "Start the message with feat:, fix: or docs:"\n  exit 1\nfi' }, { cmd: 'git commit -m "stuff"' }, { out: 'Start the message with feat:, fix: or docs:', color: 'yellow' }]} />

Hook `commit-msg` semak mesej. Git beri fail mesej kepadanya sebagai `$1`. Di sini, "stuff" tak lepas.
</Card>

<Card id="try-share" type="try">
Untuk kongsi hook, commit dalam folder seperti `.githooks`. Kemudian setiap orang tetapkan `core.hooksPath`. Baca hook itu, kemudian tetapkannya.

<Interactive name="Sim" scenario="w10-hooks" panels={[]} goal={{ typed: 'config (--local )?core\\.hooks[Pp]ath (\\./)?\\.githooks' }} hints={['Taip cat .githooks/pre-commit', 'Kemudian taip git config core.hooksPath .githooks']} success="Siap! Git sebenar anda kini cari hook dalam .githooks. Terminal latihan ini tak pernah jalankan hook." />

<Hint>Taip `cat .githooks/pre-commit`. Kemudian `git config core.hooksPath .githooks`.</Hint>
</Card>

<Card id="deeper" type="deeper">
Repo baru dapat contoh hook dalam `.git/hooks`, yang berakhir dengan `.sample`. Buang hujung itu untuk mencuba. Hook boleh ditulis dalam apa-apa bahasa: baris pertama namakannya. `git commit --no-verify` langkau pre-commit dan commit-msg. `git hook run pre-commit` jalankan hook secara manual.
</Card>
