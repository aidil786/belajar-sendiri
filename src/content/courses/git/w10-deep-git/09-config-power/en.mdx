<Card id="see-include-if" type="see">
<Interactive name="Transcript" title="bash" label="Aina's ~/.gitconfig has her name and email, then an includeIf for gitdir ~/work/ that loads ~/.gitconfig-work. That file sets her work email." lines={[{ cmd: 'cat ~/.gitconfig' }, { out: '[user]\n    name = Aina\n    email = aina@example.com\n[includeIf "gitdir:~/work/"]\n    path = ~/.gitconfig-work' }, { cmd: 'cat ~/.gitconfig-work' }, { out: '[user]\n    email = aina@company.example' }]} />

**<Term id="include-if">includeIf</Term>** loads extra settings in some folders only. Every repo inside `~/work/` uses Aina's work email.
</Card>

<Card id="try-attributes" type="try">
<Term id="line-ending">Line endings</Term> differ: Windows uses CRLF, Mac and Linux use LF. A **<Term id="gitattributes">.gitattributes</Term>** file sets one rule for the whole team. Make one and commit it.

<Interactive name="Sim" scenario="w10-aliases" panels={['areas']} goal={{ fileContains: { '.gitattributes': '*.png binary' }, typed: 'text=auto', lastCommitHas: ['.gitattributes'] }} hints={['Type echo "* text=auto" > .gitattributes', 'Then type echo "*.png binary" >> .gitattributes', 'Then git add .gitattributes and git commit -m "Add line ending rules"']} success="Committed! Text files get LF in the repo. Pictures stay untouched." />

<Hint>`* text=auto` lets Git handle line endings in text files. `*.png binary` tells Git to never touch pictures.</Hint>
</Card>

<Card id="deeper" type="deeper">
On Windows, `git config --global core.autocrlf true` gives CRLF on your desk and LF in Git. On Mac or Linux, use `input`. Put `includeIf` after `[user]`, so its email wins. An alias that starts with `!` runs a shell command. Line endings already messy? See the World 11 lesson "Windows line-ending chaos".

</Card>
