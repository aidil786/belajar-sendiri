<Card id="see-include-if" type="see">
<Interactive name="Transcript" title="bash" label="~/.gitconfig Aina ada nama dan e-melnya, kemudian includeIf untuk gitdir ~/work/ yang muatkan ~/.gitconfig-work. Fail itu tetapkan e-mel kerjanya." lines={[{ cmd: 'cat ~/.gitconfig' }, { out: '[user]\n    name = Aina\n    email = aina@example.com\n[includeIf "gitdir:~/work/"]\n    path = ~/.gitconfig-work' }, { cmd: 'cat ~/.gitconfig-work' }, { out: '[user]\n    email = aina@company.example' }]} />

**<Term id="include-if">includeIf</Term>** muatkan tetapan tambahan dalam folder tertentu sahaja. Setiap repo dalam `~/work/` guna e-mel kerja Aina.
</Card>

<Card id="try-attributes" type="try">
<Term id="line-ending">Hujung baris</Term> (line ending) berbeza. Windows guna CRLF, Mac dan Linux guna LF. Fail **<Term id="gitattributes">.gitattributes</Term>** tetapkan satu peraturan untuk seluruh pasukan. Buat satu dan commit.

<Interactive name="Sim" scenario="w10-aliases" panels={['areas']} goal={{ fileContains: { '.gitattributes': '*.png binary' }, typed: 'text=auto', lastCommitHas: ['.gitattributes'] }} hints={['Taip echo "* text=auto" > .gitattributes', 'Kemudian taip echo "*.png binary" >> .gitattributes', 'Kemudian git add .gitattributes dan git commit -m "Add line ending rules"']} success="Dah commit! Fail teks dapat LF dalam repo. Gambar tak diusik." />

<Hint>`* text=auto` biar Git uruskan hujung baris fail teks. `*.png binary` suruh Git jangan usik gambar.</Hint>

<Card id="deeper" type="deeper">
Di Windows, `git config --global core.autocrlf true` beri CRLF atas meja anda dan LF dalam Git. Di Mac atau Linux, guna `input`. Letak `includeIf` selepas `[user]`, supaya e-melnya menang. Alias yang bermula dengan `!` jalankan arahan shell. Hujung baris dah bersepah? Lihat pelajaran World 11 "Huru-hara hujung baris Windows".

</Card>
