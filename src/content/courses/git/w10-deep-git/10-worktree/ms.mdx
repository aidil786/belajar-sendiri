<Interactive name="Choice" options={[{ label: 'Buka folder kedua daripada repo yang sama', correct: true, why: 'Itulah git worktree. Bersepah!' }]} />
</Card>

<Card id="see-add" type="see">
<Interactive name="TermReplay" scenario="w10-worktree" commands={['git worktree add ../diary-fix -b fix', 'git worktree list']} label="git worktree add buat ../diary-fix di branch baru fix. git worktree list tunjuk dua folder: diary di main dan diary-fix di fix." />

`git worktree add` buat folder kerja kedua, di branch (cabang) sendiri. Repo sama, sejarah sama. Setiap folder ialah **<Term id="worktree">worktree</Term>**.

<Card id="see-remove" type="see">
<Interactive name="TermReplay" scenario="w10-worktree" commands={['git worktree add ../diary-fix -b fix', 'git worktree remove ../diary-fix', 'git worktree list', 'git branch']} label="Selepas git worktree remove, senarai tunjuk diary sahaja. git branch masih senaraikan fix dan main." />

Dah siap? `git worktree remove` padam folder tambahan itu. Branch dan commitnya kekal selamat.

<Card id="win" type="win">
Kini anda boleh kerja di dua branch serentak, dalam dua folder.
</Card>

<Card id="deeper" type="deeper">
Satu branch hanya boleh di-checkout dalam satu worktree pada satu masa. Git tolak yang kedua. `git worktree remove` menolak kalau folder itu ada perubahan; `--force` buang perubahan itu. Terpadam folder worktree dengan tangan? `git worktree prune` bersihkan nota Git tentangnya.
</Card>
