<Card id="see-submodule" type="see">
<Interactive name="Transcript" title="bash" label="git submodule add puts the kuih-menu repo in a folder called menu. Then .gitmodules shows the path menu and the url." lines={[{ cmd: 'git submodule add https://github.com/you/kuih-menu.git menu' }, { cmd: 'cat .gitmodules' }, { out: '[submodule "menu"]\n\tpath = menu\n\turl = https://github.com/you/kuih-menu.git' }]} />

A **<Term id="submodule">submodule</Term>** is a repo inside your repo. Your repo keeps a link: the URL and one exact commit.
</Card>

<Card id="see-subtree" type="see">
<Interactive name="Transcript" title="bash" label="git subtree add copies the main branch of kuih-menu into the menu folder, squashed into one commit." lines={[{ cmd: 'git subtree add --prefix=menu https://github.com/you/kuih-menu.git main --squash' }]} />

A **<Term id="subtree">subtree</Term>** copies the other repo's files into a folder. They become normal files in your repo. Teammates need nothing extra.
</Card>

</Card>

<Card id="deeper" type="deeper">
`git submodule update --remote` moves a submodule to the newest commit of its branch. Then commit that change. `git subtree pull --prefix=menu <url> main --squash` brings in new menu work. `git subtree` lives in Git's contrib area, so check `git subtree -h` first. Sometimes a package manager is simpler than both.
</Card>
