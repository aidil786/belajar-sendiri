<Card id="see-subtree" type="see">
<Interactive name="Transcript" title="bash" label="git subtree add salin branch main kuih-menu ke dalam folder menu, dipadatkan jadi satu commit." lines={[{ cmd: 'git subtree add --prefix=menu https://github.com/you/kuih-menu.git main --squash' }]} />

**<Term id="subtree">Subtree</Term>** salin fail repo lain ke dalam satu folder. Fail itu jadi fail biasa dalam repo anda. Rakan sepasukan tak perlu buat apa-apa tambahan.

<Card id="deeper" type="deeper">
`git submodule update --remote` gerakkan submodule ke commit terbaru branchnya. Kemudian commit perubahan itu. `git subtree pull --prefix=menu <url> main --squash` bawa masuk kerja menu yang baru. `git subtree` datang daripada bahagian contrib Git, jadi semak `git subtree -h` dulu. Kadang-kadang pengurus pakej lebih mudah daripada kedua-duanya.
</Card>
