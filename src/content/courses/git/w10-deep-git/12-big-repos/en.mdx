<Card id="see-shallow" type="see">
<Interactive name="Transcript" title="bash" label="One command: git clone --depth 1 with the game repo's address." lines={[{ cmd: 'git clone --depth 1 https://github.com/you/big-game.git' }]} />

A **<Term id="shallow-clone">shallow clone</Term>** takes only the newest commits. `--depth 1` means just the last one. Quick for a one-off fix or a test robot.
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'Just one commit', correct: true, why: 'The older history was never downloaded. git fetch --unshallow gets it later.' }, { label: 'The whole history', why: 'Only one commit came down. The rest stayed on the server.' }, { label: 'Nothing at all', why: 'You still get the newest commit and all its files.' }]} />
</Card>

<Card id="see-partial" type="see">
<Interactive name="Transcript" title="bash" label="One command: git clone --filter=blob:none with the game repo's address." lines={[{ cmd: 'git clone --filter=blob:none https://github.com/you/big-game.git' }]} />

A **<Term id="partial-clone">partial clone</Term>** gets every commit, but file contents only when needed. `blob:none` means: no blobs up front. Git fetches them as you check files out.
</Card>

<Card id="try-sparse" type="try">

<Card id="see-lfs" type="see">
<Interactive name="Transcript" title="bash" label="git lfs install, then git lfs track star dot psd. The .gitattributes file now says *.psd filter=lfs diff=lfs merge=lfs -text." lines={[{ cmd: 'git lfs install' }, { cmd: 'git lfs track "*.psd"' }, { cmd: 'cat .gitattributes' }, { out: '*.psd filter=lfs diff=lfs merge=lfs -text' }]} />

**<Term id="git-lfs">Git LFS</Term>** is an add-on for big files. Git keeps a tiny pointer. The real file lives on an LFS server.
</Card>

<Card id="deeper" type="deeper">
`git fetch --unshallow` turns a shallow clone into a full one. `git clone --sparse` starts with only the top folder; then `git sparse-checkout set`. `git sparse-checkout disable` shows everything again. Git LFS is an add-on. Missing? Get it from git-lfs.com. Hosting sites limit LFS storage, so check your plan.
</Card>
