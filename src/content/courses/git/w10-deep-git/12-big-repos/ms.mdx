<Card id="see-shallow" type="see">
<Interactive name="Transcript" title="bash" label="Satu arahan: git clone --depth 1 dengan alamat repo permainan itu." lines={[{ cmd: 'git clone --depth 1 https://github.com/you/big-game.git' }]} />

**<Term id="shallow-clone">Shallow clone</Term>** (clone cetek) ambil commit terbaru sahaja. `--depth 1` maksudnya yang terakhir sahaja. Pantas untuk pembaikan sekali atau robot ujian.
</Card>

Anda buat shallow clone dengan `--depth 1`. Anda jalankan `git log --oneline`. Apa yang anda nampak?

Yang lain kekal di pelayan.' }, { label: 'Kosong langsung', why: 'Anda masih dapat commit terbaru dan semua failnya.' }]} />
</Card>

<Card id="see-partial" type="see">
<Interactive name="Transcript" title="bash" label="Satu arahan: git clone --filter=blob:none dengan alamat repo permainan itu." lines={[{ cmd: 'git clone --filter=blob:none https://github.com/you/big-game.git' }]} />

**<Term id="partial-clone">Partial clone</Term>** (clone separa) ambil setiap commit. Isi fail diambil bila perlu sahaja. `blob:none` maksudnya tiada blob pada awalnya. Git ambil blob bila anda checkout fail.
</Card>

<Card id="try-sparse" type="try">
**<Term id="sparse-checkout">sparse-checkout</Term>** papar sebahagian folder sahaja atas meja anda. Bina arahan untuk tengok folder `docs` sahaja.

<Card id="see-lfs" type="see">
<Interactive name="Transcript" title="bash" label="git lfs install, kemudian git lfs track bintang titik psd. Fail .gitattributes kini sebut *.psd filter=lfs diff=lfs merge=lfs -text." lines={[{ cmd: 'git lfs install' }, { cmd: 'git lfs track "*.psd"' }, { cmd: 'cat .gitattributes' }, { out: '*.psd filter=lfs diff=lfs merge=lfs -text' }]} />

**<Term id="git-lfs">Git LFS</Term>** ialah tambahan untuk fail besar. Git simpan penunjuk kecil sahaja. Fail sebenar tinggal di pelayan LFS.
</Card>

<Card id="win" type="win">
Kini anda boleh kerja dengan repo gergasi tanpa muat turun semuanya.
</Card>

<Card id="deeper" type="deeper">
`git fetch --unshallow` tukar shallow clone jadi clone penuh. `git clone --sparse` mula dengan folder atas sahaja; kemudian `git sparse-checkout set`. `git sparse-checkout disable` papar semua semula. Git LFS ialah tambahan: kalau Git anda tiada, dapatkan dari git-lfs.com. Laman hosting hadkan storan LFS, jadi semak pelan anda.
</Card>
