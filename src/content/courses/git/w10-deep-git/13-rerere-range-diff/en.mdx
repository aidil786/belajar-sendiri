<Card id="deeper" type="deeper">
Recorded fixes live in `.git/rr-cache`. `git rerere forget index.html` drops a bad one. Set `rerere.autoUpdate` to true to add replayed fixes for you. `git range-diff main...feature` compares two branches that share a base. The practice terminal only explains these commands.
</Card>
