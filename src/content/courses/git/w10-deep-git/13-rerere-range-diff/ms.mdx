<Card id="see-range-diff" type="see">
<Interactive name="Transcript" title="bash" label="Dua arahan: git rebase main, kemudian git range-diff main feature@{1} feature." lines={[{ cmd: 'git rebase main' }, { cmd: 'git range-diff main feature@{1} feature' }]} />

Selepas rebase, ada commit yang berubah? **<Term id="range-diff">range-diff</Term>** banding dua versi branch, satu commit demi satu commit. `feature@{1}` ialah branch itu sebelum rebase.
</Card>

<Card id="deeper" type="deeper">
Pembaikan yang dirakam tinggal dalam `.git/rr-cache`. `git rerere forget index.html` buang pembaikan yang tak elok. Tetapkan `rerere.autoUpdate` kepada true supaya pembaikan yang diulang terus di-add. `git range-diff main...feature` banding dua branch yang berkongsi asas. Terminal latihan cuma terangkan arahan ini.
</Card>
