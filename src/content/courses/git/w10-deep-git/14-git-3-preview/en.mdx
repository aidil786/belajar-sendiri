<Card id="deeper" type="deeper">
Try the future today: `git init --object-format=sha256` or `git init --ref-format=reftable`. Check that your hosting site supports them first. `safe.bareRepository` becomes `explicit`: Git won't use a <Term id="bare-repository">bare repo</Term> it just stumbles into. Building Git yourself will need Rust. Source: git-scm.com/docs/BreakingChanges.
