Your clue is `test.sh`. It runs `! grep -q "disabled" order.html`. When does the test pass?

<Interactive name="Choice" options={[{ label: 'When order.html does not say disabled', correct: true, why: 'grep finds disabled, then ! flips it into a fail. <Card id="round-1" type="try">
Round 1: question the suspects. Run the test, then mark each commit good or bad.

<Hint>Watch out: a guilty-sounding name can be innocent. Trust the test.</Hint>

<Card id="predict" type="predict">
"Fix button colour" sounds guilty. Was it?

<Interactive name="Choice" options={[{ label: 'No. The test passed there', correct: true, why: 'It only added style.css. Bisect trusts tests, not names.' }, { label: 'Yes, its name says button', why: 'Names can fool you. At that commit, the test passed.' }, { label: 'Bisect never tested it', why: 'It did, as the last test. And it passed.' }]} />
</Card>

<Card id="round-2" type="try">
Round 2: the real terminal. Start bisect, let `test.sh` judge every step, then go back to `main`.

<Interactive name="Sim" scenario="w10-boss" panels={['graph']} goal={{ bisectFound: '^Clean up the form$', bisectActive: false }} hints={['Type git bisect start HEAD HEAD~13', 'Let the script judge: git bisect run sh test.sh', 'Last, type git bisect reset']} success="Case closed! Clean up the form disabled the Buy button. You are back on main." />

<Hint>`git bisect start HEAD HEAD~13`, then `git bisect run sh test.sh`, then `git bisect reset`.</Hint>
