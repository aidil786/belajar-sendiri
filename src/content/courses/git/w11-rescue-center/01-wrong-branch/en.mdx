<Interactive name="GraphScene" scenario="w11-l01-before" commands={['git commit -m "Add about page"']} label="A new commit, Add about page, lands on main. The main label and HEAD move up to it." />

Oops. You committed your about page on `main`. It was meant for its own branch. This happens to everyone. Here's the safe way out.
</Card>

<Card id="decide" type="try">
First question: did you push it? Not yet. So which fix fits?

<Interactive name="Choice" options={[{ label: 'Move the commit to a new branch', correct: true, why: 'Nobody else has it yet, so you can move it freely.' }, { label: 'Revert it on main', why: 'Revert is for pushed commits. This one is still only yours.' }, { label: 'Delete the folder and start again', why: 'No need! Git can move the commit for you.' }]} />
</Card>

<Card id="see-move" type="see">
<Interactive name="GraphScene" scenario="w11-l01" commands={['git branch about', 'git reset --hard HEAD~1']} label="A new label, about, appears on the Add about page commit. Then main moves back one commit, to Add style. The commit stays safe on about." />

`git branch about` sticks a new label on your commit. `git reset --hard HEAD~1` moves main back one step. Your commit stays safe on about.
</Card>

<Card id="try-move" type="try">
Your turn. Move the commit to a branch called `about`. Then switch to it.

<Interactive name="Sim" scenario="w11-l01" panels={['graph']} goal={{ branchAt: { about: '^Add about page$', main: '^Add style$' }, currentBranch: 'about' }} hints={['First: git branch about', 'Then: git reset --hard HEAD~1', 'Last: git switch about']} success="Fixed! main is clean, and your page lives on about." />

<Hint>Type `git branch about`, then `git reset --hard HEAD~1`, then `git switch about`.</Hint>
</Card>

<Card id="predict" type="predict">
Careful: `reset --hard` also wipes changes you haven't committed. When is it safe here?

<Interactive name="Choice" options={[{ label: 'When git status says the working tree is clean', correct: true, why: 'Nothing is waiting, so nothing gets lost. Your commit is safe on about.' }, { label: 'Always, no matter what', why: 'Uncommitted changes would be wiped. Commit or stash them first.' }, { label: 'Never, it deletes the commit', why: 'The about label keeps the commit safe. Only main moves.' }]} />
</Card>

<Card id="check-pushed" type="check">
What if you had pushed it? Pick the fix for each case.

<Interactive name="SortCards" buckets={[{ id: 'move', label: 'Move it (branch + reset)' }, { id: 'undo', label: 'Undo it (revert)' }]} items={[{ label: 'Only on my laptop', bucket: 'move', why: 'Only you have it, so moving it is fine.' }, { label: 'Already on GitHub', bucket: 'undo', why: 'Others may have it. <Card id="win" type="win">
You can now move a commit to the branch it belongs on.
</Card>

<Card id="deeper" type="deeper">
Does the right branch exist already? Switch to it and run `git cherry-pick main` to copy the commit. Then take it off main with `git reset --hard HEAD~1`. Already pushed? Run `git revert HEAD` on main and push. Then `git switch -c about` and `git cherry-pick main~1` bring your work over.
</Card>
