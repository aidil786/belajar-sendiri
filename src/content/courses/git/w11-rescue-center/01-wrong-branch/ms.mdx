<Card id="decide" type="try">

<Interactive name="Choice" options={[{ label: 'Pindahkan commit ke branch baru', correct: true, why: 'Belum ada orang lain yang ada, jadi anda bebas pindahkan.' }, { label: 'Revert di main', why: 'Revert untuk commit yang dah push. <Card id="see-move" type="see">
<Interactive name="GraphScene" scenario="w11-l01" commands={['git branch about', 'git reset --hard HEAD~1']} label="Label baru, about, muncul pada commit Add about page. Kemudian main undur satu commit, ke Add style. Commit itu kekal selamat di about." />

`git branch about` lekatkan label baru pada commit anda. `git reset --hard HEAD~1` undurkan main satu langkah. Commit anda kekal selamat di about.
</Card>

<Card id="try-move" type="try">
Giliran anda. Pindahkan commit ke branch bernama `about`. Kemudian tukar ke branch itu.

<Hint>Taip `git branch about`, kemudian `git reset --hard HEAD~1`, kemudian `git switch about`.</Hint>

<Card id="win" type="win">
Kini anda boleh pindahkan commit ke branch yang sepatutnya.
</Card>

<Card id="deeper" type="deeper">
Branch yang betul dah wujud? Tukar ke branch itu dan jalankan `git cherry-pick main` untuk salin commit. Kemudian buang dari main dengan `git reset --hard HEAD~1`. Dah push? Jalankan `git revert HEAD` di main dan push. Kemudian `git switch -c about` dan `git cherry-pick main~1` bawa kerja anda ke situ.
</Card>
