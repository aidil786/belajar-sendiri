You pushed. Then you spot it: `.env` holds your secret key. And it's on GitHub now. Breathe. This happens to everyone. Here's the safe way out.
</Card>

<Card id="decide" type="try">
What do you do first?

<Interactive name="Choice" options={[{ label: 'Cancel the old key and make a new one', correct: true, why: 'This is called rotating. <Hint>A leaked key must stop working before anything else.</Hint>
</Card>

<Card id="see-untrack" type="see">
<Interactive name="AreasScene" zones={['working', 'staging']} command="git rm --cached .env" label="The command git rm --cached .env types itself. .env stays on your desk. The key is rotated. Now clean up. `git rm --cached .env` tells Git to stop tracking the file. It stays on your computer.
</Card>

<Card id="try-fix" type="try">
Stop tracking `.env`. Add it to `.gitignore`. Commit and push.

<Interactive name="Sim" scenario="w11-l02" panels={['areas']} goal={{ lastCommitLacks: ['.env'], filesExist: ['.env'], fileContains: { '.gitignore': '.env' }, pushed: ['main'], clean: true }} hints={['Type git rm --cached .env', 'Then: echo ".env" >> .gitignore and git add .gitignore', 'Then: git commit -m "Stop tracking .env" and git push']} success="Clean! .env is ignored, and the fix is on GitHub." />

<Hint>Type `git rm --cached .env`, then `echo ".env" >> .gitignore`, then `git add .gitignore`. Then commit and push.</Hint>
</Card>

<Card id="deeper" type="deeper">
Not pushed yet? Nobody saw it. Untrack and ignore `.env`, then run `git commit --amend --no-edit`. Pushed? Wiping the key from every old commit takes git filter-repo. World 8's lesson "Leaked a key? Rotate first" shows how. GitHub's push protection can block some secrets before they leave.
</Card>
