<Card id="try-revert" type="try">

<Card id="win" type="win">
Kini anda boleh undur commit terakhir, dah push atau belum.
</Card>

<Card id="deeper" type="deeper">
`--soft` simpan perubahan dalam kotak. `git reset HEAD~1` biasa simpan perubahan atas meja, di luar kotak. `--hard` padam perubahan, jadi guna hanya untuk perubahan yang betul-betul tak mahu. Commit itu masih boleh dicari. Lihat "Reflog, jaring keselamatan anda" dalam Dunia 2.
</Card>
