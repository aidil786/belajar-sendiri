<Card id="deeper" type="deeper">
Mesej salah pada commit lebih lama? Sebelum push, `git rebase -i` boleh tukar mesejnya (Dunia 3). Dah push, tapi di branch (cabang) anda seorang? Amend, kemudian `git push --force-with-lease` gantikannya dengan selamat (Dunia 4). Jangan buat begitu di branch dikongsi seperti main.
</Card>
