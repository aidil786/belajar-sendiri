You committed your day 2 page. But its style file is still on your desk! This happens to everyone. Here's the safe way out.

<Card id="decide" type="try">
You haven't pushed yet. What's the neatest fix?

<Interactive name="Choice" options={[{ label: 'Add the file into the last commit', correct: true, why: 'One tidy commit, as if you never forgot.' }, { label: 'A new commit: "oops forgot css"', why: 'It works, but adds noise. </Card>

<Card id="build" type="try">
First, `git add day2.css` puts the file in the box. Now build the command that tucks the box into your last commit.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Talk to Git' }, { text: 'commit', means: 'save the box' }, { text: '--amend', means: 'into the last commit' }, { text: '--no-edit', means: 'keep the same message' }]} decoys={[{ text: 'revert', means: 'undo a commit' }, { text: '--hard', means: 'wipe changes' }]} success="That's it! git commit --amend --no-edit." />
</Card>

<Card id="try-fix" type="try">

<Card id="check-stat" type="check">

<Card id="predict" type="predict">
New story: you had pushed the commit already. What now?

<Interactive name="Choice" options={[{ label: 'Make a small new commit with the file', correct: true, why: 'Shared history stays the same. Nobody else has to fix anything.' }, { label: 'Amend anyway', why: "Amend makes a new commit. Teammates' copies would clash." }, { label: 'Leave the file out forever', why: 'Your page needs it! Just commit it.' }]} />
</Card>

<Card id="win" type="win">
You can now add a forgotten file to your last commit.
</Card>

<Card id="deeper" type="deeper">
Amend makes a brand-new commit with a new hash. That is why it's only for commits you haven't pushed. Forgot a file several commits ago? Just commit it now with a clear message. Simple wins.
</Card>
