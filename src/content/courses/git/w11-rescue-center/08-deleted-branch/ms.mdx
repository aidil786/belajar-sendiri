<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w11-l08-before" commands={['git branch -D about']} label="git branch -D about papar: Deleted branch about, was, dan satu hash pendek." />

Anda kemas branch (cabang) dengan `-D`. Kemudian anda teringat: `about` belum pernah di-merge (dicantum)! Kerja anda hilang? Tarik nafas. Ini berlaku pada semua orang.
</Card>

<Card id="spot-reflog" type="try">
Padam branch cuma tanggalkan labelnya. Commit (titik simpan) kekal untuk sementara. **<Term id="reflog">Reflog</Term>** ingat semuanya.

<Interactive name="SpotLines" scenario="w11-l08" commands={['git reflog']} targets="commit: Add about page" prompt="Ketik baris dengan commit halaman about anda." success="Jumpa! Namanya HEAD@{1}." />
</Card>

<Card id="try-restore" type="try">
Lekatkan label `about` baru pada commit itu.

<Interactive name="Sim" scenario="w11-l08" panels={['graph']} showLost goal={{ branchAt: { about: '^Add about page$' } }} hints={['Taip git branch about HEAD@{1}']} success="Dah balik! Branch about simpan halaman anda semula." />

<Hint>Taip `git branch about HEAD@{1}`, kemudian tekan Enter.</Hint>
</Card>

<Card id="deeper" type="deeper">
Tengok semula hook tadi. Git papar hash lama selepas perkataan `was`. `git branch about` dengan hash itu pun boleh. Terpadam branch di GitHub juga? Halaman pull request selalunya boleh pulihkannya.
</Card>
