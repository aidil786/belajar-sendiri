<Card id="check-swipe" type="check">

<Card id="win" type="win">
Kini anda boleh baiki push yang ditolak tanpa memaksa.
</Card>

<Card id="deeper" type="deeper">
`git pull` biasa mungkin tanya cara cantumkan dua garis itu. Pilih `--rebase` atau `--no-rebase`. Atau tetapkan sekali: `git config --global pull.rebase true`. Pull berhenti dengan konflik? Lihat "Pull bersepah: abort". Jangan guna `--force` pada branch (cabang) dikongsi.
</Card>
