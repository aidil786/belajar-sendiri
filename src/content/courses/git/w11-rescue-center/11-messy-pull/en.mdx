<Card id="spot-exit" type="try">
A pull with `--rebase` stops in the middle of a rebase. `git status` tells you how to leave.

<Interactive name="SpotLines" scenario="w11-l11" commands={['git pull --rebase', 'git status']} targets={'use "git rebase --abort"'} prompt="Tap the line in git status that shows the way back." success="Found the exit: git rebase --abort." />

<Hint>Look near the end, for the word abort.</Hint>
</Card>

<Card id="try-abort" type="try">
Back out of the messy pull. Your work goes back to just before it.

<Interactive name="Sim" scenario="w11-l11" intro={['git pull --rebase']} panels={['graph']} goal={{ inRebase: false, clean: true, typed: 'rebase --abort' }} hints={['Type git rebase --abort']} success="Calm again. Your commit is back, untouched." />

<Hint>Type `git rebase --abort`, then press Enter.</Hint>
</Card>

You can now back out of a messy pull, calmly.

<Card id="deeper" type="deeper">
Ready to try again? Pull once more and fix the clash. In a rebase: edit the file, `git add` it, then `git rebase --continue`. In a merge: edit, `git add`, then `git commit`. Unsure whose line wins? Ask your teammate first.
</Card>
