<Card id="hook" type="hook">
<Interactive name="TermReplay" scenario="w11-l11" commands={['git pull --rebase']} label="git pull --rebase ambil commit Aisyah, kemudian berhenti: CONFLICT (content): Merge conflict in index.html. Could not apply Say Git is fun." />

Anda pull. CONFLICT! Anda dan Aisyah ubah baris yang sama. Terlalu bersepah sekarang? Ini berlaku pada semua orang. Anda sentiasa boleh undur diri.
</Card>

<Card id="spot-exit" type="try">
Pull dengan `--rebase` berhenti di tengah-tengah rebase. `git status` beritahu cara keluar.

<Interactive name="SpotLines" scenario="w11-l11" commands={['git pull --rebase', 'git status']} targets={'use "git rebase --abort"'} prompt="Ketik baris dalam git status yang tunjuk jalan balik." success="Jumpa jalan keluar: git rebase --abort." />

<Hint>Tengok berhampiran hujung, cari perkataan abort.</Hint>
</Card>

<Card id="try-abort" type="try">
Undur diri dari pull yang bersepah. Kerja anda kembali seperti sejurus sebelumnya.

<Interactive name="Sim" scenario="w11-l11" intro={['git pull --rebase']} panels={['graph']} goal={{ inRebase: false, clean: true, typed: 'rebase --abort' }} hints={['Taip git rebase --abort']} success="Tenang semula. Commit anda dah balik, tak terusik." />

<Hint>Taip `git rebase --abort`, kemudian tekan Enter.</Hint>
</Card>

<Card id="sort-exit" type="check">

<Card id="predict" type="predict">

<Card id="win" type="win">
Kini anda boleh undur diri dari pull yang bersepah, dengan tenang.
</Card>

<Card id="deeper" type="deeper">
Sedia cuba lagi? Pull sekali lagi dan baiki pertembungan itu. Dalam rebase: sunting fail, `git add`, kemudian `git rebase --continue`. Dalam merge: sunting, `git add`, kemudian `git commit`. Tak pasti baris siapa yang menang? Tanya kawan sepasukan dulu.
</Card>
