<Card id="see-untrack" type="see">
<Interactive name="TermReplay" scenario="w11-l12" commands={['git rm --cached video.mp4', 'git status -s']} label="git rm --cached video.mp4 prints rm video.mp4. Then git status -s shows D video.mp4 in the box, and video.mp4 as untracked." />

`git rm --cached video.mp4` tells Git to stop tracking it. The video stays on your computer, safe.
</Card>

<Card id="try-fix" type="try">
Take the video out of the last commit. Ignore `*.mp4` so it can't sneak back.

<Interactive name="Sim" scenario="w11-l12" panels={['areas']} goal={{ lastCommitLacks: ['video.mp4'], lastCommitHas: ['trip.html'], filesExist: ['video.mp4'], fileContains: { '.gitignore': 'mp4' }, commits: 4 }} hints={['Type git rm --cached video.mp4', 'Then: echo "*.mp4" >> .gitignore and git add .gitignore', 'Last: git commit --amend --no-edit']} success="Light again! The commit keeps trip.html. The video stays on your computer." />

<Hint>Type `git rm --cached video.mp4`, then `echo "*.mp4" >> .gitignore` and `git add .gitignore`. Last, `git commit --amend --no-edit`.</Hint>
</Card>

<Card id="deeper" type="deeper">
GitHub warns above 50 MiB and blocks files over 100 MiB. Need big files in a repo? Git LFS is an add-on: `git lfs track "*.mp4"` keeps videos outside normal history. Big file in an older commit, not pushed? `git reset --soft origin/main` puts all unpushed work back in the box. Remove the file, then commit again.
</Card>
