<Card id="deeper" type="deeper">
GitHub beri amaran melebihi 50 MiB dan sekat fail melebihi 100 MiB. Perlu fail besar dalam repo? Git LFS ialah tambahan: `git lfs track "*.mp4"` simpan video di luar sejarah biasa. Fail besar dalam commit lebih lama, belum push? `git reset --soft origin/main` masukkan semula semua kerja yang belum push ke dalam kotak. Keluarkan fail itu, kemudian commit semula.
</Card>
