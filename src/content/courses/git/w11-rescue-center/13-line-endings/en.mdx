<Card id="see-endings" type="see">
Every line ends with an invisible **line ending**. Windows uses two marks: CRLF. Mac and Linux use one: LF. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'crlf', label: 'CRLF (two marks)' }, { id: 'lf', label: 'LF (one mark)' }]} items={[{ label: 'Windows', bucket: 'crlf', why: 'Windows tools often end lines with CRLF.' }, { label: 'macOS', bucket: 'lf', why: 'Mac uses LF.' }, { label: 'Linux', bucket: 'lf', why: 'Linux uses LF.' }, { label: 'Inside the repo, with text=auto', bucket: 'lf', why: 'Git stores text files with LF inside the repo.' }]} success="Sorted! Two styles. Git can keep them in line." />
</Card>

<Card id="try-attributes" type="try">
One file fixes it for the whole team. Make `.gitattributes` with `* text=auto`. Then commit it.

<Interactive name="Sim" scenario="w11-l13" panels={['areas']} goal={{ fileContains: { '.gitattributes': 'text=auto' }, lastCommitHas: ['.gitattributes'], clean: true }} hints={['Type echo "* text=auto" > .gitattributes', 'Then type git add .gitattributes', 'Then type git commit -m "Normalize line endings"']} success="Done! Git now handles line endings for everyone." />

<Hint>Type `echo "* text=auto" > .gitattributes`, then `git add .gitattributes`. Then commit.</Hint>
</Card>

<Card id="see-renormalize" type="see">
<Interactive name="Transcript" title="bash" label="Two commands: git add --renormalize dot, then git commit -m Normalize all the line endings." lines={[{ cmd: 'git add --renormalize .' }, { cmd: 'git commit -m "Normalize all the line endings"' }]} />

Old files may still have the old endings. `git add --renormalize .` re-adds every tracked file with the new rule. Then commit once.
</Card>

<Card id="deeper" type="deeper">
Scripts that must keep LF? Add `*.sh text eol=lf`. Windows-only files? `*.bat text eol=crlf`. Mark pictures as `binary` so Git never touches them. Run `git add --renormalize .` from a clean working folder. GitHub Docs has a full guide.
</Card>
