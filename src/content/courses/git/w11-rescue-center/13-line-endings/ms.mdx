<Card id="see-endings" type="see">
Setiap baris berakhir dengan **hujung baris** (line ending) yang halimunan. Windows guna dua tanda: CRLF. Mac dan Linux guna satu: LF. Susun mereka.

<Interactive name="SortCards" buckets={[{ id: 'crlf', label: 'CRLF (dua tanda)' }, { id: 'lf', label: 'LF (satu tanda)' }]} items={[{ label: 'Windows', bucket: 'crlf', why: 'Alat Windows selalunya tamatkan baris dengan CRLF.' }, { label: 'macOS', bucket: 'lf', why: 'Mac guna LF.' }, { label: 'Linux', bucket: 'lf', why: 'Linux guna LF.' }, { label: 'Dalam repo, dengan text=auto', bucket: 'lf', why: 'Git simpan fail teks dengan LF di dalam repo.' }]} success="Tersusun! Dua gaya. Git boleh selaraskan mereka." />
</Card>

<Card id="try-attributes" type="try">
Satu fail baiki untuk seluruh pasukan. Buat `.gitattributes` dengan `* text=auto`. Kemudian commit (titik simpan).

<Interactive name="Sim" scenario="w11-l13" panels={['areas']} goal={{ fileContains: { '.gitattributes': 'text=auto' }, lastCommitHas: ['.gitattributes'], clean: true }} hints={['Taip echo "* text=auto" > .gitattributes', 'Kemudian taip git add .gitattributes', 'Kemudian taip git commit -m "Normalize line endings"']} success="Siap! Git kini uruskan hujung baris untuk semua." />

<Hint>Taip `echo "* text=auto" > .gitattributes`, kemudian `git add .gitattributes`. Lepas tu commit.</Hint>
</Card>

<Card id="see-renormalize" type="see">
<Interactive name="Transcript" title="bash" label="Dua arahan: git add --renormalize titik, kemudian git commit -m Normalize all the line endings." lines={[{ cmd: 'git add --renormalize .' }, { cmd: 'git commit -m "Normalize all the line endings"' }]} />

Fail lama mungkin masih guna hujung baris lama. `git add --renormalize .` tambah semula setiap fail yang dijejak dengan peraturan baru. Kemudian commit sekali.
</Card>

<Card id="deeper" type="deeper">
Skrip yang mesti kekal LF? Tambah `*.sh text eol=lf`. Fail khas Windows? `*.bat text eol=crlf`. Tandakan gambar sebagai `binary` supaya Git tak usik. Jalankan `git add --renormalize .` dari folder kerja yang bersih. GitHub Docs ada panduan penuh.
</Card>
