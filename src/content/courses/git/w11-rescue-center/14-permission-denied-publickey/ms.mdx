Komputer anda buktikan siapa anda dengan kunci SSH. Uji kunci itu sendirian dengan `ssh -T git@github.com`. Jawapan sama: GitHub tak kenal kunci ini.

<Card id="try-https" type="try">
Tergesa-gesa? Tukar `origin` ke alamat HTTPS. Kemudian push semula.

SSH boleh tunggu hari yang lebih tenang." />

<Hint>Taip `git remote set-url origin https://github.com/you/diary.git`, kemudian `git push`.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh baiki Permission denied (publickey), dengan dua cara.
</Card>

<Card id="deeper" type="deeper">
Belum ada kunci? Buat satu dengan `ssh-keygen -t ed25519 -C "you@example.com"` (Dunia 4). Hanya fail `.pub` dihantar ke GitHub. Jangan kongsi kunci peribadi. Guna `sudo git push`? Buang `sudo`. Kunci anda milik anda, bukan akaun admin.
</Card>
