<Card id="deeper" type="deeper">
Tidy up afterwards: `git switch main`, then `git pull`. Does pull say the branches diverged? The pull request was probably squashed. Your work is on GitHub, so `git reset --hard origin/main` is safe then. Or, right after pushing your branch, run `git branch -f main origin/main`.
</Card>
