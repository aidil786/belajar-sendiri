<Card id="deeper" type="deeper">
Kemaskan selepas itu: `git switch main`, kemudian `git pull`. Pull kata branch dah berpecah (diverged)? Pull request itu mungkin di-squash. Kerja anda ada di GitHub, jadi `git reset --hard origin/main` selamat ketika itu. Atau, sejurus selepas push branch anda, jalankan `git branch -f main origin/main`.
</Card>
