<Card id="deeper" type="deeper">
Commit (titik simpan) hanya dikira jika e-melnya ada pada akaun GitHub anda. Ia mesti masuk ke default branch (cabang utama), bukan fork. Semak e-mel yang Git guna dengan `git config user.email`. Kerja persendirian boleh keluar sebagai petak tanpa nama. Hidupkan dari profil anda.
