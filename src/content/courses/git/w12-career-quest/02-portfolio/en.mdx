<Card id="hook" type="hook">
A job post says: "Link three projects you built." Your repos are all tutorial copies. What will a reviewer look for?

<Interactive name="Choice" options={[{ label: 'Something you built and finished yourself', correct: true, why: 'Your own idea, working, with a README. That shows real skill.' }, { label: 'The biggest number of repos', why: 'Count does not matter. Quality does.' }, { label: 'Fancy words in the description', why: 'Reviewers open the code. Working projects win.' }]} />
</Card>

<Card id="see-life" type="see">
<Interactive name="TimelineTap" events={[{ when: 'Day 1', title: 'A real problem', text: 'Pick something small that annoys you or a friend.' }, { when: 'Week 1', title: 'It works', text: 'Build the tiniest version that works. Small, clean commits.' }, { when: 'Week 2', title: 'README and demo', text: 'Say what it does and how to run it. Put a live demo online.' }, { when: 'Later', title: 'Polish', text: 'Fix bugs people report. Note each change for users.' }]} />

A great **portfolio** is a few small, finished projects. Each one tells a short story. Tap through one project's life.
</Card>

<Card id="try-sort" type="try">
Pick projects that match the job you want. Sort each idea by the skill it shows.

<Interactive name="SortCards" buckets={[{ id: 'front', label: 'Frontend (what people see)' }, { id: 'back', label: 'Backend (data and servers)' }, { id: 'tools', label: 'Tools (save time)' }]} items={[{ label: 'A personal site with a dark mode switch', bucket: 'front', why: 'Layout, colours and clicks: frontend.' }, { label: 'A recipe page that works on phones', bucket: 'front', why: 'Making a page fit every screen is frontend work.' }, { label: 'A small API that saves to-do items', bucket: 'back', why: 'Storing and serving data is backend work.' }, { label: 'A login system with safe passwords', bucket: 'back', why: 'Passwords live on the server side.' }, { label: 'A script that renames 100 photos', bucket: 'tools', why: 'It saves you time. That is a tool.' }, { label: 'A workflow that runs your tests on every push', bucket: 'tools', why: 'Automation is a tools skill. World 7 shows how.' }]} success="Sorted! Now pick the bucket that fits your dream job." />

<Hint>Ask: do people see it? Does it store data? Does it save time?</Hint>
</Card>

<Card id="check-ideas" type="check">
Good project or not yet? Judge each idea.

<Interactive name="SwipeJudge" prose cards={[{ text: 'A budget tracker you use every week', good: true, why: 'Real use means real features and real fixes.' }, { text: 'A tutorial app, renamed, nothing changed', good: false, why: 'Add your own twist. Then it becomes yours.' }, { text: 'A booking page for a family business', good: true, why: 'It solves a real problem. Great story for interviews.' }, { text: 'A giant social network, 5% done', good: false, why: 'Too big. Finish something small first.' }, { text: 'A tutorial app plus your own new feature', good: true, why: 'Your twist shows you can think, not just copy.' }]} />
</Card>

<Card id="check-readme" type="check">
A reviewer opens your best repo. They have one minute. What should they see first?

<Interactive name="Choice" options={[{ label: 'A README: what it does, a picture, a live link', correct: true, why: 'In one minute, they know what you built and can try it.' }, { label: 'A list of every file', why: 'Files come later. First, tell them what it is.' }, { label: 'An empty page that says "coming soon"', why: 'Finish one thing before you show it.' }]} />
</Card>
