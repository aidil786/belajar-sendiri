<Card id="try-roles" type="try">
**Open source** code is public. Anyone can suggest a change. The project's keepers, called maintainers, decide what goes in. Who does what?

<Interactive name="SortCards" buckets={[{ id: 'you', label: 'You (helper)' }, { id: 'keeper', label: 'Maintainer' }]} items={[{ label: 'Fork the project and change it', bucket: 'you', why: 'Your fork is your own copy to work in.' }, { label: 'Open a pull request', bucket: 'you', why: 'That is how you ask them to take your change.' }, { label: 'Reply to review comments', bucket: 'you', why: 'You answer questions about your change.' }, { label: 'Review the pull request', bucket: 'keeper', why: 'Maintainers check every change.' }, { label: 'Merge it into the project', bucket: 'keeper', why: 'Only maintainers can merge into their project.' }, { label: 'Label easy issues for newcomers', bucket: 'keeper', why: 'Maintainers label issues so helpers can find them.' }]} success="Right! You suggest. They decide." />
</Card>

<Card id="try-order" type="try">
Put the whole journey in order. You met forks in World 4 and pull requests in World 5.

<Interactive name="OrderList" items={['Fork the project to your account', 'Clone your fork', 'Make a new branch', 'Make one small change and commit it', 'Push the branch to your fork', 'Open a pull request', 'Reply kindly to the review']} label="First step at the top" success="That's the path every open-source helper walks!" />

<Hint>You can't clone a fork that doesn't exist yet. And the PR comes after the push.</Hint>
</Card>

<Card id="try-push" type="try">
Your fix is committed on a branch called `fix-readme-typo`. Build the command that sends it to your fork.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Talk to Git' }, { text: 'push', means: 'send commits up' }, { text: '-u', means: 'remember this link for next time' }, { text: 'origin', means: 'your fork on GitHub' }, { text: 'fix-readme-typo', means: 'your branch' }]} decoys={[{ text: '--force', means: 'overwrite (never needed here)' }, { text: 'main', means: 'the main branch, not your fix' }]} success="Sent! Your fork now has your branch." />

<Hint>After cloning your fork, `origin` is your fork.</Hint>
</Card>

<Card id="deeper" type="deeper">
Many repos have a contribute page that lists their good first issues. Try `github.com/OWNER/REPO/contribute`. Your PR may sit for days. Maintainers are often volunteers, so be patient. Some projects ask you to sign a contributor agreement first. CONTRIBUTING.md will say so.
</Card>
