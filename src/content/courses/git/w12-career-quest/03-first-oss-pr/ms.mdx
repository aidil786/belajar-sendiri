<Card id="try-roles" type="try">
Kod **sumber terbuka** (open source) boleh dilihat semua orang. Sesiapa pun boleh cadangkan perubahan. Penjaga projek, iaitu maintainer, tentukan apa yang masuk. Siapa buat apa?

Anda cadangkan. Mereka yang putuskan." />
</Card>

<Card id="try-order" type="try">
Susun seluruh perjalanan ini. Anda dah kenal fork (salinan projek orang lain) dalam World 4. Pull request (minta perubahan diterima) pula dalam World 5.

<Interactive name="OrderList" items={['Fork projek ke akaun anda', 'Clone fork anda', 'Buat branch baru', 'Buat satu perubahan kecil dan commit', 'Push branch ke fork anda', 'Buka pull request', 'Balas semakan dengan baik']} label="Langkah pertama di atas" success="Itulah laluan setiap penyumbang sumber terbuka!" />

<Hint>Anda tak boleh clone fork yang belum wujud. Dan PR datang selepas push.</Hint>
</Card>

<Card id="try-push" type="try">
Pembetulan anda dah di-commit (titik simpan) dalam branch (cabang) `fix-readme-typo`. Bina arahan untuk hantar ke fork anda.

<Interactive name="CommandBuilder" pieces={[{ text: 'git', means: 'Bercakap dengan Git' }, { text: 'push', means: 'hantar commit ke atas' }, { text: '-u', means: 'ingat pautan ini untuk lain kali' }, { text: 'origin', means: 'fork anda di GitHub' }, { text: 'fix-readme-typo', means: 'branch anda' }]} decoys={[{ text: '--force', means: 'tulis ganti (tak perlu langsung di sini)' }, { text: 'main', means: 'branch utama, bukan pembetulan anda' }]} success="Dah dihantar! Fork anda kini ada branch anda." />

<Hint>Selepas clone fork anda, `origin` ialah fork anda.</Hint>
</Card>

<Card id="deeper" type="deeper">
Banyak repo ada halaman contribute yang senaraikan good first issue mereka. Cuba `github.com/OWNER/REPO/contribute`. PR anda mungkin menunggu beberapa hari. Maintainer selalunya sukarelawan, jadi bersabar. Sesetengah projek minta anda tandatangan perjanjian penyumbang dulu. CONTRIBUTING.md akan beritahu.
</Card>
