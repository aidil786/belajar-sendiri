Question two: reset or revert? **<Term id="revert">Revert</Term>** adds a new commit that undoes an old one. Nothing is erased. So it is safe for shared work.
</Card>

<Card id="predict-reset" type="predict">
"Then when is reset the better choice?" Pick the answer you would give.

<Interactive name="Choice" options={[{ label: 'For local commits that nobody else has yet', correct: true, why: 'Reset rewrites history. That is fine when only you have it.' }, { label: 'For commits already shared on main', why: 'Then use revert. Reset would rewrite history your team has.' }, { label: 'Never. Reset is always a mistake', why: 'Reset is a great tool for your own local commits.' }]} />
</Card>

<Card id="try-fetch" type="try">
Question three: fetch or pull? **fetch** downloads the news but changes nothing. pull downloads it and joins it in. Sort each fact.

<Interactive name="SortCards" buckets={[{ id: 'fetch', label: 'git fetch' }, { id: 'pull', label: 'git pull' }]} items={[{ label: 'Downloads new commits only', bucket: 'fetch', why: 'It brings the news. Your branch stays put.' }, { label: 'Leaves your files alone', bucket: 'fetch', why: 'Fetch never touches your working folder.' }, { label: 'A safe way to peek first', bucket: 'fetch', why: 'Fetch, look, then decide.' }, { label: 'Downloads, then joins into your branch', bucket: 'pull', why: 'Pull = fetch + merge (or rebase).' }, { label: 'Can cause a merge conflict', bucket: 'pull', why: 'Joining work can clash. Fetch alone never does.' }, { label: 'Updates your branch and your files', bucket: 'pull', why: 'Pull changes your branch. Fetch only updates the news.' }]} success="Sorted! That answer would impress any interviewer." />

<Hint>Need a refresher? See "Fetch vs pull" in World 4.</Hint>
</Card>

<Card id="check-answers" type="check">
Interviewers love honest, careful habits. Judge each answer.

<Interactive name="SwipeJudge" prose cards={[{ text: '"I run `git status` before every commit."', good: true, why: 'It shows a careful habit.' }, { text: '"I never make mistakes in Git."', good: false, why: 'Everyone does.
