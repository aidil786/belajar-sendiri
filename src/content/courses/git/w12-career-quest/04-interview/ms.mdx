Soalan kedua: reset atau revert? **<Term id="revert">Revert</Term>** (batalkan) tambah commit (titik simpan) baru yang membatalkan commit lama. Tiada apa dipadam. Jadi ia selamat untuk kerja yang dikongsi.

<Interactive name="Choice" options={[{ label: 'Untuk commit tempatan yang belum ada pada orang lain', correct: true, why: 'Reset tulis semula sejarah. </Card>

<Card id="try-fetch" type="try">
Soalan ketiga: fetch atau pull? **fetch** muat turun berita tapi tak ubah apa-apa. pull muat turun dan terus gabungkan. Susun setiap fakta.

<Interactive name="SortCards" buckets={[{ id: 'fetch', label: 'git fetch' }, { id: 'pull', label: 'git pull' }]} items={[{ label: 'Muat turun commit baru sahaja', bucket: 'fetch', why: 'Ia bawa berita. Branch anda tak bergerak.' }, { label: 'Tak usik fail anda', bucket: 'fetch', why: 'Fetch tak pernah sentuh folder kerja anda.' }, { label: 'Cara selamat untuk intai dulu', bucket: 'fetch', why: 'Fetch, tengok, kemudian putuskan.' }, { label: 'Muat turun, kemudian gabung ke branch anda', bucket: 'pull', why: 'Pull = fetch + merge (atau rebase).' }, { label: 'Boleh sebabkan konflik merge', bucket: 'pull', why: 'Menggabungkan kerja boleh bertembung. Fetch sahaja tak pernah.' }, { label: 'Kemas kini branch dan fail anda', bucket: 'pull', why: 'Pull ubah branch anda. Fetch cuma kemas kini berita.' }]} success="Siap! Jawapan itu pasti buat penemu duga kagum." />

<Hint>Nak ulang kaji? Lihat "Fetch lawan pull" dalam World 4.</Hint>
</Card>
