**<Term id="changelog">Changelog</Term>** (senarai perubahan) ialah diari untuk pengguna. Setiap versi senaraikan apa yang ditambah, diubah atau dibaiki. Versi terbaru duduk di atas.
</Card>

<Card id="try-sort" type="try">
Satu gaya yang popular, Keep a Changelog, kumpulkan entri bawah tajuk. Susun setiap entri.

<Interactive name="SortCards" buckets={[{ id: 'added', label: 'Added' }, { id: 'changed', label: 'Changed' }, { id: 'fixed', label: 'Fixed' }]} items={[{ label: 'Butang baru "eksport ke PDF"', bucket: 'added', why: 'Ciri yang serba baru masuk bawah Added.' }, { label: 'Terjemahan Bahasa Melayu yang baru', bucket: 'added', why: 'Benda baru untuk pengguna: Added.' }, { label: 'Carian kini dua kali lebih laju', bucket: 'changed', why: 'Ciri lama berfungsi dengan cara lain: Changed.' }, { label: 'Tetapan dipindah ke menu atas', bucket: 'changed', why: 'Ia dah ada sebelum ini. Kini ia berpindah: Changed.' }, { label: 'Tiada lagi ranap bila nota kosong', bucket: 'fixed', why: 'Pepijat dah hilang: Fixed.' }, { label: 'Tarikh tunjuk zon waktu yang betul', bucket: 'fixed', why: 'Dulu rosak. Kini berfungsi: Fixed.' }]} success="Siap! Pengguna boleh imbas dalam beberapa saat." />

<Hint>Benda baru? Added. Benda yang berubah? Changed. Benda rosak yang kini okey? Fixed.</Hint>
</Card>

<Card id="try-commit" type="try">
`CHANGELOG.md` anda dah siap ditulis. Simpan dalam satu commit (titik simpan). Mulakan mesej dengan `docs:`.

<Interactive name="Sim" scenario="w12-l06" panels={['areas']} goal={{ lastCommitHas: ['CHANGELOG.md'], lastMessage: '^docs(\\(.+\\))?: \\S' }} hints={['Mula-mula masukkan ke kotak: git add CHANGELOG.md', 'Kemudian simpan: git commit -m "docs: add changelog"']} success="Dah disimpan! Pengguna anda akhirnya dapat cerita yang jelas." />

<Hint>Dua langkah: `git add CHANGELOG.md`, kemudian `git commit -m "docs: add changelog"`.</Hint>
</Card>

<Card id="check-docs" type="check">

<Card id="deeper" type="deeper">
Conventional Commits membantu di sini. Commit `feat:` selalunya jadi Added. Commit `fix:` jadi Fixed. World 6 terangkan gaya ini. Sesetengah alat buat draf changelog daripada commit anda. Manusia tetap perlu suntingnya. Keep a Changelog juga ada tajuk Deprecated, Removed dan Security.
</Card>
