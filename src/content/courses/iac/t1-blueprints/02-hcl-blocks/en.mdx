<Card id="deeper" type="deeper">
Lines starting with `#` are comments. OpenTofu reads every `.tf` file in the folder as one blueprint. File names are only for people. In strings, `\n` is a new line and `${ }` puts a value inside the text.

The settings inside a block are called **<Term id="argument">arguments</Term>**. Each provider's docs list the arguments its resources take.
</Card>
