<Card id="hook" type="hook">
Ini pelan yang kecil. Apa yang ia minta OpenTofu buat?

```hcl
resource "random_pet" "stall" {
  length = 2
}
```

<Interactive name="Choice" options={[{ label: 'Nama gerai rawak, dua perkataan', correct: true, why: 'random_pet buat nama lucu seperti lucky-civet. length = 2 bermaksud dua perkataan.' }, { label: 'Haiwan peliharaan bernama stall', why: 'stall cuma label kita. random_pet buat nama rawak.' }, { label: 'Dua gerai', why: 'length ialah bilangan perkataan dalam satu nama.' }]} />
</Card>

<Card id="see-blocks" type="see">
Tekan dua baris di mana blok baru bermula.

<Interactive name="SpotLines" lines={[{ text: 'resource "random_pet" "stall" {', target: true }, { text: '  length = 2' }, { text: '}' }, { text: '' }, { text: 'resource "local_file" "sign" {', target: true }, { text: '  filename = "sign.txt"' }, { text: '  content  = "Welcome to ${random_pet.stall.id}\\n"' }, { text: '}' }]} success="Dua blok. Pelan dibina daripada **<Term id="block">block (blok)</Term>**. Bahasa ini dipanggil HCL.
</Card>

<Interactive name="CommandBuilder" pieces={[{ text: 'resource', means: 'jenis blok: bina sesuatu' }, { text: '"local_file"', means: 'jenis benda: sebuah fail' }, { text: '"menu"', means: 'nama anda sendiri untuknya' }, { text: '{', means: 'tetapan bermula di sini' }]} decoys={[{ text: 'output', means: 'blok yang kongsi nilai' }, { text: 'menu.txt', means: 'nama fail, tanpa tanda petik' }]} success="resource, jenis, nama anda, kemudian {. <Card id="predict" type="predict">
Papan tanda guna `${random_pet.stall.id}`. Itu **<Term id="reference">reference (rujukan)</Term>**: jenis, nama, kemudian nilai. Apa itu `stall` di sini?

<Interactive name="Choice" options={[{ label: 'Nama kita sendiri untuk blok random_pet', correct: true, why: 'Jenis random_pet, nama stall, nilai id. </Card>

<Card id="win" type="win">
Kini anda boleh baca blok dan ikut reference.
</Card>

<Card id="deeper" type="deeper">
Baris yang bermula dengan `#` ialah komen. OpenTofu baca setiap fail `.tf` dalam folder sebagai satu pelan. Nama fail cuma untuk manusia. Dalam string, `\n` ialah baris baru dan `${ }` letak nilai di dalam teks.

Tetapan di dalam blok dipanggil **<Term id="argument">argument</Term>**. Dokumen setiap provider senaraikan argument yang resource-nya terima.
</Card>
