<Card id="see-providers" type="see">
OpenTofu can't make files or names by itself. **<Term id="provider">Providers</Term>** do the work, like suppliers. Who supplies what?

<Interactive name="SortCards" buckets={[{ id: 'random', label: 'random (names and numbers)' }, { id: 'local', label: 'local (files on this computer)' }]} items={[{ label: 'A stall name: `random_pet`', bucket: 'random', why: 'random makes random names, numbers and strings.' }, { label: 'A sign file: `local_file`', bucket: 'local', why: 'local writes files on this computer.' }, { label: 'A table number: `random_integer`', bucket: 'random', why: 'A random whole number comes from random.' }, { label: 'A menu file', bucket: 'local', why: 'Files are local work.' }]} success="The first word of a resource type names its provider." />
</Card>

<Card id="see-version" type="check">
`providers.tf` lists the suppliers. `~> 3.7` means "3.7 or newer, but not 4". Which version may init pick?

```hcl
random = {
  source  = "hashicorp/random"
  version = "~> 3.7"
}
```

<Interactive name="Choice" compact options={[{ label: '3.9.1', correct: true, why: 'Newer than 3.7, still a 3. Allowed.' }, { label: '4.0.0', why: 'A 4 could break things. ~> stops before 4.' }, { label: '3.6.0', why: 'Older than 3.7. Not allowed.' }]} />
</Card>

<Card id="deeper" type="deeper">
init also makes a hidden `.terraform/` folder with the provider programs. Keep it out of Git; commit `.terraform.lock.hcl`. OpenTofu downloads providers from its own registry, `registry.opentofu.org`. `terraform init` does the same job in Terraform, from HashiCorp's registry.
</Card>
