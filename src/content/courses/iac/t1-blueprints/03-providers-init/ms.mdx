<Card id="see-version" type="check">
`providers.tf` senaraikan pembekal. `~> 3.7` bermaksud "3.7 atau lebih baru, tapi bukan 4". Versi mana init boleh pilih?

```hcl
random = {
  source  = "hashicorp/random"
  version = "~> 3.7"
}
```

<Interactive name="Choice" compact options={[{ label: '3.9.1', correct: true, why: 'Lebih baru dari 3.7, masih 3. Dibenarkan.' }, { label: '4.0.0', why: 'Versi 4 mungkin rosakkan sesuatu. ~> berhenti sebelum 4.' }, { label: '3.6.0', why: 'Lebih lama dari 3.7. Tak dibenarkan.' }]} />
</Card>

<Card id="deeper" type="deeper">
init juga buat folder tersembunyi `.terraform/` berisi program provider. Jangan masukkan ke Git; commit `.terraform.lock.hcl`. OpenTofu muat turun provider dari registry sendiri, `registry.opentofu.org`. `terraform init` buat kerja sama dalam Terraform, dari registry HashiCorp.
</Card>
