<Card id="hook" type="hook">
You built a test stall to try an idea. The test is over. In the cloud, a stall costs money every hour. What now?

<Interactive name="Choice" options={[{ label: 'Tear down everything the blueprint built', correct: true, why: 'One command removes it all. Nothing is left running.' }, { label: 'Delete the .tf files', why: 'The building stays. Only the drawings go.' }, { label: 'Leave it. It is only a test.', why: 'Forgotten tests still cost money.' }]} />
</Card>

<Card id="try-apply" type="try">
Build the stall first. Type `tofu apply`. Read the plan it shows. Then type `yes`.

<Interactive name="TofuSim" scenario="t1-ready" goal={{ resourceInState: ['random_pet.stall', 'local_file.sign'] }} hints={['Type tofu apply.', 'It shows the plan, then waits. Type yes.']} success="Built. The picture shows both things in the register." />

<Hint>`tofu apply`, read, then `yes`.</Hint>
</Card>

<Card id="predict" type="predict">
At the question you type `y`, not `yes`. What happens?

<Interactive name="Choice" options={[{ label: 'Nothing is built. Only yes counts.', correct: true, why: 'OpenTofu says it: Only yes will be accepted. Anything else cancels.' }, { label: 'It builds, because y means yes', why: 'Not here. A typo should never build by accident.' }, { label: 'It asks again', why: 'It stops at once and changes nothing.' }]} />
</Card>

<Card id="try-destroy" type="try">
Now tear it down. Type `tofu destroy`. Read the red note, then answer `yes`.

<Interactive name="TofuSim" scenario="t1-built" goal={{ stateCount: 0, filesMissing: ['sign.txt'] }} hints={['Type tofu destroy.', 'Read the list of what goes. Then type yes.']} success="Gone. The register is empty, and sign.txt is deleted." />

**<Term id="destroy">destroy</Term>** deletes real things. Careful: always read its list first.
</Card>

</Card>

<Card id="check-swipe" type="check">
`-auto-approve` skips the question. Good idea or not?

<Card id="win" type="win">
You can now build with apply and tear down with destroy, safely.
</Card>

<Card id="deeper" type="deeper">
`tofu plan -destroy` shows what destroy would delete, and deletes nothing. `tofu destroy` is the same as `tofu apply -destroy`. Careful: `-auto-approve` skips the question. Use it only in practice, or in a pipeline that showed a plan first.
</Card>
