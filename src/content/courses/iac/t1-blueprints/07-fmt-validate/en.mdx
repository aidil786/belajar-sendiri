<Card id="deeper" type="deeper">
`tofu fmt -check` changes nothing. It lists messy files and fails, so CI can stop untidy code. `-diff` shows the changes; `-recursive` tidies sub-folders too. validate needs `tofu init` first, but never reads the state or the real things. Many editors run fmt each time you save.
</Card>
