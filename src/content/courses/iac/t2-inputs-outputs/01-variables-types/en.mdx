<Card id="see-types" type="see">
Each variable has a **<Term id="type-constraint">type</Term>**: the kind of value that fits. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'string', label: 'string (text)' }, { id: 'number', label: 'number' }, { id: 'bool', label: 'bool (true or false)' }, { id: 'list', label: 'list' }]} items={[{ label: '`"Kedai Kancil"`', bucket: 'string', why: 'Text goes in quotes.' }, { label: '`4`', bucket: 'number', why: 'A number, no quotes.' }, { label: '`true`', bucket: 'bool', why: 'true or false, no quotes.' }, { label: '`["nasi", "mee"]`', bucket: 'list', why: 'Square brackets hold a list.' }, { label: '`"4"`', bucket: 'string', why: 'The quotes make it text, not a number.' }]} success="Quotes, numbers, true or false, brackets." />
</Card>

<Card id="predict" type="predict">
`tables` has `type = number`. Someone types `-var tables=lots`. What happens?

<Interactive name="Choice" options={[{ label: 'OpenTofu stops: a number is required', correct: true, why: 'The type is a guard at the door. <Card id="try-rule" type="try">
This blueprint allows 1 to 10 tables. Ask for 20: `tofu plan -var tables=20`. Then plan again with 6.

<Interactive name="TofuSim" scenario="t2-inputs" intro={['tofu init']} open="variables.tf" goal={{ typed: 'tables=20', planSummary: { add: 1 } }} hints={['Type tofu plan -var tables=20 and read the error.', 'Now type tofu plan -var tables=6.']} success="20 was refused by the rule. 6 passed, and the plan worked." />

`Error: Invalid value for variable`. Plain words: the blueprint's own rule says 1 to 10.
</Card>

<Card id="deeper" type="deeper">
More types: `map(number)` holds name-to-value pairs. `set(string)` is a list without repeats. `object({ … })` groups named fields. A `default` makes a variable optional. `sensitive = true` hides a value on screen, but it is still in the state (World T3).
