<Card id="see-types" type="see">
Setiap variable ada **<Term id="type-constraint">type (jenis)</Term>**: jenis nilai yang muat. Asingkan.

<Interactive name="SortCards" buckets={[{ id: 'string', label: 'string (teks)' }, { id: 'number', label: 'number (nombor)' }, { id: 'bool', label: 'bool (true atau false)' }, { id: 'list', label: 'list (senarai)' }]} items={[{ label: '`"Kedai Kancil"`', bucket: 'string', why: 'Teks dalam tanda petik.' }, { label: '`4`', bucket: 'number', why: 'Nombor, tanpa tanda petik.' }, { label: '`true`', bucket: 'bool', why: 'true atau false, tanpa tanda petik.' }, { label: '`["nasi", "mee"]`', bucket: 'list', why: 'Kurungan segi empat simpan senarai.' }, { label: '`"4"`', bucket: 'string', why: 'Tanda petik jadikannya teks, bukan nombor.' }]} success="Tanda petik, nombor, true atau false, kurungan." />
</Card>

<Card id="predict" type="predict">
`tables` ada `type = number`. Seseorang taip `-var tables=lots`. Apa jadi?

<Interactive name="Choice" options={[{ label: 'OpenTofu berhenti: perlu nombor', correct: true, why: 'Jenis ialah pengawal di pintu. Tiada apa dibina.' }, { label: 'Ia bina papan tanda dengan banyak meja', why: 'lots ialah teks. Jenis itu cuma benarkan nombor.' }, { label: 'Ia guna nilai default', why: 'Nilai salah tak pernah ditukar diam-diam. Ia berhenti dan beri sebab.' }]} />
</Card>

<Card id="try-rule" type="try">
Pelan ini benarkan 1 hingga 10 meja. Minta 20: `tofu plan -var tables=20`. Kemudian plan lagi dengan 6.

<Interactive name="TofuSim" scenario="t2-inputs" intro={['tofu init']} open="variables.tf" goal={{ typed: 'tables=20', planSummary: { add: 1 } }} hints={['Taip tofu plan -var tables=20 dan baca ralatnya.', 'Sekarang taip tofu plan -var tables=6.']} success="20 ditolak oleh peraturan. 6 lulus, dan plan berjaya." />

`Error: Invalid value for variable`. Maksudnya: peraturan pelan itu sendiri kata 1 hingga 10.
</Card>

<Card id="deeper" type="deeper">
Jenis lain: `map(number)` simpan pasangan nama-nilai. `set(string)` ialah senarai tanpa ulangan. `object({ … })` kumpul medan bernama. `default` jadikan variable pilihan. `sensitive = true` sorok nilai di skrin, tapi ia masih dalam state (Dunia T3).
