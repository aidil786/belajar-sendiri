<Card id="predict" type="predict">

<Card id="try-add" type="try">
Open `outputs.tf`. Add the output below. Then `tofu apply`, and `yes`.

<Interactive name="TofuSim" scenario="t2-outputs" open="outputs.tf" goal={{ outputEquals: { sign_filename: 'sign.txt' } }} hints={['Add a new block under the first one, in outputs.tf.', 'output "sign_filename" { value = local_file.sign.filename }', 'Then tofu apply, and yes.']} success="sign_filename = sign.txt. You shared a second value." />

```hcl
output "sign_filename" {
  value = local_file.sign.filename
}
```
</Card>

<Card id="deeper" type="deeper">
`tofu output -json` prints every output as JSON for other programs. `sensitive = true` on an output hides it on screen; `tofu output -raw` still shows it. Outputs also pass values out of modules (World T4).
</Card>
