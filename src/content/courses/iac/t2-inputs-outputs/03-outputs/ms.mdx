OpenTofu pilih nama gerai secara rawak. Pencetak menu perlukan nama itu. Di mana rakan anda boleh jumpa?

<Interactive name="Choice" options={[{ label: 'Dalam output yang pelan kongsi selepas apply', correct: true, why: 'Output serahkan nilai yang dibina kepada manusia dan skrip.' }, { label: 'Dengan korek terraform.tfstate', why: 'Boleh, tapi bersepah. <Card id="try-read" type="try">
Bina dulu, kemudian baca output: `tofu apply`, `yes`, kemudian `tofu output`.

<Interactive name="TofuSim" scenario="t2-outputs" open="outputs.tf" goal={{ outputExists: ['stall_name'], lastTyped: '^tofu output' }} hints={['Taip tofu apply, kemudian yes.', 'Kemudian taip tofu output.']} success="stall_name = nama yang OpenTofu pilih. Sesiapa boleh baca sekarang." />

**<Term id="output-value">Output</Term>** ialah nilai yang pelan kongsi selepas apply.
</Card>

<Card id="see-raw" type="see">
Satu skrip cuma perlukan nama itu, tanpa tanda petik. Bina arahannya.

<Interactive name="CommandBuilder" pieces={[{ text: 'tofu', means: 'cakap dengan OpenTofu' }, { text: 'output', means: 'baca output' }, { text: '-raw', means: 'nilai sahaja, tanpa tanda petik' }, { text: 'stall_name', means: 'output yang mana' }]} decoys={[{ text: 'apply', means: 'bina benda' }, { text: '-json', means: 'semua output sebagai JSON' }]} success="tofu output -raw stall_name paparkan nama itu sahaja." />
</Card>

<Card id="predict" type="predict">

<Card id="try-add" type="try">
Buka `outputs.tf`. Tambah output di bawah. Kemudian `tofu apply`, dan `yes`.

<Interactive name="TofuSim" scenario="t2-outputs" open="outputs.tf" goal={{ outputEquals: { sign_filename: 'sign.txt' } }} hints={['Tambah blok baru di bawah blok pertama, dalam outputs.tf.', 'output "sign_filename" { value = local_file.sign.filename }', 'Kemudian tofu apply, dan yes.']} success="sign_filename = sign.txt. Anda kongsi nilai kedua." />

```hcl
output "sign_filename" {
  value = local_file.sign.filename
}
```
</Card>

<Card id="win" type="win">
Kini anda boleh kongsi nilai yang dibina dengan output.
</Card>

<Card id="deeper" type="deeper">
`tofu output -json` paparkan semua output sebagai JSON untuk program lain. `sensitive = true` pada output sorok nilainya di skrin; `tofu output -raw` masih tunjuk. Output juga hantar nilai keluar dari modul (Dunia T4).
</Card>
