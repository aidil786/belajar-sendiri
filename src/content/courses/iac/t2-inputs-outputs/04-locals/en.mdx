<Card id="hook" type="hook">
The opening hours appear twice in the blueprint. Now the shop opens at 7am. What could go wrong?

```hcl

```

<Card id="see-locals" type="see">
Here the hours are written once, in a `locals` block. Tap every line that uses them.

<Interactive name="SpotLines" lines={[{ text: 'locals {' }, { text: '  hours = "8am to 10pm"' }, { text: '}' }, { text: '' }, { text: 'resource "local_file" "door" {' }, { text: '  filename = "door.txt"' }, { text: '  content  = "Open ${local.hours}\\n"', target: true }, { text: '}' }, { text: '' }, { text: 'resource "local_file" "board" {' }, { text: '  filename = "board.txt"' }, { text: '  content  = "Kedai Kancil, ${local.hours}\\n"', target: true }, { text: '}' }]} success="Two users, one value. local.hours." />

A **<Term id="local-value">local value</Term>** gives a value one name, used anywhere in the blueprint.

<Card id="deeper" type="deeper">
The block is `locals` (plural); you read one value as `local.hours` (singular). A local can use variables, functions and other locals, like `upper(var.shop)`. Don't overdo it: a local used only once just adds a hop to follow.
</Card>
