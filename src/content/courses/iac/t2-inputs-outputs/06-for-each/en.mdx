<Card id="try-map" type="try">
`for_each` takes a map too: `each.key` is the dish, `each.value` its price. Build the price tags: `tofu apply`, `yes`.

<Interactive name="TofuSim" scenario="t2-prices" goal={{ fileContains: { 'nasi-price.txt': 'RM5' } }} hints={['Type tofu apply.', 'Read the plan: 2 to add. Type yes.', 'Then cat nasi-price.txt to read one tag.']} success="nasi: RM5 and teh: RM2. One file per map entry." />

```hcl
resource "local_file" "price" {
  for_each = var.prices
  filename = "${each.key}-price.txt"
  content  = "${each.key}: RM${each.value}\n"
}
```
</Card>

<Card id="deeper" type="deeper">
for_each takes a map or a set of strings. Turn a list into a set with `toset(var.stalls)`. The keys must be known before apply, so they can't come from random values. In a shell, quote addresses with brackets: `tofu state show 'local_file.stall["mee"]'`.
</Card>
