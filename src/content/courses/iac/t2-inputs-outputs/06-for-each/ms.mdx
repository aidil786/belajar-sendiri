<Card id="try-map" type="try">
`for_each` terima map juga: `each.key` ialah hidangan, `each.value` harganya. Bina tanda harga: `tofu apply`, `yes`.

<Interactive name="TofuSim" scenario="t2-prices" goal={{ fileContains: { 'nasi-price.txt': 'RM5' } }} hints={['Taip tofu apply.', 'Baca plan: 2 to add. Taip yes.', 'Kemudian cat nasi-price.txt untuk baca satu tanda.']} success="nasi: RM5 dan teh: RM2. Satu fail untuk setiap entri map." />

```hcl
resource "local_file" "price" {
  for_each = var.prices
  filename = "${each.key}-price.txt"
  content  = "${each.key}: RM${each.value}\n"
}
```
</Card>

<Card id="deeper" type="deeper">
for_each terima map atau set string. Tukar list jadi set dengan `toset(var.stalls)`. Kunci mesti diketahui sebelum apply, jadi ia tak boleh datang dari nilai rawak. Dalam shell, letak tanda petik pada alamat berkurungan: `tofu state show 'local_file.stall["mee"]'`.
</Card>
