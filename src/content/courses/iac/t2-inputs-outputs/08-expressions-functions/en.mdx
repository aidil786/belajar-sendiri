<Card id="predict" type="predict">
A **<Term id="conditional">conditional</Term>** picks one of two values. With `open = false`, what does `door` say?

```hcl
output "door" {
  value = var.open ? "OPEN" : "CLOSED"
}
```

<Interactive name="Choice" compact options={[{ label: '"CLOSED"', correct: true, why: 'false picks the value after the colon.' }, { label: '"OPEN"', why: 'OPEN is picked only when var.open is true.' }, { label: 'An error', why: 'false is a fine answer. It picks CLOSED.' }]} />
</Card>

<Card id="try-closed" type="try">

<Interactive name="TofuSim" scenario="t2-functions" goal={{ outputEquals: { door: 'CLOSED' } }} hints={['Type tofu apply -var open=false', 'Then type yes.']} success="door = CLOSED. One variable flips the answer." />

<Card id="check-for" type="check">
A `for` expression changes every item. What does this give?

```hcl
[for s in var.stalls : upper(s)]
```

<Interactive name="Choice" options={[{ label: '["NASI", "MEE", "ROTI"]', correct: true, why: 'For each stall s, upper(s). A new list.' }, { label: '"NASI, MEE, ROTI"', why: 'Square brackets make a list, not one text. join would make text.' }, { label: '["nasi", "mee", "roti"]', why: 'upper(s) changes each item to capitals.' }]} />
</Card>
