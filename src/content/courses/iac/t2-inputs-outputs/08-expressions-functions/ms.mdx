<Card id="predict" type="predict">
**<Term id="conditional">Conditional (bersyarat)</Term>** pilih satu daripada dua nilai. Dengan `open = false`, apa `door` kata?

```hcl
output "door" {
  value = var.open ? "OPEN" : "CLOSED"
}
```

<Interactive name="Choice" compact options={[{ label: '"CLOSED"', correct: true, why: 'false pilih nilai selepas titik bertindih.' }, { label: '"OPEN"', why: 'OPEN dipilih hanya bila var.open ialah true.' }, { label: 'Ralat', why: 'false ialah jawapan yang sah. Ia pilih CLOSED.' }]} />
</Card>

<Card id="try-closed" type="try">
Tutup kedai untuk malam ini: `tofu apply -var open=false`, kemudian `yes`.

<Interactive name="TofuSim" scenario="t2-functions" goal={{ outputEquals: { door: 'CLOSED' } }} hints={['Taip tofu apply -var open=false', 'Kemudian taip yes.']} success="door = CLOSED. Satu variable tukar jawapannya." />

<Hint>`tofu apply -var open=false`, kemudian `yes`.</Hint>
</Card>

<Card id="check-for" type="check">
Ungkapan `for` ubah setiap item. Apa hasilnya?

```hcl
[for s in var.stalls : upper(s)]
```

<Interactive name="Choice" options={[{ label: '["NASI", "MEE", "ROTI"]', correct: true, why: 'Untuk setiap gerai s, upper(s). Senarai baru.' }, { label: '"NASI, MEE, ROTI"', why: 'Kurungan segi empat buat senarai, bukan satu teks. join yang buat teks.' }, { label: '["nasi", "mee", "roti"]', why: 'upper(s) tukar setiap item jadi huruf besar.' }]} />
</Card>
