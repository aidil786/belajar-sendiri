<Card id="try-three" type="try">

<Interactive name="TofuSim" scenario="t2-boss" open="terraform.tfvars" goal={{ stateCount: 3, filesExist: ['stalls/mee.txt', 'stalls/roti.txt'] }} hints={['Add two lines inside the braces: mee = 4 and roti = 2.', 'Then tofu apply.   nasi = 5
```hcl
  mee  = 4
  roti = 2
}
```

<Card id="predict" type="predict">
`stall_files` joins every file name with a `for` expression. What does `tofu output` print?

<Interactive name="Choice" options={[{ label: 'stall_files = "stalls/mee.txt, stalls/nasi.txt, stalls/roti.txt"', correct: true, why: 'for collects the names; join glues them into one text, in key order.' }, { label: 'stall_files = "stalls/nasi.txt"', why: 'The for goes over every stall, not just the first.' }, { label: 'Nothing, outputs need a separate command', why: 'tofu output reads them from the state after apply.' }]} />
</Card>

<Card id="try-output" type="try">
The boss wants the stall names too. In `outputs.tf`, add the output below. Then apply.

<Interactive name="TofuSim" scenario="t2-boss-built" open="outputs.tf" goal={{ outputExists: ['stall_names'] }} hints={['Add a new output block under stall_files.', 'output "stall_names" { value = join(", ", keys(var.stalls)) }', 'Then tofu apply, and yes.']} success="stall_names = mee, nasi, roti. The boss can read the list." />

```hcl
output "stall_names" {
  value = join(", ", keys(var.stalls))
}
```
</Card>
