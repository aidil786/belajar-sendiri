<Interactive name="Choice" options={[{ label: 'Tambah mee dan roti ke map stalls dalam terraform.tfvars', correct: true, why: 'for_each buat satu fail untuk setiap entri. </Card>

<Card id="try-three" type="try">
Dalam `terraform.tfvars`, tambah `mee = 4` dan `roti = 2` ke dalam map. Kemudian `tofu apply`, dan `yes`.

<Interactive name="TofuSim" scenario="t2-boss" open="terraform.tfvars" goal={{ stateCount: 3, filesExist: ['stalls/mee.txt', 'stalls/roti.txt'] }} hints={['Tambah dua baris dalam kurungan: mee = 4 dan roti = 2.', 'Kemudian tofu apply. Plan tambah 3. Taip yes.']} success="Tiga gerai, satu blok, satu senarai." />

```hcl
stalls = {
  nasi = 5
  mee  = 4
  roti = 2
}
```
</Card>

<Card id="predict" type="predict">
`stall_files` gabungkan setiap nama fail dengan ungkapan `for`. Apa `tofu output` paparkan?

<Interactive name="Choice" options={[{ label: 'stall_files = "stalls/mee.txt, stalls/nasi.txt, stalls/roti.txt"', correct: true, why: 'for kumpul nama-nama itu; join cantumkannya jadi satu teks, ikut susunan kunci.' }, { label: 'stall_files = "stalls/nasi.txt"', why: 'for lalu setiap gerai, bukan yang pertama sahaja.' }, { label: 'Tiada apa, output perlukan arahan lain', why: 'tofu output baca dari state selepas apply.' }]} />
</Card>

<Card id="try-output" type="try">
Bos mahu nama gerai juga. Dalam `outputs.tf`, tambah output di bawah. Kemudian apply.

<Interactive name="TofuSim" scenario="t2-boss-built" open="outputs.tf" goal={{ outputExists: ['stall_names'] }} hints={['Tambah blok output baru di bawah stall_files.', 'output "stall_names" { value = join(", ", keys(var.stalls)) }', 'Kemudian tofu apply, dan yes.']} success="stall_names = mee, nasi, roti. Bos boleh baca senarai itu." />

```hcl
output "stall_names" {
  value = join(", ", keys(var.stalls))
}
```
</Card>
