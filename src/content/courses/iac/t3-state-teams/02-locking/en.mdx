<Card id="deeper" type="deeper">
Most shared backends lock: `s3` with `use_lockfile = true`, `gcs`, `azurerm`, `pg`. Terraform's docs call DynamoDB locking for `s3` deprecated; OpenTofu keeps both. The local backend uses the computer's own file lock. That is how this real error happened: two runs on one machine.

Real rep (optional): two terminals, one folder, one register.
