<Card id="deeper" type="deeper">
`lifecycle { ignore_changes = [tags] }` tells OpenTofu to stop caring about one argument that others change on purpose. Drift checks often run on a schedule in CI. `tofu refresh` is an old, deprecated twin of `tofu apply -refresh-only -auto-approve`. Use `tofu apply -refresh-only`: it asks before it writes.
