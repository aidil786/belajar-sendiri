**<Term id="import-block">Blok import</Term>** berkata: "Benda ini sudah wujud. Ambil alih, jangan bina." `to` ialah alamat dalam pelan anda. `id` tunjuk benda sebenar.
</Card>

<Card id="try-import" type="try">
Tambah blok import di bawah resource pintu dalam `main.tf`. Jalankan `tofu plan`: cari `1 to import`. Kemudian `tofu apply`.

<Interactive name="TofuSim" scenario="t3-import-door" goal={{ outputEquals: { door: 'KANCIL' } }} hints={['Di bawah blok resource, tambah: import { to = random_string.door, id = "KANCIL" }, satu tetapan satu baris.', 'tofu plan patut kata: Plan: 1 to import, 0 to add.', 'Kemudian tofu apply dan yes. Tersilap bina kod baharu? Tekan Mula semula.']} success="Berjaya diambil alih! Output door kata KANCIL, dan tiada apa dibina semula." />

<Hint>Salin empat baris dari kad tadi.</Hint>
</Card>

<Card id="check" type="check">

<Interactive name="SwipeJudge" prose cards={[{ text: 'Baca plan dahulu: "1 to import, 0 to destroy"', good: true, why: 'Tepat seperti yang dimahukan: ambil alih, tiada perubahan.' }, { text: 'Plan kata "Warning: this will destroy the imported resource". Apply juga.', good: false, why: 'Berhenti. Jadikan pelan sepadan dengan benda sebenar dahulu.' }, { text: 'Salin id dari tetapan benda sebenar', good: true, why: 'Setiap provider terangkan id import-nya. Salin, jangan teka.' }, { text: 'Teka id dan jalankan apply -auto-approve', good: false, why: 'id yang salah boleh ambil alih, atau nanti padam, benda yang salah.' }]} />
</Card>

<Card id="win" type="win">

<Card id="deeper" type="deeper">
Blok import boleh guna `for_each` untuk ambil alih banyak benda sekaligus. `tofu plan -generate-config-out=generated.tf` boleh draf blok resource untuk anda; dokumentasi masih panggil ia eksperimen. Dokumentasi setiap provider senaraikan id import-nya, dalam bahagian "Import".
