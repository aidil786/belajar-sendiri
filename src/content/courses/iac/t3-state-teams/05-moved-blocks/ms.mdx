OpenTofu kenal benda melalui alamatnya. Nama baharu nampak macam benda baharu. **<Term id="moved-block">Blok moved</Term>** (blok pindah) berkata: "Benda sama, nama baharu."
</Card>

<Card id="try-moved" type="try">
Tambah blok moved dalam `main.tf`. Kemudian `tofu plan`: cari `has moved to`. Kemudian `tofu apply`.

<Interactive name="TofuSim" scenario="t3-rename" goal={{ resourceInState: ['random_pet.chef'], outputEquals: { stall: 'lucky-civet' } }} hints={['Tambah blok moved: from = random_pet.stall, to = random_pet.chef, satu setiap baris.', 'tofu plan patut kata: Plan: 0 to add, 0 to change, 0 to destroy.', 'Kemudian tofu apply dan yes. Dapat nama baharu? Tekan Mula semula.']} success="Nama ditukar, dan gerai kekal namanya: lucky-civet." />

<Hint>Salin empat baris dari kad tadi.</Hint>
</Card>

<Card id="predict" type="predict">

<Card id="win" type="win">
Kini anda boleh tukar nama dan susun semula pelan tanpa bina semula apa-apa.
</Card>

<Card id="deeper" type="deeper">
moved juga boleh tukar nama seluruh modul: `from = module.a`, `to = module.b`. Untuk berhenti mengurus sesuatu tanpa memusnahkannya, guna blok `removed` dengan `lifecycle { destroy = false }`. Modul yang orang lain guna patut simpan blok moved untuk masa yang lama.
