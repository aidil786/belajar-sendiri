<Card id="deeper" type="deeper">
Each state command that changes the register saves a timestamped backup first, like `terraform.tfstate.1793491219.backup`. The reviewable way to forget a thing is a `removed` block in the code. OpenTofu 1.13 also has `lifecycle { destroy = false }`: forget it instead of destroying it.
