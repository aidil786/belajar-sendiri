<Card id="deeper" type="deeper">
Setiap arahan state yang ubah daftar simpan sandaran bertarikh dahulu, seperti `terraform.tfstate.1793491219.backup`. Cara yang boleh disemak untuk melupakan sesuatu ialah blok `removed` dalam kod. OpenTofu 1.13 juga ada `lifecycle { destroy = false }`: lupakan, bukan musnahkan.
