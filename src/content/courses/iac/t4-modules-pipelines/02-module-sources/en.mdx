Your blueprint uses a stall module from the internet, with no version. Tonight its author changes it. Tomorrow CI runs `tofu init` and `tofu plan`. What can happen?

<Interactive name="Choice" options={[{ label: 'It pulls in the new code. Modules need their own pin.' }]} />
</Card>

<Card id="see-pins" type="see">
<Interactive name="SpotLines" prompt="Tap the two lines that pin a version." lines={[{ text: 'module "kiosk" {' }, { text: '  source = "./modules/kiosk"' }, { text: '}' }, { text: '' }, { text: 'module "stall" {' }, { text: '  source  = "kedai-kancil/stall/local"' }, { text: '  version = "~> 1.2"', target: true }, { text: '}' }, { text: '' }, { text: 'module "oven" {' }, { text: '  source = "git::https://example.com/oven.git?ref=v2.0.1"', target: true }, { text: '}' }]} success="Registry modules pin with version. Git pins with ?ref= (a tag or a commit)." />

A **<Term id="version-pin">version pin</Term>** says which versions you trust. A local folder needs none: it changes only when you change it.
</Card>

<Card id="deeper" type="deeper">
OpenTofu can also fetch modules from OCI registries (`oci://`) and from S3, GCS or HTTP. To move to a newer module version, change the pin, then run `tofu init -upgrade`. The lock file (next lesson) records providers only, not modules.
