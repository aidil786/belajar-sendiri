The **<Term id="lock-file">dependency lock file</Term>** records the exact provider version, plus checksums. Then every laptop installs the very same files.
</Card>

<Card id="deeper" type="deeper">
To upgrade, change the pin if needed and run `tofu init -upgrade`. Then review the lock file change in a pull request. OpenTofu 1.13 writes checksums for every platform on init. `tofu providers lock` can still add them by hand. Terraform's lock file has the same name, but its entries point at `registry.terraform.io`.
