<Card id="hook" type="hook">
Semalam ia berjalan. Hari ini, di laptop baharu, `tofu init` pilih provider lebih baharu, dan plan nampak lain. Apa yang patut kekalkan semuanya sama?

<Interactive name="Choice" options={[{ label: 'Fail lock, yang di-commit ke Git', correct: true, why: 'Ia rekod versi tepat yang setiap laptop mesti guna.' }, { label: 'Internet yang lebih laju', why: 'Kelajuan bukan masalahnya. Versi itulah masalahnya.' }, { label: 'Jalankan tofu init dua kali', why: 'Tanpa fail lock, init pilih padanan terbaharu setiap kali.' }]} />
</Card>

<Card id="try-read" type="try">

<Interactive name="TofuSim" scenario="t4-lock" open="providers.tf" goal={{ lastTyped: '^cat \\.terraform\\.lock\\.hcl$' }} hints={['Taip cat .terraform.lock.hcl dan tekan Enter.']} success="Dua provider, setiap satu dengan satu versi tepat dan senarai checksum." />

<Hint>Nama fail bermula dengan titik: `.terraform.lock.hcl`.</Hint>
</Card>

<Interactive name="SpotLines" prompt="Tekan baris dengan versi tepat yang init pilih." lines={[{ text: '# This file is maintained automatically by "tofu init".' }, { text: '# Manual edits may be lost in future updates.' }, { text: '' }, { text: 'provider "registry.opentofu.org/hashicorp/random" {' }, { text: '  version     = "3.9.1"', target: true }, { text: '  constraints = "~> 3.7"' }, { text: '  hashes = [' }, { text: '    "h1:38E2VQmQDhws/3AL3D/EzBGuCseepyZRIswAOx8CqoQ=",' }, { text: '    … (29 checksum lagi)' }, { text: '  ]' }, { text: '}' }]} success="Pin benarkan ~> 3.7. **<Term id="lock-file">Fail lock kebergantungan</Term>** rekod versi provider yang tepat, berserta checksum. Jadi setiap laptop pasang fail yang betul-betul sama.
</Card>

<Card id="win" type="win">
Kini anda boleh baca fail lock dan kekalkan versi provider sama di mana-mana.
</Card>

<Card id="deeper" type="deeper">
Untuk naik taraf, ubah pin jika perlu dan jalankan `tofu init -upgrade`. Kemudian semak perubahan fail lock dalam pull request. OpenTofu 1.13 tulis checksum untuk setiap platform semasa init. `tofu providers lock` masih boleh tambahnya secara manual. Fail lock Terraform ada nama sama, tapi entrinya tunjuk ke `registry.terraform.io`.
