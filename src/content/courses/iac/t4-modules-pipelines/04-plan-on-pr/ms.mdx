<Card id="deeper" type="deeper">
Dalam CI, plan perlukan backend bersama (T3·1), kalau tidak ia nampak daftar kosong. Untuk letak plan sebagai komen, perlukan `pull-requests: write` dan skrip kecil. Untuk apply selepas merge, simpan plan dengan `-out` dan apply fail itu tepat-tepat. Alat seperti Atlantis atau HCP Terraform jalankan kitaran ini untuk anda. Latihan sebenar: Misi 8 letak workflow ini dalam repo anda sendiri.
</Card>
