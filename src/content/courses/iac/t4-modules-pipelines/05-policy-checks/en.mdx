A **<Term id="policy-check">policy check</Term>** is a written rule a robot checks on every plan. This one is Rego, the rule language of Open Policy Agent.

<Card id="predict" type="predict">
The plan replaces the stall (`-/+`). It does not plainly destroy it. Does the rule catch it?

<Interactive name="Choice" options={[{ label: 'Yes: a replace is a delete plus a create', correct: true, why: 'In the JSON its actions are ["delete", "create"].' }, { label: 'No: replace is its own action', why: 'In the plan JSON, a replace lists both delete and create.' }, { label: 'Only if it says -auto-approve', why: 'The rule only reads the plan. Flags do not matter.' }]} />
</Card>
