<Interactive name="SortCards" buckets={[{ id: 'up', label: 'Bill goes up' }, { id: 'down', label: 'Bill goes down or stays' }]} items={[{ label: 'Two new stalls (+)', bucket: 'up', why: 'More things running, more to pay.' }, { label: 'The oven goes from small to large (~)', bucket: 'up', why: 'Bigger sizes cost more.' }, { label: 'The old fridge is removed (-)', bucket: 'down', why: 'One less thing to pay for.' }, { label: 'A rename with a moved block', bucket: 'down', why: 'Nothing real changes, so the price stays.' }]} success="That is what a cost check does, line by line." />

<Card id="deeper" type="deeper">
Infracost is a well-known cost tool. It works as a GitHub App, or as a step in CI. It reads the code, looks up public price lists, and comments the monthly change. Usage-based costs, like traffic, need your own guesses. The AWS course (A1) sets up budget alarms.
</Card>
