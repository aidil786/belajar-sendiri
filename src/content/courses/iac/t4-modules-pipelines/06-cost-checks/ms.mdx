<Card id="see-cost" type="see">
**<Term id="cost-check">Semakan kos</Term>** letak harga pada setiap perubahan dalam plan. Ia tunjuk beza bulanan dalam pull request. Susun perubahan ini.

<Interactive name="SortCards" buckets={[{ id: 'up', label: 'Bil naik' }, { id: 'down', label: 'Bil turun atau sama' }]} items={[{ label: 'Dua gerai baharu (+)', bucket: 'up', why: 'Lebih banyak benda berjalan, lebih banyak bayaran.' }, { label: 'Ketuhar dari kecil ke besar (~)', bucket: 'up', why: 'Saiz lebih besar lebih mahal.' }, { label: 'Peti sejuk lama dibuang (-)', bucket: 'down', why: 'Satu benda kurang untuk dibayar.' }, { label: 'Tukar nama dengan blok moved', bucket: 'down', why: 'Tiada benda sebenar berubah, jadi harga kekal.' }]} success="Itulah kerja semakan kos, baris demi baris." />
</Card>

<Card id="deeper" type="deeper">
Infracost ialah alat kos yang terkenal. Ia boleh jadi GitHub App, atau satu langkah dalam CI. Ia baca kod, semak senarai harga awam, dan komen perubahan bulanan. Kos ikut penggunaan, seperti trafik, perlukan anggaran anda sendiri. Kursus AWS (A1) sediakan penggera bajet.
</Card>
