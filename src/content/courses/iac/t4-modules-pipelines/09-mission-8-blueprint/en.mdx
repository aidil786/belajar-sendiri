<Card id="try-setup" type="try">
Step 1: tools and a folder. Then write `providers.tf` (below). It uses the Docker provider, version 4.6 or a newer 4.x.

<Interactive name="Mission" id="iac-m8-setup" steps={[{ id: 'tofu', text: 'Install OpenTofu 1.13 (see Go deeper for the link). Check it.', command: 'tofu version' }, { id: 'docker', text: 'Start Docker on your laptop. Check it answers.', command: 'docker info' }, { id: 'folder', text: 'Make the project folder and a Git repo.', command: 'mkdir kedai-blueprint && cd kedai-blueprint && git init' }, { id: 'providers', text: 'Save providers.tf with the lines below.' }]} success="Tools ready, folder ready." />

```hcl
terraform {
  required_providers {
    docker = {
      source  = "kreuzwerker/docker"
      version = "~> 4.6"
    }
  }
}

provider "docker" {}
```
</Card>

<Card id="try-write" type="try">
Step 2: the blueprint. Which line opens the shop on your laptop's port 8080?

<Interactive name="Choice" compact options={[{ label: 'external = 8080', correct: true, why: 'external is the laptop side. internal = 80 is nginx inside.' }, { label: 'internal = 80', why: 'That is the port inside the container.' }, { label: 'keep_locally = true', why: 'That keeps the image after destroy.' }]} />

Save this as `main.tf`. Add `outputs.tf` too: `output "url" { value = "http://localhost:8080" }`.

```hcl
resource "docker_image" "web" {
  name         = "nginx:1.30-alpine"
  keep_locally = true
}

resource "docker_container" "web" {
  name  = "kedai-kancil-web"
  image = docker_image.web.image_id

  ports {
    internal = 80
    external = 8080
  }
}
```
</Card>
