<Card id="try-setup" type="try">
Langkah 1: alat dan folder. Kemudian tulis `providers.tf` (di bawah). Ia guna provider Docker, versi 4.6 atau 4.x yang lebih baharu.

<Interactive name="Mission" id="iac-m8-setup" steps={[{ id: 'tofu', text: 'Pasang OpenTofu 1.13 (pautan dalam Nak tahu lebih). Semak.', command: 'tofu version' }, { id: 'docker', text: 'Hidupkan Docker di laptop. Semak ia menjawab.', command: 'docker info' }, { id: 'folder', text: 'Buat folder projek dan repo Git.', command: 'mkdir kedai-blueprint && cd kedai-blueprint && git init' }, { id: 'providers', text: 'Simpan providers.tf dengan baris di bawah.' }]} success="Alat sedia, folder sedia." />

```hcl
terraform {
  required_providers {
    docker = {
      source  = "kreuzwerker/docker"
      version = "~> 4.6"
    }
  }
}

provider "docker" {}
```
</Card>

<Card id="try-write" type="try">
Langkah 2: pelan. Baris mana yang buka kedai pada port 8080 laptop anda?

<Interactive name="Choice" compact options={[{ label: 'external = 8080', correct: true, why: 'external ialah sebelah laptop. internal = 80 ialah nginx di dalam.' }, { label: 'internal = 80', why: 'Itu port di dalam container.' }, { label: 'keep_locally = true', why: 'Itu simpan image selepas destroy.' }]} />

Simpan ini sebagai `main.tf`. Tambah `outputs.tf` juga: `output "url" { value = "http://localhost:8080" }`.

```hcl
resource "docker_image" "web" {
  name         = "nginx:1.30-alpine"
  keep_locally = true
}

resource "docker_container" "web" {
  name  = "kedai-kancil-web"
  image = docker_image.web.image_id

  ports {
    internal = 80
    external = 8080
  }
}
```
</Card>
