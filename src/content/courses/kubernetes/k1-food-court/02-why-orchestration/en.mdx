<Card id="see-manager" type="see">
<Interactive name="KubeReplay" scenario="k1-first-cluster" commands={['kubectl create deployment shop --image=nginx:1.29-alpine --replicas=3', 'sleep 10', 'kubectl get pods']} label="One order asks for 3 shop trays. Ten seconds later, 3 trays run, spread over two stalls." />

An **<Term id="orchestrator">orchestrator</Term>** is a food court manager for containers. You give one order: 3 trays. It finds stalls and spreads the trays out.
</Card>

<Card id="try-sort" type="try">
Who does each job? Sort them.

<Interactive name="SortCards" buckets={[{ id: 'you', label: 'You' }, { id: 'manager', label: 'The manager (Kubernetes)' }]} items={[{ label: 'Decide how many copies you want', bucket: 'you', why: 'You write that on the order.' }, { label: 'Choose the app’s image', bucket: 'you', why: 'You pick what goes on the tray.' }, { label: 'Pick a machine for each copy', bucket: 'manager', why: 'It finds a stall with room.' }, { label: 'Replace a copy that died', bucket: 'manager', why: 'It spots the gap and fills it.' }, { label: 'Spread copies over machines', bucket: 'manager', why: 'Then one dead stall can’t take them all.' }, { label: 'Keep every copy running at 3 a.m.', bucket: 'manager', why: 'It never sleeps.' }]} success="Right! You write the order. The manager does the running around." />

<Hint>You decide what you want. The manager makes it true.</Hint>
</Card>

<Card id="predict" type="predict">
This time a manager is on duty. A stall closes at 1 a.m. What happens to its trays?

<Interactive name="Choice" options={[{ label: 'New trays are made on other stalls', correct: true, why: 'Yes. The manager rebuilds them where there is room.' }, { label: 'They stay gone until you wake up', why: 'That was the night without a manager.' }, { label: 'Every stall closes too', why: 'The other stalls keep serving. Only the lost trays are rebuilt.' }]} />
</Card>

<Card id="check-night" type="check">
<Interactive name="KubeReplay" scenario="k1-night" commands={['kubectl get nodes', 'sleep 300', 'kubectl get pods']} label="dev-worker is NotReady. Five minutes later, its two trays show Terminating, and two new trays run on dev-worker2." />

Here is that night, with a manager. `sleep 300` skips 5 minutes. Two new trays now run on another stall. Nobody woke up.
</Card>
