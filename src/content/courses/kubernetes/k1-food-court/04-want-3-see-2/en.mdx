<Card id="deeper" type="deeper">
This loop is called <Term id="reconciliation">reconciliation</Term>. If only a container crashes, the kubelet restarts it in the same pod. Watch the RESTARTS column. When a node dies, Kubernetes waits about 5 minutes. Then it replaces the pods.
