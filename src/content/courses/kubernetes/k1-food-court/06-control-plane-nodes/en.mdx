<Card id="predict-etcd" type="predict">
The office writes every order in one book: **<Term id="etcd">etcd</Term>**. The book is lost, and there is no backup. What then?

<Interactive name="Choice" options={[{ label: 'The cluster forgets every order', correct: true, why: 'Yes. etcd holds all the cluster’s data. </Card>

<Card id="deeper" type="deeper">
The <Term id="controller-manager">controller manager</Term> is one program that runs many small controllers. With managed Kubernetes, the cloud runs the whole office for you. You only see the stalls.

Real rep (optional): on your kind cluster, `kubectl get pods -n kube-system -o wide` shows which stall runs each part.
