<Card id="deeper" type="deeper">
<Term id="controller-manager">Controller manager</Term> ialah satu program yang jalankan banyak controller kecil. Dengan managed Kubernetes, penyedia cloud jalankan seluruh pejabat untuk anda. Anda cuma nampak gerai.

Latihan sebenar (pilihan): di kluster kind anda, `kubectl get pods -n kube-system -o wide` tunjuk gerai mana jalankan setiap bahagian.
</Card>
