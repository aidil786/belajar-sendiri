<Card id="predict-config" type="predict">
This file is `kind-dev.yaml`. How many stalls will your cluster get?

```yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
  - role: worker
  - role: worker
```

<Interactive name="Choice" options={[{ label: '3: one office stall and two workers', correct: true, why: 'Yes. Each role line is one node.' }, { label: '1', why: 'Count the role lines under nodes.' }, { label: '2', why: 'The control plane is a node too.' }]} />

<Card id="deeper" type="deeper">
Other practice clusters work too. minikube runs a cluster in a container or a virtual machine. k3d runs k3s, a light Kubernetes, inside Docker. The kubectl commands stay the same.

A cluster needs memory. About 8 GB of RAM works for a small one. Your kind version may print a newer node image.
</Card>
