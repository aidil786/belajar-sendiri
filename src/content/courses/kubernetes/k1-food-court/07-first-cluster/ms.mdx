<Card id="predict-config" type="predict">
Fail ini ialah `kind-dev.yaml`. Berapa gerai yang kluster anda akan dapat?

```yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
  - role: worker
  - role: worker
```

<Interactive name="Choice" options={[{ label: '3: satu gerai pejabat dan dua pekerja', correct: true, why: 'Ya. Setiap baris role ialah satu node.' }, { label: '1', why: 'Kira baris role di bawah nodes.' }, { label: '2', why: 'Control plane pun satu node.' }]} />
</Card>

<Card id="deeper" type="deeper">
Kluster latihan lain pun boleh. minikube jalankan kluster dalam container atau mesin maya. k3d jalankan k3s, Kubernetes yang ringan, dalam Docker. Arahan kubectl tetap sama.

Kluster perlukan memori. Lebih kurang 8 GB RAM cukup untuk kluster kecil. Versi kind anda mungkin cetak image node yang lebih baharu.
</Card>
