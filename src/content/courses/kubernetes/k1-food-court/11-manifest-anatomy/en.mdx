<Card id="try-keys" type="try">
This file is a **<Term id="manifest">manifest</Term>**: an order slip written in YAML. Tap its 4 top-level keys. They start at the left edge.

<Interactive name="SpotLines" prompt="Tap the 4 top-level keys of tray.yaml." lines={[{ text: 'apiVersion: v1', target: true }, { text: 'kind: Pod', target: true }, { text: 'metadata:', target: true }, { text: '  name: tray' }, { text: '  labels:' }, { text: '    app: tray' }, { text: 'spec:', target: true }, { text: '  containers:' }, { text: '    - name: web' }, { text: '      image: nginx:1.29-alpine' }]} success="apiVersion, kind, metadata, spec: every order has them." />

<Hint>Indented lines belong to the key above them.</Hint>
</Card>

<Card id="try-sort" type="try">
Who writes each part? Sort them.

<Interactive name="SortCards" buckets={[{ id: 'you', label: 'You write it' }, { id: 'k8s', label: 'Kubernetes writes it' }]} items={[{ label: '`apiVersion: v1`', bucket: 'you', why: 'Which rulebook version to use.' }, { label: '`kind: Pod`', bucket: 'you', why: 'What kind of thing to make.' }, { label: '`metadata.name: tray`', bucket: 'you', why: 'Its name, plus labels if you like.' }, { label: '`spec.containers`', bucket: 'you', why: 'What you want: the order itself.' }, { label: '`status.phase: Running`', bucket: 'k8s', why: 'What is really there now.' }, { label: '`metadata.uid`', bucket: 'k8s', why: 'A unique id the cluster hands out.' }]} success="You write the order. Kubernetes writes what happened." />
</Card>

<Card id="see-status" type="see">

<Card id="predict" type="predict">
You add `replicas: 3` under this Pod’s `spec`. What happens?

<Interactive name="Choice" options={[{ label: 'It is refused', correct: true, why: 'Kubernetes says: strict decoding error: unknown field "spec.replicas". Plain words: a Pod has no such field. Counting trays is a Deployment’s job.' }, { label: '3 trays appear', why: 'A Pod is one tray. It can’t count. A Deployment can (World K2).' }, { label: 'It is quietly ignored', why: 'Kubernetes checks fields strictly. It refuses ones it doesn’t know.' }]} />
</Card>

<Card id="try-doctor" type="try">
This order is refused. Read the red line, then fix the file until `kubectl apply` turns green.

<Interactive name="YamlDoctor" file="tray.yaml" manifest={'apiVersion: apps/v1\nkind: Pod\nmetadata:\n  name: tray\n  labels:\n    app: tray\nspec:\n  containers:\n    - name: web\n      image: nginx:1.29-alpine\n'} solution={'apiVersion: v1\nkind: Pod\nmetadata:\n  name: tray\n  labels:\n    app: tray\nspec:\n  containers:\n    - name: web\n      image: nginx:1.29-alpine\n'} keep={['^kind: Pod$', 'name: tray']} hint="Pods live in the core group. Their apiVersion is just v1." success="pod/tray created. Right rulebook, right kind." />

<Hint>Deployments use apps/v1. Pods use v1.</Hint>
</Card>

<Card id="deeper" type="deeper">
See every field Kubernetes added. `uid`, `creationTimestamp` and the whole `status` come from the cluster. Don’t copy them back into your file.
