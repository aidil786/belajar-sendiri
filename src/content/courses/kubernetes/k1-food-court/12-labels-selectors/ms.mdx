<Card id="see-labels" type="see">
<Interactive name="KubeReplay" scenario="k1-labels" commands={['kubectl get pods --show-labels']} label="Tiga pod dengan label: api-1 ada app=api, shop-1 ada app=shop dan tier=web, shop-2 ada app=shop." />

**<Term id="label">Label (pelekat)</Term>** ialah pelekat: satu kunci dan satu nilai, contohnya `app=shop`. Satu dulang boleh pakai banyak. `--show-labels` tunjuk semuanya.
</Card>

<Card id="try-select" type="try">
**<Term id="selector">Selector (pemilih)</Term>** pilih dulang ikut pelekatnya. Tunjuk dulang shop sahaja: `kubectl get pods -l app=shop`.

<Interactive name="FoodCourtSim" scenario="k1-labels" goal={{ typed: '(-l|--selector)[ =]?app=shop\\b' }} hints={['Taip kubectl get pods -l app=shop dan tekan Enter.']} success="shop-1 dan shop-2. api-1 tinggal di luar." />

<Hint>`-l` bermaksud label selector.</Hint>
</Card>

<Card id="predict" type="predict">
Pod mana yang padan dengan `-l app=shop,tier=web`?

<Interactive name="Choice" options={[{ label: 'shop-1 sahaja', correct: true, why: 'Koma bermaksud DAN. Hanya shop-1 pakai kedua-dua pelekat.' }, { label: 'shop-1 dan shop-2', why: 'shop-2 belum ada pelekat tier=web.' }, { label: 'Ketiga-tiganya', why: 'api-1 ada app=api, bukan app=shop.' }]} />
</Card>

<Card id="try-match" type="try">
Nombor pesanan shop pilih `app=shop` dan `tier=web`. Lekatkan label supaya kedua-dua dulang shop menjawab, tapi api-1 tidak.

<Interactive name="LabelMatchmaker" pods={[{ name: 'shop-1', labels: { app: 'shop', tier: 'web' } }, { name: 'shop-2', labels: { app: 'shop' } }, { name: 'api-1', labels: { app: 'api' } }]} labels={['tier=web', 'app=shop', 'app=api']} selector={{ app: 'shop', tier: 'web' }} task={{ type: 'select', pods: ['shop-1', 'shop-2'] }} success="Kedua-dua dulang shop menyala. api-1 kekal gelap." />

<Hint>shop-2 kurang satu pelekat.</Hint>
</Card>

<Card id="try-label" type="try">
Sekarang buat dengan kubectl: `kubectl label pod shop-2 tier=web`. Kemudian semak dengan `kubectl get pods -l tier=web`.

<Interactive name="FoodCourtSim" scenario="k1-labels" goal={{ labels: { kind: 'Pod', name: 'shop-2', labels: { tier: 'web' } } }} hints={['Taip kubectl label pod shop-2 tier=web dan tekan Enter.']} success="pod/shop-2 labeled. Kini ia pakai tier=web." />
</Card>

<Card id="check-good" type="check">

<Card id="win" type="win">
Kini anda boleh lekatkan label pada dulang dan pilihnya dengan selector.
</Card>

<Card id="deeper" type="deeper">
Deployment pun guna selector. Templat pod-nya mesti pakai label yang selector minta. Cuba:

<Interactive name="LabelMatchmaker" pods={[]} labels={['app=shop', 'tier=web']} selector={{ app: 'shop' }} templateLabels={{ app: 'web' }} task={{ type: 'template' }} success="Selector dan templat sepadan. Deployment diterima." />

Latihan sebenar (pilihan): `kubectl get pods -l app!=shop` tunjuk setiap dulang tanpa pelekat itu.
</Card>
