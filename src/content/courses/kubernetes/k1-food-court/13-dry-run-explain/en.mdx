<Card id="predict" type="predict">
`--dry-run=client` stays on your laptop. `--dry-run=server` asks the cluster to check, then throws it away. Which one catches more mistakes?

<Interactive name="Choice" options={[{ label: 'server: the cluster checks it for real', correct: true, why: 'Yes. The API server runs its full checks, then saves nothing.' }, { label: 'client: it is faster', why: 'Faster, but your laptop can’t check everything the cluster knows.' }, { label: 'They are the same', why: 'Only server sends the order to the API server.' }]} />
</Card>

<Interactive name="KubeReplay" scenario="k1-dry-run" picture={false} commands={['kubectl explain deployment.spec.replicas']} label="kubectl explain deployment.spec.replicas: an integer, the number of desired pods, default 1." />

Forgot what a field means? **kubectl explain** reads the cluster’s own docs. Join the field path with dots: deployment, then spec, then replicas.
</Card>
