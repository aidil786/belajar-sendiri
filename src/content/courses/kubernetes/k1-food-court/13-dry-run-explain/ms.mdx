**<Term id="dry-run">Dry run (raptai)</Term>** ialah latihan. `--dry-run=client -o yaml` cetak pesanan tanpa cipta apa-apa. `get deployments` buktikannya: tiada apa-apa.
</Card>

<Card id="predict" type="predict">
`--dry-run=client` kekal dalam laptop anda. `--dry-run=server` minta kluster menyemak, kemudian membuangnya. Yang mana tangkap lebih banyak kesilapan?

<Interactive name="Choice" options={[{ label: 'server: kluster betul-betul menyemak', correct: true, why: 'Ya. API server buat semakan penuh, kemudian tak simpan apa-apa.' }, { label: 'client: ia lebih laju', why: 'Lebih laju, tapi laptop anda tak boleh semak semua yang kluster tahu.' }, { label: 'Kedua-duanya sama', why: 'Hanya server hantar pesanan ke API server.' }]} />
</Card>

<Card id="see-explain" type="see">
<Interactive name="KubeReplay" scenario="k1-dry-run" picture={false} commands={['kubectl explain deployment.spec.replicas']} label="kubectl explain deployment.spec.replicas: integer, bilangan pod yang diingini, lalai 1." />

Lupa maksud satu medan? **kubectl explain** baca dokumen kluster sendiri. Sambung laluan medan dengan titik: deployment, kemudian spec, kemudian replicas.
</Card>
