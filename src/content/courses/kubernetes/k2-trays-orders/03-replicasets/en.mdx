</Card>

<Card id="try-fix" type="try">
A ReplicaSet has 3 parts: how many (`replicas`), which trays count (`selector`), how to make one (`template`). Here the labels do not match. Fix it.

<Interactive name="YamlDoctor" file="trays.yaml" manifest={'apiVersion: apps/v1\nkind: ReplicaSet\nmetadata:\n  name: trays\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: tray\n  template:\n    metadata:\n      labels:\n        app: food\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} solution={'apiVersion: apps/v1\nkind: ReplicaSet\nmetadata:\n  name: trays\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: tray\n  template:\n    metadata:\n      labels:\n        app: tray\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} keep={['matchLabels:\\n\\s+app: tray', 'replicas: 3']} hint="New trays must carry the label the selector looks for." success="It applies! Every new tray carries app: tray." />

<Hint>The template's label must match the selector, word for word.</Hint>
</Card>

<Card id="predict" type="predict">
The ReplicaSet wants 3. You start one more pod by hand, with the label `app=tray`. What happens?

<Interactive name="Choice" options={[{ label: 'It counts 4 and deletes one', correct: true, why: 'It counts every tray with its label, no matter who made it.' }, { label: 'It ignores your pod', why: 'It counts by label. Your pod has the label, so it counts.' }, { label: 'It now wants 4', why: 'The order still says 3. Only you can change that.' }]} />
</Card>

<Card id="check" type="check">
<Interactive name="KubeReplay" scenario="k2-replicaset" commands={['kubectl run extra --image=nginx:1.29-alpine --labels=app=tray', 'kubectl get pods']} label="kubectl run creates the pod extra. A moment later get pods lists only the 3 trays: extra was one too many." />

`extra` was created, then deleted at once. It matched `app=tray`, so it made 4. Labels decide what counts.
</Card>

Real rep (optional): on a throwaway cluster, apply a ReplicaSet, delete one pod, then run `kubectl describe rs trays`. Its Events show each new pod.
