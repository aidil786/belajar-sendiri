**<Term id="replicaset">ReplicaSet</Term>** mengira dulang, berulang kali. Mahu 3, nampak 2? Ia buat 1 lagi. Tekan delete pada satu dulang dan perhati papan.

<Card id="try-fix" type="try">
ReplicaSet ada 3 bahagian: berapa banyak (`replicas`), dulang mana dikira (`selector`), cara buat satu (`template`). Di sini label tak sepadan. Baiki.

<Interactive name="YamlDoctor" file="trays.yaml" manifest={'apiVersion: apps/v1\nkind: ReplicaSet\nmetadata:\n  name: trays\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: tray\n  template:\n    metadata:\n      labels:\n        app: food\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} solution={'apiVersion: apps/v1\nkind: ReplicaSet\nmetadata:\n  name: trays\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: tray\n  template:\n    metadata:\n      labels:\n        app: tray\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} keep={['matchLabels:\\n\\s+app: tray', 'replicas: 3']} hint="Dulang baharu mesti bawa label yang selector cari." success="Berjaya! Setiap dulang baharu bawa app: tray." />

<Hint>Label dalam template mesti sama dengan selector, perkataan demi perkataan.</Hint>
</Card>

<Card id="predict" type="predict">
ReplicaSet mahu 3. Anda mulakan satu pod lagi dengan tangan, berlabel `app=tray`. Apa jadi?

<Interactive name="Choice" options={[{ label: 'Ia kira 4 dan padam satu', correct: true, why: 'Ia kira setiap dulang yang ada labelnya, tak kira siapa yang buat.' }, { label: 'Ia abaikan pod anda', why: 'Ia mengira ikut label. Pod anda ada label itu, jadi ia dikira.' }, { label: 'Kini ia mahu 4', why: 'Pesanan masih kata 3. Hanya anda boleh tukar.' }]} />
</Card>

<Card id="check" type="check">
<Interactive name="KubeReplay" scenario="k2-replicaset" commands={['kubectl run extra --image=nginx:1.29-alpine --labels=app=tray', 'kubectl get pods']} label="kubectl run cipta pod extra. Sekejap kemudian get pods hanya senaraikan 3 dulang: extra satu terlebih." />

`extra` dicipta, kemudian terus dipadam. Ia sepadan dengan `app=tray`, jadi jumlahnya 4. Label tentukan apa yang dikira.
</Card>

<Card id="deeper" type="deeper">
Anda jarang tulis ReplicaSet sendiri. Deployment buatkannya untuk anda, dan tambah kemas kini yang selamat. Itu pelajaran seterusnya.

Latihan sebenar (pilihan): dalam kluster yang boleh dibuang, apply ReplicaSet, padam satu pod, kemudian jalankan `kubectl describe rs trays`. Events tunjuk setiap pod baharu.
</Card>
