<Interactive name="KubeReplay" scenario="k2-rolling" commands={['kubectl set image deployment/shop web=nginx:1.30-alpine', 'sleep 3', 'kubectl get pods', 'kubectl rollout status deployment/shop --timeout=180s', 'kubectl get rs']} label="Selepas set image, satu pod baharu dicipta sementara 3 pod lama terus berjalan. `kubectl set image` tulis image baharu dalam pesanan. **<Term id="rolling-update" course="cicd">Rolling update</Term>** bermula: satu dulang baharu masuk, satu dulang lama keluar, berulang-ulang.
</Card>

<Card id="try-update" type="try">
Giliran anda. Hantar nginx 1.30 ke kedai. Kemudian tunggu rollout tamat.

<Hint>`kubectl set image deployment/shop web=nginx:1.30-alpine`, kemudian `kubectl rollout status deployment/shop`.</Hint>
</Card>

<Card id="see-history" type="see">
<Interactive name="KubeReplay" scenario="k2-rolling" commands={['kubectl set image deployment/shop web=nginx:1.30-alpine', 'kubectl rollout status deployment/shop --timeout=180s', 'kubectl rollout history deployment/shop']} label="rollout history senaraikan revision 1 dan revision 2." />

Setiap templat baharu dapat nombor **<Term id="revision">revision</Term>** (semakan). ReplicaSet lama kekal, kosong, supaya mudah untuk kembali.
</Card>

<Card id="try-undo" type="try">
Ia berlaku. Dulang baharu tunjuk `ErrImagePull`, kemudian `ImagePullBackOff`. Maksudnya: image itu tak boleh diambil. Undur rollout.

<Interactive name="FoodCourtSim" scenario="k2-bad-rollout" board="shop" goal={{ deploymentImage: { name: 'shop', image: 'nginx:1.29-alpine' }, rolloutComplete: { name: 'shop', minRevision: 3 }, podsReady: { selector: 'app=shop', count: 3 } }} hints={['Taip kubectl rollout undo deployment/shop', 'Kemudian kubectl rollout status deployment/shop']} success="Kembali ke versi baik terakhir. Dulang yang tersangkut sudah tiada." />

<Hint>`kubectl rollout undo deployment/shop` kembali satu revision.</Hint>
</Card>

Kini anda boleh hantar versi baharu tanpa henti, dan undur versi yang rosak.
</Card>

<Card id="deeper" type="deeper">
Selepas `rollout undo`, kubectl cetak Warning: kluster berubah, tapi fail anda tidak. Baiki fail dalam Git juga, atau `apply` seterusnya bawa balik bug itu. Secara lalai, rollout tambah sehingga 25% dulang lebih dan kurangkan paling banyak 25%.

Latihan sebenar (pilihan): dalam kluster yang boleh dibuang, letak image rosak, kemudian undur.
</Card>
