<Card id="see-requests" type="see">
**<Term id="resource-request">Request</Term>** (tempahan) ialah ruang rak yang dulang tempah. Scheduler letak dulang hanya di tempat request itu muat. Muatkan dulang ini di gerai.

<Card id="see-yaml" type="see">
Requests dan **<Term id="resource-limit">limit</Term>** (had) duduk dalam setiap container.

```yaml
resources:
  requests:
    cpu: 100m
  limits:
    memory: 128Mi
```

Yang mana scheduler guna untuk pilih gerai?

<Interactive name="Choice" options={[{ label: 'Requests', correct: true, why: 'Ia tempah ruang ikut request. Limits hanya penting bila dulang berjalan.' }, { label: 'Limits', why: 'Limits hadkan penggunaan kemudian. Meletak dulang guna requests.' }, { label: 'Apa yang aplikasi guna sekarang', why: 'Scheduler tempah ikut request, bukan ikut penggunaan semasa.' }]} />
</Card>

<Card id="try-fix" type="try">
`big` minta 64 CPU. Ralat sebenar: `Insufficient cpu`. Maksudnya: tiada gerai sebesar itu, jadi ia tunggu dalam Pending selamanya. Minta satu persepuluh CPU.

<Interactive name="FoodCourtSim" scenario="k2-limits" goal={{ podsReady: { selector: 'app=big', count: 1 }, rolloutComplete: { name: 'big' } }} hints={['Taip kubectl get pods untuk lihat big menunggu', 'Taip kubectl set resources deployment big --requests=cpu=100m']} success="big dapat gerai. Request yang munasabah dapat tempat duduk." />

<Hint>`kubectl set resources deployment big --requests=cpu=100m` tukar request.</Hint>
</Card>

<Card id="try-doctor" type="try">
Request yang lebih besar daripada limit tak masuk akal. Kubernetes tolak. Baiki satu nombor.

<Interactive name="YamlDoctor" file="web.yaml" manifest={'apiVersion: v1\nkind: Pod\nmetadata:\n  name: web\nspec:\n  containers:\n    - name: web\n      image: nginx:1.29-alpine\n      resources:\n        requests:\n          cpu: 500m\n        limits:\n          cpu: 250m\n'} solution={'apiVersion: v1\nkind: Pod\nmetadata:\n  name: web\nspec:\n  containers:\n    - name: web\n      image: nginx:1.29-alpine\n      resources:\n        requests:\n          cpu: 250m\n        limits:\n          cpu: 250m\n'} keep={['requests:\\n\\s+cpu:', 'limits:\\n\\s+cpu:']} hint="Request mesti sama dengan limit, atau lebih kecil." success="Siap! Tempahan muat bawah had maksimum." />

<Card id="deeper" type="deeper">
CPU dikira dalam teras: `1000m` ialah 1 CPU. Memori guna `Mi` dan `Gi` (1Gi ialah 1024Mi). `kubectl top pods` (Dunia K5) tunjuk penggunaan semasa, supaya anda boleh pilih nombor yang adil.

Latihan sebenar (pilihan): dalam kluster yang boleh dibuang, minta 64 CPU. Kemudian baca Events.
</Card>
