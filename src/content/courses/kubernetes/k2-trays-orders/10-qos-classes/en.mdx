<Card id="see-classes" type="see">
Kubernetes gives every pod a **<Term id="qos-class">QoS class</Term>**, worked out from its requests and limits. Sort these trays.

<Interactive name="SortCards" buckets={[{ id: 'g', label: 'Guaranteed' }, { id: 'b', label: 'Burstable' }, { id: 'e', label: 'BestEffort' }]} items={[{ label: 'gold: CPU and memory requests equal their limits', bucket: 'g', why: 'Every container books exactly its maximum. Burstable.' }, { label: 'bronze: no requests, no limits', bucket: 'e', why: 'Nothing booked at all. BestEffort.' }, { label: 'Only a memory limit, nothing else', bucket: 'b', why: 'Some numbers, not all equal for CPU and memory. Burstable.' }]} success="Sorted! All pinned: Guaranteed. </Card>

<Card id="deeper" type="deeper">
If a container sets only limits, its requests copy the limits. So limits for CPU and memory alone also give Guaranteed. When memory runs short, the kubelet evicts pods using more than they requested first.

Real rep (optional): on a throwaway cluster, apply the three pods and run `kubectl describe pod bronze`. Find the QoS Class line.
</Card>
