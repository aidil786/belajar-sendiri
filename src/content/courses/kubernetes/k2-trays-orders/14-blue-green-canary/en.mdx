**<Term id="canary" course="cicd">Canary</Term>**: a second Deployment with the same `app: shop` label, but only 1 tray. The Service picks all 4, so about 1 in 4 customers tastes version 2.
</Card>

<Card id="deeper" type="deeper">
Where the story breaks: a real tray is a running program. A stall is a whole computer. A replica canary is rough: 1 of 4 is 25%, not 5%. For exact shares, use Gateway API weights (World K3) or Argo Rollouts (World K7).

Real rep (optional): on a throwaway cluster, switch a Service selector, then switch it back.
</Card>
