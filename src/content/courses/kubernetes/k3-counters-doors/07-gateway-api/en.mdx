<Card id="deeper" type="deeper">
Gateway API is not built in. A cluster needs its CRDs plus one controller. Envoy Gateway, Istio, Cilium and NGINX Gateway Fabric are some. Every route here uses `gateway.networking.k8s.io/v1`. On kind, the Gateway address may need cloud-provider-kind.
