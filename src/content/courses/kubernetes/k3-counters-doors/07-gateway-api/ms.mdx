<Card id="deeper" type="deeper">
Gateway API tidak terbina dalam. Kluster perlukan CRD Gateway API serta satu controller. Envoy Gateway, Istio, Cilium dan NGINX Gateway Fabric antaranya. Setiap laluan di sini guna `gateway.networking.k8s.io/v1`. Di kind, alamat Gateway mungkin perlukan cloud-provider-kind.
