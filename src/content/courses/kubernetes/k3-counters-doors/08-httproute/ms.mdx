**<Term id="httproute">HTTPRoute</Term>** pegang papan tanda. Setiap peraturan ialah satu laluan, kemudian satu Service. Papan paling khusus menang.
</Card>

<Card id="try-routes" type="try">
`routes.yaml` tambah papan tanda ini. Apply, kemudian minta `/api/menu` sekali lagi.

```yaml
    - matches:
        - path:
            type: PathPrefix
            value: /api
      backendRefs:
        - name: api
          port: 80
```

<Card id="deeper" type="deeper">
Peraturan juga boleh padankan hostname dan header. Dua `backendRefs` dengan weight, contohnya 90 dan 10, jadi canary. Filter boleh hala HTTP ke HTTPS. `kubectl describe httproute` tunjuk `ResolvedRefs`: Service yang hilang tunjuk `BackendNotFound`.
