<Card id="try-doctor" type="try">
This Ingress comes from an old blog post. It won't apply on Kubernetes 1.37. Fix the first line.

<Interactive name="YamlDoctor" file="ingress.yaml" manifest={'apiVersion: extensions/v1beta1\nkind: Ingress\nmetadata:\n  name: shop\nspec:\n  rules:\n    - http:\n        paths:\n          - path: /\n            pathType: Prefix\n            backend:\n              service:\n                name: shop\n                port:\n                  number: 80\n'} solution={'apiVersion: networking.k8s.io/v1\nkind: Ingress\nmetadata:\n  name: shop\nspec:\n  rules:\n    - http:\n        paths:\n          - path: /\n            pathType: Prefix\n            backend:\n              service:\n                name: shop\n                port:\n                  number: 80\n'} keep={['pathType: Prefix', 'name: shop']} hint="Ingress moved to networking.k8s.io/v1." success="Applied! extensions/v1beta1 was removed in Kubernetes 1.22." />

Plain words: Kubernetes no longer knows Ingress under that old group.
</Card>
