<Card id="see-listener" type="see">
<Interactive name="KubeReplay" scenario="k3-tls" commands={['kubectl get secret kedai-tls', 'kubectl apply -f tls.yaml', 'kubectl get gateway entrance']} label="The Secret kedai-tls has type kubernetes.io/tls with 2 data items. After apply, the entrance is still PROGRAMMED True." />

The entrance gets a second door: HTTPS on port 443. It shows the certificate kept in the Secret `kedai-tls`.

```yaml
    - name: https
      protocol: HTTPS
      port: 443
      hostname: kedai.example
      tls:
        mode: Terminate
        certificateRefs:
          - name: kedai-tls
```
</Card>

<Card id="see-cert-manager" type="see">
Certificates expire. **<Term id="cert-manager">cert-manager</Term>** gets and renews them for you. Put its steps in order.

<Interactive name="OrderList" items={['You add a cert-manager annotation to the Gateway', 'cert-manager reads the HTTPS listener and its hostname', 'It asks Let’s Encrypt for a certificate', 'It proves you own kedai.example', 'It saves the certificate in the Secret kedai-tls', 'It renews it before it expires']} label="First step at the top" success="That's the loop. You never touch the certificate yourself." />
</Card>

This HTTPS door won't apply. Read the error, then fix it.

<Interactive name="YamlDoctor" file="tls.yaml" manifest={'apiVersion: gateway.networking.k8s.io/v1\nkind: Gateway\nmetadata:\n  name: entrance\nspec:\n  gatewayClassName: eg\n  listeners:\n    - name: https\n      protocol: HTTPS\n      hostname: kedai.example\n      tls:\n        mode: Terminate\n        certificateRefs:\n          - name: kedai-tls\n'} solution={'apiVersion: gateway.networking.k8s.io/v1\nkind: Gateway\nmetadata:\n  name: entrance\nspec:\n  gatewayClassName: eg\n  listeners:\n    - name: https\n      protocol: HTTPS\n      port: 443\n      hostname: kedai.example\n      tls:\n        mode: Terminate\n        certificateRefs:\n          - name: kedai-tls\n'} keep={['protocol: HTTPS', 'name: kedai-tls', 'hostname: kedai.example']} hint="Every listener needs a port. <Card id="deeper" type="deeper">
cert-manager 1.15 and newer reads Gateways when its Helm value `config.gatewayAPI.enabled` is true. The listener needs a hostname, `mode: Terminate` and a certificateRefs name. Try Let's Encrypt's staging server first: it has looser limits.
