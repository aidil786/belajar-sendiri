<Card id="see-listener" type="see">
<Interactive name="KubeReplay" scenario="k3-tls" commands={['kubectl get secret kedai-tls', 'kubectl apply -f tls.yaml', 'kubectl get gateway entrance']} label="Secret kedai-tls jenis kubernetes.io/tls dengan 2 item data. Selepas apply, pintu masuk masih PROGRAMMED True." />

Pintu masuk dapat pintu kedua: HTTPS di port 443. Ia tunjuk sijil yang disimpan dalam Secret `kedai-tls`.

```yaml
    - name: https
      protocol: HTTPS
      port: 443
      hostname: kedai.example
      tls:
        mode: Terminate
        certificateRefs:
          - name: kedai-tls
```
</Card>

<Card id="check-doctor" type="check">
Pintu HTTPS ini tak boleh apply. Baca ralatnya, kemudian baiki.

<Card id="deeper" type="deeper">
cert-manager 1.15 ke atas baca Gateway bila nilai Helm `config.gatewayAPI.enabled` ialah true. Listener perlukan hostname, `mode: Terminate` dan nama certificateRefs. Cuba pelayan staging Let's Encrypt dulu: hadnya lebih longgar.
