<Card id="see-lock" type="see">
A **<Term id="networkpolicy">NetworkPolicy</Term>** is a guest list on a pod's door. Nobody on the list? The door stays shut. Turn on the lock, then send an order.

<Hint>The lock drops packets. Nobody says no, so the customer just waits.</Hint>

<Card id="predict" type="predict">
You apply this policy. Can the client still reach the shop?

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: deny-all
spec:
  podSelector: {}
  policyTypes:
    - Ingress
```

<Interactive name="Choice" options={[{ label: 'No: it picks every pod and lets nobody in', correct: true, why: 'An empty podSelector means every pod in the namespace.' }, { label: 'Yes: it doesn’t name the client', why: 'It locks the shop’s door. The guest list is empty.' }, { label: 'Yes: Services skip policies', why: 'The lock is on the tray’s door, even behind a Service.' }]} />
</Card>

<Card id="try-allow" type="try">
Every door is locked now. Let only the client back in with `allow-client.yaml`.

<Interactive name="FoodCourtSim" scenario="k3-policy-locked" goal={{ reachable: { url: 'http://shop', from: 'client' }, unreachable: { url: 'http://shop', from: 'stranger' } }} hints={['Type kubectl apply -f allow-client.yaml', 'Test it: kubectl exec client -- wget -qO- -T 5 http://shop', 'And: kubectl exec stranger -- wget -qO- -T 5 http://shop']} success="The client gets in. The stranger waits outside." />

Its guest list:

```yaml
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: client
      ports:
        - port: 80
```
</Card>

<Card id="check-doctor" type="check">
This lock won't apply. Read kubectl's words, then fix it.

<Interactive name="YamlDoctor" file="deny-all.yaml" manifest={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: deny-all\nspec:\n  podSelector: {}\n  policyTypes:\n    - ingress\n'} solution={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: deny-all\nspec:\n  podSelector: {}\n  policyTypes:\n    - Ingress\n'} keep={['podSelector: \\{\\}', 'name: deny-all']} hint="kubectl lists the two words it knows. Copy the capital letter." success="Applied! Ingress and Egress start with a capital." />

Plain words: Kubernetes knows `Ingress` and `Egress`, with capitals only.
</Card>

<Card id="see-cni" type="see">
A policy is only words. The **<Term id="cni">CNI</Term>** plugin, the food court's walkways, makes them real. Which plugins do that?

<Card id="deeper" type="deeper">
Where the story breaks: a Service is not a real counter. Nobody stands there; each stall just rewrites addresses. A locked door makes no sound: dropped packets vanish, so you see a timeout. Policies add up: any matching allow rule opens the door. Egress rules can block DNS too.
