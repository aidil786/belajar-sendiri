<Card id="predict" type="predict">
Anda apply policy ini. Bolehkah client masih sampai ke kedai?

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: deny-all
spec:
  podSelector: {}
  policyTypes:
    - Ingress
```

<Interactive name="Choice" options={[{ label: 'Tidak: ia pilih setiap pod dan tak benarkan sesiapa masuk', correct: true, why: 'podSelector kosong bermaksud setiap pod dalam namespace itu.' }, { label: 'Ya: ia tak sebut client', why: 'Ia kunci pintu kedai. Senarai tetamunya kosong.' }, { label: 'Ya: Service langkau policy', why: 'Kunci ada di pintu dulang, walaupun di belakang Service.' }]} />
</Card>

<Card id="try-allow" type="try">
Setiap pintu kini berkunci. Benarkan client sahaja masuk semula dengan `allow-client.yaml`.

<Interactive name="FoodCourtSim" scenario="k3-policy-locked" goal={{ reachable: { url: 'http://shop', from: 'client' }, unreachable: { url: 'http://shop', from: 'stranger' } }} hints={['Taip kubectl apply -f allow-client.yaml', 'Uji: kubectl exec client -- wget -qO- -T 5 http://shop', 'Dan: kubectl exec stranger -- wget -qO- -T 5 http://shop']} success="Client boleh masuk. Orang asing tunggu di luar." />

Senarai tetamunya:

```yaml
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: client
      ports:
        - port: 80
```
</Card>

<Card id="check-doctor" type="check">
Kunci ini tak boleh apply. Baca kata-kata kubectl, kemudian baiki.

<Interactive name="YamlDoctor" file="deny-all.yaml" manifest={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: deny-all\nspec:\n  podSelector: {}\n  policyTypes:\n    - ingress\n'} solution={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: deny-all\nspec:\n  podSelector: {}\n  policyTypes:\n    - Ingress\n'} keep={['podSelector: \\{\\}', 'name: deny-all']} hint="kubectl senaraikan dua perkataan yang ia kenal. Salin huruf besarnya." success="Berjaya! Ingress dan Egress bermula dengan huruf besar." />

Maksudnya: Kubernetes kenal `Ingress` dan `Egress`, dengan huruf besar sahaja.
</Card>

<Card id="deeper" type="deeper">
Di mana cerita ini tak tepat: Service bukan kaunter sebenar. Tiada siapa berdiri di situ; setiap gerai cuma tukar alamat. Pintu berkunci tak berbunyi: paket yang dibuang hilang begitu sahaja, jadi anda nampak timeout. Policy bertambah: mana-mana peraturan allow yang sepadan buka pintu. Peraturan egress boleh sekat DNS juga.
