<Card id="try-sign" type="try">
Bilik 1: Mei salin papan /api dari Ingress lama. Ia tak boleh apply. Baikinya.

<Interactive name="YamlDoctor" file="api-route.yaml" manifest={'apiVersion: gateway.networking.k8s.io/v1\nkind: HTTPRoute\nmetadata:\n  name: kedai-api\nspec:\n  parentRefs:\n    - name: entrance\n  rules:\n    - matches:\n        - path:\n            type: Prefix\n            value: /api\n      backendRefs:\n        - name: api\n          port: 80\n'} solution={'apiVersion: gateway.networking.k8s.io/v1\nkind: HTTPRoute\nmetadata:\n  name: kedai-api\nspec:\n  parentRefs:\n    - name: entrance\n  rules:\n    - matches:\n        - path:\n            type: PathPrefix\n            value: /api\n      backendRefs:\n        - name: api\n          port: 80\n'} keep={['value: /api', 'name: api']} hint="Ingress sebut Prefix. HTTPRoute sebut sesuatu yang lebih panjang." success="Bilik 1 selesai! Papan itu kini sebut PathPrefix." />

<Hint>kubectl senaraikan jenis laluan yang ia kenal. Pilih yang prefix.</Hint>
</Card>

<Card id="try-entrance" type="try">
Bilik 2: bina pintu masuk dan pasang papan tanda. Kemudian ketuk di `/api`.

<Interactive name="FoodCourtSim" scenario="k3-boss" goal={{ objectExists: ['gateway/entrance', 'httproute/kedai'], reachable: { url: 'http://172.18.0.200/api', contains: 'nasi lemak' } }} hints={['Taip ls untuk lihat fail.', 'Taip kubectl apply -f entrance.yaml, kemudian kubectl apply -f routes.yaml', 'Uji: curl -s http://172.18.0.200/api']} success="Bilik 2 selesai! / pergi ke kedai, /api ke api." />

<Hint>Pintunya `entrance.yaml`. Papan tandanya `routes.yaml`.</Hint>

<Card id="try-tls" type="try">
Bilik 4: kunci pesanan di tengah jalan. Secret sijil `kedai-tls` dah sedia. Buka pintu HTTPS.

<Interactive name="FoodCourtSim" scenario="k3-boss-tls" goal={{ reachable: { url: 'https://172.18.0.200/', host: 'kedai.example' } }} hints={['Taip cat tls.yaml untuk membacanya.', 'Taip kubectl apply -f tls.yaml', 'Semak: kubectl get gateway entrance']} success="Bilik 4 selesai! HTTPS di port 443 untuk kedai.example." />

<Hint>`tls.yaml` tambah listener HTTPS pada pintu masuk yang sama.</Hint>
</Card>

<Card id="try-lock" type="try">

<Interactive name="FoodCourtSim" scenario="k3-boss-lock" goal={{ unreachable: { url: 'http://db:5432', from: 'app=shop' }, reachable: { url: 'http://db:5432', from: 'app=api' } }} hints={['Taip cat db-deny.yaml dan cat db-lock.yaml. Kedai timeout di pangkalan data. api boleh masuk." />

<Hint>Kunci semua orang juga kunci api. Anda perlukan senarai tetamu.</Hint>
