<Card id="see-note" type="see">
<Interactive name="SpotLines" lines={[{ text: 'apiVersion: v1' }, { text: 'kind: ConfigMap' }, { text: 'metadata:' }, { text: '  name: settings' }, { text: 'data:' }, { text: '  GREETING: Selamat datang', target: true }, { text: '  SPICY: "3"', target: true }]} prompt="Tap the two settings on the note." success="GREETING and SPICY. Plain text, outside the image." />

A note on the stall wall holds the settings. The cook reads it, and the recipe never changes. In Kubernetes, that note is a **<Term id="configmap">ConfigMap</Term>**.
</Card>

<Card id="try-create" type="try">
Pin up the note from the terminal. Then open the shop.

<Interactive name="FoodCourtSim" scenario="k4-notes-new" goal={{ objectExists: ['configmap/settings'], podsReady: { selector: 'app=shop', count: 1 } }} hints={['Type kubectl create configmap settings --from-literal=GREETING=Hai', 'Then open the shop: kubectl apply -f shop.yaml']} success="The note is up, and the tray is reading it." />

<Hint>`--from-literal=GREETING=Hai` writes one line on the note.</Hint>
</Card>

<Card id="see-two-ways" type="see">
<Interactive name="SpotLines" lines={[{ text: 'containers:' }, { text: '  - name: web' }, { text: '    image: nginx:1.29-alpine' }, { text: '    envFrom:', target: true }, { text: '      - configMapRef:', target: true }, { text: '          name: settings', target: true }, { text: '    volumeMounts:' }, { text: '      - name: notes' }, { text: '        mountPath: /etc/notes' }, { text: 'volumes:' }, { text: '  - name: notes' }, { text: '    configMap:' }, { text: '      name: settings' }]} prompt="Tap the lines that turn the note into env vars." success="envFrom copies every line of the note into the box." />

The tray reads the note two ways. `envFrom` makes each line an **environment variable**. The volume makes each line a file in `/etc/notes`.
</Card>

<Card id="try-read" type="try">
Read the note both ways. First the env var, then the file.

<Interactive name="FoodCourtSim" scenario="k4-notes" goal={{ typed: 'printenv GREETING', lastTyped: 'cat /etc/notes/GREETING' }} hints={['Type kubectl exec deploy/shop -- printenv GREETING', 'Then: kubectl exec deploy/shop -- cat /etc/notes/GREETING']} success="Same words, two doors: an env var and a file." />

<Hint>Everything after `--` runs inside the box.</Hint>
</Card>

<Card id="predict" type="predict">
You change the note to `Jemput makan`. You wait two minutes. What does the tray see?

<Interactive name="Choice" options={[{ label: 'The file changes. The env var stays old.', correct: true, why: 'Files follow the note. </Card>

<Card id="check" type="check">
<Interactive name="KubeReplay" scenario="k4-notes" commands={['kubectl apply -f settings-v2.yaml', 'sleep 120', 'kubectl exec deploy/shop -- cat /etc/notes/GREETING', 'kubectl exec deploy/shop -- printenv GREETING']} label="The new note is applied. The file caught up. The env var did not. Restart the trays to read it again: `kubectl rollout restart deployment/shop`.
</Card>

<Card id="win" type="win">
You can now read settings from a ConfigMap, two ways.
</Card>

<Card id="deeper" type="deeper">
A ConfigMap holds up to 1 MiB. It is not secret: anyone who can read ConfigMaps sees it. A file mounted with `subPath` never updates. `immutable: true` stops changes by accident.
