<Card id="see-note" type="see">
<Interactive name="SpotLines" lines={[{ text: 'apiVersion: v1' }, { text: 'kind: ConfigMap' }, { text: 'metadata:' }, { text: '  name: settings' }, { text: 'data:' }, { text: '  GREETING: Selamat datang', target: true }, { text: '  SPICY: "3"', target: true }]} prompt="Tekan dua tetapan pada nota." success="GREETING dan SPICY. Nota di dinding gerai simpan tetapan. Tukang masak membacanya, dan resepi tak pernah berubah. Dalam Kubernetes, nota itu ialah **<Term id="configmap">ConfigMap</Term>**.
</Card>

<Card id="try-create" type="try">
Tampal nota dari terminal. Kemudian buka kedai.

<Interactive name="FoodCourtSim" scenario="k4-notes-new" goal={{ objectExists: ['configmap/settings'], podsReady: { selector: 'app=shop', count: 1 } }} hints={['Taip kubectl create configmap settings --from-literal=GREETING=Hai', 'Kemudian buka kedai: kubectl apply -f shop.yaml']} success="Nota sudah ditampal, dan dulang sedang membacanya." />

<Hint>`--from-literal=GREETING=Hai` tulis satu baris pada nota.</Hint>
</Card>

<Card id="see-two-ways" type="see">
<Interactive name="SpotLines" lines={[{ text: 'containers:' }, { text: '  - name: web' }, { text: '    image: nginx:1.29-alpine' }, { text: '    envFrom:', target: true }, { text: '      - configMapRef:', target: true }, { text: '          name: settings', target: true }, { text: '    volumeMounts:' }, { text: '      - name: notes' }, { text: '        mountPath: /etc/notes' }, { text: 'volumes:' }, { text: '  - name: notes' }, { text: '    configMap:' }, { text: '      name: settings' }]} prompt="Tekan baris yang jadikan nota sebagai env var." success="envFrom salin setiap baris nota ke dalam bekas." />

Dulang baca nota dengan dua cara. `envFrom` jadikan setiap baris satu **environment variable** (pemboleh ubah persekitaran). Volume jadikan setiap baris satu fail dalam `/etc/notes`.
</Card>

<Card id="try-read" type="try">
Baca nota dengan dua cara. Mula-mula env var, kemudian fail.

<Interactive name="FoodCourtSim" scenario="k4-notes" goal={{ typed: 'printenv GREETING', lastTyped: 'cat /etc/notes/GREETING' }} hints={['Taip kubectl exec deploy/shop -- printenv GREETING', 'Kemudian: kubectl exec deploy/shop -- cat /etc/notes/GREETING']} success="Perkataan sama, dua pintu: env var dan fail." />

<Hint>Semua selepas `--` berjalan di dalam bekas.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh baca tetapan daripada ConfigMap, dengan dua cara.
</Card>

<Card id="deeper" type="deeper">
ConfigMap muat sehingga 1 MiB. Ia bukan rahsia: sesiapa yang boleh baca ConfigMap nampak isinya. Fail yang di-mount dengan `subPath` tak pernah dikemas kini. `immutable: true` halang perubahan tanpa sengaja.

Latihan sebenar (pilihan), hanya pada kluster kind untuk latihan:
