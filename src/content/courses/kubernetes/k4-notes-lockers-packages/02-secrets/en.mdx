You put the till password in a **<Term id="secret">Secret</Term>**. Its YAML says `c3VwM3ItcmFoc2lh`. It looks scrambled. But is it safe?
</Card>

<Card id="see-base64" type="see">
<Interactive name="Transcript" title="bash" label="echo the scrambled text into base64 -d. It prints sup3r-rahsia." lines={[{ cmd: 'echo c3VwM3ItcmFoc2lh | base64 -d' }, { out: 'sup3r-rahsia', color: 'red' }]} />

One command turns it back. That was **base64**: any bytes written as plain letters. It is a sticker that looks like a lock.
</Card>

<Card id="predict" type="predict">
Who can read the till password right now?

<Interactive name="Choice" options={[{ label: 'Anyone allowed to read Secrets in this namespace', correct: true, why: 'Reading the Secret is enough. base64 stops nobody.' }, { label: 'Only the till pod', why: 'Almost! The pod reads it, but so can any person or bot allowed to get Secrets.' }, { label: 'Nobody. It is encrypted.', why: 'base64 is not encryption. One command undoes it.' }]} />
</Card>

<Card id="try-fix" type="try">

<Card id="see-locks" type="see">
<Interactive name="SortCards" buckets={[{ id: 'lock', label: 'A real lock' }, { id: 'sticker', label: 'Just a sticker' }]} items={[{ label: 'base64 in the Secret', bucket: 'sticker', why: 'Anyone can decode it.' }, { label: 'Encryption at rest in etcd', bucket: 'lock', why: 'A stolen disk shows only scrambled bytes.' }, { label: 'RBAC: only the till may read Secrets', bucket: 'lock', why: 'Nobody else gets past the API server.' }, { label: 'A Secret YAML file in Git', bucket: 'sticker', why: 'Everyone with the repo can decode it.' }]} success="Two real locks: encryption at rest and RBAC." />

Real locks exist. With **encryption at rest**, the API server locks Secrets before saving them. RBAC decides who may read them.
</Card>

<Card id="check" type="check">
Good habit or not? Swipe each one.

<Interactive name="SwipeJudge" prose cards={[{ text: 'Commit secret.yaml with the real password to Git.', good: false, why: 'base64 in Git is plain text to everyone.' }, { text: 'Let only the till read Secrets in its namespace.', good: true, why: 'Fewer readers, fewer leaks.' }, { text: 'Turn on encryption at rest for Secrets.', good: true, why: 'Backups and disks stay scrambled.' }, { text: 'Print the password in the logs to debug.', good: false, why: 'Logs are read by many people and tools.' }]} />
</Card>

<Card id="win" type="win">
You can now hand a pod a password with a Secret, safely.
</Card>

<Card id="deeper" type="deeper">
`kubectl describe secret till` shows sizes, never values. Mount a Secret as files, not env vars. Env vars can leak into crash reports. Managed clusters often encrypt Secrets with a cloud key (KMS). Next lesson: keeping Secrets out of Git.
