<Card id="see-base64" type="see">
<Interactive name="Transcript" title="bash" label="echo teks berselerak itu ke base64 -d. Ia cetak sup3r-rahsia." lines={[{ cmd: 'echo c3VwM3ItcmFoc2lh | base64 -d' }, { out: 'sup3r-rahsia', color: 'red' }]} />

<Card id="try-fix" type="try">
Rakan sepasukan tulis Secret ini sendiri. Apply gagal. Baiki ia.

<Interactive name="YamlDoctor" file="secret.yaml" manifest={'apiVersion: v1\nkind: Secret\nmetadata:\n  name: spice-box\ntype: Opaque\ndata:\n  password: kancil123\n'} solution={'apiVersion: v1\nkind: Secret\nmetadata:\n  name: spice-box\ntype: Opaque\nstringData:\n  password: kancil123\n'} keep={['kancil123']} keepHint="Kekalkan kata laluan. Tukar cara ia ditulis." hint="data: mahu base64. stringData: terima teks biasa." success="Berjaya! stringData simpan sebagai base64 untuk anda." />
</Card>

<Card id="see-locks" type="see">
<Interactive name="SortCards" buckets={[{ id: 'lock', label: 'Kunci sebenar' }, { id: 'sticker', label: 'Pelekat sahaja' }]} items={[{ label: 'base64 dalam Secret', bucket: 'sticker', why: 'Sesiapa boleh nyahkodnya.' }, { label: 'Encryption at rest dalam etcd', bucket: 'lock', why: 'Cakera yang dicuri cuma tunjuk data berselerak.' }, { label: 'RBAC: hanya till boleh baca Secret', bucket: 'lock', why: 'Orang lain tak lepas API server.' }, { label: 'Fail YAML Secret dalam Git', bucket: 'sticker', why: 'Semua yang ada repo boleh nyahkodnya.' }]} success="Dua kunci sebenar: encryption at rest dan RBAC." />

Kunci sebenar memang ada. Dengan **encryption at rest** (penyulitan semasa disimpan), API server kunci Secret sebelum menyimpannya. RBAC tentukan siapa boleh membacanya.
</Card>

<Card id="deeper" type="deeper">
`kubectl describe secret till` tunjuk saiz, bukan nilai. Mount Secret sebagai fail, bukan env var. Env var boleh bocor dalam laporan crash. Kluster terurus selalunya sulitkan Secret dengan kunci awan (KMS). Pelajaran seterusnya: jauhkan Secret daripada Git.

Latihan sebenar (pilihan), hanya pada kluster latihan. Guna kata laluan palsu:
