<Card id="deeper" type="deeper">
Both tools end with a plain Secret. So RBAC and encryption at rest still matter. A sealed file opens only with the same name and namespace. Back up the controller's private key. Lose it, and old sealed files never open. Other tools: SOPS, and the Secrets Store CSI driver.
