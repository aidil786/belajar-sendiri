<Card id="see-modes" type="see">
<Interactive name="SortCards" buckets={[{ id: 'one', label: 'Penulis di satu gerai' }, { id: 'many', label: 'Penulis di banyak gerai' }, { id: 'read', label: 'Pembaca sahaja' }]} items={[{ label: 'ReadWriteOnce (RWO)', bucket: 'one', why: 'Satu node pada satu masa. **<Term id="access-mode">Access mode</Term>** (mod akses) sebut siapa boleh guna loker serentak. Bukan semua StorageClass beri semua mod.
</Card>

<Card id="predict-rwx" type="predict">
Tiga dulang di tiga gerai mesti simpan gambar ke satu folder. Mod mana?

<Interactive name="Choice" options={[{ label: 'ReadWriteMany', correct: true, why: 'Banyak node, semua menulis. Anda perlu storan yang menyokongnya, contohnya perkongsian fail rangkaian.' }, { label: 'ReadWriteOnce', why: 'Hampir! RWO benarkan satu node sahaja. Dulang di gerai lain tak boleh mount.' }, { label: 'ReadOnlyMany', why: 'Baca sahaja. Tiada siapa boleh simpan gambar.' }]} />
</Card>

<Card id="try-fix" type="try">
Claim ini ditolak. Baiki saiznya.

<Interactive name="YamlDoctor" file="claim.yaml" manifest={'apiVersion: v1\nkind: PersistentVolumeClaim\nmetadata:\n  name: orders\nspec:\n  accessModes:\n    - ReadWriteOnce\n  resources:\n    requests:\n      storage: 1Gb\n'} solution={'apiVersion: v1\nkind: PersistentVolumeClaim\nmetadata:\n  name: orders\nspec:\n  accessModes:\n    - ReadWriteOnce\n  resources:\n    requests:\n      storage: 1Gi\n'} keep={['storage: 1G']} keepHint="Kekalkan loker sebesar satu gigabait. Baiki unitnya sahaja." hint="Kubernetes tulis saiz seperti 1Gi atau 500Mi. Gb bukan unit yang ia kenal." success="Berjaya! 1Gi ialah satu gibibait." />
</Card>

<Card id="deeper" type="deeper">
`WaitForFirstConsumer` tunggu pod, jadi PV dibina di tempat pod berjalan. `Immediate` terus bina. `allowVolumeExpansion: true` benarkan claim membesar kemudian. Awan beri class seperti SSD laju atau storan fail rangkaian.
