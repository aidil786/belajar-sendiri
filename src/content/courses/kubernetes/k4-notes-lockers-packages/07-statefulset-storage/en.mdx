<Card id="win" type="win">
You can now give every StatefulSet pod its own lasting locker.
</Card>

<Card id="deeper" type="deeper">
Want claims cleaned up? Set `persistentVolumeClaimRetentionPolicy`. `whenDeleted` and `whenScaled` each take `Retain` (the default) or `Delete`. It is stable since Kubernetes 1.32. Deleting claims deletes data, so think twice.
