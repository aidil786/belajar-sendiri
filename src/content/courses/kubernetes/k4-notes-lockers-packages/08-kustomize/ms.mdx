**<Term id="kustomize">Kustomize</Term>** simpan satu resepi asas (base). Setiap <Term id="overlay">overlay</Term> ialah nota lekat di atasnya, untuk satu dapur. Base tak pernah berubah.

<Card id="deeper" type="deeper">
Overlay boleh buat lebih: `images:` tukar tag, `namePrefix:` tukar nama, `labels:` tambah label. `configMapGenerator` tambah hash pada nama nota, jadi perubahan akan gulung semula dulang. `kubectl diff -k overlays/prod` tunjuk perubahan dahulu.
