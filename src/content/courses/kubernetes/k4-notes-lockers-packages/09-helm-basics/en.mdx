**<Term id="helm">Helm</Term>** is Kubernetes' package manager. A <Term id="chart">chart</Term> is a meal kit: templates plus default values.
</Card>

<Card id="try-template" type="try">
Order 3 trays from the kit. Look at the YAML before anything is installed.

<Interactive name="FoodCourtSim" scenario="k4-helm" goal={{ lastTyped: '^helm template .*replicaCount=3' }} hints={['Type helm template shop ./kedai --set replicaCount=3']} success="replicas: 3 in the YAML. Nothing is installed yet." />

<Hint>`--set` changes one value for this run only.</Hint>
</Card>

<Card id="see-release" type="see">
<Interactive name="Transcript" title="bash" label="Four Helm commands: install shop, upgrade it to 3 replicas, show its history, and roll back to revision 1." lines={[{ cmd: 'helm install shop ./kedai' }, { cmd: 'helm upgrade shop ./kedai --set replicaCount=3' }, { cmd: 'helm history shop' }, { cmd: 'helm rollback shop 1' }]} />

`install` makes a **<Term id="helm-release">release</Term>** called shop, at revision 1. Every `upgrade` adds a revision. `rollback` brings an old one back.
</Card>

<Card id="predict" type="predict">
Revision 1: install. Revision 2: an upgrade with a bad image. You run `helm rollback shop 1`. What is the newest revision now?

<Interactive name="Choice" options={[{ label: '3, a copy of revision 1', correct: true, why: 'A rollback is a new revision. History never gets erased.' }, { label: '1', why: 'Almost! Helm never rewinds history. It writes revision 3 with the old settings.' }, { label: '2', why: 'Revision 2 is the bad one you are leaving.' }]} />
</Card>
