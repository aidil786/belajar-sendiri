A chart is a folder in three parts. `Chart.yaml` is the label. `values.yaml` holds the defaults. `templates/` holds YAML with holes.
</Card>

<Card id="see-holes" type="see">
<Interactive name="SpotLines" lines={[{ text: 'apiVersion: apps/v1' }, { text: 'kind: Deployment' }, { text: 'metadata:' }, { text: '  name: {{ .Release.Name }}-kedai', target: true }, { text: 'spec:' }, { text: '  replicas: {{ .Values.replicaCount }}', target: true }, { text: '  template:' }, { text: '    spec:' }, { text: '      containers:' }, { text: '        - name: kedai' }, { text: '          image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"', target: true }]} prompt="A piece of templates/deployment.yaml. Each `{{ }}` is a hole. Helm fills `.Values` holes from **<Term id="helm-values">values</Term>**: `values.yaml`, or your `--set`.
</Card>

<Card id="deeper" type="deeper">
`helm create kedai` makes a starter chart like this one. `helm lint ./kedai` finds mistakes. `helm package ./kedai` makes a `.tgz` to share. Templates use Go templates, so `{{ .Values.name | quote }}` wraps a value in quotes. `Chart.yaml` starts with `apiVersion: v2`.
