An **<Term id="api-deprecation">API deprecation</Term>** is an old form the office will stop taking. First comes a warning. A few releases later, the form is gone.
</Card>

<Card id="try-fix" type="try">
Bring the old Deployment up to date.

<Interactive name="YamlDoctor" file="shop.yaml" manifest={'apiVersion: extensions/v1beta1\nkind: Deployment\nmetadata:\n  name: shop\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: shop\n  template:\n    metadata:\n      labels:\n        app: shop\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} solution={'apiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: shop\nspec:\n  replicas: 3\n  selector:\n    matchLabels:\n      app: shop\n  template:\n    metadata:\n      labels:\n        app: shop\n    spec:\n      containers:\n        - name: web\n          image: nginx:1.29-alpine\n'} keep={['kind: Deployment', 'replicas: 3']} keepHint="Keep the Deployment and its 3 trays. Only the form version changes." hint="Deployments live in apps/v1 now." success="Applied! Same order, on today's form." />
</Card>

<Card id="see-kyaml" type="see">
<Interactive name="Transcript" title="bash" label="kubectl create configmap with dry run and -o kyaml prints the ConfigMap with braces, and every string in double quotes." lines={[{ cmd: 'kubectl create configmap settings --from-literal=GREETING=Selamat --from-literal=SPICY=3 --dry-run=client -o kyaml' }, { out: '---\n{\n  kind: "ConfigMap",\n  apiVersion: "v1",\n  metadata: {\n    name: "settings",\n  },\n  data: {\n    GREETING: "Selamat",\n    SPICY: "3",\n  },\n}', color: 'green' }]} />

kubectl 1.37 can print **<Term id="kyaml">KYAML</Term>**: YAML written strictly. Every string sits in double quotes. Braces wrap each map, so spaces never change the meaning.
</Card>

<Card id="predict-yes" type="predict">
Plain YAML. A ConfigMap says `SPICY: yes`. What does the API server get?

<Interactive name="Choice" options={[{ label: 'true, a yes/no value, so apply fails', correct: true, why: 'Plain YAML turns yes into true. ConfigMap data must be text. KYAML writes "yes".' }, { label: 'The text yes', why: 'Almost! Only with quotes: SPICY: "yes".' }, { label: 'The number 1', why: 'YAML reads yes as true, not as a number.' }]} />
</Card>

<Card id="deeper" type="deeper">
The `kubectl convert` plugin rewrites old files, but check its defaults. Where the story breaks: kind's lockers sit on one stall. If that stall's disk dies, the locker dies too. And notes on the wall are readable by anyone allowed to read ConfigMaps.
