<Card id="try-fix" type="try">
Kitchen 2 has a problem. A teammate added a cache switch to staging's note. The API server refuses it. Fix the note.

<Interactive name="YamlDoctor" file="settings-patch.yaml" manifest={'apiVersion: v1\nkind: ConfigMap\nmetadata:\n  name: settings\ndata:\n  LOG_LEVEL: info\n  CACHE: true\n'} solution={'apiVersion: v1\nkind: ConfigMap\nmetadata:\n  name: settings\ndata:\n  LOG_LEVEL: info\n  CACHE: "true"\n'} keep={['LOG_LEVEL: info', 'CACHE: ']} keepHint="Keep both settings. Change how CACHE is written." hint="ConfigMap data is always text. Put true in quotes." success="Fixed! The note says CACHE is the text true." />
</Card>
