<Card id="see-meter" type="see">
<Interactive name="KubeReplay" scenario="k1-want3" commands={['kubectl top pods']} fails={['kubectl top pods']} label="On a fresh kind cluster, kubectl top pods prints: error: Metrics API not available." />

`kubectl top` needs a meter reader. That reader is **<Term id="metrics-server">metrics-server</Term>**. A fresh kind cluster has none.

`error: Metrics API not available` means: nobody reads the meters yet.
</Card>

<Card id="check-sort" type="check">
metrics-server is built for autoscaling, not for monitoring. Sort each job.

<Interactive name="SortCards" buckets={[{ id: 'ms', label: 'metrics-server does it' }, { id: 'mon', label: 'Needs a monitoring tool' }]} items={[{ label: 'kubectl top pods, right now', bucket: 'ms', why: 'Live numbers are its job.' }, { label: 'The HPA deciding to add trays', bucket: 'ms', why: 'Autoscalers read metrics-server.' }, { label: 'A chart of last Tuesday', bucket: 'mon', why: 'metrics-server keeps no history.' }, { label: 'An alert at 3 a.m.', bucket: 'mon', why: 'Alerts need stored numbers and rules.' }]} success="Sorted! Live numbers here, history elsewhere." />
</Card>
