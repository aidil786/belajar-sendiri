<Card id="deeper" type="deeper">
Since Kubernetes 1.35, you can resize a running pod's CPU and memory in place. VPA's `InPlaceOrRecreate` mode uses this. If a resize can't happen, VPA replaces the pod. For queues and events, look at KEDA, a CNCF project. Karpenter can pick machine sizes itself. Cluster Autoscaler usually grows machine groups you set up.
</Card>
