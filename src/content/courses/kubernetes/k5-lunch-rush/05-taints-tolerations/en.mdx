<Card id="see-spread" type="see">
Don't put all trays in one stall. **<Term id="topology-spread">Topology spread</Term>** keeps stalls even. `maxSkew: 1` means stall counts differ by 1 at most. 4 trays, 2 stalls: which split is allowed?

<Interactive name="Choice" compact options={[{ label: '2 and 2', correct: true, why: 'The gap is 0. Within maxSkew 1.' }, { label: '3 and 1', why: 'The gap is 2. maxSkew 1 says the gap may be at most 1.' }, { label: '4 and 0', why: 'One closed stall would stop lunch. That is what spread prevents.' }]} />

In YAML, inside the pod template:

```yaml
topologySpreadConstraints:
  - maxSkew: 1
    topologyKey: kubernetes.io/hostname
    whenUnsatisfiable: ScheduleAnyway
    labelSelector:
      matchLabels: { app: shop }
```
</Card>

<Card id="deeper" type="deeper">
Effects: `NoSchedule`, `PreferNoSchedule` (try to avoid) and `NoExecute` (also evicts). A minus at the end removes a taint: `kubectl taint nodes dev-worker2 oven=big:NoSchedule-`. With `whenUnsatisfiable: DoNotSchedule`, spread becomes a hard rule. Then a locked stall can still count as a domain. Read the docs before you use it.

Real rep (optional): taint a kind worker, then remove it again.
</Card>
