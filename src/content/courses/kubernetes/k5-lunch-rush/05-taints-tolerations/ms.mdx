**<Term id="taint">Taint</Term>** ialah kunci pada gerai. Yang ini datang daripada `kubectl taint nodes dev-worker2 oven=big:NoSchedule`. Semua pod kedai pergi ke dev-worker.

<Card id="see-spread" type="see">
Jangan letak semua pod dalam satu gerai. **<Term id="topology-spread">Topology spread</Term>** jaga gerai seimbang. `maxSkew: 1` maksudnya bilangan pod antara gerai beza paling banyak 1. 4 pod, 2 gerai: pembahagian mana yang dibenarkan?

<Interactive name="Choice" compact options={[{ label: '2 dan 2', correct: true, why: 'Bezanya 0. Dalam had maxSkew 1.' }, { label: '3 dan 1', why: 'Bezanya 2. maxSkew 1 kata beza paling banyak 1.' }, { label: '4 dan 0', why: 'Satu gerai tutup akan hentikan makan tengah hari. Itulah yang sebaran elakkan.' }]} />

Dalam YAML, di dalam templat pod:

```yaml
topologySpreadConstraints:
  - maxSkew: 1
    topologyKey: kubernetes.io/hostname
    whenUnsatisfiable: ScheduleAnyway
    labelSelector:
      matchLabels: { app: shop }
```
</Card>

<Card id="deeper" type="deeper">
Kesan: `NoSchedule`, `PreferNoSchedule` (cuba elak) dan `NoExecute` (turut mengusir). Tanda tolak di hujung buang taint: `kubectl taint nodes dev-worker2 oven=big:NoSchedule-`. Dengan `whenUnsatisfiable: DoNotSchedule`, sebaran jadi peraturan keras. Gerai berkunci masih boleh dikira sebagai domain. Baca dokumen sebelum guna.

Latihan sebenar (pilihan): taint satu pekerja kind, kemudian buang semula.
</Card>
