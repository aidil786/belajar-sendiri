<Card id="hook" type="hook">
Tonight you fix stall dev-worker. Two of your three shop trays sit there. If both leave at once, one tray serves the whole queue. How do you stop that?

<Interactive name="Choice" options={[{ label: 'Set a rule: at least 2 trays stay up', correct: true, why: 'Then trays leave one at a time, and the queue keeps moving.' }, { label: 'Never fix stalls', why: 'Stalls need upgrades and repairs. Plan for them instead.' }, { label: 'Fix it at lunch time', why: 'The busiest time is the worst time to lose trays.' }]} />
</Card>

<Card id="see-pdb" type="see">
<Interactive name="KubeReplay" scenario="k5-pdb" commands={['kubectl create pdb shop --selector=app=shop --min-available=2', 'kubectl get pdb shop']} label="The PodDisruptionBudget shop is created: min available 2, allowed disruptions 1." />

That rule is a **<Term id="pdb">PodDisruptionBudget</Term>** (PDB). `--min-available=2` keeps 2 trays up. With 3 ready, ALLOWED DISRUPTIONS is 1: one may leave at a time.
</Card>

<Card id="try-build" type="try">
Build that command yourself. Each piece shows what it means.

<Interactive name="CommandBuilder" pieces={[{ text: 'kubectl', means: 'Talk to the cluster' }, { text: 'create', means: 'make a new object' }, { text: 'pdb', means: 'a PodDisruptionBudget' }, { text: 'shop', means: 'its name' }, { text: '--selector=app=shop', means: 'which trays it protects' }, { text: '--min-available=2', means: 'at least 2 stay up' }]} decoys={[{ text: '--max-unavailable=0', means: 'no tray may ever leave' }, { text: 'delete', means: 'remove an object' }]} success="That is the budget: protect app=shop, keep 2 up." />
</Card>

<Card id="try-drain" type="try">
Now empty stall dev-worker. The danger badge shows: a drain moves trays. Watch the budget make one tray wait its turn.

```bash
kubectl drain dev-worker --ignore-daemonsets
```

<Hint>Copy the command above. Then let the clock run.</Hint>
</Card>

<Card id="check-sort" type="check">
A PDB only slows down planned moves. Sort each event.

<Interactive name="SortCards" buckets={[{ id: 'pdb', label: 'PDB protects' }, { id: 'no', label: 'PDB cannot help' }]} items={[{ label: 'kubectl drain before an upgrade', bucket: 'pdb', why: 'Drain asks politely (an eviction). The budget can say "wait".' }, { label: 'A node autoscaler removing a quiet stall', bucket: 'pdb', why: 'It evicts trays too, so it respects the budget.' }, { label: 'A power cut closes a stall', bucket: 'no', why: 'Nobody asked first. <Card id="deeper" type="deeper">
Use `--max-unavailable` instead to say how many may be down. Careful: a budget that allows 0 disruptions blocks every drain forever. After the work, `kubectl uncordon dev-worker` opens the stall again.

Real rep (optional): on kind, make a PDB. Then drain a worker and read each line.
</Card>
