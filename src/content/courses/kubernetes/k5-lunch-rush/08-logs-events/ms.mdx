<Card id="see-logs" type="see">
<Interactive name="KubeReplay" scenario="k5-logs" commands={['kubectl logs kitchen']} label="kubectl logs kitchen cetak tiga baris: order 41 ready, order 42 oven too cold, order 42 ready." />

**<Term id="logs">Log</Term>** ialah buku nota tukang masak: semua yang container cetak. `kubectl logs kitchen` membacanya. Itu petunjuknya: ketuhar terlalu sejuk.
</Card>

<Card id="try-tail" type="try">
Tukang masak yang sibuk tulis buku nota yang panjang. Tunjuk baris terakhir sahaja dengan `--tail=1`.

<Interactive name="FoodCourtSim" scenario="k5-logs" goal={{ lastTyped: '^(kubectl|k) logs .*--tail[= ]1(\\s|$)' }} hints={['Taip kubectl logs kitchen --tail=1']} success="Baris terbaru sahaja: order 42 ready." />

<Hint>Taip `kubectl logs kitchen --tail=1`.</Hint>
</Card>

<Card id="see-previous" type="see">
<Interactive name="KubeReplay" scenario="k2-crashloop" commands={['kubectl get pods', 'kubectl logs {pod:app=oops} --previous']} label="Pod oops dalam CrashLoopBackOff. Larian sebelumnya cetak: starting the kitchen, kemudian oh no, no gas." />

`CrashLoopBackOff`: pod asyik rosak, jadi Kubernetes tunggu lebih lama antara setiap restart. Setiap restart mula buku nota baharu. `--previous` baca buku nota larian yang rosak.
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'Tidak. Ia pergi bersama pod lama.', correct: true, why: 'kubectl logs baca dari gerai. </Card>

<Card id="see-events" type="see">
<Interactive name="KubeReplay" scenario="k5-logs" commands={['kubectl get events --field-selector involvedObject.name=kitchen']} label="Empat event untuk pod kitchen: Scheduled ke dev-worker, image sudah ada, Created, Started." />

**<Term id="event">Event</Term>** ialah papan notis pengurus: diletak, ditarik, dimulakan, dan amaran. Kubernetes yang tulis, bukan aplikasi anda. Ia hilang selepas masa yang singkat.
</Card>

<Card id="deeper" type="deeper">
`kubectl logs -f kitchen` ikut baris baharu. `-c cook` pilih satu container. `--since=10m` tunjuk baris terkini sahaja. `kubectl events --for pod/kitchen` tunjuk event satu pod. Secara lalai, API server simpan event selama sejam. Untuk simpan log lebih lama, hantar ke stor log (pelajaran seterusnya).
</Card>
