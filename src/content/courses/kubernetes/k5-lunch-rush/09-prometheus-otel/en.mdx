<Card id="check-trace" type="check">
A **<Term id="trace">trace</Term>** follows one order's whole journey. It times each step. Here is order 42:

```text
gateway   2 ms
web      12 ms
api      30 ms
db      900 ms
```

Where is the slow part?

<Interactive name="Choice" compact options={[{ label: 'db', correct: true, why: '900 of 944 ms. Look at the database first.' }, { label: 'gateway', why: 'Only 2 ms. The entrance is fast.' }, { label: 'api', why: '30 ms is fine. Something else takes most of the time.' }]} />
</Card>

Metrics, logs and traces are three kinds of clues. **<Term id="opentelemetry">OpenTelemetry</Term>** (OTel) is one shared way to collect all three. Sort each clue.

<Interactive name="SortCards" buckets={[{ id: 'metric', label: 'Metric (a number over time)' }, { id: 'log', label: 'Log (a line the app wrote)' }, { id: 'trace', label: 'Trace (one order’s journey)' }]} items={[{ label: 'CPU at 80% at 12:30', bucket: 'metric', why: 'A number with a time.' }, { label: 'order 42 oven too cold', bucket: 'log', why: 'A line the cook wrote.' }, { label: 'order 42: gateway, web, api, db, with times', bucket: 'trace', why: 'One request, step by step.' }, { label: '200 orders per second', bucket: 'metric', why: 'A rate, counted over time.' }]} success="Three clues, one kit." />
