<Card id="see-versions" type="see">
<Interactive name="KubeReplay" scenario="k1-empty" commands={['kubectl version', 'kubectl get nodes']} label="kubectl version tunjuk Client v1.37.2 dan Server v1.37.0. Ketiga-tiga node guna v1.37.0." />

kubectl anda, API server dan kubelet setiap node (gerai) semuanya ada versi. **<Term id="version-skew">Version skew</Term>** ialah sejauh mana ia boleh berbeza dan masih berfungsi bersama.
</Card>

<Card id="try-node" type="try">

<Card id="deeper" type="deeper">
Setiap minor dapat tampalan kira-kira setahun. Cloud terurus boleh naik taraf control plane untuk anda. Anda masih semak YAML anda dulu. Kluster binaan sendiri guna alat seperti `kubeadm upgrade`. Naik taraf minor kubelet di tempat tidak disokong: drain gerai dulu.
</Card>
