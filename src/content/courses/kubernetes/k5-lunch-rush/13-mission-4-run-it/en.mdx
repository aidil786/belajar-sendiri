<Card id="see-overlay" type="see">
The base only says `kedai-kancil-web`. The dev overlay below has an `images:` part. What does it do?

<Interactive name="Choice" options={[{ label: 'Swaps the short image names for your GHCR images', correct: true, why: 'The base says kedai-kancil-web. The overlay points it at your freezer.' }, { label: 'Builds the images', why: 'Mission 2’s pipeline builds them. Kustomize only changes names.' }, { label: 'Pushes them to GHCR', why: 'Kustomize never pushes. It only writes YAML.' }]} />

Here is the overlay. Put your GitHub name where it says YOU.

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
namespace: kedai
resources: [../../base, hpa.yaml, gateway.yaml]
images:
  - { name: kedai-kancil-web, newName: ghcr.io/YOU/kedai-kancil-web, newTag: main }
  - { name: kedai-kancil-api, newName: ghcr.io/YOU/kedai-kancil-api, newTag: main }
```
</Card>

<Card id="deeper" type="deeper">
Safety: use a throwaway kind cluster. Run `kubectl config current-context` before every delete. The insecure metrics-server flag is for kind only. Your images are public, so never bake a secret into them. Make the database Secret with kubectl, and keep the password out of Git.
</Card>
