<Card id="see-overlay" type="see">
Base cuma kata `kedai-kancil-web`. Overlay dev di bawah ada bahagian `images:`. Apa yang ia buat?

<Interactive name="Choice" options={[{ label: 'Tukar nama image pendek kepada image GHCR anda', correct: true, why: 'Base kata kedai-kancil-web. Overlay halakan ke peti sejuk anda.' }, { label: 'Bina image', why: 'Pipeline Misi 2 yang bina. Kustomize cuma tukar nama.' }, { label: 'Push ke GHCR', why: 'Kustomize tak pernah push. Ia cuma tulis YAML.' }]} />

Ini overlay itu. Letak nama GitHub anda di tempat YOU.

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
namespace: kedai
resources: [../../base, hpa.yaml, gateway.yaml]
images:
  - { name: kedai-kancil-web, newName: ghcr.io/YOU/kedai-kancil-web, newTag: main }
  - { name: kedai-kancil-api, newName: ghcr.io/YOU/kedai-kancil-api, newTag: main }
```
</Card>

Keselamatan: guna kluster kind untuk dibuang. Jalankan `kubectl config current-context` sebelum setiap padam. Flag metrics-server yang tak selamat itu untuk kind sahaja. Image anda awam, jadi jangan sekali-kali bakar rahsia ke dalamnya. Buat Secret pangkalan data dengan kubectl, dan simpan kata laluan di luar Git.
