<Card id="deeper" type="deeper">
Latihan sebenar (pilihan), pada kluster kind untuk dibuang yang ada metrics-server. Mulakan Service bernama shop, kemudian buat pod beban. Padamnya bila siap.

```bash
kubectl run load --image=busybox:1.37 --restart=Never -- /bin/sh -c "while sleep 0.01; do wget -q -O- http://shop; done"
kubectl get hpa shop --watch
kubectl delete pod load
```
