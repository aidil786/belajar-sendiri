<Card id="see-role" type="see">
<Interactive name="KubeReplay" scenario="k6-rbac-start" commands={['cat deployer.yaml', 'kubectl apply -f deployer.yaml']} picture={false} label="cat tunjuk Role bernama deployer: dalam kumpulan API apps, pada deployments, kata kerja get, list dan patch. kubectl apply ciptanya." />

**<Term id="role">Role</Term>** ialah kad tugas. Ia senaraikan kata kerja, seperti `patch`, pada benda, seperti `deployments`. Ia hanya berfungsi dalam satu zon.
</Card>

<Card id="win" type="win">
Kini anda boleh beri bot satu kad tugas untuk satu zon.
</Card>

<Card id="deeper" type="deeper">
RoleBinding boleh tunjuk pada ClusterRole. Kad itu hanya berfungsi dalam zon binding tersebut. ClusterRole terbina: `view`, `edit`, `admin`, `cluster-admin`. Pod dapat token ServiceAccount yang cepat tamat. Tetapkan `automountServiceAccountToken: false` bila aplikasi tak pernah panggil API.

<Interactive name="Mission" id="k6-l02-rep" steps={[{ id: 'cluster', text: 'Dalam kluster kind buang sahaja, buat lencana untuk bot.', command: 'kubectl create serviceaccount ci-bot' }, { id: 'role', text: 'Buat kad tugas tanpa fail.', command: 'kubectl create role deployer --verb=get,list,patch --resource=deployments' }, { id: 'bind', text: 'Pin kad pada lencana.', command: 'kubectl create rolebinding ci-bot-deployer --role=deployer --serviceaccount=default:ci-bot' }, { id: 'look', text: 'Baca semula binding itu.', command: 'kubectl describe rolebinding ci-bot-deployer' }]} success="Bot anda ada tepat satu kad tugas." />
