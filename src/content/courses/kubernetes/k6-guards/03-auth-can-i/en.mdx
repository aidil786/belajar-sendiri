<Card id="see-cani" type="see">
<Interactive name="KubeReplay" scenario="k6-rbac" commands={['kubectl auth can-i list pods --as=system:serviceaccount:default:ci-bot', 'kubectl auth can-i delete pods --as=system:serviceaccount:default:ci-bot']} picture={false} label="can-i list pods as the CI bot says yes. can-i delete pods says no." />

`kubectl auth can-i` asks gate 2 a yes or no question. It changes nothing. `--as` lets you **impersonate** the bot: ask as if you were it.
</Card>

<Card id="deeper" type="deeper">
`kubectl auth can-i --list --as=…` lists everything that identity may do. can-i exits with 0 for yes and 1 for no, so scripts can use it. To use `--as`, you need the `impersonate` right yourself. Cluster admins have it.
