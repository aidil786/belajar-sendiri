<Card id="hook" type="hook">
Kerja CI anda gagal pukul 2 pagi. Ini ralatnya.

```
Error from server (Forbidden): secrets is forbidden: User "system:serviceaccount:default:ci-bot" cannot list resource "secrets" in API group "" in the namespace "default"
```

Macam mana anda boleh tahu sebelum ia berjalan?

<Interactive name="Choice" options={[{ label: 'Tanya kluster dulu, sebagai bot itu', correct: true, why: 'Satu soalan tunjuk jawapannya. </Card>

<Card id="see-cani" type="see">
<Interactive name="KubeReplay" scenario="k6-rbac" commands={['kubectl auth can-i list pods --as=system:serviceaccount:default:ci-bot', 'kubectl auth can-i delete pods --as=system:serviceaccount:default:ci-bot']} picture={false} label="can-i list pods sebagai bot CI jawab yes. can-i delete pods jawab no." />

`kubectl auth can-i` tanya pintu 2 soalan ya atau tidak. Ia tak ubah apa-apa. `--as` biar anda **impersonate** (menyamar) bot itu: tanya seolah-olah anda bot itu.
</Card>

<Card id="deeper" type="deeper">
`kubectl auth can-i --list --as=…` senaraikan semua yang identiti itu boleh buat. can-i keluar dengan 0 untuk ya dan 1 untuk tidak, jadi skrip boleh gunanya. Untuk guna `--as`, anda sendiri perlu hak `impersonate`. Admin kluster memilikinya.
