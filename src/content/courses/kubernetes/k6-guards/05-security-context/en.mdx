Lock 1 goes on the whole tray. **<Term id="security-context">securityContext</Term>** holds the locks. Tap the two lines that stop root.

<Card id="see-container" type="see">
<Interactive name="KubeReplay" scenario="k6-locks" commands={['kubectl apply -f half.yaml']} fails={['kubectl apply -f half.yaml']} picture={false} label="half.yaml has the tray locks only. It is forbidden: the container must set allowPrivilegeEscalation=false and drop ALL capabilities." />

The tray locks are not enough. Each container needs two more. **<Term id="capabilities">Capabilities</Term>** are slices of root's power. Drop them all:

```yaml
securityContext:
  allowPrivilegeEscalation: false
  capabilities:
    drop: ["ALL"]
```
</Card>

<Card id="deeper" type="deeper">
Restricted lets one power back in: `NET_BIND_SERVICE`, for ports under 1024. Many images run as root by default. With `runAsNonRoot: true` and a root image, the kubelet refuses to start it: `CreateContainerConfigError`. Pick a non-root image, or set `runAsUser`.
