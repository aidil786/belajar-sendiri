<Card id="see-container" type="see">
<Interactive name="KubeReplay" scenario="k6-locks" commands={['kubectl apply -f half.yaml']} fails={['kubectl apply -f half.yaml']} picture={false} label="half.yaml hanya ada kunci dulang. Ia ditolak: container mesti tetapkan allowPrivilegeEscalation=false dan buang SEMUA capabilities." />

Kunci dulang belum cukup. Setiap container perlu dua lagi. **<Term id="capabilities">Capabilities</Term>** ialah cebisan kuasa root. Buang semuanya:

```yaml
securityContext:
  allowPrivilegeEscalation: false
  capabilities:
    drop: ["ALL"]
```
</Card>

<Card id="deeper" type="deeper">
Restricted benarkan satu kuasa kembali: `NET_BIND_SERVICE`, untuk port bawah 1024. Banyak image berjalan sebagai root secara lalai. Dengan `runAsNonRoot: true` dan image root, kubelet enggan memulakannya: `CreateContainerConfigError`. Pilih image bukan root, atau tetapkan `runAsUser`.

<Interactive name="Mission" id="k6-l05-rep" steps={[{ id: 'zone', text: 'Dalam kluster buang sahaja, buat zon restricted.', command: 'kubectl create namespace locks && kubectl label ns locks pod-security.kubernetes.io/enforce=restricted' }, { id: 'file', text: 'Tulis locked.yaml: pod busybox bernama locked, dengan kunci dari pelajaran ini. Jangan letak baris namespace.' }, { id: 'apply', text: 'Apply dalam zon itu.', command: 'kubectl apply -n locks -f locked.yaml' }, { id: 'id', text: 'Tanya ia berjalan sebagai siapa.', command: 'kubectl exec -n locks locked -- id' }]} success="Bekas anda sudah berkunci!" />
</Card>
