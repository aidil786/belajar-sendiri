<Card id="try-doctor" type="try">
This fence will not apply. Fix the line the API server does not know.

<Interactive name="YamlDoctor" file="db-from-api.yaml" manifest={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: db-from-api\nspec:\n  podSelector:\n    app: db\n  ingress:\n    - from:\n        - podSelector:\n            matchLabels:\n              app: api\n'} solution={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: db-from-api\nspec:\n  podSelector:\n    matchLabels:\n      app: db\n  ingress:\n    - from:\n        - podSelector:\n            matchLabels:\n              app: api\n'} keep={['app: db', 'app: api']} keepHint="Keep both labels. The fence needs them." hint="A podSelector holds matchLabels. Copy the shape from the one lower down." success="Applied! The fence guards app=db, and opens for app=api." />
</Card>

<Card id="deeper" type="deeper">
`policyTypes: [Egress]` fences what goes out. `namespaceSelector` lets a whole zone through. Plugins like Cilium and Calico enforce policies. Check your plugin's docs before you trust a fence.
