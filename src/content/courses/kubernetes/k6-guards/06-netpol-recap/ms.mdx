<Card id="try-doctor" type="try">
Pagar ini tak boleh di-apply. Baiki baris yang API server tak kenal.

<Interactive name="YamlDoctor" file="db-from-api.yaml" manifest={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: db-from-api\nspec:\n  podSelector:\n    app: db\n  ingress:\n    - from:\n        - podSelector:\n            matchLabels:\n              app: api\n'} solution={'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata:\n  name: db-from-api\nspec:\n  podSelector:\n    matchLabels:\n      app: db\n  ingress:\n    - from:\n        - podSelector:\n            matchLabels:\n              app: api\n'} keep={['app: db', 'app: api']} keepHint="Simpan kedua-dua label. Pagar memerlukannya." hint="podSelector simpan matchLabels. Tiru bentuk yang di bawah." success="Berjaya! Pagar jaga app=db, dan buka untuk app=api." />
</Card>

<Card id="try-sim" type="try">

<Card id="deeper" type="deeper">
`policyTypes: [Egress]` pagar apa yang keluar. `namespaceSelector` benarkan seluruh zon lalu. Plugin seperti Cilium dan Calico kuatkuasakan polisi. Semak dokumen plugin anda sebelum percaya pada pagar.
