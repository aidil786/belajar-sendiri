<Card id="see-vap" type="see">
A **<Term id="validating-admission-policy">ValidatingAdmissionPolicy</Term>** is a house rule, built into Kubernetes. The rule itself is one line of CEL. Tap it.

<Interactive name="SpotLines" lines={[{ text: 'apiVersion: admissionregistration.k8s.io/v1' }, { text: 'kind: ValidatingAdmissionPolicy' }, { text: 'metadata:' }, { text: '  name: no-latest' }, { text: 'spec:' }, { text: '  matchConstraints:' }, { text: '    resourceRules:' }, { text: '      - apiGroups: [""]' }, { text: '        apiVersions: ["v1"]' }, { text: '        operations: ["CREATE", "UPDATE"]' }, { text: '        resources: ["pods"]' }, { text: '  validations:' }, { text: "    - expression: \"object.spec.containers.all(c, !c.image.endsWith(':latest'))\"", target: true }, { text: '      message: "Pin a version tag, not latest."' }]} prompt="Tap the line that holds the rule." success="Yes! Every container's image must not end in :latest." />
</Card>

<Card id="predict" type="predict">
`image: nginx` has no tag at all. Does this rule stop it?

<Interactive name="Choice" options={[{ label: 'No. No tag means latest, but the text has no :latest', correct: true, why: 'A rule only sees text. Make it ask for a version tag instead.' }, { label: 'Yes. Kubernetes adds :latest first', why: 'Kubernetes does not rewrite your image. The rule sees plain nginx.' }, { label: 'Yes. CEL knows what latest means', why: 'CEL compares text. It knows nothing about tags.' }]} />
</Card>

<Card id="try-order" type="try">
A policy does nothing alone. A **binding** says where it runs, and what to do: Deny, Warn or Audit. Put a safe rollout in order.

<Interactive name="OrderList" items={['Write the policy (the rule)', 'Bind it with validationActions: [Warn]', 'Read the warnings. Fix the old YAML.', 'Switch the binding to [Deny]']} label="First step at the top" success="Warn first, then Deny. Nobody gets locked out by surprise." />
</Card>

<Card id="see-denied" type="see">

<Interactive name="Choice" options={[{ label: 'Use a version tag, like nginx:1.29-alpine', correct: true, why: 'The house rule said no, and told her why.' }, { label: 'Ask for cluster-admin', why: 'Gate 3 checks the tray, not her rights. <Card id="deeper" type="deeper">
Since Kubernetes 1.36, MutatingAdmissionPolicy is stable too: it changes objects with CEL. `failurePolicy: Fail` refuses requests when the rule itself breaks. A binding's `matchResources` picks zones by label. Kyverno and Gatekeeper run as webhooks: extra pods you keep healthy.
