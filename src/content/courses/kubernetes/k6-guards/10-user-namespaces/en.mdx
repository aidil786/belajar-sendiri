<Card id="try-sort" type="try">

<Card id="predict" type="predict">
Zone kedai enforces restricted. A pod sets `hostUsers: false` and `runAsUser: 0`, plus every other lock. Does the guard let it in?

<Interactive name="Choice" options={[{ label: 'Yes: the guard relaxes the root checks', correct: true, why: 'Root inside is never root on the node, so runAsNonRoot and runAsUser are not checked.' }, { label: 'No: restricted always refuses root', why: 'Not for user-namespace pods. <Card id="try-doctor" type="try">
Mei wrote the line, but the API server refuses it. Fix it.

<Interactive name="YamlDoctor" file="legacy.yaml" manifest={'apiVersion: v1\nkind: Pod\nmetadata:\n  name: legacy\nspec:\n  hostUsers: "false"\n  containers:\n    - name: app\n      image: busybox:1.37\n      command: ["sleep", "3600"]\n'} solution={'apiVersion: v1\nkind: Pod\nmetadata:\n  name: legacy\nspec:\n  hostUsers: false\n  containers:\n    - name: app\n      image: busybox:1.37\n      command: ["sleep", "3600"]\n'} keep={['hostUsers: false']} keepHint="Keep hostUsers. It is the point of this pod." hint="Quotes make a word. hostUsers wants true or false, with no quotes." success="Applied! A real true/false, not a word." />
</Card>

<Card id="check" type="check">
Does a user namespace need this? Swipe each one.

<Interactive name="SwipeJudge" prose cards={[{ text: 'Linux nodes with kernel 6.3 or newer', good: true, why: 'Older kernels lack what the pod volumes need.' }, { text: 'containerd 2.0+ or CRI-O 1.25+', good: true, why: 'The runtime must know how to set up the mapping.' }, { text: 'Windows nodes', good: false, why: 'User namespaces are Linux only.' }, { text: 'hostNetwork: true on the same pod', good: false, why: 'Not allowed with hostUsers: false.' }]} />

<Card id="deeper" type="deeper">
Where the story breaks: real guards use judgement. Kubernetes gates only follow written rules. RBAC has no "deny" list at all. The gates check requests, not what a container does later. securityContext and the Linux kernel guard that part. A logbook only helps if someone reads it.
