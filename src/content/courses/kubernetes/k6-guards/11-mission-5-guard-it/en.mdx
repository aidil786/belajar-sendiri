Mission 5: Guard it. Your goal: your own cluster refuses a root or unsigned image, like this. Four jobs: badges, locks, fences, seals.
</Card>

<Card id="try-badges" type="try">
Step 1: badges and locks. kubectl can write the YAML for you with `--dry-run=client -o yaml`.

<Interactive name="Mission" id="k6-m5-badges" steps={[
  { id: 'sa', text: "Start `k8s/base/rbac.yaml` with the CI bot's badge.", command: 'kubectl create serviceaccount ci-bot -n kedai --dry-run=client -o yaml > k8s/base/rbac.yaml' },
  { id: 'role', text: 'Add its job card.', command: 'echo "---" >> k8s/base/rbac.yaml && kubectl create role deployer -n kedai --verb=get,list,patch --resource=deployments --dry-run=client -o yaml >> k8s/base/rbac.yaml' },
  { id: 'bind', text: 'Add the pin.', command: 'echo "---" >> k8s/base/rbac.yaml && kubectl create rolebinding ci-bot-deployer -n kedai --role=deployer --serviceaccount=kedai:ci-bot --dry-run=client -o yaml >> k8s/base/rbac.yaml' },
  { id: 'dry', text: 'Dry run the guard on your kind cluster. Read which pods would break.', command: 'kubectl label --dry-run=server --overwrite ns kedai pod-security.kubernetes.io/enforce=restricted' },
  { id: 'locks', text: 'Add the four locks to every container in your Deployments. Your mission 1 images should already run as non-root.' },
  { id: 'label', text: 'Put the label `pod-security.kubernetes.io/enforce: restricted` on your kedai Namespace file.' },
  { id: 'apply', text: 'List `rbac.yaml` in `k8s/base/kustomization.yaml`. Apply your overlay, as in mission 4.' },
  { id: 'ask', text: 'Ask as the bot. Secrets must say no.', command: 'kubectl auth can-i get secrets -n kedai --as=system:serviceaccount:kedai:ci-bot' }]}
  success="Badges and locks are in Git." />
</Card>

<Card id="see-zone" type="see">
Your kedai zone will carry two guard labels. One checks locks. One checks seals.

<Interactive name="SpotLines" lines={[{ text: 'apiVersion: v1' }, { text: 'kind: Namespace' }, { text: 'metadata:' }, { text: '  name: kedai' }, { text: '  labels:' }, { text: '    pod-security.kubernetes.io/enforce: restricted', target: true }, { text: '    policy.sigstore.dev/include: "true"' }]} prompt="Tap the label that refuses a root tray." success="Yes! The other label waits for step 2." />
</Card>
