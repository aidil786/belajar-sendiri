Misi 5: Kawal. Matlamat anda: kluster anda sendiri tolak image root atau tanpa tandatangan, macam ini. Empat kerja: lencana, kunci, pagar, meterai.
</Card>

<Card id="try-badges" type="try">
Langkah 1: lencana dan kunci. kubectl boleh tuliskan YAML untuk anda dengan `--dry-run=client -o yaml`.

<Interactive name="Mission" id="k6-m5-badges" steps={[
  { id: 'sa', text: 'Mulakan `k8s/base/rbac.yaml` dengan lencana bot CI.', command: 'kubectl create serviceaccount ci-bot -n kedai --dry-run=client -o yaml > k8s/base/rbac.yaml' },
  { id: 'role', text: 'Tambah kad tugasnya.', command: 'echo "---" >> k8s/base/rbac.yaml && kubectl create role deployer -n kedai --verb=get,list,patch --resource=deployments --dry-run=client -o yaml >> k8s/base/rbac.yaml' },
  { id: 'bind', text: 'Tambah pinnya.', command: 'echo "---" >> k8s/base/rbac.yaml && kubectl create rolebinding ci-bot-deployer -n kedai --role=deployer --serviceaccount=kedai:ci-bot --dry-run=client -o yaml >> k8s/base/rbac.yaml' },
  { id: 'dry', text: 'Dry run pengawal dalam kluster kind anda. Baca pod mana yang akan gagal.', command: 'kubectl label --dry-run=server --overwrite ns kedai pod-security.kubernetes.io/enforce=restricted' },
  { id: 'locks', text: 'Tambah empat kunci pada setiap container dalam Deployment anda. Image misi 1 anda patut sudah berjalan bukan sebagai root.' },
  { id: 'label', text: 'Letak label `pod-security.kubernetes.io/enforce: restricted` pada fail Namespace kedai anda.' },
  { id: 'apply', text: 'Senaraikan `rbac.yaml` dalam `k8s/base/kustomization.yaml`. Apply overlay anda, macam misi 4.' },
  { id: 'ask', text: 'Tanya sebagai bot. Secret mesti jawab no.', command: 'kubectl auth can-i get secrets -n kedai --as=system:serviceaccount:kedai:ci-bot' }]}
  success="Lencana dan kunci sudah dalam Git." />
</Card>

<Card id="see-zone" type="see">

<Card id="deeper" type="deeper">
Keselamatan: guna kluster kind anda sahaja, jangan kluster kerja. Baca bar merah jambu "anda di sini" sebelum setiap label atau delete. Pod tersekat? Jalankan `kubectl get events -n kedai`. Kyverno atau Gatekeeper pun boleh semak meterai, kalau pasukan anda sudah guna salah satunya.
</Card>
