<Card id="see-flux" type="see">
**<Term id="flux">Flux</Term>** is a set of small controllers, driven from Git and its command line. A `GitRepository` names the repo. A `Kustomization` says which folder to apply.

Which line below says how often to check?

<Interactive name="Choice" options={[{ label: 'interval: 10m', correct: true, why: 'Every 10 minutes, Flux applies this folder again and fixes any gap.' }, { label: 'prune: true', why: 'prune deletes objects you removed from Git.' }, { label: 'sourceRef', why: 'sourceRef points at the GitRepository object.' }]} />

```yaml
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: kedai-kancil
  namespace: flux-system
spec:
  interval: 10m
  path: ./apps/kedai-kancil
  prune: true
  sourceRef:
    kind: GitRepository
    name: gitops
```
</Card>
