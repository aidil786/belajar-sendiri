<Card id="see-flux" type="see">
**<Term id="flux">Flux</Term>** ialah set controller kecil, dipandu dari Git dan baris arahannya. `GitRepository` namakan repo. `Kustomization` beritahu folder mana perlu di-apply.

Baris mana di bawah beritahu berapa kerap ia perlu menyemak?

<Interactive name="Choice" options={[{ label: 'interval: 10m', correct: true, why: 'Setiap 10 minit, Flux apply folder ini semula dan baiki sebarang beza.' }, { label: 'prune: true', why: 'prune padam objek yang anda buang dari Git.' }, { label: 'sourceRef', why: 'sourceRef menunjuk ke objek GitRepository.' }]} />

```yaml
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: kedai-kancil
  namespace: flux-system
spec:
  interval: 10m
  path: ./apps/kedai-kancil
  prune: true
  sourceRef:
    kind: GitRepository
    name: gitops
```
</Card>
