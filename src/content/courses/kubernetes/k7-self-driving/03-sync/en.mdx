<Card id="deeper" type="deeper">
Sync can be automated or manual. Manual sync waits for a button or `argocd app sync shop`. With `prune: true`, objects you delete from Git are deleted from the cluster too. Real rep (optional): install Argo CD on a throwaway kind cluster. Watch an example app sync. Mission 6 walks you through it.
</Card>
