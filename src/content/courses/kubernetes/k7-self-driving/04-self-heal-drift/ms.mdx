<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'Kekal 1 dan tunjuk OutOfSync sehingga seseorang tekan Sync', correct: true, why: 'Tanpa self-heal, Argo CD laporkan drift tetapi tak undurkannya.' }, { label: 'Argo CD tetap kembalikan 3 serta-merta', why: 'Hanya jika self-heal hidup. <Card id="try-off" type="try">
Self-heal dimatikan. Buat perubahan manual, kemudian undurkannya sendiri.

<Interactive name="GitOpsMirror" app={{ name: 'shop', namespace: 'shop', replicas: 3, image: 'ghcr.io/kedai-kancil/shop:1.4.0' }} selfHeal={false} task={{ type: 'drift' }} success="Anda tangkap drift itu dan sync semula versi Git." />

<Hint>Selepas perubahan manual, tekan Sync sekarang.</Hint>

<Card id="try-catch" type="try">
Kluster ini tiada pembantu GitOps. Jadilah pembantu itu. Cari drift, kemudian kembalikan versi dalam fail.

<Card id="deeper" type="deeper">
Secara lalai, self-heal tunggu 5 saat sebelum sync semula. Sesetengah drift memang sengaja: autoscaler ubah replicas. Beritahu Argo CD untuk abaikan medan itu dengan `ignoreDifferences`. Latihan sebenar (pilihan): pada kluster kind, `kubectl scale` satu Deployment, kemudian `kubectl apply -f` failnya. Lihat bilangannya kembali.
</Card>
