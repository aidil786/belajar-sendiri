<Card id="deeper" type="deeper">
Prefer one folder per environment over one branch per environment. Folders are easy to compare and never need merging back. Some teams automate promotion with tools like Kargo. Real rep (optional): make `envs/staging` and `envs/prod` overlays for Kedai Kancil. Run `kubectl kustomize envs/prod` to see the result.
</Card>
