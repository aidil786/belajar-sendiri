<Card id="see-crd" type="see">

<Card id="see-operator" type="see">
An **<Term id="operator">operator</Term>** is a new kind plus its own manager. This one, below, runs Postgres. Who makes the 3 database pods?

<Interactive name="Choice" options={[{ label: 'The operator’s controller, reading this object', correct: true, why: 'Want 3. See 0. Make 3. It also handles failover.' }, { label: 'The object makes them by itself', why: 'An object is only a wish on the board. A controller acts on it.' }, { label: 'You, with kubectl run', why: 'The whole point: the operator does it for you.' }]} />

```yaml
apiVersion: postgresql.cnpg.io/v1
kind: Cluster
metadata:
  name: kedai-db
spec:
  instances: 3
  storage:
    size: 1Gi
```
</Card>

<Card id="deeper" type="deeper">
`kubectl get crds` lists the kinds your cluster learned. `kubectl explain` works on them too, when the CRD has a schema. Popular operators: cert-manager, CloudNativePG and the Prometheus Operator. Real rep (optional): install Argo CD on kind, then run `kubectl get crds`. Spot `applications.argoproj.io`.
</Card>
