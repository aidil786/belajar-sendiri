<Card id="see-file" type="see">
Step 2: the order board. In your `kedai-kancil` repo, make `apps/kedai-kancil.yaml` with the YAML below. Which line will you change in step 4?

<Interactive name="Choice" options={[{ label: 'replicas: 2', correct: true, why: 'One number. The easiest one-line change to see.' }, { label: 'kind: Deployment', why: 'That would change what the object is.' }, { label: 'app: kedai-kancil', why: 'Labels tie the trays to the order. Leave them.' }]} />

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: kedai-kancil
spec:
  replicas: 2
  selector:
    matchLabels:
      app: kedai-kancil
  template:
    metadata:
      labels:
        app: kedai-kancil
    spec:
      containers:
        - name: web
          image: nginx:1.30-alpine
```
</Card>

<Card id="try-connect" type="try">
Step 3: point Argo CD at Git. Save the YAML below as `argocd/application.yaml`. Put your username in `repoURL`.

<Interactive name="Mission" id="k8s-m6-connect" steps={[
  { id: 'push', text: 'Commit both files and push them to your public repo.', command: 'git add apps argocd && git commit -m "Add GitOps app" && git push' },
  { id: 'app', text: 'Hand the Application to Argo CD. This is the last change by kubectl.', command: 'kubectl apply -f argocd/application.yaml' },
  { id: 'synced', text: 'Wait a minute. Two kedai-kancil pods appear. Reading is fine.', command: 'kubectl get deployment kedai-kancil' }]}
  success="Argo CD now drives Kedai Kancil from Git." />

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: kedai-kancil
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/YOUR-USERNAME/kedai-kancil.git
    path: apps
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      selfHeal: true
```
</Card>
