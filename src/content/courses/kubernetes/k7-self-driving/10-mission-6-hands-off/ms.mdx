<Card id="see-file" type="see">
Langkah 2: papan pesanan. Dalam repo `kedai-kancil` anda, buat `apps/kedai-kancil.yaml` dengan YAML di bawah. Baris mana yang anda akan tukar dalam langkah 4?

<Interactive name="Choice" options={[{ label: 'replicas: 2', correct: true, why: 'Satu nombor. Perubahan satu baris yang paling mudah dilihat.' }, { label: 'kind: Deployment', why: 'Itu akan tukar jenis objek itu.' }, { label: 'app: kedai-kancil', why: 'Label ikat dulang dengan pesanan. Biarkan.' }]} />

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: kedai-kancil
spec:
  replicas: 2
  selector:
    matchLabels:
      app: kedai-kancil
  template:
    metadata:
      labels:
        app: kedai-kancil
    spec:
      containers:
        - name: web
          image: nginx:1.30-alpine
```
</Card>

<Card id="try-connect" type="try">
Langkah 3: halakan Argo CD ke Git. Simpan YAML di bawah sebagai `argocd/application.yaml`. Letak nama pengguna anda dalam `repoURL`.

<Interactive name="Mission" id="k8s-m6-connect" steps={[
  { id: 'push', text: 'Commit kedua-dua fail dan push ke repo awam anda.', command: 'git add apps argocd && git commit -m "Add GitOps app" && git push' },
  { id: 'app', text: 'Serahkan Application kepada Argo CD. Ini perubahan terakhir dengan kubectl.', command: 'kubectl apply -f argocd/application.yaml' },
  { id: 'synced', text: 'Tunggu seminit. Dua pod kedai-kancil muncul. Membaca tak mengapa.', command: 'kubectl get deployment kedai-kancil' }]}
  success="Argo CD kini pandu Kedai Kancil dari Git." />

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: kedai-kancil
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/YOUR-USERNAME/kedai-kancil.git
    path: apps
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      selfHeal: true
```
</Card>
