<Card id="try-ship" type="try">

<Card id="try-fix" type="try">
Room 4: a teammate's commit broke the sync. Read the real error. Fix the file in Git.

<Interactive name="YamlDoctor" file="shop.yaml" manifest={'apiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: shop\nspec:\n  replicas: 5\n  selector:\n    matchLabels:\n      app: shop\n  template:\n    metadata:\n      labels:\n        app: shop\n    spec:\n      contianers:\n        - name: web\n          image: ghcr.io/kedai-kancil/shop:1.5.0\n'} solution={'apiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: shop\nspec:\n  replicas: 5\n  selector:\n    matchLabels:\n      app: shop\n  template:\n    metadata:\n      labels:\n        app: shop\n    spec:\n      containers:\n        - name: web\n          image: ghcr.io/kedai-kancil/shop:1.5.0\n'} keep={['replicas: 5', 'shop:1.5.0', '^      containers:']} hint="Look closely at how containers is spelt." success="Room 4 cleared! The next sync goes green." />
</Card>

<Card id="try-drift" type="try">
Room 5: self-heal is off on this app. Someone scales it by hand. Catch the drift and undo it.

<Interactive name="GitOpsMirror" app={{ name: 'kedai-kancil', namespace: 'shop', deployment: 'shop', replicas: 5, image: 'ghcr.io/kedai-kancil/shop:1.5.0' }} selfHeal={false} task={{ type: 'drift' }} success="Caught and undone! Git's 5 trays are back." />

<Hint>Press the kubectl button, then Sync now. Or turn self-heal on.</Hint>
</Card>
