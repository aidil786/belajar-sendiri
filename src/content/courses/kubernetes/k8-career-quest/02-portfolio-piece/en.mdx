<Card id="hook" type="hook">
Kedai Kancil works. All six missions are done. But your repo page shows only a list of files. Will a busy reviewer get it?

<Interactive name="Choice" options={[{ label: 'Probably not. Show the story first', correct: true, why: 'Reviewers skim. A clear README tells the story in one minute.' }, { label: 'Yes. </Card>

<Card id="try-trip" type="try">
An **<Term id="architecture-diagram">architecture diagram</Term>** is a map of your app's parts. Arrows show who talks to whom. Put one order's trip in order.

<Interactive name="OrderList" items={['Browser: a customer opens the menu', 'Gateway: the main entrance reads /api', 'Service: the order number for the API', 'api pod: the small API cooks the answer', 'Postgres: the database holds the menu']} label="Start of the trip at the top" success="That's the main arrow path on your diagram." />

<Hint>Outside first. The data lives at the very end.</Hint>
</Card>

<Card id="try-mermaid" type="try">
GitHub draws <Term id="mermaid" course="git">Mermaid</Term> text as a diagram. Each `-->` is an arrow. Add the last arrow: from api to db.

<Interactive name="MarkdownPlayground" initial={'## How it fits together\n\n```mermaid\nflowchart LR\n  browser --> gateway\n  gateway --> web\n  gateway --> api\n```\n'} prompt="Add the arrow api --> db inside the mermaid block." goal={{ mustMatch: ['^\\s*api\\s*-->\\s*db\\b'], hint: ['Add a new line inside the block: api --> db'] }} success="Nice! Now the diagram shows where the data lives." />
</Card>

<Card id="check-lines" type="check">
Judge each README line.

<Interactive name="SwipeJudge" prose cards={[{ text: '"Kedai Kancil: a tiny shop app on Kubernetes, shipped by GitOps."', good: true, why: 'One clear line. The reader knows what it is.' }, { text: '"This is my project."', good: false, why: 'Which project? Say what it does.' }, { text: '"Run it with one command: docker compose up"', good: true, why: 'One command to try it. Reviewers love that.' }, { text: '"TODO: write the README later."', good: false, why: 'Later rarely comes. Write three lines today.' }, { text: '"Mission 2 proof: a link to the green run on main."', good: true, why: 'A link is proof. A claim alone is not.' }]} />
</Card>

<Card id="deeper" type="deeper">
GitHub draws Mermaid diagrams in Markdown files. Your diagram lives next to your code. Upload the video anywhere with a share link. Be honest in the README. Say it runs in a kind cluster, not a paid cloud. Honesty builds trust.
</Card>
