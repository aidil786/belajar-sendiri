<Card id="try-sort" type="try">
Posts hide two lists. **<Term id="must-have">Must-haves</Term>** are real needs. Nice-to-haves are bonus points. Sort each line.

<Interactive name="SortCards" buckets={[{ id: 'must', label: 'Must-have' }, { id: 'nice', label: 'Nice-to-have' }]} items={[{ label: '"Required: Docker and Linux basics"', bucket: 'must', why: 'Required means required.' }, { label: '"You have: built a CI pipeline"', bucket: 'must', why: '"You have" lists the core needs.' }, { label: '"Must: know Git well"', bucket: 'must', why: '"Must" is the clearest signal.' }, { label: '"Bonus: a CKA certificate"', bucket: 'nice', why: 'Bonus means extra points, not a must.' }, { label: '"A plus: Go or Python"', bucket: 'nice', why: '"A plus" is a nice-to-have.' }, { label: '"Preferred: Terraform"', bucket: 'nice', why: '"Preferred" means they would like it.' }]} success="Sorted! Now you can read a post in two minutes." />

<Hint>Look for the signal word: required, must, bonus, a plus, preferred.</Hint>
