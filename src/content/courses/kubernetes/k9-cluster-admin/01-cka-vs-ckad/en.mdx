<Card id="try-inside" type="try">
Each stall is a real machine. Step into its back room: a **<Term id="node-shell">node shell</Term>**. Type `ssh dev-worker`, then `hostname`.

<Interactive name="FoodCourtSim" scenario="k9-kubelet" goal={{ typed: '^(ssh dev-worker|docker exec -it dev-worker bash)$', lastTyped: '^hostname$' }} hints={['Type ssh dev-worker and press Enter.', 'The prompt now says root@dev-worker. Type hostname.']} success="You are inside dev-worker. The prompt shows it too." />

<Hint>Look at the prompt. It changes when you are inside a node.</Hint>
</Card>

<Card id="see-kind" type="see">
<Interactive name="KubeReplay" scenario="k9-kubelet" picture={false} commands={['docker exec -it dev-worker bash', 'hostname', 'exit']} label="docker exec -it dev-worker bash opens a root prompt inside the node. hostname prints dev-worker. exit goes back to the laptop." />

On **<Term id="kind">kind</Term>**, each stall is a Docker container with no SSH server. So you step in with `docker exec -it dev-worker bash`. Same back room, other door.
</Card>
