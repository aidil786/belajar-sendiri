<Card id="try-inside" type="try">
Setiap gerai ialah mesin sebenar. Masuk ke bilik belakangnya: **<Term id="node-shell">node shell</Term>**. Taip `ssh dev-worker`, kemudian `hostname`.

<Interactive name="FoodCourtSim" scenario="k9-kubelet" goal={{ typed: '^(ssh dev-worker|docker exec -it dev-worker bash)$', lastTyped: '^hostname$' }} hints={['Taip ssh dev-worker dan tekan Enter.', 'Prompt kini tulis root@dev-worker. Taip hostname.']} success="Anda di dalam dev-worker. Prompt pun tunjuk begitu." />

<Hint>Lihat prompt. Ia berubah bila anda di dalam node.</Hint>
</Card>

<Card id="see-kind" type="see">
<Interactive name="KubeReplay" scenario="k9-kubelet" picture={false} commands={['docker exec -it dev-worker bash', 'hostname', 'exit']} label="docker exec -it dev-worker bash buka prompt root di dalam node. hostname cetak dev-worker. exit kembali ke laptop." />

Dalam **<Term id="kind">kind</Term>**, setiap gerai ialah container Docker tanpa server SSH. Jadi anda masuk dengan `docker exec -it dev-worker bash`. Bilik belakang sama, pintu lain.
</Card>
