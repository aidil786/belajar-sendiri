<Card id="try-admin" type="try">
kubeadm left a master key on the office machine: **<Term id="admin-conf">admin.conf</Term>**. Use it on purpose. Type `kubectl --kubeconfig /etc/kubernetes/admin.conf get nodes`.

<Interactive name="FoodCourtSim" scenario="k9-certs" intro={['docker exec -it dev-control-plane bash']} goal={{ typed: 'KUBECONFIG=/etc/kubernetes/admin\\.conf|--kubeconfig[= ]/etc/kubernetes/admin\\.conf', lastTyped: '^kubectl\\b.*\\bget (nodes?|no)\\b' }} hints={['Type kubectl --kubeconfig /etc/kubernetes/admin.conf get nodes', 'Or first export KUBECONFIG=/etc/kubernetes/admin.conf, then kubectl get nodes.']} success="kubectl reached the office with the master key. admin.conf can do anything, so guard it." />

<Hint>Workers get no admin.conf. Only the office machine has it.</Hint>
</Card>

<Card id="try-join" type="try">
A new stall joins with a ticket: a **<Term id="bootstrap-token">join token</Term>**. Build the join command.

<Interactive name="CommandBuilder" pieces={[{ text: 'kubeadm join', means: 'bring this machine into a cluster' }, { text: '172.18.0.2:6443', means: 'the office’s front counter (API server)' }, { text: '--token abcdef.0123456789abcdef', means: 'the ticket' }, { text: '--discovery-token-ca-cert-hash sha256:<hash>', means: 'check the office’s ID, so you join the right food court' }]} decoys={[{ text: 'kubeadm init', means: 'builds a new office: not what a new stall needs' }, { text: '--discovery-token-unsafe-skip-ca-verification', means: 'skips the ID check: not safe' }]} success="That’s the join command. kubeadm init prints one like it." />

<Hint>Start with kubeadm join. Address, then ticket, then the ID check.</Hint>
</Card>

<Card id="deeper" type="deeper">
kubeadm adds no Pod network. You install one yourself, and only one per cluster. CoreDNS will not start before a network is there. The join token is a secret: anyone holding it can add machines.
