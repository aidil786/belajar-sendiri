<Card id="try-look" type="try">
Lihat apa yang pembina tinggalkan. Taip `docker exec -it dev-control-plane bash`. Kemudian `ls /etc/kubernetes`.

<Interactive name="FoodCourtSim" scenario="k9-certs" goal={{ typed: '^(ssh dev-control-plane|docker exec -it dev-control-plane bash)$', lastTyped: '^ls( -l)? /etc/kubernetes/?$' }} hints={['Taip docker exec -it dev-control-plane bash dan tekan Enter.', 'Sekarang taip ls /etc/kubernetes']} success="Fail kubeconfig, folder manifests dan folder pki: semuanya daripada kubeadm init." />

<Hint>Nak lagi? Cuba ls /etc/kubernetes/pki dan ls /etc/kubernetes/manifests.</Hint>
</Card>

<Card id="check-files" type="check">
Di mana kubeadm letak setiap fail? Susun.

<Interactive name="SortCards" buckets={[{ id: 'pki', label: 'pki/: kunci dan sijil' }, { id: 'manifests', label: 'manifests/: kad tugas pejabat' }, { id: 'conf', label: '/etc/kubernetes: fail kubeconfig' }]} items={[{ label: 'ca.crt', bucket: 'pki', why: 'CA kluster sendiri. Ia tandatangan setiap lencana.' }, { label: 'apiserver.key', bucket: 'pki', why: 'Kunci peribadi kaunter depan.' }, { label: 'kube-scheduler.yaml', bucket: 'manifests', why: 'Kad tugas: kubelet hidupkan scheduler daripadanya.' }, { label: 'etcd.yaml', bucket: 'manifests', why: 'Kad tugas untuk buku pesanan, etcd.' }, { label: 'admin.conf', bucket: 'conf', why: 'Kunci induk untuk kubectl.' }, { label: 'scheduler.conf', bucket: 'conf', why: 'Cara scheduler sampai ke API server.' }]} success="Lencana dalam pki, kad tugas dalam manifests, kunci pejabat sebagai fail .conf." />

<Hint>.crt dan .key ialah lencana dan kunci. Fail .yaml di sini ialah kad tugas.</Hint>
</Card>

<Card id="try-admin" type="try">
kubeadm tinggalkan kunci induk pada mesin pejabat: **<Term id="admin-conf">admin.conf</Term>**. Gunakannya dengan sengaja. Taip `kubectl --kubeconfig /etc/kubernetes/admin.conf get nodes`.

<Interactive name="FoodCourtSim" scenario="k9-certs" intro={['docker exec -it dev-control-plane bash']} goal={{ typed: 'KUBECONFIG=/etc/kubernetes/admin\\.conf|--kubeconfig[= ]/etc/kubernetes/admin\\.conf', lastTyped: '^kubectl\\b.*\\bget (nodes?|no)\\b' }} hints={['Taip kubectl --kubeconfig /etc/kubernetes/admin.conf get nodes', 'Atau export KUBECONFIG=/etc/kubernetes/admin.conf dahulu, kemudian kubectl get nodes.']} success="kubectl sampai ke pejabat dengan kunci induk. admin.conf boleh buat apa sahaja, jadi jaga baik-baik." />

<Hint>Worker tidak dapat admin.conf. Hanya mesin pejabat yang ada.</Hint>
</Card>

<Card id="try-join" type="try">
Gerai baharu menyertai dengan tiket: **<Term id="bootstrap-token">join token</Term>**. Bina arahan join.

<Interactive name="CommandBuilder" pieces={[{ text: 'kubeadm join', means: 'bawa mesin ini masuk ke kluster' }, { text: '172.18.0.2:6443', means: 'kaunter depan pejabat (API server)' }, { text: '--token abcdef.0123456789abcdef', means: 'tiketnya' }, { text: '--discovery-token-ca-cert-hash sha256:<hash>', means: 'semak ID pejabat, supaya anda sertai medan selera yang betul' }]} decoys={[{ text: 'kubeadm init', means: 'bina pejabat baharu: bukan untuk gerai baharu' }, { text: '--discovery-token-unsafe-skip-ca-verification', means: 'langkau semakan ID: tidak selamat' }]} success="Itulah arahan join. kubeadm init cetak arahan seperti ini." />

<Hint>Mula dengan kubeadm join. Alamat, kemudian tiket, kemudian semakan ID.</Hint>
</Card>

<Card id="deeper" type="deeper">
kubeadm tidak tambah rangkaian Pod. Anda pasang sendiri, dan hanya satu untuk setiap kluster. CoreDNS tidak akan hidup sebelum rangkaian ada. Join token ialah rahsia: sesiapa yang memegangnya boleh tambah mesin.
