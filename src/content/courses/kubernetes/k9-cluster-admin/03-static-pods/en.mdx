<Card id="try-look" type="try">
The office can’t hire itself. So the kubelet on its stall starts them from files: **<Term id="static-pod">static pods</Term>**. Type `ssh dev-control-plane`, then `ls /etc/kubernetes/manifests`.

<Interactive name="FoodCourtSim" scenario="k9-static-pods" goal={{ typed: '^(ssh dev-control-plane|docker exec -it dev-control-plane bash)$', lastTyped: '^ls( -l)? /etc/kubernetes/manifests/?$' }} hints={['Type ssh dev-control-plane and press Enter.', 'Then ls /etc/kubernetes/manifests']} success="Four job cards: the whole manager’s office." />

<Hint>The kubelet watches this one folder. Its setting is called staticPodPath.</Hint>
</Card>

<Card id="try-fix" type="try">
Someone moved the scheduler’s job card to `/root`. Put it back. Careful: this folder runs the office. Change only what you mean.

<Interactive name="FoodCourtSim" scenario="k9-scheduler-down" goal={{ staticPodRunning: { name: 'kube-scheduler' }, podsReady: { selector: 'run=tray', count: 1 } }} hints={['Type ssh dev-control-plane', 'Look in /root: ls /root', 'Move it back: mv /root/kube-scheduler.yaml /etc/kubernetes/manifests/', 'Then exit and press +30s. Watch the tray.']} success="The scheduler is back, and the waiting tray got a stall." />

<Hint>ls /etc/kubernetes/manifests shows only three files. Which one is missing?</Hint>
</Card>

<Card id="deeper" type="deeper">
The folder comes from the kubelet’s settings: `staticPodPath` in `/var/lib/kubelet/config.yaml`. Workers have the folder too, only empty. Files starting with a dot are skipped. Keep backups outside, for example in `/etc/kubernetes/backup/`.
