<Card id="try-look" type="try">
Pejabat tak boleh ambil pekerja untuk dirinya. Jadi kubelet di gerainya hidupkan mereka daripada fail: **<Term id="static-pod">static pod</Term>**. Taip `ssh dev-control-plane`, kemudian `ls /etc/kubernetes/manifests`.

<Interactive name="FoodCourtSim" scenario="k9-static-pods" goal={{ typed: '^(ssh dev-control-plane|docker exec -it dev-control-plane bash)$', lastTyped: '^ls( -l)? /etc/kubernetes/manifests/?$' }} hints={['Taip ssh dev-control-plane dan tekan Enter.', 'Kemudian ls /etc/kubernetes/manifests']} success="Empat kad tugas: seluruh pejabat pengurus." />

<Hint>kubelet perhatikan satu folder ini. Tetapannya dipanggil staticPodPath.</Hint>
</Card>

<Card id="try-spot" type="try">
Pejabat tunjuk setiap static pod sebagai **<Term id="mirror-pod">mirror pod</Term>**: gambar baca-sahaja. Tekan dua baris: “daripada fail”, dan pemiliknya.

</Card>

<Card id="try-fix" type="try">
Seseorang pindahkan kad tugas scheduler ke `/root`. Letak semula. Hati-hati: folder ini jalankan pejabat. Ubah apa yang perlu sahaja.

<Interactive name="FoodCourtSim" scenario="k9-scheduler-down" goal={{ staticPodRunning: { name: 'kube-scheduler' }, podsReady: { selector: 'run=tray', count: 1 } }} hints={['Taip ssh dev-control-plane', 'Lihat dalam /root: ls /root', 'Pindahkan semula: mv /root/kube-scheduler.yaml /etc/kubernetes/manifests/', 'Kemudian exit dan tekan +30s. Perhatikan dulang itu.']} success="Scheduler kembali, dan dulang yang menunggu dapat gerai." />

<Hint>ls /etc/kubernetes/manifests tunjuk tiga fail sahaja. Yang mana hilang?</Hint>
</Card>

<Card id="deeper" type="deeper">
Folder itu datang dari tetapan kubelet: `staticPodPath` dalam `/var/lib/kubelet/config.yaml`. Worker pun ada folder ini, cuma kosong. Fail yang bermula dengan titik dilangkau. Simpan sandaran di luar, contohnya dalam `/etc/kubernetes/backup/`.

<Interactive name="Mission" id="k8s-k9-l03-real" steps={[{ id: 'where', text: 'Guna kluster kind pakai buang anda sahaja.', command: 'kubectl config current-context' }, { id: 'make', text: 'Letak kad tugas kecil dalam folder satu worker.', command: "docker exec dev-worker sh -c 'printf \"apiVersion: v1\\nkind: Pod\\nmetadata:\\n  name: static-web\\nspec:\\n  containers:\\n  - name: web\\n    image: nginx:1.29-alpine\\n\" > /etc/kubernetes/manifests/static-web.yaml'" }, { id: 'see', text: 'Lihat mirror pod-nya: static-web-dev-worker.', command: 'kubectl get pods -o wide' }, { id: 'delete', text: 'Padam gambarnya. Lihat semula: ia kembali.', command: 'kubectl delete pod static-web-dev-worker' }, { id: 'clean', text: 'Kemas semula: keluarkan kad tugas itu.', command: 'docker exec dev-worker rm /etc/kubernetes/manifests/static-web.yaml' }]} success="Anda buat, perhati dan buang static pod sebenar!" />
