<Hint>Cari perkataan enabled dan running.</Hint>

<Card id="try-restart" type="try">
Selepas tetapan kubelet berubah, anda mulakan semula. Taip `ssh dev-worker`, kemudian `systemctl restart kubelet`. Kemudian baca **<Term id="journal">journal (diari)</Term>**: `journalctl -u kubelet -n 5 --no-pager`. Hati-hati: restart mengubah node.

<Interactive name="FoodCourtSim" scenario="k9-kubelet" goal={{ typed: '^systemctl restart kubelet(\\.service)?$', lastTyped: '^journalctl\\b.*(-u ?|--unit[= ])kubelet' }} hints={['Taip ssh dev-worker', 'Kemudian systemctl restart kubelet', 'Kemudian journalctl -u kubelet -n 5 --no-pager']} success="Diari tunjuk permulaan baharu, dengan nombor proses baharu dalam kubelet[…]." />

<Hint>Restart ialah henti sekejap dan hidup semula. Node kekal Ready.</Hint>
</Card>

<Card id="deeper" type="deeper">
`cat /etc/systemd/system/kubelet.service` tunjuk `Restart=always`: jika kubelet ranap, systemd hidupkannya semula. `systemctl stop` yang dirancang kekal berhenti. `journalctl -u kubelet -f` ikut baris baharu secara langsung; tekan Ctrl+C untuk keluar.
