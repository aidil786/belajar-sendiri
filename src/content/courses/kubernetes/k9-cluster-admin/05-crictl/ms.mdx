<Card id="try-pods" type="try">
Pergi terus ke dapur dengan **<Term id="crictl">crictl</Term>**. Taip `docker exec -it dev-worker2 bash`, kemudian `crictl pods`.

<Interactive name="FoodCourtSim" scenario="k9-crictl" goal={{ typed: '^(ssh dev-worker2|docker exec -it dev-worker2 bash)$', lastTyped: '^crictl pods\\b' }} hints={['Taip docker exec -it dev-worker2 bash', 'Kemudian crictl pods']} success="Dapur senaraikan pod oven, tanpa tanya pejabat." />

<Hint>crictl bercakap dengan containerd pada mesin ini sahaja. Ia tak perlukan API server.</Hint>
</Card>

<Card id="try-logs" type="try">
Baca kata-kata terakhir oven. Taip `crictl ps -a --name oven`. Salin id CONTAINER. Kemudian taip `crictl logs` dan tampal id itu.

<Interactive name="FoodCourtSim" scenario="k9-crictl" intro={['docker exec -it dev-worker2 bash']} goal={{ typed: '^crictl ps -a\\b', lastTyped: '^crictl logs (--tail[= ]?\\d+ )?[0-9a-f]{4,}' }} hints={['Taip crictl ps -a --name oven', 'Salin id dari lajur pertama.
