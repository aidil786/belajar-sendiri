<Card id="predict-next" type="predict">
“Kubelet stopped posting node status.” Where is the next rung?

<Interactive name="Choice" options={[{ label: 'Inside dev-worker: the kubelet service', correct: true, why: 'Yes. The supervisor went quiet. </Card>

<Card id="try-climb" type="try">
Climb down. Type `ssh dev-worker`, then `systemctl status kubelet`. Then read the diary: `journalctl -u kubelet -n 10 --no-pager`.

<Interactive name="FoodCourtSim" scenario="k9-notready" goal={{ typed: '^systemctl status kubelet(\\.service)?$', lastTyped: '^journalctl\\b.*(-u ?|--unit[= ])kubelet' }} hints={['Type ssh dev-worker', 'Then systemctl status kubelet', 'Then journalctl -u kubelet -n 10 --no-pager']} success="inactive (dead), and the diary ends with “Stopped kubelet.service”." />

<Hint>Look at the Active line first. Then at the last diary lines.</Hint>
</Card>

These are the diary’s last lines. Tap the two lines where systemd stops the kubelet.

<Card id="try-fix" type="try">
Now fix it: `systemctl start kubelet`. Then `exit`, and watch the stall with `kubectl get nodes -w`.

<Interactive name="FoodCourtSim" scenario="k9-notready" goal={{ nodeReady: { name: 'dev-worker' } }} hints={['Type ssh dev-worker', 'Then systemctl start kubelet', 'Then exit, and kubectl get nodes -w']} success="The supervisor is back on duty, so dev-worker is Ready again." />

<Hint>Starting the kubelet is safe. It only brings the supervisor back.</Hint>
</Card>

<Card id="check-ladder" type="check">
Put the whole ladder in order, top rung first.

<Interactive name="OrderList" items={['Which stall? kubectl get nodes', 'Why? kubectl describe node dev-worker', 'Go inside: ssh dev-worker', 'Is the supervisor on duty? systemctl status kubelet', 'What did it write? journalctl -u kubelet', 'Fix: systemctl start kubelet', 'Watch it turn Ready: kubectl get nodes -w']} label="Top rung at the top" success="That’s the ladder. <Card id="check-moves" type="check">

<Interactive name="SwipeJudge" prose cards={[{ text: 'Read systemctl status before you change anything', good: true, why: 'Look first. <Card id="deeper" type="deeper">
Other NotReady nights use the same ladder. Maybe the stove (containerd) is down. Maybe there is no Pod network yet, or the disk is full. `kubectl describe` shows where to look. The diary shows why. Practise breaking a stall on a throwaway cluster only.
