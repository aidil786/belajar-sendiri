<Card id="predict-next" type="predict">
“Kubelet stopped posting node status” bermaksud kubelet berhenti melapor. Di mana anak tangga seterusnya?

<Interactive name="Choice" options={[{ label: 'Di dalam dev-worker: servis kubelet', correct: true, why: 'Ya. Penyelia senyap. Pergi tanya mesinnya.' }, { label: 'Padam pod di dev-worker', why: 'Dulang bukan masalahnya. Penyelianya yang bermasalah.' }, { label: 'Mulakan semula API server', why: 'Pejabat okey. Cuma satu gerai senyap.' }]} />
</Card>

<Card id="try-climb" type="try">
Turun ke bawah. Taip `ssh dev-worker`, kemudian `systemctl status kubelet`. Kemudian baca diari: `journalctl -u kubelet -n 10 --no-pager`.

<Interactive name="FoodCourtSim" scenario="k9-notready" goal={{ typed: '^systemctl status kubelet(\\.service)?$', lastTyped: '^journalctl\\b.*(-u ?|--unit[= ])kubelet' }} hints={['Taip ssh dev-worker', 'Kemudian systemctl status kubelet', 'Kemudian journalctl -u kubelet -n 10 --no-pager']} success="inactive (dead), dan diari berakhir dengan “Stopped kubelet.service”." />

<Hint>Lihat baris Active dahulu. Kemudian baris terakhir diari.</Hint>
</Card>

<Card id="try-fix" type="try">
Sekarang baiki: `systemctl start kubelet`. Kemudian `exit`, dan perhatikan gerai dengan `kubectl get nodes -w`.

<Interactive name="FoodCourtSim" scenario="k9-notready" goal={{ nodeReady: { name: 'dev-worker' } }} hints={['Taip ssh dev-worker', 'Kemudian systemctl start kubelet', 'Kemudian exit, dan kubectl get nodes -w']} success="Penyelia kembali bertugas, jadi dev-worker Ready semula." />

<Hint>Hidupkan kubelet itu selamat. Ia cuma bawa penyelia kembali.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh panjat tangga NotReady dan pulihkan node.
</Card>

<Card id="deeper" type="deeper">
Malam NotReady yang lain guna tangga yang sama. Mungkin dapur (containerd) mati. Mungkin belum ada rangkaian Pod, atau cakera penuh. `kubectl describe` tunjuk di mana nak lihat. Diari tunjuk kenapa. Berlatih rosakkan gerai di kluster pakai buang sahaja.
