<Card id="see-cordon" type="see">
<Interactive name="KubeReplay" scenario="k9-drain" commands={['kubectl cordon dev-worker', 'kubectl get nodes']} label="kubectl cordon prints node/dev-worker cordoned. kubectl get nodes shows dev-worker as Ready,SchedulingDisabled." />

A **<Term id="cordon">cordon</Term>** is the “no new orders” sign on a stall. New trays go elsewhere. Trays already there keep serving.
</Card>

<Card id="try-error" type="try">
**<Term id="drain">Drain</Term>** puts up the sign, then moves every tray away. Without flags, it stops. Tap the line that names the fix.

<Interactive name="SpotLines" prompt="Tap the line that names the fix." lines={[{ text: 'node/dev-worker cordoned' }, { text: 'error: unable to drain node "dev-worker" due to error: cannot delete DaemonSet-managed Pods (use --ignore-daemonsets to ignore): kube-system/kindnet-nbg2q, kube-system/kube-proxy-tlh9j, continuing command...', target: true }, { text: 'There are pending nodes to be drained:' }, { text: ' dev-worker' }]} success="Yes: --ignore-daemonsets. Those trays belong to every stall." />

Plain words: kube-proxy and kindnet live on every stall. They cannot move.

<Hint>Look for the words in brackets: “use … to ignore”.</Hint>
</Card>

<Card id="try-sort" type="try">
Drain treats trays differently. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'move', label: 'Moves to another stall' }, { id: 'stay', label: 'Stays: every stall has one' }, { id: 'force', label: 'Needs --force: nobody remakes it' }]} items={[{ label: 'A shop tray (Deployment)', bucket: 'move', why: 'Its ReplicaSet makes a new tray on another stall.' }, { label: 'A CoreDNS tray (Deployment)', bucket: 'move', why: 'Also owned by a Deployment, so it is made again elsewhere.' }, { label: 'kube-proxy (DaemonSet)', bucket: 'stay', why: 'A DaemonSet runs one per stall. --ignore-daemonsets leaves it.' }, { label: 'kindnet (DaemonSet)', bucket: 'stay', why: 'The stall’s own wiring. It stays with the stall.' }, { label: 'A tray from kubectl run', bucket: 'force', why: 'No owner. --force deletes it, and it does not come back.' }]} success="Sorted! Owners decide what happens to a tray." />
</Card>

<Card id="try-drain" type="try">
Empty stall dev-worker for the electrician. A drain moves trays, so the danger badge shows.

<Interactive name="FoodCourtSim" scenario="k9-drain" goal={{ typed: '^(kubectl|k) drain dev-worker .*--ignore-daemonsets', nodeCordoned: { name: 'dev-worker', cordoned: true }, podsReady: { selector: 'app=shop', count: 3 } }} hints={['Type kubectl drain dev-worker --ignore-daemonsets', 'Let the clock run until 3 shop trays are ready again.', 'kubectl get pods -o wide shows where they went.']} success="Stall empty. <Hint>`kubectl drain dev-worker --ignore-daemonsets`. Then let the clock run.</Hint>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'They stay where they are now', correct: true, why: 'Uncordon only takes the sign down. <Card id="deeper" type="deeper">
Trays with an `emptyDir` need `--delete-emptydir-data`: that scratch data is lost. A PodDisruptionBudget makes drain wait its turn ([K5](/en/kubernetes/#world-5)). Drain cordons first, even when it then stops.
