Kedai jadi gelap.' }]} />
</Card>

<Hint>kubeadm naik taraf pejabat. Kubelet pakej berasingan, jadi ia datang selepas itu.</Hint>
</Card>

<Card id="try-build" type="try">
Pejabat latihan anda guna v1.37.0. Bina arahan yang bawanya ke patch v1.37.2.

<Interactive name="CommandBuilder" pieces={[{ text: 'sudo', means: 'sebagai root' }, { text: 'kubeadm', means: 'alat yang membina kluster' }, { text: 'upgrade', means: 'ubah suai' }, { text: 'apply', means: 'buat sekarang, pada node control-plane pertama' }, { text: 'v1.37.2', means: 'versi sasaran' }]} decoys={[{ text: 'v1.39.0', means: 'dua minor ke depan: tak dibenarkan' }, { text: 'node', means: 'untuk node lain, selepas yang pertama' }]} success="Itulah arahannya. Ia ubah seluruh pejabat, jadi sandarkan etcd dulu." />

`apply` tulis semula pejabat. Bahaya: ambil snapshot etcd sebelum itu.
</Card>

<Card id="try-stall" type="try">
Sekarang satu gerai. Drain dev-worker, mulakan semula kubelet-nya, kemudian buka. Anggap pakej baharu sudah dipasang.

<Interactive name="FoodCourtSim" scenario="k9-drain" goal={{ typed: 'systemctl restart kubelet', lastTyped: '^(kubectl|k) uncordon dev-worker', nodeCordoned: { name: 'dev-worker', cordoned: false }, nodeReady: { name: 'dev-worker' } }} hints={['Taip kubectl drain dev-worker --ignore-daemonsets', 'Kemudian ssh dev-worker, dan systemctl restart kubelet', 'Taip exit, kemudian kubectl uncordon dev-worker']} success="Satu gerai siap diubah suai dan dibuka semula. Gerai seterusnya, rutin yang sama." />

<Hint>Drain, kemudian `ssh dev-worker`. Mulakan semula kubelet, `exit`, kemudian uncordon.</Hint>
</Card>

<Card id="deeper" type="deeper">
Node control-plane lain dan worker guna `sudo kubeadm upgrade node`, bukan apply. kubeadm juga baharui sijilnya semasa naik taraf. Ia simpan sandaran di bawah `/etc/kubernetes/tmp`. Terminal latihan kami tunjuk `kubeadm upgrade plan` sebenar di dev-control-plane. Ia dirakam pada kluster kind. Ia tak boleh jalankan apply.
