<Card id="try-save" type="try">
Your turn. Open the office node, save a snapshot, then check it.

<Interactive name="FoodCourtSim" scenario="k9-etcd-backup" goal={{ snapshotTaken: { path: '/opt/backup.db' }, typed: '^etcdutl .*snapshot status' }} hints={['Type ssh dev-control-plane', 'Copy the etcdctl … snapshot save command below.', 'Check it: etcdutl --write-out=table snapshot status /opt/backup.db']} success="Saved and checked.
```bash
etcdctl --endpoints=https://127.0.0.1:2379 --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key snapshot save /opt/backup.db
etcdutl --write-out=table snapshot status /opt/backup.db
```
</Card>

<Card id="try-restore" type="try">
The shop was deleted after the snapshot. **<Term id="etcdutl">etcdutl</Term>** restores the copy into a new, empty folder. Then point etcd there. Danger: newer objects are lost.

<Interactive name="FoodCourtSim" scenario="k9-etcd-restore" goal={{ deploymentRestored: { name: 'shop' } }} hints={['Type ssh dev-control-plane', 'Restore: etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db', 'Point etcd at it with the sed line below. Then exit and wait about 30 s.']} success="The shop is back, with its old uid and its trays." />

```bash
etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db
sed -i 's#/var/lib/etcd$#/var/lib/etcd-restore#' /etc/kubernetes/manifests/etcd.yaml
```
</Card>

<Card id="deeper" type="deeper">
kind nodes have no etcdctl. There, run it inside the etcd pod. Only `/var/lib/etcd` and the certificates are shared with the node.

<Interactive name="KubeReplay" scenario="k9-etcd-kind" picture={false} commands={['kubectl -n kube-system exec etcd-dev-control-plane -- etcdctl --endpoints=https://127.0.0.1:2379 --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key snapshot save /var/lib/etcd/backup.db']} label="On kind, kubectl exec runs etcdctl inside the etcd pod. The snapshot lands in /var/lib/etcd/backup.db." />
