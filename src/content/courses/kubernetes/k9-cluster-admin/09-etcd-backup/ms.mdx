<Card id="try-save" type="try">
Giliran anda. Buka node pejabat, simpan snapshot, kemudian semak.

<Interactive name="FoodCourtSim" scenario="k9-etcd-backup" goal={{ snapshotTaken: { path: '/opt/backup.db' }, typed: '^etcdutl .*snapshot status' }} hints={['Taip ssh dev-control-plane', 'Salin arahan etcdctl … snapshot save di bawah.', 'Semak: etcdutl --write-out=table snapshot status /opt/backup.db']} success="Disimpan dan disemak. Jadual itu tunjuk revision dan saiznya." />

```bash
etcdctl --endpoints=https://127.0.0.1:2379 --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key snapshot save /opt/backup.db
etcdutl --write-out=table snapshot status /opt/backup.db
```
</Card>

<Card id="try-restore" type="try">
Shop dipadam selepas snapshot diambil. **<Term id="etcdutl">etcdutl</Term>** pulihkan salinan ke folder baharu yang kosong. Kemudian tunjukkan etcd ke situ. Bahaya: objek yang lebih baharu hilang.

<Interactive name="FoodCourtSim" scenario="k9-etcd-restore" goal={{ deploymentRestored: { name: 'shop' } }} hints={['Taip ssh dev-control-plane', 'Pulihkan: etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db', 'Tunjukkan etcd ke situ dengan baris sed di bawah. Kemudian exit dan tunggu kira-kira 30 s.']} success="Shop sudah kembali, dengan uid lamanya dan dulang-dulangnya." />

```bash
etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db
sed -i 's#/var/lib/etcd$#/var/lib/etcd-restore#' /etc/kubernetes/manifests/etcd.yaml
```
</Card>
