A kubeadm cluster ran fine for a year. This morning the office stops talking. Nobody changed anything. What is a likely cause?

<Interactive name="Choice" options={[{ label: 'The office’s ID cards (certificates) expired', correct: true, why: 'kubeadm’s certificates last one year. A date fits better.' }, { label: 'The kubelets need more memory', why: 'Memory trouble does not start on one exact day.' }]} />
</Card>

<Card id="predict" type="predict">
You run `kubeadm certs renew all`. It says “renewed” for each card. Yet the API server still shows the old one. Why?

<Interactive name="Choice" options={[{ label: 'It read its card at start. Restart the control-plane pods.', correct: true, why: 'Yes. The docs say to restart them after a renew.' }, { label: 'The renew failed', why: 'It printed renewed for each card. The files are new.' }, { label: 'You must renew the CA too', why: 'The CAs last ten years. renew all leaves them alone.' }]} />
</Card>

<Card id="try-renew" type="try">
Renew the API server’s card, then check the dates again. Renewing changes the office, so the danger note shows.

<Hint>Open the control-plane node first. Then renew, then check.</Hint>
</Card>

<Card id="check-order" type="check">
Put a renewal day in order.

<Interactive name="OrderList" items={['kubeadm certs check-expiration', 'kubeadm certs renew all', 'Restart the control-plane pods: move each manifest out, wait 20 s, move it back', 'Copy the new admin.conf to ~/.kube/config']} label="First step at the top" success="Look, renew, restart, then update your own kubeconfig." />
</Card>

<Card id="check-sort" type="check">
Who keeps each card fresh? Sort them.

<Interactive name="SortCards" buckets={[{ id: 'kubeadm', label: 'kubeadm renews it (or an upgrade)' }, { id: 'self', label: 'The kubelet rotates it itself' }, { id: 'ca', label: 'A CA: lasts ten years' }]} items={[{ label: 'apiserver', bucket: 'kubeadm', why: 'A one-year card. renew or upgrade makes a new one.' }, { label: 'admin.conf', bucket: 'kubeadm', why: 'Your admin card. <Card id="win" type="win">
You can now read certificate expiry dates and renew in time.
</Card>

<Card id="deeper" type="deeper">
`kubeadm upgrade` renews the certificates too. So a yearly upgrade keeps the cards fresh. Many teams also set an alarm a month before the date.
