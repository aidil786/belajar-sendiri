<Card id="hook" type="hook">
Satu kluster kubeadm berjalan lancar selama setahun. Pagi ini pejabat berhenti berhubung. Tiada siapa ubah apa-apa. Apa punca yang mungkin?

<Interactive name="Choice" options={[{ label: 'Kad pengenalan pejabat (sijil) sudah luput', correct: true, why: 'Sijil kubeadm tahan setahun. Pada hari itu ia berhenti berfungsi.' }, { label: 'Seseorang padam etcd', why: 'Mungkin, tapi tiada yang berubah. Tarikh lebih sesuai sebagai punca.' }, { label: 'Kubelet perlukan lebih memori', why: 'Masalah memori tak bermula pada satu hari yang tepat.' }]} />
</Card>

<Card id="see-check" type="see">
<Interactive name="KubeReplay" scenario="k9-certs" picture={false} commands={['docker exec -it dev-control-plane bash', 'kubeadm certs check-expiration', 'exit']} label="kubeadm certs check-expiration senaraikan setiap sijil dengan tarikh luputnya: baki 364d untuk yang biasa, 9y untuk tiga CA." />

Setiap bahagian tunjuk kad pengenalan kepada yang lain. Setiap kad ada tarikh **<Term id="cert-expiry">certificate expiry</Term>** (luput). `kubeadm certs check-expiration` senaraikan semuanya.
</Card>

Jadual terakhir senaraikan penandatangan. Ketik baris yang tahan 9 tahun.

Penandatangan tahan sepuluh tahun. Kad yang ditandatangan, setahun." />

**<Term id="certificate-authority">Certificate authority</Term>** (CA) tandatangan setiap kad. kubeadm buat CA-nya tahan sepuluh tahun.
</Card>

<Card id="predict" type="predict">
Anda jalankan `kubeadm certs renew all`. Ia kata “renewed” untuk setiap kad. Tapi API server masih tunjuk kad lama. Kenapa?

<Interactive name="Choice" options={[{ label: 'Ia baca kadnya semasa bermula. Mulakan semula pod control-plane.', correct: true, why: 'Ya. Dokumentasi suruh mulakan semula selepas renew.' }, { label: 'Renew itu gagal', why: 'Ia cetak renewed untuk setiap kad. Failnya sudah baharu.' }, { label: 'Anda mesti baharui CA juga', why: 'CA tahan sepuluh tahun. renew all tak sentuh CA.' }]} />
</Card>

<Card id="try-renew" type="try">
Baharui kad API server, kemudian semak tarikh semula. Renew ubah pejabat, jadi nota bahaya muncul.

<Interactive name="FoodCourtSim" scenario="k9-certs" goal={{ typed: '^kubeadm certs renew ', lastTyped: '^kubeadm certs check-expiration' }} hints={['Taip docker exec -it dev-control-plane bash', 'Kemudian kubeadm certs renew apiserver', 'Semak: kubeadm certs check-expiration']} success="Tarikh baharu pada baris apiserver. Seterusnya: mulakan semula pod-nya." />

<Hint>Buka node control-plane dulu. Kemudian renew, kemudian semak.</Hint>
</Card>
