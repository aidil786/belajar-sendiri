<Card id="try-build" type="try">
Build Aina’s request. CN is her name. O is her team.

<Interactive name="CommandBuilder" pieces={[{ text: 'openssl', means: 'the certificate toolkit' }, { text: 'req', means: 'make a request' }, { text: '-new', means: 'a new one' }, { text: '-key aina.key', means: 'from her secret key' }, { text: '-out aina.csr', means: 'save the request here' }, { text: '-subj "/CN=aina/O=kitchen"', means: 'name aina, team kitchen' }]} decoys={[{ text: '-x509', means: 'sign it yourself: not a request' }, { text: '-subj "/CN=kitchen/O=aina"', means: 'name and team swapped' }]} success="That is her request. The key stays on her laptop." />
</Card>

<Card id="try-yaml" type="try">
This CSR asks for a server’s card. Aina signs in as a client. Fix the usage.

<Interactive name="YamlPlayground" file="aina-csr.yaml" initial={'apiVersion: certificates.k8s.io/v1\nkind: CertificateSigningRequest\nmetadata:\n  name: aina\nspec:\n  # base64 of aina.csr (shortened here)\n  request: LS0tLS1CRUdJTiBDRVJUSUZJQ0FURSBSRVFVRVNULS0tLS0K\n  signerName: kubernetes.io/kube-apiserver-client\n  expirationSeconds: 86400\n  usages:\n    - server auth\n'} expect={[{ path: 'spec.usages', type: 'list', count: 1, includes: 'client auth', hint: 'Change server auth to client auth.' }, { path: 'spec.signerName', type: 'text', equals: 'kubernetes.io/kube-apiserver-client', hint: 'Keep the signerName as it was.' }]} solution={'apiVersion: certificates.k8s.io/v1\nkind: CertificateSigningRequest\nmetadata:\n  name: aina\nspec:\n  # base64 of aina.csr (shortened here)\n  request: LS0tLS1CRUdJTiBDRVJUSUZJQ0FURSBSRVFVRVNULS0tLS0K\n  signerName: kubernetes.io/kube-apiserver-client\n  expirationSeconds: 86400\n  usages:\n    - client auth\n'} hint="A person who signs in is a client." success="Right. For a user, usages is client auth." />
</Card>

<Card id="predict" type="predict">
You run `kubectl certificate approve aina`. She signs in with her new card. Can she list the trays?

<Interactive name="Choice" options={[{ label: 'Not yet: nobody gave her rights', correct: true, why: 'The card proves who she is. Rights come from RBAC.' }, { label: 'Only in kube-system', why: 'She has no rights anywhere yet.' }]} />
</Card>

<Card id="try-rbac" type="try">
The Role cook (read trays) exists. Bind it to user aina. Then ask as her.

<Interactive name="FoodCourtSim" scenario="k9-users" intro={['kubectl create role cook --verb=get --verb=list --resource=pods']} goal={{ canI: [{ verb: 'list', resource: 'pods', as: 'aina', allowed: true }, { verb: 'delete', resource: 'pods', as: 'aina', allowed: false }], typed: 'auth can-i .*--as=aina' }} hints={['Type kubectl create rolebinding cook-aina --role=cook --user=aina', 'Ask as her: kubectl auth can-i list pods --as=aina']} success="Aina may read trays. She may not delete them." />

<Hint>`--user=aina` must match the CN in her card exactly.</Hint>
</Card>

<Card id="check-kubeconfig" type="check">
Aina’s card is signed. Put her kubeconfig steps in order.

<Interactive name="OrderList" items={['kubectl get csr aina -o jsonpath=\'{.status.certificate}\' | base64 -d > aina.crt', 'kubectl config set-credentials aina --client-key=aina.key --client-certificate=aina.crt --embed-certs=true', 'kubectl config set-context aina --cluster=kind-dev --user=aina', 'kubectl --context aina auth whoami']} label="First step at the top" success="Card out, card in, context made, then check who you are." />
</Card>

<Card id="deeper" type="deeper">
`expirationSeconds: 86400` asks for a one-day card. The minimum is 10 minutes. Our practice terminal has no CSR objects. Do this part on kind. Never share or commit the `.key` file.

<Interactive name="Mission" id="k8s-k9-l11-real" steps={[{ id: 'key', text: 'On your laptop, make a key.', command: 'openssl genrsa -out aina.key 3072' }, { id: 'req', text: 'Make the request.', command: 'openssl req -new -key aina.key -out aina.csr -subj "/CN=aina/O=kitchen"' }, { id: 'b64', text: 'Turn it into one base64 line for request: in your YAML.', command: 'cat aina.csr | base64 | tr -d "\\n"' }, { id: 'apply', text: 'Apply the CSR on a throwaway kind cluster, then approve it.', command: 'kubectl apply -f aina-csr.yaml && kubectl certificate approve aina' }, { id: 'look', text: 'Read the CONDITION column.', command: 'kubectl get csr aina' }]} success="A real cluster signed a real user card!" />
</Card>
