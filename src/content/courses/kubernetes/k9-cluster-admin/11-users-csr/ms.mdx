<Card id="try-yaml" type="try">
CSR ini minta kad untuk server. Aina log masuk sebagai klien. Baiki usage-nya.

<Interactive name="YamlPlayground" file="aina-csr.yaml" initial={'apiVersion: certificates.k8s.io/v1\nkind: CertificateSigningRequest\nmetadata:\n  name: aina\nspec:\n  # base64 of aina.csr (shortened here)\n  request: LS0tLS1CRUdJTiBDRVJUSUZJQ0FURSBSRVFVRVNULS0tLS0K\n  signerName: kubernetes.io/kube-apiserver-client\n  expirationSeconds: 86400\n  usages:\n    - server auth\n'} expect={[{ path: 'spec.usages', type: 'list', count: 1, includes: 'client auth', hint: 'Tukar server auth kepada client auth.' }, { path: 'spec.signerName', type: 'text', equals: 'kubernetes.io/kube-apiserver-client', hint: 'Kekalkan signerName seperti asal.' }]} solution={'apiVersion: certificates.k8s.io/v1\nkind: CertificateSigningRequest\nmetadata:\n  name: aina\nspec:\n  # base64 of aina.csr (shortened here)\n  request: LS0tLS1CRUdJTiBDRVJUSUZJQ0FURSBSRVFVRVNULS0tLS0K\n  signerName: kubernetes.io/kube-apiserver-client\n  expirationSeconds: 86400\n  usages:\n    - client auth\n'} hint="Orang yang log masuk ialah klien." success="Betul. Untuk pengguna, usages ialah client auth." />
</Card>

<Card id="try-rbac" type="try">
Role cook (baca dulang) sudah ada. Ikat ia kepada pengguna aina. Kemudian tanya sebagai dia.

<Interactive name="FoodCourtSim" scenario="k9-users" intro={['kubectl create role cook --verb=get --verb=list --resource=pods']} goal={{ canI: [{ verb: 'list', resource: 'pods', as: 'aina', allowed: true }, { verb: 'delete', resource: 'pods', as: 'aina', allowed: false }], typed: 'auth can-i .*--as=aina' }} hints={['Taip kubectl create rolebinding cook-aina --role=cook --user=aina', 'Tanya sebagai dia: kubectl auth can-i list pods --as=aina']} success="Aina boleh baca dulang. <Card id="check-kubeconfig" type="check">
Kad Aina sudah ditandatangan. Susun langkah kubeconfig-nya ikut urutan.

<Interactive name="OrderList" items={['kubectl get csr aina -o jsonpath=\'{.status.certificate}\' | base64 -d > aina.crt', 'kubectl config set-credentials aina --client-key=aina.key --client-certificate=aina.crt --embed-certs=true', 'kubectl config set-context aina --cluster=kind-dev --user=aina', 'kubectl --context aina auth whoami']} label="Langkah pertama di atas" success="Kad dikeluarkan, kad dimasukkan, context dibuat, kemudian semak siapa anda." />

<Card id="deeper" type="deeper">
`expirationSeconds: 86400` minta kad untuk sehari. Paling singkat 10 minit. Terminal latihan kami tiada objek CSR, jadi buat bahagian ini pada kind. Jangan kongsi atau commit fail `.key`.

<Interactive name="Mission" id="k8s-k9-l11-real" steps={[{ id: 'key', text: 'Di laptop anda, buat kunci.', command: 'openssl genrsa -out aina.key 3072' }, { id: 'req', text: 'Buat permohonan.', command: 'openssl req -new -key aina.key -out aina.csr -subj "/CN=aina/O=kitchen"' }, { id: 'b64', text: 'Tukar jadi satu baris base64 untuk request: dalam YAML anda.', command: 'cat aina.csr | base64 | tr -d "\\n"' }, { id: 'apply', text: 'Apply CSR itu pada kluster kind latihan, kemudian luluskan.', command: 'kubectl apply -f aina-csr.yaml && kubectl certificate approve aina' }, { id: 'look', text: 'Baca lajur CONDITION.', command: 'kubectl get csr aina' }]} success="Kluster sebenar tandatangan kad pengguna sebenar!" />
</Card>
