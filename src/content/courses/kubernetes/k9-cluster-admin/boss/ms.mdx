<Card id="try-plan" type="try">
Bilik 2: rancang pemulihan sebelum sentuh apa-apa.

<Interactive name="OrderList" items={['ssh dev-control-plane', 'etcdutl --write-out=table snapshot status /opt/backup.db', 'etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db', 'Tunjukkan etcd.yaml ke /var/lib/etcd-restore (sed -i)', 'exit, tunggu kira-kira 30 s, kubectl get deployments']} label="Langkah pertama di atas" success="Pelan sedia. <Card id="try-all" type="try">
Bilik terakhir: kedua-dua masalah kembali. Baiki gerai itu, dan pulihkan shop dari snapshot. Bahaya: pemulihan tulis semula etcd.

<Interactive name="FoodCourtSim" scenario="k9-boss" goal={{ nodeReady: { name: 'dev-worker2' }, deploymentRestored: { name: 'shop' } }} hints={['Bilik 1 semula: ssh dev-worker2, systemctl start kubelet, exit.', 'ssh dev-control-plane, kemudian etcdutl --data-dir /var/lib/etcd-restore snapshot restore /opt/backup.db', "sed -i 's#/var/lib/etcd$#/var/lib/etcd-restore#' /etc/kubernetes/manifests/etcd.yaml, kemudian exit dan tunggu"]} success="Boss selesai!
