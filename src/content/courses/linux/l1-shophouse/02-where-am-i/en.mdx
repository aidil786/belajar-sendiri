<Card id="see-pwd" type="see">
<Interactive name="LinuxSim" scenario="linux-l1-shop" intro={['pwd', 'ls']} />

Every room has an address: its **path**. `pwd` prints where you stand. `ls` lists what is in this room. Try `ls kedai` too.
</Card>

<Card id="see-paths" type="see">
`/home/you` starts at `/`, the front door. It works from anywhere. `kedai/menu` starts from where you stand. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'abs', label: 'From the front door /' }, { id: 'rel', label: 'From where I stand' }]} items={[{ label: '/home/you/kedai', bucket: 'abs', why: 'It starts with /: the same address from any room.' }, { label: 'kedai/menu', bucket: 'rel', why: 'No / at the start: it begins in your current room.' }, { label: '/etc', bucket: 'abs', why: 'It starts with /.' }, { label: '../counter', bucket: 'rel', why: '.. means one room up from where you stand.' }]} success="A / at the start means: begin at the front door." />
</Card>

<Card id="try-cd" type="try">
Walk into the kitchen with `cd kedai/kitchen`. Then list it with `ls`.

<Interactive name="LinuxSim" scenario="linux-l1-shop" goal={{ cwd: '~/kedai/kitchen', lastTyped: '^ls' }} hints={['Type cd kedai/kitchen and press Enter.', 'Now type ls.']} solution={['cd kedai/kitchen', 'ls']} success="You are in the kitchen. Two recipes are here." />

<Card id="predict-up" type="predict">

<Interactive name="Choice" options={[{ label: '/home/you/kedai', correct: true, why: '.. is the room one level up. kitchen sits inside kedai.' }, { label: '/home/you', why: 'That is two levels up. <Card id="check-home" type="check">

<Card id="win" type="win">
You can now see where you are and walk between folders.
</Card>

<Card id="deeper" type="deeper">
`cd -` jumps back to the room you were in before. `ls -a` also shows hidden names that start with a dot, like `.keys`. `ls -l` shows owners and keys: that is World L2.
