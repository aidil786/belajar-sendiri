<Card id="see-pwd" type="see">
<Interactive name="LinuxSim" scenario="linux-l1-shop" intro={['pwd', 'ls']} />

Setiap bilik ada alamat: **path** (laluan). `pwd` cetak tempat anda berdiri. `ls` senaraikan isi bilik ini. Cuba `ls kedai` juga.

<Card id="see-paths" type="see">

<Interactive name="SortCards" buckets={[{ id: 'abs', label: 'Dari pintu depan /' }, { id: 'rel', label: 'Dari tempat saya berdiri' }]} items={[{ label: '/home/you/kedai', bucket: 'abs', why: 'Ia bermula dengan /: alamat sama dari bilik mana pun.' }, { label: 'kedai/menu', bucket: 'rel', why: 'Tiada / di depan: ia bermula di bilik anda sekarang.' }, { label: '/etc', bucket: 'abs', why: 'Ia bermula dengan /.' }, { label: '../counter', bucket: 'rel', why: '.. maksudnya naik satu bilik dari tempat anda.' }]} success="/ di depan maksudnya: mula dari pintu depan." />
</Card>

<Card id="try-cd" type="try">

<Hint>`cd` maksudnya "change directory": masuk ke folder.</Hint>

<Card id="try-counter" type="try">

<Card id="deeper" type="deeper">
`cd -` lompat balik ke bilik sebelum ini. `ls -a` juga tunjuk nama tersembunyi yang bermula dengan titik, seperti `.keys`. `ls -l` tunjuk pemilik dan kunci: itu Dunia L2.
