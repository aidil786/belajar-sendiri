The counter keeps an order book, `orders.log`. It grows all day. You only need the newest orders. What do you do?

<Card id="try-tail" type="try">
Show only the last 3 orders: `tail -n 3 orders.log`.

<Interactive name="LinuxSim" scenario="linux-l1-counter" goal={{ lastTyped: '^tail (-n ?3|-3) orders\\.log$' }} hints={['Type tail -n 3 orders.log']} solution={['tail -n 3 orders.log']} success="Three lines: the newest orders, up to 08:44." />

<Hint>`-n 3` means "3 lines".</Hint>
</Card>

<Card id="predict-head" type="predict">
What does `head -n 1 orders.log` print?

<Interactive name="Choice" options={[{ label: '08:01 T1 nasi-lemak 5 paid', correct: true, why: 'head starts at the top. The first order came at 08:01.' }, { label: '08:44 T3 roti-canai 2 paid', why: 'That is the last line. tail would show it.' }, { label: 'All 15 orders', why: '-n 1 asks for one line only.' }]} />
</Card>

<Card id="try-follow" type="try">
Watch the book grow with `tail -f orders.log`. It holds the terminal. Stop it with **Ctrl+C**.

<Interactive name="LinuxSim" scenario="linux-l1-counter" goal={{ typed: '^tail (.* )?-f', noForeground: true }} hints={['Type tail -f orders.log', 'Press the Ctrl+C button to stop watching.']} solution={['tail -f orders.log', '^C']} success="You watched, then stopped. Ctrl+C ends most programs that hold the terminal." />

<Hint>`-f` means "follow": keep watching for new lines.</Hint>
</Card>

<Card id="check-less" type="check">
You opened a long log with `less orders.log`. You read enough. How do you leave?

<Interactive name="Choice" options={[{ label: 'Press q', correct: true, why: 'q quits less. You are back at the prompt.' }, { label: 'Press Ctrl+Z', why: 'That only pauses less in the background. q leaves it.' }, { label: 'Close the terminal window', why: 'That works, but it ends your whole session. q is gentler.' }]} />
</Card>

<Card id="win" type="win">
You can now read the top, the end, or a whole file.
</Card>

<Card id="deeper" type="deeper">
In `less`, Space shows the next page and `q` quits. `/sambal` searches, and `G` jumps to the end. `head` and `tail` show 10 lines unless you say `-n`. `cat -n` numbers the lines. `wc -l` counts them.

Real rep (optional): on Linux, try `tail -n 5 /var/log/dpkg.log`, then `less /etc/os-release` and press q.
</Card>
