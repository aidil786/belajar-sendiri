<Card id="predict-parents" type="predict">
`store` has no `2026` room yet. You type `mkdir store/2026/nov`. What happens?

<Interactive name="Choice" options={[{ label: "mkdir: cannot create directory ‘store/2026/nov’: No such file or directory", correct: true, why: 'Plain words: the room 2026 is missing, so nov has nowhere to go. mkdir -p builds the missing rooms too.' }, { label: 'It builds 2026 and nov', why: 'Only with -p. <Card id="sort-cp-mv" type="check">
`cp` makes a copy: the first file stays. `mv` moves or renames: nothing stays behind. Which one?

<Interactive name="SortCards" buckets={[{ id: 'cp', label: 'cp: copy' }, { id: 'mv', label: 'mv: move or rename' }]} items={[{ label: 'Back up today.txt before editing', bucket: 'cp', why: 'You want two files: the menu and its backup.' }, { label: 'Rename draft.txt to promo.txt', bucket: 'mv', why: 'Renaming is moving to a new name.' }, { label: 'Put promo.txt into the menu room', bucket: 'mv', why: 'It should leave the floor, not stay there too.' }, { label: 'A spare menu for the night stall', bucket: 'cp', why: 'The shop keeps its own menu.' }]} success="Two files after: cp. One file after: mv." />
</Card>

<Card id="try-cp-mv" type="try">
Back up the menu as `menu/today.bak`. Then rename `draft.txt` to `promo.txt`.

<Interactive name="LinuxSim" scenario="linux-l1-make" goal={{ fileExists: ['~/kedai/menu/today.bak', '~/kedai/promo.txt'], fileMissing: ['~/kedai/draft.txt'] }} hints={['Copy: cp menu/today.txt menu/today.bak', 'Rename: mv draft.txt promo.txt']} solution={['cp menu/today.txt menu/today.bak', 'mv draft.txt promo.txt']} success="A backup in the menu room, and the promo has its real name." />

<Hint>The order is always: from, then to.</Hint>
</Card>

<Card id="check-folder" type="check">
You type `cp kitchen kitchen-copy`. The server says `cp: -r not specified; omitting directory 'kitchen'`. What now?

<Interactive name="Choice" options={[{ label: 'cp -r kitchen kitchen-copy', correct: true, why: 'A folder holds many files. -r copies it and everything inside.' }, { label: 'mv kitchen kitchen-copy', why: 'That renames the kitchen. No copy is left.' }, { label: 'mkdir kitchen-copy', why: 'That makes an empty room. The recipes stay behind.' }]} />
</Card>

<Card id="deeper" type="deeper">
Careful: `cp` and `mv` replace a file with the same name without asking. `cp -i` and `mv -i` ask first on a real machine. `touch notes.txt` makes an empty file.
