<Card id="hook" type="hook">
On your laptop, deleted files wait in a bin. On a Linux server, where does `rm` send them?

<Interactive name="Choice" options={[{ label: 'Nowhere. They are gone for good.', correct: true, why: 'rm has no bin and no undo. Only a backup can bring a file back.' }, { label: 'To a trash folder', why: 'The shell has no trash folder. rm deletes at once.' }, { label: 'To a backup, by magic', why: 'Only if you made a backup yourself.' }]} />
</Card>

<Card id="deeper" type="deeper">
`rmdir old` deletes a folder only when it is empty: a gentle choice. `rm -i` asks before each file on a real machine. `-f` never asks and hides errors, so treat it like a sharp knife.
