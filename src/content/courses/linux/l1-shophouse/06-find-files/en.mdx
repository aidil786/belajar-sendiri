<Card id="predict-case" type="predict">
Mak named her file `Sambal-Mak.txt`. Does `find kedai -name "sambal*"` find it?

<Interactive name="Choice" options={[{ label: 'No. -name cares about big and small letters.', correct: true, why: 'S and s are different letters to Linux. -iname ignores the difference.' }, { label: 'Yes. </Card>

<Card id="deeper" type="deeper">
Search from `/` and you see lines like `find: ‘/root’: Permission denied`. Plain words: rooms you have no key for. World L2 explains keys. `-delete` and `-exec` act on every match: run the search alone first.

Real rep (optional): on Linux, `find /etc -name "*.conf"` lists settings files. Ignore the Permission denied lines.
</Card>
