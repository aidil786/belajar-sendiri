<Card id="predict-case" type="predict">
One cashier wrote `Unpaid`, not `UNPAID`. Did grep show that line?

<Interactive name="Choice" options={[{ label: 'No. grep cares about big and small letters.', correct: true, why: 'UNPAID and Unpaid are different to grep. -i ignores case.' }, { label: 'Yes. grep ignores case anyway.', why: 'Only with -i. Plain grep matches letters exactly.' }, { label: 'Only if the line is short', why: 'Length does not matter. The letters must match.' }]} />
</Card>

<Card id="deeper" type="deeper">
`grep laksa orders.log` prints nothing and ends with exit code 1. Plain words: no line matched; nothing broke. `grep -r belacan ~/kedai` searches every file in every room. `grep -n` and `-i` mix: `grep -ni unpaid orders.log`.

Real rep (optional): on Linux, `grep -c bash /etc/passwd` counts users with bash as their shell.
</Card>
