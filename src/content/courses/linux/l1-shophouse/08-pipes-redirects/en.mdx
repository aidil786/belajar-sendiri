<Card id="order-stations" type="try">
Build the best-seller belt. Put the four stations in order.

<Interactive name="OrderList" items={['cut -d" " -f3 orders.log: keep only the dish column', 'sort: line up the same dishes together', 'uniq -c: count each group', 'sort -rn: biggest number first']} label="First station at the top" success="Cut, sort, count, sort again. A real belt!" />
</Card>

<Card id="try-belt" type="try">
Now run the whole belt in one line:

`cut -d" " -f3 orders.log | sort | uniq -c | sort -rn`

<Interactive name="LinuxSim" scenario="linux-l1-counter" goal={{ lastTyped: 'uniq -c *\\| *sort -(rn|nr)' }} hints={['Copy the line above exactly. The spaces around | do not matter.']} solution={['cut -d" " -f3 orders.log | sort | uniq -c | sort -rn']} success="6 nasi-lemak, 4 teh-tarik, 3 roti-canai, 2 mee-goreng." />

<Hint>`-d" "` splits on spaces. `-f3` keeps the third piece.</Hint>
</Card>

<Card id="deeper" type="deeper">
`2> /dev/null` throws error lines away. `cmd > all.txt 2>&1` saves both kinds. `tee report.txt` shows the lines and saves them too. `<` feeds a file in: `sort < today.txt`.
