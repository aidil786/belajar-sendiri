<Card id="try-tab" type="try">
**Tab completion** (lengkap automatik) jimat menaip. Taip `cat no`, kemudian tekan Tab. Shell habiskan nama itu. Tekan Enter.

<Interactive name="LinuxSim" scenario="linux-l1-wild" goal={{ lastTyped: '^cat notes\\.md$' }} hints={['Taip cat no, kemudian ketik kekunci Tab.', 'Baris jadi cat notes.md. Tekan Enter.']} solution={['cat notes.md']} success="Tab taip selebihnya untuk anda. Tiada salah taip." />

<Hint>Di telefon, Tab ada dalam baris kekunci di bawah terminal.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh padankan banyak fail sekali gus, dan biar Tab menaip.
</Card>

<Card id="deeper" type="deeper">
Tanda petik hentikan pertukaran: `echo "*.jpg"` cetak bintang itu sendiri. Tiada padanan? `ls *.png` kata `No such file or directory`.

Latihan sebenar (pilihan): di Linux, taip `cat /etc/os-` dan tekan Tab.

Di mana cerita ini tak tepat: rumah kedai sebenar ada dinding. Di sini bilik cuma nama dalam senarai. Alih bilik cuma tukar nama.
</Card>
