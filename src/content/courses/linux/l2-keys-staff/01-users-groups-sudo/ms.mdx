<Card id="deeper" type="deeper">
`sudo -i` buka shell root: prompt berakhir dengan `#` dan lencana root muncul. Taip `exit` untuk pulangkan kunci. Tanpa sudo, `useradd` kata `command not found`: alat admin ada dalam `/usr/sbin`, di luar PATH anda.

Latihan sebenar (pilihan): di Linux anda sendiri, jalankan `id` dan `groups`. Kemudian `sudo -l` tunjuk apa sudo benarkan.
</Card>
