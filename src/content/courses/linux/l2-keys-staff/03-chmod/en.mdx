`chmod +x open.sh` added the run key. **chmod** means "change mode". Letters: `u` owner, `g` group, `o` others. `+` adds, `-` takes away.

<Card id="deeper" type="deeper">
Common pairs: `644` for files, `755` for scripts and folders, `600` for secrets. `chmod -R` changes a whole folder tree, so check twice. A script also needs a first line like `#!/bin/bash`.

Real rep (optional): in a practice folder, `touch s.sh`, `ls -l s.sh`, `chmod 755 s.sh`, then `ls -l s.sh` again.
</Card>
