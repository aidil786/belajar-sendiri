<Card id="see-letters" type="see">
<Interactive name="LinuxSim" scenario="linux-l2-chmod" intro={['chmod +x open.sh', 'ls -l open.sh']} />

`chmod +x open.sh` tambah kunci jalan. **chmod** maksudnya "change mode" (tukar mod). Huruf: `u` pemilik, `g` kumpulan, `o` orang lain. `+` tambah, `-` buang.
</Card>

<Card id="deeper" type="deeper">
Pasangan biasa: `644` untuk fail, `755` untuk skrip dan folder, `600` untuk rahsia. `chmod -R` ubah seluruh pokok folder, jadi semak dua kali. Skrip juga perlukan baris pertama seperti `#!/bin/bash`.

Latihan sebenar (pilihan): dalam folder latihan, `touch s.sh`, `ls -l s.sh`, `chmod 755 s.sh`, kemudian `ls -l s.sh` lagi.
</Card>
