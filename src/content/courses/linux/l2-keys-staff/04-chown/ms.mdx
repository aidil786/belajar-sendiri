<Card id="try-chown" type="try">
Serahkan folder itu kepada pekerja web dan kumpulan mereka: `sudo chown www-data:www-data uploads`.

<Interactive name="LinuxSim" scenario="linux-l2-chown" goal={{ owner: { '/srv/kedai/uploads': 'www-data:www-data' } }} hints={['Taip sudo chown www-data:www-data uploads', 'Semak dengan ls -l']} solution={['sudo chown www-data:www-data uploads']} success="uploads kini milik www-data. Gambar tunjuk pemilik baru." />

<Hint>**chown** maksudnya "change owner" (tukar pemilik). Bentuknya `pemilik:kumpulan`.</Hint>
</Card>

Kini anda boleh serahkan fail dan folder kepada pemilik yang betul.
</Card>

<Card id="deeper" type="deeper">
`sudo chown -R www-data:www-data uploads` ubah folder dan semua isinya: semak path dua kali. `sudo chown :kitchen roster.txt` tukar kumpulan sahaja. Jangan sekali-kali serahkan seluruh rumah anda kepada pengguna lain.

Latihan sebenar (pilihan): di Linux, `ls -l /var/www` tunjuk siapa pemilik fail web.
</Card>
