<Card id="try-top" type="try">
`top` shows the same, live, busiest first. Run `top`, look at the top row, then press q.

<Interactive name="LinuxSim" scenario="linux-l2-procs" goal={{ typed: '^top$', noForeground: true }} hints={['Type top and press Enter.', 'Press the q (quit) button to leave top.']} solution={['top', 'q']} success="PID 1241, bash, near 100% CPU. That is the stuck script." />

<Hint>`top` holds the terminal until you press q.</Hint>
</Card>

<Card id="try-pgrep" type="try">
Long lists are tiring. Ask for the PID by name: `pgrep -f stock-check`.

<Interactive name="LinuxSim" scenario="linux-l2-procs" goal={{ lastTyped: '^pgrep (-f )?.*stock' }} hints={['Type pgrep -f stock-check']} solution={['pgrep -f stock-check']} success="1241. Keep that number: the next lesson stops it." />

<Hint>`-f` searches the whole command line, not just the program name.</Hint>
</Card>

<Card id="predict-ps" type="predict">
You type plain `ps`, with no `aux`. Do you see `stock-check.sh`?

<Interactive name="Choice" options={[{ label: 'No. Plain ps shows only this terminal’s programs.', correct: true, why: 'stock-check runs outside your terminal. aux means all users, all terminals.' }, { label: 'Yes. ps always shows everything.', why: 'Only with aux (or -e). Plain ps is short.' }, { label: 'Only if it uses the CPU', why: 'Busy or not, plain ps skips other terminals.' }]} />
</Card>

<Card id="deeper" type="deeper">
In `top`, `M` sorts by memory and `P` by CPU. `ps aux | grep nginx` filters the list with a pipe. `htop` is a friendlier top: you install it in lesson 10.

Real rep (optional): on Linux, run `top` for ten seconds, then press q. Which process is busiest?
</Card>
