<Card id="see-vars" type="see">
<Interactive name="LinuxSim" scenario="linux-l2-path" intro={['echo $HOME', 'echo $PATH']} />

Nota di dinding: **environment variables** (pemboleh ubah persekitaran). `$HOME` ialah bilik anda. `$PATH` senaraikan bilik yang shell cari untuk arahan, dipisah dengan `:`.
</Card>

<Card id="predict-export" type="predict">

<Interactive name="Choice" options={[{ label: 'Nota itu kekal dalam shell. export yang kongsikannya.', correct: true, why: 'Pemboleh ubah biasa peribadi bagi shell ini. export lekatkannya di dinding untuk program yang anda mulakan.' }, { label: 'Skrip tak boleh baca pemboleh ubah', why: 'Boleh, selepas pemboleh ubah itu di-export.' }, { label: 'Ejaan Kancil salah', why: 'Ejaannya betul. <Card id="try-export" type="try">
Lekatkan nota di dinding: `export SHOP=Kancil`. Kemudian jalankan `tools/menu` sekali lagi.

<Interactive name="LinuxSim" scenario="linux-l2-path" goal={{ envVar: { SHOP: '^Kancil$' }, lastTyped: '^(\\./)?tools/menu$' }} hints={['Taip export SHOP=Kancil', 'Kemudian jalankan tools/menu']} solution={['export SHOP=Kancil', 'tools/menu']} success="Today at Kancil: nasi lemak. Skrip itu baca nota tadi." />

<Hint>Tiada jarak di sekeliling `=`.</Hint>
</Card>

<Card id="order-path" type="check">
Katakan PATH ialah `/home/you/tools:/usr/local/bin:/usr/bin:/bin`. Anda taip `menu`. Susun bilik ikut urutan shell mencari.

<Interactive name="OrderList" items={['/home/you/tools', '/usr/local/bin', '/usr/bin', '/bin']} label="Dicari dulu di atas" success="Kiri ke kanan. Padanan pertama menang." />

<Card id="try-path" type="try">
Letak `~/tools` di depan <Term id="path-variable">PATH</Term>: `export PATH="$HOME/tools:$PATH"`. Kemudian taip `menu` sahaja.

<Interactive name="LinuxSim" scenario="linux-l2-path" goal={{ envVar: { PATH: '/home/you/tools:.*' }, lastTyped: '^menu$' }} hints={['Salin dengan tepat: export PATH="$HOME/tools:$PATH"', 'Kemudian taip menu']} solution={['export PATH="$HOME/tools:$PATH"', 'menu']} success="menu kini jalan dari mana-mana. Cuba which menu untuk tengok di mana ia tinggal." />

<Hint>`$PATH` di hujung kekalkan senarai lama.</Hint>
</Card>

<Card id="win" type="win">
Kini anda boleh kongsi nota dengan export dan beritahu shell di mana alat berada.
</Card>

<Card id="deeper" type="deeper">
Perubahan ini kekal sampai anda log keluar. Untuk simpan, tambah baris export dalam `~/.profile`. Di Debian, `~/.profile` sudah tambah `~/bin` ke PATH jika ia wujud. `env` senaraikan setiap nota yang di-export; `unset SHOP` turunkan satu.

Latihan sebenar (pilihan): di Linux, `echo $PATH`, kemudian `which ls`, kemudian `env | wc -l`.
</Card>
