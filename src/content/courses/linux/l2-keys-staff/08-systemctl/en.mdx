<Card id="sort-now-boot" type="check">
Some commands act now. Others decide what happens at the next boot. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'now', label: 'Right now' }, { id: 'boot', label: 'At the next boot' }]} items={[{ label: 'start: turn it on', bucket: 'now', why: 'It runs at once, until stopped or rebooted.' }, { label: 'enable: come back after a power cut', bucket: 'boot', why: 'enable only plans the next boot.' }, { label: 'stop: turn it off for a fix', bucket: 'now', why: 'Off at once.' }, { label: 'disable: stay off after reboots', bucket: 'boot', why: 'It changes the boot plan, not now.' }]} success="start and stop: now. enable and disable: at boot." />
</Card>

<Card id="try-enable" type="try">
Do both jobs in one go: start nginx now and at every boot: `sudo systemctl enable --now nginx`.

<Interactive name="LinuxSim" scenario="linux-l2-services" goal={{ serviceActive: ['nginx'], serviceEnabled: ['nginx'] }} hints={['Type sudo systemctl enable --now nginx', 'Check: systemctl is-enabled nginx']} solution={['sudo systemctl enable --now nginx']} success="Running, and it starts at boot. The next power cut won't bite." />

<Hint>`--now` means "and start it right away too".</Hint>
</Card>

<Interactive name="Choice" options={[{ label: 'sudo systemctl restart nginx', correct: true, why: 'Stop, then start with the new settings. reload is gentler for nginx.' }, { label: 'sudo systemctl enable nginx', why: 'enable only plans the next boot.' }, { label: 'systemctl status nginx', why: 'status only looks. <Card id="win" type="win">
You can now start, stop, restart and enable a service.
</Card>

<Card id="deeper" type="deeper">
`systemctl status nginx` shows it all: a green ● running, ○ stopped, × failed, plus the last log lines. `reload` re-reads settings without dropping visitors. `systemctl list-units --type=service` lists every service.
