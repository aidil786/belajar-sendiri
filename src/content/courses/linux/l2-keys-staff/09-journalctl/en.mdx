<Card id="try-search" type="try">
Long diaries hide the one line you need. Search it: `sudo journalctl -u nginx -g emerg`.

<Interactive name="LinuxSim" scenario="linux-l2-journal" goal={{ lastTyped: '^sudo journalctl (.* )?-g ' }} hints={['Type sudo journalctl -u nginx -g emerg']} solution={['sudo journalctl -u nginx -g emerg']} success="One line, straight to the problem. -g works like grep." />

<Hint>`-g` means "grep": keep only matching lines.</Hint>
</Card>

<Card id="deeper" type="deeper">
systemd's own error message suggests `journalctl -xeu nginx.service`: `-x` adds help text and `-e` jumps to the end. Errors often point one line late, as here. The boss fixes a broken nginx with all of this.

Real rep (optional): on a Debian or Ubuntu VM, `sudo journalctl -u ssh -n 10` shows recent logins.
</Card>
