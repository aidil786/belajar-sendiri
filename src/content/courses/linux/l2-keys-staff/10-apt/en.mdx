<Card id="deeper" type="deeper">
Real rep (optional): on a Debian or Ubuntu VM, try `apt search monitor`. Install security updates often: `sudo apt update && sudo apt upgrade`.

Where the story breaks: real staff can say no. A process does exactly what its program says, and root can do anything. That is why keys matter so much.
</Card>
