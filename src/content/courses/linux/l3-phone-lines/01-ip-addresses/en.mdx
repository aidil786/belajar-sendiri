<Card id="try-valid" type="try">
An <Term id="ip-address">IP address</Term> is a computer's phone number. It has four numbers, each 0 to 255, joined by dots. Real address or not?

<Interactive name="SwipeJudge" cards={[{ text: '10.0.0.5', good: true, why: 'Four numbers, all between 0 and 255.' }, { text: '10.0.5', good: false, why: 'Only three numbers. An address needs four.' }, { text: '192.168.1.20', good: true, why: 'Four numbers. Many home routers use 192.168.' }, { text: '300.1.2.3', good: false, why: '300 is too big. Each number stops at 255.' }, { text: '127.0.0.1', good: true, why: 'A real address: the machine you are on.' }]} />
</Card>

<Card id="see-two" type="see">
kedai has two lines. `lo` is 127.0.0.1, the **loopback**: the shop's intercom. `eth0` is 10.0.0.5: the line to the street. Which one can Aina's laptop call?

<Interactive name="Choice" options={[{ label: '10.0.0.5', correct: true, why: 'The street line. Other computers can reach it.' }, { label: '127.0.0.1', why: 'That is the intercom. On her laptop, it calls her own laptop.' }, { label: 'Both', why: 'The intercom never leaves the shop.' }]} />
</Card>

<Card id="try-find" type="try">

Newer IPv6 addresses look like `2001:db8::5`. Our practice server has none. Numbers like 203.0.113.x are kept for examples, like fake phone numbers in films.
