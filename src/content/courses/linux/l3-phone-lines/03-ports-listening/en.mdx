<Card id="try-ports" type="try">
The IP address reaches the building. The <Term id="port">port</Term> picks the extension inside. Some are famous. Match each job to its port.

<Interactive name="SortCards" buckets={[{ id: 'p22', label: '22' }, { id: 'p80', label: '80' }, { id: 'p443', label: '443' }]} items={[{ label: 'ssh you@kedai', bucket: 'p22', why: 'SSH, the remote login line, uses 22.' }, { label: 'http://kedai.example', bucket: 'p80', why: 'Plain web pages use 80.' }, { label: 'https://kedai.example', bucket: 'p443', why: 'Sealed web pages use 443.' }]} success="22 for SSH, 80 for web, 443 for sealed web." />
</Card>

<Card id="see-ss" type="see">
A program waiting by an extension is **listening**. `ss -tln` lists them: TCP, listening, numbers. Tap the line for the web counter.

<Interactive name="SpotLines" lines={[{ text: 'State  Recv-Q Send-Q Local Address:Port Peer Address:Port' }, { text: 'LISTEN 0      128          0.0.0.0:22        0.0.0.0:*' }, { text: 'LISTEN 0      511          0.0.0.0:80        0.0.0.0:*', target: true }]} prompt="Tap the line for port 80." success="Port 80 is the web counter. Nobody listens on 8080." />
</Card>

<Card id="try-who" type="try">
Who answers each port? Add `-p` for the program names. Only root may see them, so use `sudo`.

<Interactive name="LinuxSim" scenario="linux-l3-ports" goal={{ lastTyped: '^sudo ss -\\w*p' }} hints={['Type sudo ss -tlnp', 'Read the users:(...) part at the end.']} solution={['sudo ss -tlnp']} success="sshd answers 22. nginx answers 80." />

<Hint>Without sudo, the process column stays empty.</Hint>
</Card>

<Card id="deeper" type="deeper">
`ss -tln` letters: `t` TCP, `l` listening, `n` numbers, `p` programs. Add `u` for UDP. Old guides use `netstat`; Debian 13 doesn't install it. `/etc/services` lists famous port names.

</Card>
