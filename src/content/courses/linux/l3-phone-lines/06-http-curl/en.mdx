<Card id="deeper" type="deeper">
Other methods: `POST` sends something, `PUT` replaces, `DELETE` removes. Headers carry facts like `Content-Type`. In scripts, `curl -f` fails on 4xx and 5xx: exit code 22. `curl -L` follows a redirect (3xx).
