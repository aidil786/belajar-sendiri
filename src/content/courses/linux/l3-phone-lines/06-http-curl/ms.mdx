<Card id="see-order" type="see">
<Term id="http">HTTP</Term> ialah cara pesanan disebut di kaunter web. `curl -v` tunjuk seluruh perbualan. Baris dengan `>` ialah kata-kata curl. Tekan baris itu.

<Interactive name="SpotLines" lines={[{ text: '*   Trying 127.0.0.1:80...' }, { text: '> GET /menu.html HTTP/1.1', target: true }, { text: '> Host: localhost', target: true }, { text: '> User-Agent: curl/8.14.1', target: true }, { text: '< HTTP/1.1 200 OK' }, { text: '< Content-Type: text/html' }, { text: '< Content-Length: 36' }, { text: '<h1>Menu</h1>' }]} prompt="Tekan setiap baris yang curl sebut." success="GET ialah kaedahnya: tolong beri /menu.html. Baris dengan < ialah jawapan." />
</Card>

<Card id="try-codes" type="try">
Jawapan bermula dengan **status code** (kod status). Digit pertama bercerita. Susun mereka.

<Interactive name="SortCards" buckets={[{ id: 'ok', label: '2xx: nah, ambil' }, { id: 'you', label: '4xx: ada hal dengan pesanan anda' }, { id: 'kitchen', label: '5xx: dapur bermasalah' }]} items={[{ label: '200 OK', bucket: 'ok', why: 'Semua okey. </Card>

<Card id="deeper" type="deeper">
Kaedah lain: `POST` hantar sesuatu, `PUT` ganti, `DELETE` buang. Header bawa fakta seperti `Content-Type`. Dalam skrip, `curl -f` gagal pada 4xx dan 5xx: kod keluar 22. `curl -L` ikut lencongan (3xx).
