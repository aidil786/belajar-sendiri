<Card id="see-card" type="see">
<Term id="certificate">Sijil</Term> ialah kad pengenalan server: namanya, siapa yang tandatangan, dan tarikhnya. `curl -v` menunjukkannya. Tekan tarikh tamat.

<Interactive name="SpotLines" lines={[{ text: '* Server certificate:' }, { text: '*  subject: CN=kedai.example' }, { text: '*  start date: Nov  1 12:47:46 2026 GMT' }, { text: '*  expire date: Jan 30 12:47:46 2027 GMT', target: true }, { text: '*  subjectAltName: host "kedai.example" matched cert\'s "kedai.example"' }, { text: '*  issuer: CN=Kancil Practice CA' }, { text: '*  SSL certificate verify ok.' }]} prompt="Tekan baris dengan tarikh tamat." success="Kad ini sah hingga 30 Januari 2027." />
</Card>

<Card id="see-ca" type="see">
<Term id="https">HTTPS</Term> ialah HTTP dalam sampul bermeterai. Pejabat dipercayai, iaitu **certificate authority** (CA), tandatangan kad pengenalan. Susun semakan ini.

<Interactive name="OrderList" items={['curl beri salam dan minta kad pengenalan', 'Kedai tunjuk sijilnya', 'curl semak penandatangan, nama dan tarikh', 'Kedua-duanya setuju satu kunci rahsia', 'Pesanan bergerak bermeterai']} label="Langkah pertama di atas" success="Semak kad dahulu, kemudian bercakap secara rahsia." />
</Card>

<Card id="try-443" type="try">
kedai belum ada talian bermeterai. Buktikan: hubungi `https://localhost`, kemudian tengok `ss -tln`.

<Interactive name="LinuxSim" scenario="linux-l3-https" goal={{ lastTyped: '^curl .*https://localhost' }} hints={['Taip curl -sS https://localhost', 'Kemudian ss -tln: tiada 443 dalam senarai.']} solution={['curl -sS https://localhost']} success="Tiada yang mendengar di 443. HTTPS perlukan kaunter sendiri dan sijil." />
</Card>

<Card id="see-dates" type="see">
<Interactive name="Transcript" title="laptop" label="openssl baca sijil kedai.example: subject CN=kedai.example, issuer Kancil Practice CA, notAfter Jan 30 2027. checkend 2592000 kata Certificate will not expire."
  lines={[{ cmd: 'openssl s_client -connect kedai.example:443 < /dev/null 2>/dev/null | openssl x509 -noout -subject -issuer -dates' }, { out: 'subject=CN=kedai.example\nissuer=CN=Kancil Practice CA\nnotBefore=Nov  1 12:47:46 2026 GMT\nnotAfter=Jan 30 12:47:46 2027 GMT' }, { cmd: 'openssl s_client -connect kedai.example:443 < /dev/null 2>/dev/null | openssl x509 -noout -checkend 2592000' }, { out: 'Certificate will not expire', color: 'green' }]} />

`openssl s_client` ambil kad pengenalan seperti pelayar. `x509` membacanya. `-checkend 2592000` bertanya: masih sah dalam 30 hari?
</Card>

<Card id="deeper" type="deeper">
Output ini datang dari makmal latihan kita sendiri. Ia ada CA buatan sendiri, jadi kami suruh laptop mempercayainya. Kedai sebenar dapat sijil percuma daripada Let's Encrypt dan membaharuinya secara automatik. `curl -k` langkau semua semakan: guna untuk melihat sahaja, jangan dalam skrip.
