<Card id="deeper" type="deeper">
Di bawah ufw ada nftables, senarai peraturan kernel (`sudo nft list ruleset`). Firewall cloud berada di luar server: kedua-duanya mesti benarkan port itu. Awas: port yang Docker buka melangkau peraturan ufw. Output ufw di sini datang dari makmal Debian 13 sebenar.
