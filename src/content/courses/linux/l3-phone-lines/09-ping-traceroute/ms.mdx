<Card id="see-ping" type="see">
<Term id="ping">ping</Term> hantar salam kecil dan ukur masa gemanya. `-c 3` hantar tiga, kemudian berhenti. Tekan baris yang kata berapa yang kembali.

</Card>

<Card id="try-ping" type="try">
Ping pasar.example tiga kali. Tanpa `-c`, ping tak pernah berhenti: tekan Ctrl+C.

</Card>

<Card id="see-trace" type="see">
<Interactive name="Transcript" title="kedai (makmal)" label="traceroute kedai.example tunjuk tiga hop: gateway.kedai 10.0.0.1, exchange.example 198.51.100.1, kemudian kedai.example 203.0.113.10."
  lines={[{ cmd: 'traceroute kedai.example' }, { out: 'traceroute to kedai.example (203.0.113.10), 30 hops max, 60 byte packets\n 1  gateway.kedai (10.0.0.1)  0.026 ms  0.003 ms  0.002 ms\n 2  exchange.example (198.51.100.1)  0.012 ms  0.004 ms  0.003 ms\n 3  kedai.example (203.0.113.10)  0.024 ms  0.004 ms  0.005 ms' }]} />

<Term id="traceroute">traceroute</Term> senaraikan setiap ibu sawat dalam perjalanan. Setiap baris ialah satu **hop**. Makmal ini dalam satu mesin, jadi masanya sangat kecil.
</Card>

<Card id="predict" type="predict">
Hari lain, traceroute yang sama tunjuk ini. Adakah jalannya putus di hop 2?

```
 1  gateway.kedai (10.0.0.1)  0.040 ms  0.004 ms  0.004 ms
 2  * * *
 3  kedai.example (203.0.113.10)  0.015 ms  0.007 ms  0.007 ms
```

<Interactive name="Choice" options={[{ label: 'Tidak: hop 2 cuma diam', correct: true, why: 'Hop 3 menjawab, jadi panggilan itu sudah lepas hop 2.' }, { label: 'Ya: panggilan berhenti di hop 2', why: 'Kalau begitu hop 3 takkan menjawab.' }, { label: 'Kedai itu mati', why: 'Kedai menjawab di hop 3.' }]} />
</Card>

<Card id="win" type="win">
Kini anda boleh ping sesebuah mesin dan jejak jalan ke sana.
</Card>

<Card id="deeper" type="deeper">
Banyak server sengaja sekat ping. Tiada balasan tak semestinya mati: uji port sebenar dengan curl. `mtr` gabungkan ping dan traceroute dalam satu jadual hidup. Output traceroute kita datang dari makmal Debian 13 sebenar.
