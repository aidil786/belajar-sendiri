<Card id="try-climb" type="try">
Panjat untuk tiga kedai lagi: `satu`, `dua` dan `tiga`. Baca setiap ralat sebelum tengok kedai seterusnya.

Ralat itu yang beritahu." />
</Card>

<Card id="predict" type="predict">
`curl localhost` berjaya di server anda. Dari laptop anda, halaman yang sama tamat masa. Anak tangga mana?

<Interactive name="Choice" options={[{ label: 'Pintu: firewall, atau mendengar di 127.0.0.1 sahaja', correct: true, why: 'Pekerja menjawab di dalam. Ada yang halang pemanggil dari luar.' }, { label: 'Nama', why: 'Masalah nama berbunyi Could not resolve host.' }, { label: 'Jawapan', why: 'Anda langsung tak dapat jawapan dari luar.' }]} />
</Card>

<Card id="try-own" type="try">
Sekarang kedai anda sendiri: `curl localhost` gagal. Panjat tangga di kedai dan baikinya.

<Interactive name="LinuxSim" scenario="linux-l3-fixlocal" goal={{ serviceActive: ['nginx'], reachable: { localhost: 200 } }} hints={['curl -sS localhost: tidak yang serta-merta. Tiada orang di pintu?', 'ss -tln: ada apa-apa di 80? systemctl status nginx', 'sudo systemctl start nginx']} solution={['sudo ss -tlnp', 'systemctl status nginx', 'sudo systemctl start nginx']} success="Pekerja kembali di 80. curl localhost jawab 200 OK." />
</Card>

</Card>
