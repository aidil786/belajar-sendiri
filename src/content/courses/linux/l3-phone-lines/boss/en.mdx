<Card id="try-name" type="try">
Rung 1, the name. Ask `getent hosts menu.kedai`, read `/etc/hosts`, then fix it. kedai's own number is 10.0.0.5.

<Interactive name="LinuxSim" scenario="linux-l3-boss-name" goal={{ resolves: { 'menu.kedai': '10.0.0.5' } }} hints={['getent hosts menu.kedai finds nothing. cat /etc/hosts shows a typo: kedia.', "Add the right line: echo '10.0.0.5 menu.kedai' | sudo tee -a /etc/hosts"]} solution={["echo '10.0.0.5 menu.kedai' | sudo tee -a /etc/hosts"]} success="Rung 1 fixed: menu.kedai is 10.0.0.5." />

<Hint>Look closely at the last line of /etc/hosts.</Hint>
</Card>

<Card id="try-port" type="try">
Move nginx back to port 80. Change the `listen` line, test with `sudo nginx -t`, then restart nginx.

<Interactive name="LinuxSim" scenario="linux-l3-boss-port" goal={{ portListening: [80], reachable: { localhost: 200 } }} hints={['grep listen /etc/nginx/sites-available/default', "sudo sed -i 's/listen 8080 default_server/listen 80 default_server/' /etc/nginx/sites-available/default", 'sudo nginx -t, then sudo systemctl restart nginx']} solution={["sudo sed -i 's/listen 8080 default_server/listen 80 default_server/' /etc/nginx/sites-available/default", 'sudo nginx -t', 'sudo systemctl restart nginx']} success="Rung 2 fixed: nginx answers on 80 again." />
</Card>

Rung 3. From a laptop outside, curl says `Connection timed out after 5004 milliseconds`. Plain words: a guard drops the call. Port 80 is not on the guard's list.
</Card>

<Card id="try-guard" type="try">
Build the command that lets web customers in, and keeps the guard on duty.

<Interactive name="CommandBuilder" pieces={[{ text: 'sudo', means: 'as root: the guard takes orders only from root' }, { text: 'ufw', means: 'talk to the guard' }, { text: 'allow', means: 'let callers in' }, { text: '80/tcp', means: 'on the web extension' }]} decoys={[{ text: 'disable', means: 'send the guard home: everything opens' }, { text: 'deny', means: 'keep callers out' }]} success="Rung 3 fixed: sudo ufw allow 80/tcp. SSH stays allowed too." />
</Card>

<Card id="try-service" type="try">
Rung 4. Last night kedai rebooted, and nginx stayed off. Start it now, and make it start at every boot.

<Interactive name="LinuxSim" scenario="linux-l3-boss-service" goal={{ serviceActive: ['nginx'], serviceEnabled: ['nginx'], reachable: { localhost: 200 } }} hints={['systemctl is-active nginx; systemctl is-enabled nginx', 'sudo systemctl enable --now nginx']} solution={['sudo systemctl enable --now nginx']} success="Rung 4 fixed: nginx runs, and comes back after every reboot." />
