<Card id="try-scp" type="try">
First the simple courier: `scp` copies over SSH, every time. Build "copy menu.txt to my home folder on kedai".

<Interactive name="CommandBuilder" pieces={[{ text: 'scp', means: 'copy over the SSH line' }, { text: 'menu.txt', means: 'the file here' }, { text: 'kedai:', means: 'to kedai: the colon means the other machine' }]} decoys={[{ text: 'kedai', means: 'no colon: a local copy named kedai!' }]} success="scp menu.txt kedai: lands in your home folder there." />
</Card>

<Card id="see-rsync" type="see">
<Interactive name="Transcript" title="laptop (lab)" label="The first rsync -av site/ kedai:shop/ creates shop and sends index.html, menu.html and old.html."
  lines={[{ cmd: 'rsync -av site/ kedai:shop/' }, { out: 'sending incremental file list\ncreated directory shop\n./\nindex.html\nmenu.html\nold.html\n\nsent 313 bytes  received 103 bytes  832.00 bytes/sec\ntotal size is 62  speedup is 0.15' }]} />

<Term id="rsync">rsync</Term> is a smart courier. It compares both sides first, then carries only what differs. `-a` keeps times and permissions. `-v` lists each file.
</Card>

<Card id="predict" type="predict">
You leave out the slash: `rsync -av site kedai:copy/`. Then you list both folders on kedai. What did the slash change?

```
copy/site/menu.html
copy/site/index.html
shop/menu.html
shop/index.html
```

<Interactive name="Choice" options={[{ label: 'No slash sends the folder itself', correct: true, why: 'site travels as copy/site. With site/ only what is inside travels.' }, { label: 'Nothing: both are the same', why: 'Look again: copy has an extra site folder.' }, { label: 'No slash deletes files', why: 'Only --delete removes files. The slash picks what to send.' }]} />
</Card>

<Card id="try-order" type="try">
You want kedai's shop folder to match your site folder exactly, extras removed. `--delete` can remove files there. Put the safe steps in order.

<Interactive name="OrderList" items={['rsync -av --delete --dry-run site/ kedai:shop/', 'Read the list: is every deleting line expected?', 'rsync -av --delete site/ kedai:shop/', 'curl the page to check it']} label="First step at the top" success="Dry run, read, then the real run." />
</Card>

<Card id="see-dry" type="see">
<Interactive name="Transcript" title="laptop (lab)" label="rsync -av --delete --dry-run says deleting old.html and ends with (DRY RUN)."
  lines={[{ cmd: 'rsync -av --delete --dry-run site/ kedai:shop/' }, { out: 'sending incremental file list\ndeleting old.html\n\nsent 104 bytes  received 31 bytes  270.00 bytes/sec\ntotal size is 58  speedup is 0.43 (DRY RUN)', color: 'yellow' }]} />

`--dry-run` says what would happen and changes nothing. Here: `deleting old.html`. Expected? Then run it for real.
</Card>
