<Card id="try-scp" type="try">
Mula-mula kurier biasa: `scp` salin melalui SSH, setiap kali. Bina "salin menu.txt ke folder rumah saya di kedai".

<Interactive name="CommandBuilder" pieces={[{ text: 'scp', means: 'salin melalui talian SSH' }, { text: 'menu.txt', means: 'fail di sini' }, { text: 'kedai:', means: 'ke kedai: titik bertindih bermaksud mesin lain' }]} decoys={[{ text: 'kedai', means: 'tiada titik bertindih: salinan tempatan bernama kedai!' }]} success="scp menu.txt kedai: mendarat dalam folder rumah anda di sana." />
</Card>

<Card id="see-rsync" type="see">
<Interactive name="Transcript" title="laptop (makmal)" label="rsync -av site/ kedai:shop/ yang pertama cipta shop dan hantar index.html, menu.html dan old.html."
  lines={[{ cmd: 'rsync -av site/ kedai:shop/' }, { out: 'sending incremental file list\ncreated directory shop\n./\nindex.html\nmenu.html\nold.html\n\nsent 313 bytes  received 103 bytes  832.00 bytes/sec\ntotal size is 62  speedup is 0.15' }]} />

<Term id="rsync">rsync</Term> ialah kurier pintar. Ia bandingkan kedua-dua belah dahulu, kemudian bawa apa yang berbeza sahaja. `-a` kekalkan masa dan kebenaran. `-v` senaraikan setiap fail.
</Card>

<Card id="predict" type="predict">
Tanpa garis condong: `rsync -av site kedai:copy/`. Ini isi kedua-dua folder di kedai. Apa bezanya?

```
copy/site/menu.html
copy/site/index.html
shop/menu.html
shop/index.html
```

<Interactive name="Choice" options={[{ label: 'Tanpa garis condong, folder itu sendiri dihantar', correct: true, why: 'site dihantar sebagai copy/site. Dengan site/ hanya isinya dihantar.' }, { label: 'Tiada beza: kedua-duanya sama', why: 'Tengok lagi: copy ada folder site tambahan.' }, { label: 'Tanpa garis condong, fail dipadam', why: 'Hanya --delete buang fail. Garis condong pilih apa yang dihantar.' }]} />
</Card>

<Card id="try-order" type="try">
Anda mahu folder shop di kedai sama betul dengan folder site anda, yang lebih dibuang. `--delete` boleh buang fail di sana. Susun langkah yang selamat.

<Interactive name="OrderList" items={['rsync -av --delete --dry-run site/ kedai:shop/', 'Baca senarai: setiap baris deleting memang dijangka?', 'rsync -av --delete site/ kedai:shop/', 'curl halaman itu untuk menyemak']} label="Langkah pertama di atas" success="Cubaan kering, baca, kemudian larian sebenar." />
</Card>

<Card id="see-dry" type="see">
<Interactive name="Transcript" title="laptop (makmal)" label="rsync -av --delete --dry-run kata deleting old.html dan berakhir dengan (DRY RUN)."
  lines={[{ cmd: 'rsync -av --delete --dry-run site/ kedai:shop/' }, { out: 'sending incremental file list\ndeleting old.html\n\nsent 104 bytes  received 31 bytes  270.00 bytes/sec\ntotal size is 58  speedup is 0.43 (DRY RUN)', color: 'yellow' }]} />

`--dry-run` beritahu apa yang akan berlaku dan tak ubah apa-apa. Di sini: `deleting old.html`. Memang dijangka? Kemudian jalankan betul-betul.
</Card>

<Card id="deeper" type="deeper">
Server latihan kita berdiri sendirian. Output ini datang dari dua mesin Debian 13 sebenar. rsync mesti ada di kedua-dua mesin: `sudo apt install rsync`. Salin balik arah sebaliknya dengan `scp kedai:menu.txt .` (titik bermaksud di sini).
