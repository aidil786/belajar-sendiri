<Card id="see-df" type="see">
`df -h` shows every disk: size, used, free. `-h` means sizes people can read. Tap the main disk, the one at `/`.

<Interactive name="SpotLines" lines={[{ text: 'Filesystem      Size  Used Avail Use% Mounted on' }, { text: 'udev            963M     0  963M   0% /dev' }, { text: 'tmpfs           197M  528K  197M   1% /run' }, { text: '/dev/vda1        20G   19G  513M  98% /', target: true }, { text: '/dev/vda15      124M   12M  112M  10% /boot/efi' }]} prompt="Tap the disk mounted at /." success="20G disk, 19G used, 513M free. Time to look inside." />
</Card>

<Card id="try-du" type="try">
`df` says how full. <Term id="disk-usage">du</Term> says which shelves are fat. Look in `/var/log`, then inside the biggest folder.

<Interactive name="LinuxSim" scenario="linux-l4-disk" goal={{ lastTyped: '^sudo du -sh /var/log/kedai' }} hints={['sudo du -sh /var/log/*', 'sudo du -sh /var/log/kedai/*']} solution={['sudo du -sh /var/log/*', 'sudo du -sh /var/log/kedai/*']} success="Found it: one 17G debug log." />

<Hint>`-s` gives one total per folder. `-h` gives readable sizes.</Hint>
</Card>

<Card id="predict" type="predict">
du shows this. Which file is safe to delete?

```
17G	/var/log/kedai/debug.log
46M	/var/log/kedai/orders.log
```

<Interactive name="Choice" options={[{ label: 'debug.log: an old switch left on', correct: true, why: 'Huge, and only for debugging. orders.log holds real orders.' }, { label: 'orders.log', why: 'Small, and it holds real orders. Keep it.' }, { label: 'The whole /var/log folder', why: 'Never. Programs need it, and other logs matter.' }]} />
</Card>

<Card id="try-free" type="try">
Delete only `debug.log`. Then check `df -h /` again. There is no undo, so type the full path.

<Interactive name="LinuxSim" scenario="linux-l4-disk" goal={{ fileMissing: ['/var/log/kedai/debug.log'], fileExists: ['/var/log/kedai/orders.log'] }} hints={['sudo rm /var/log/kedai/debug.log', 'df -h /']} solution={['sudo rm /var/log/kedai/debug.log', 'df -h /']} success="Back to 11% used. orders.log is safe." />
</Card>

<Card id="deeper" type="deeper">
Real-world twist: a running program may still hold a deleted file open. Then the space returns only after a restart of that program. `journalctl --vacuum-size=200M` trims the journal. `ncdu` is a friendly du (`sudo apt install ncdu`). The full disk here is engine-only.
