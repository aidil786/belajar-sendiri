<Card id="see-df" type="see">
`df -h` tunjuk setiap cakera: saiz, terpakai, kosong. `-h` bermaksud saiz yang manusia boleh baca. Tekan cakera utama, yang di `/`.

<Interactive name="SpotLines" lines={[{ text: 'Filesystem      Size  Used Avail Use% Mounted on' }, { text: 'udev            963M     0  963M   0% /dev' }, { text: 'tmpfs           197M  528K  197M   1% /run' }, { text: '/dev/vda1        20G   19G  513M  98% /', target: true }, { text: '/dev/vda15      124M   12M  112M  10% /boot/efi' }]} prompt="Tekan cakera di /." success="Cakera 20G, 19G terpakai, 513M kosong. Masa untuk tengok ke dalam." />
</Card>

<Card id="try-du" type="try">
`df` beritahu berapa penuh. <Term id="disk-usage">du</Term> beritahu rak mana yang gemuk. Tengok dalam `/var/log`, kemudian dalam folder yang paling besar.

<Interactive name="LinuxSim" scenario="linux-l4-disk" goal={{ lastTyped: '^sudo du -sh /var/log/kedai' }} hints={['sudo du -sh /var/log/*', 'sudo du -sh /var/log/kedai/*']} solution={['sudo du -sh /var/log/*', 'sudo du -sh /var/log/kedai/*']} success="Jumpa: satu log debug 17G." />

<Hint>`-s` beri satu jumlah untuk setiap folder. `-h` beri saiz yang mudah dibaca.</Hint>
</Card>

<Card id="predict" type="predict">
du tunjuk ini. Fail mana yang selamat dipadam?

```
17G	/var/log/kedai/debug.log
46M	/var/log/kedai/orders.log
```

<Interactive name="Choice" options={[{ label: 'debug.log: suis lama yang lupa dimatikan', correct: true, why: 'Sangat besar, dan hanya untuk debug. orders.log simpan pesanan sebenar.' }, { label: 'orders.log', why: 'Kecil, dan ia simpan pesanan sebenar. Simpan.' }, { label: 'Seluruh folder /var/log', why: 'Jangan sesekali. Program memerlukannya, dan log lain penting.' }]} />
</Card>

<Card id="try-free" type="try">
Padam `debug.log` sahaja. Kemudian semak `df -h /` lagi. Tiada undo, jadi taip path penuh.

<Interactive name="LinuxSim" scenario="linux-l4-disk" goal={{ fileMissing: ['/var/log/kedai/debug.log'], fileExists: ['/var/log/kedai/orders.log'] }} hints={['sudo rm /var/log/kedai/debug.log', 'df -h /']} solution={['sudo rm /var/log/kedai/debug.log', 'df -h /']} success="Kembali kepada 11% terpakai. orders.log selamat." />
</Card>

<Card id="win" type="win">
Kini anda boleh cari apa yang memenuhi cakera dan kosongkan ruang dengan selamat.
</Card>

<Card id="deeper" type="deeper">
Hal di dunia sebenar: program yang berjalan mungkin masih buka fail yang dipadam. Ruang hanya kembali selepas program itu dimulakan semula. `journalctl --vacuum-size=200M` kecilkan journal. `ncdu` ialah du yang mesra (`sudo apt install ncdu`). Cakera penuh di sini hanya dalam enjin.
