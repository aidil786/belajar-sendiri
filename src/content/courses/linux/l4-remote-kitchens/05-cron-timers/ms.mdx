<Term id="cron">cron</Term> ialah jadual tugas di dinding. Ia semak setiap minit. Satu baris jadual ada lima medan masa, kemudian kerjanya. Susun medan itu.

<Card id="try-cron" type="try">
`jobs.txt` ada satu baris jadual untuk setiap minit. Pasang dengan `crontab jobs.txt`. Kemudian `sleep 15` sampai seminit berlalu, dan baca `cron.log`.

<Card id="deeper" type="deeper">
cron berjalan dengan PATH yang kecil dan tanpa terminal. Guna path penuh, dan simpan output: `>> /home/you/backup.log 2>&1`. `crontab -r` padam seluruh jadual anda tanpa bertanya. `systemd-analyze calendar '*-*-* 02:00:00'` beritahu bila timer berbunyi seterusnya. Output timer di sini datang dari makmal Debian 13 sebenar.
