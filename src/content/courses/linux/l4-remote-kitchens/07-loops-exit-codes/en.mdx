<Card id="see-codes" type="see">
Every program ends with an **exit code**: a thumbs-up (0) or a number for trouble. `$?` shows the last one. Sort them.

<Interactive name="SortCards" buckets={[{ id: 'ok', label: '0: all good' }, { id: 'bad', label: 'Not 0: something went wrong' }]} items={[{ label: 'true, then echo $? prints 0', bucket: 'ok', why: 'true always succeeds.' }, { label: 'ls nope, then echo $? prints 2', bucket: 'bad', why: 'No such file.' }, { label: 'check.sh with one dish missing: 1', bucket: 'bad', why: 'The script exits with the number missing.' }, { label: 'A command that does not exist: 127', bucket: 'bad', why: '127 means command not found.' }]} success="Zero is the only thumbs-up." />
</Card>

<Card id="deeper" type="deeper">
`while [ … ]; do … done` loops while a question says yes. systemd reads your exit code too. A timer's service shows failed when its script ends with non-zero. So end scripts with a meaningful number.
