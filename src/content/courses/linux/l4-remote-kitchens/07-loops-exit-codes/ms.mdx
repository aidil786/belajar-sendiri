<Card id="see-codes" type="see">
Setiap program tamat dengan **exit code** (kod keluar): tanda bagus (0) atau nombor untuk masalah. `$?` tunjuk yang terakhir. Susun mereka.

<Interactive name="SortCards" buckets={[{ id: 'ok', label: '0: semua okey' }, { id: 'bad', label: 'Bukan 0: ada yang tak kena' }]} items={[{ label: 'true, kemudian echo $? cetak 0', bucket: 'ok', why: 'true sentiasa berjaya.' }, { label: 'ls nope, kemudian echo $? cetak 2', bucket: 'bad', why: 'Fail itu tiada.' }, { label: 'check.sh dengan satu hidangan tiada: 1', bucket: 'bad', why: 'Skrip keluar dengan bilangan yang tiada.' }, { label: 'Arahan yang tak wujud: 127', bucket: 'bad', why: '127 bermaksud arahan tak dijumpai.' }]} success="Sifar sahaja tanda bagus." />
</Card>

<Card id="check" type="check">
Bina: jalankan penyemak, dan hanya jika ia gagal, sebut "Not yet".

<Interactive name="CommandBuilder" pieces={[{ text: './check.sh', means: 'jalankan penyemak' }, { text: '||', means: 'hanya jika ia gagal (bukan 0)' }, { text: 'echo "Not yet"', means: 'sebut Not yet' }]} decoys={[{ text: '&&', means: 'hanya jika ia berjaya (0)' }]} success="|| untuk pelan B. && untuk langkah seterusnya." />

<Card id="deeper" type="deeper">
`while [ … ]; do … done` berulang selagi soalannya kata ya. systemd juga baca kod keluar anda. Servis timer tunjuk failed bila skripnya tamat bukan sifar. Jadi tamatkan skrip dengan nombor yang bermakna.
