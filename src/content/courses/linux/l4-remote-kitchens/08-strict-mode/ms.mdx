<Card id="hook" type="hook">
Malam ini, `tidy.sh` berjalan. Tetapi folder `kedai/tmp` tak wujud. Apa jadi?

```bash
#!/bin/bash
# set -euo pipefail
cd "$HOME/kedai/tmp"
rm -f *.txt
echo "tidy done"
```

<Interactive name="Choice" options={[{ label: 'cd gagal, dan rm berjalan dalam folder rumah anda', correct: true, why: 'Bash teruskan selepas kegagalan. rm -f *.txt padam fail .txt di rumah.' }, { label: 'Ia berhenti di cd', why: 'Hanya dengan set -e. Di sini baris itu ialah komen.' }, { label: 'Tiada apa berlaku', why: 'rm tetap berjalan: dalam bilik yang salah.' }]} />
</Card>

<Card id="see-disaster" type="see">
<Interactive name="LinuxSim" scenario="linux-l4-strict" intro={['ls', './tidy.sh', 'ls']} />

Ralat sebenar kata `cd: … No such file or directory`. Maksudnya: skrip terus berjalan dalam bilik yang salah. Ia padam `menu.txt` dan `prices.txt`, kemudian kata `tidy done`.
</Card>

<Card id="see-strict" type="see">
**Strict mode** (mod ketat) ialah penyelia yang tegas. `set -euo pipefail` ialah tiga peraturan. Susun apa yang setiap satu hentikan.

<Interactive name="SortCards" buckets={[{ id: 'e', label: '-e' }, { id: 'u', label: '-u' }, { id: 'p', label: '-o pipefail' }]} items={[{ label: 'Satu arahan gagal: berhenti sekarang', bucket: 'e', why: '-e: keluar pada ralat pertama.' }, { label: 'cd ke folder yang tiada', bucket: 'e', why: 'cd gagal, jadi -e hentikan skrip.' }, { label: 'Balang yang namanya salah eja', bucket: 'u', why: '-u: balang yang tak pernah diisi ialah ralat.' }, { label: 'grep gagal dalam grep … | sort', bucket: 'p', why: 'pipefail: paip gagal jika mana-mana bahagian gagal.' }]} success="-e: ralat. -u: balang tak dikenali. pipefail: paip rosak." />
</Card>

<Card id="try-strict" type="try">
Kejutkan penyelia: buang `# ` di depan baris 2 dengan `sed`. Kemudian jalankan `tidy.sh`. Fail anda mesti selamat.

<Interactive name="LinuxSim" scenario="linux-l4-strict" goal={{ fileContains: { '~/tidy.sh': '^set -euo pipefail' }, scriptExitCode: { '~/tidy.sh': 1 }, fileExists: ['~/menu.txt', '~/prices.txt'] }} hints={["sed -i 's/^# set/set/' tidy.sh", 'head -n 2 tidy.sh, kemudian ./tidy.sh', 'ls: menu.txt dan prices.txt masih ada.']} solution={["sed -i 's/^# set/set/' tidy.sh", './tidy.sh']} success="Ia berhenti di cd dengan kod keluar 1. Tiada apa dipadam." />
</Card>

<Card id="deeper" type="deeper">
`-e` ada titik buta: ia abaikan kegagalan dalam ujian `if`, atau sebelum `&&` dan `||`. Untuk benarkan satu kegagalan dengan sengaja, tulis `cmd || true`. `trap` boleh mengemas bila skrip berhenti. Uji skrip di mesin pakai buang dahulu.
