<Card id="see-script" type="see">
Your backup script. Which line makes it stop at the first problem?

```bash
#!/bin/bash
set -euo pipefail
src="$HOME/kedai/menu"
dest="$HOME/backups"
mkdir -p "$dest"
cp -r "$src" "$dest/menu-$(date +%F)"
echo "backup done"
```

<Interactive name="Choice" compact options={[{ label: 'Line 2', correct: true, why: 'set -euo pipefail: the strict supervisor.' }, { label: 'Line 5', why: 'mkdir -p makes the folder. It does not stop anything.' }, { label: 'Line 7', why: 'echo only reports at the end.' }]} />
</Card>
