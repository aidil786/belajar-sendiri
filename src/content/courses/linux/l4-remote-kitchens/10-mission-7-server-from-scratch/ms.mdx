<Card id="see-script" type="see">
Skrip sandaran anda. Baris mana yang buat ia berhenti pada masalah pertama?

```bash
#!/bin/bash
set -euo pipefail
src="$HOME/kedai/menu"
dest="$HOME/backups"
mkdir -p "$dest"
cp -r "$src" "$dest/menu-$(date +%F)"
echo "backup done"
```

</Card>
