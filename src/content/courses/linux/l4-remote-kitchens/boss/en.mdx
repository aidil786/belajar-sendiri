Boss! The backup said `backup done` every night. Today the menu broke, and you need yesterday's copy. The backups folder is empty!
</Card>

<Card id="check-why" type="check">
It printed an error, then `backup done`, and exit code 0. Why did it look fine?

<Interactive name="Choice" options={[{ label: 'No strict mode: cp failed, the script kept going, and echo ended with 0', correct: true, why: 'A script ends with its last command\'s code. echo always works.' }, { label: 'cp worked, but slowly', why: 'cp said No such file or directory. Nothing was copied.' }, { label: 'The backups folder is hidden', why: 'ls backups shows nothing because nothing arrived.' }]} />
</Card>

<Card id="try-loud" type="try">
Stage 1: make it loud. Turn on strict mode (line 3), then run it. It should fail, out loud.

<Interactive name="LinuxSim" scenario="linux-l4-boss" goal={{ fileContains: { '~/backup.sh': '^set -euo pipefail' }, scriptExitCode: { '~/backup.sh': 1 } }} hints={["sed -i 's/^# set/set/' backup.sh", './backup.sh; echo $?']} solution={["sed -i 's/^# set/set/' backup.sh", './backup.sh']} success="Exit code 1, and an error you can read. No more quiet lies." />
</Card>

<Card id="see-error" type="see">
The real error says `cp: cannot create directory '/home/you/backup/menu-2026-11-01': No such file or directory`. Tap the line with the wrong folder.

<Interactive name="SpotLines" lines={[{ text: '#!/bin/bash' }, { text: '# backup.sh: copy the menu to the backups folder, every night.' }, { text: 'set -euo pipefail' }, { text: 'src="$HOME/kedai/menu"' }, { text: 'dest="$HOME/backup"', target: true }, { text: 'cp -r "$src" "$dest/menu-$(date +%F)"' }, { text: 'echo "backup done"' }]} prompt="Tap the line with the wrong folder." success="The folder is backups, with an s." />
</Card>

<Card id="try-fix" type="try">
Stage 2: fix the folder name, then run it. A dated copy should land in `backups`.

<Interactive name="LinuxSim" scenario="linux-l4-boss" intro={["sed -i 's/^# set/set/' backup.sh"]} goal={{ scriptExitCode: { '~/backup.sh': 0 }, dirExists: ['~/backups/menu-2026-11-01'] }} hints={["sed -i 's#/backup\"#/backups\"#' backup.sh", 'grep dest= backup.sh, then ./backup.sh', 'ls backups']} solution={["sed -i 's#/backup\"#/backups\"#' backup.sh", './backup.sh']} success="backups/menu-2026-11-01 is there. Exit code 0, and it means it." />
</Card>

<Card id="predict" type="predict">
Stage 3 needs a roster line for 2 a.m., every night. Which one?

<Interactive name="Choice" options={[{ label: '0 2 * * * /home/you/backup.sh', correct: true, why: 'Minute 0, hour 2, every day.' }, { label: '2 0 * * * /home/you/backup.sh', why: 'That is 00:02: minute 2, hour 0.' }, { label: '* 2 * * * /home/you/backup.sh', why: 'That runs every minute from 2:00 to 2:59!' }]} />
</Card>

<Card id="try-roster" type="try">
Stage 3: put it on the roster for 2 a.m. Bonus: keep its words in a log with `>> /home/you/backup.log 2>&1`.

<Interactive name="LinuxSim" scenario="linux-l4-boss" intro={["sed -i 's/^# set/set/' backup.sh", "sed -i 's#/backup\"#/backups\"#' backup.sh"]} goal={{ crontabHas: { you: '^0 2 \\* \\* \\* /home/you/backup\\.sh' } }} hints={["echo '0 2 * * * /home/you/backup.sh' | crontab -", 'crontab -l']} solution={["echo '0 2 * * * /home/you/backup.sh >> /home/you/backup.log 2>&1' | crontab -"]} success="On the roster: every night at 2:00, loud when it fails." />
</Card>

<Card id="check" type="check">
Lessons from the night. Good rule or not?

<Interactive name="SwipeJudge" prose cards={[{ text: 'A loud failure beats a quiet one.', good: true, why: 'You fix what you can see.' }, { text: 'Exit code 0 always means the job really worked.', good: false, why: 'Only if the script stops on errors.
