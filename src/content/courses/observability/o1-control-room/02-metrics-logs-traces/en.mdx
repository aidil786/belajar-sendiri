A **<Term id="metric">metric</Term>** is a name and a number. Prometheus writes down the time, again and again. Small, cheap, great for graphs.

<Card id="see-log" type="see">
<Interactive name="SpotLines" prompt="Tap the line that explains a failed checkout." lines={[{ text: '12:31:02 INFO  order A1041 paid in 0.4s' }, { text: '12:31:04 INFO  order A1042 sent to kitchen' }, { text: '12:31:09 ERROR order A1043 payment timeout after 5s', target: true }, { text: '12:31:11 INFO  order A1044 paid in 0.3s' }]} success="That line says what broke, and for which order." />

A **<Term id="log">log</Term>** is a diary line. It says what happened, when, with details.
</Card>

<Card id="deeper" type="deeper">
They work best together. A metric rings the alarm. A log explains it. A trace points at the slow step. Prometheus keeps metrics. Logs and traces get their own world: O4.

Prometheus writes its own diary too. This line is real:

```text
time=2026-11-01T12:50:04.542Z level=INFO source=main.go:1447 msg="Server is ready to receive web requests."
```
