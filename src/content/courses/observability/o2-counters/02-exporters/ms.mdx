<Card id="deeper" type="deeper">
Banyak exporter wujud: pangkalan data, Redis, barisan mesej. Aplikasi anda sendiri pun boleh tunjuk `/metrics` dengan pustaka klien. Latihan sebenar: tambah blackbox ke stack `kedai-watch` anda. Tambah servis ini ke `compose.yaml`, dan job ini ke `prometheus.yml`.

```yaml
  blackbox-exporter:
    image: quay.io/prometheus/blackbox-exporter:v0.29.1
    ports:
      - "9115:9115"
```

```yaml
  - job_name: blackbox
    metrics_path: /probe
    params:
      module: [http_2xx]
    static_configs:
      - targets: ["http://prometheus:9090/-/ready"]
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: blackbox-exporter:9115
```
