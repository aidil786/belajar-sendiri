A **<Term id="histogram">histogram</Term>** counts requests into buckets. `le` means “less or equal”. All 3 requests here took 0.1 s or less.
</Card>

<Card id="try-bucket" type="try">
Buckets count everything below them. `le="0.25"` says 100. `le="0.5"` says 114. How many took between 0.25 s and 0.5 s?

<Interactive name="Choice" options={[{ label: '14', correct: true, why: 'Yes. 114 − 100 = 14 requests were in that slice.' }, { label: '114', why: '114 includes the 100 faster ones too.' }, { label: '214', why: 'Buckets overlap: subtract, do not add.' }]} />
</Card>

<Card id="deeper" type="deeper">
Names help: counters end in `_total`; units go in the name, like `_seconds` or `_bytes`. Prometheus 3 also has native histograms, with buckets built in. You turn them on with `scrape_native_histograms`. This course uses the classic `le` buckets.
