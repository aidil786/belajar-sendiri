<Card id="deeper" type="deeper">
Bilangan siri dipanggil **<Term id="cardinality">kardinaliti</Term>**. Terlalu banyak siri penuhkan memori dan lambatkan setiap query. Simpan id, emel dan URL penuh dalam log atau trace. Empat pemadan: `=`, `!=`, `=~` dan `!~`.

<Interactive name="Mission" id="obs-o2-l04-real" steps={[{ id: 'up', text: 'Dalam folder kedai-watch, mulakan stack.', command: 'docker compose up -d' }, { id: 'count', text: 'Di http://localhost:9090, kira semua siri: `count({__name__=~".+"})`. Mungkin lebih daripada seribu.' }, { id: 'by', text: 'Tengok job mana yang buat paling banyak: `count by (job) ({__name__=~".+"})`' }, { id: 'stop', text: 'Hentikan stack.', command: 'docker compose down' }]} success="Anda dah ukur kardinaliti sebenar." />
</Card>
