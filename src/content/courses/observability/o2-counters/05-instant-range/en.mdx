<Card id="hook" type="hook">
Two questions: “How many customers wait now?” and “What was the most in the last 10 minutes?” Same kind of answer?

<Interactive name="Choice" options={[{ label: 'No. One number now, versus many numbers over time.', correct: true, why: 'Yes. The second question needs a window of values.' }, { label: 'Yes. Both are one number.', why: 'The answer is one number, but you need many values to find it.' }, { label: 'Prometheus cannot answer the second', why: 'It can. It keeps the old values.' }]} />
</Card>

<Card id="try-range" type="try">
One value per series, right now, is an **<Term id="instant-vector">instant vector</Term>**. Ask for a window instead.

<Interactive name="PromQLPlayground" scenario="o2-kedai" metrics={['kedai_customers_waiting']} initial="kedai_customers_waiting" prompt="Add [5m] right after the name, then Run. Count the samples in each row." goal={{ resultType: 'matrix', resultCount: 2 }} hints={['Type [5m] at the end: kedai_customers_waiting[5m]']} solution="kedai_customers_waiting[5m]" success="Each row now holds a list of samples, with their times." />
</Card>

<Card id="predict" type="predict">
That window is a **<Term id="range-vector">range vector</Term>**. Prometheus scrapes every 1m here. How many samples are in `[5m]`?

<Interactive name="Choice" options={[{ label: '5', correct: true, why: 'Yes. In Prometheus 3 the window leaves out the sample exactly 5 minutes ago.' }, { label: '6', why: 'Close! Prometheus 3 windows leave out the very first edge, so 5.' }, { label: '300', why: '300 is the seconds. Samples come once a minute.' }]} />
</Card>

<Card id="try-fix" type="try">
Run it and read the red message. Then fix it.

<Interactive name="PromQLPlayground" scenario="o2-kedai" metrics={['kedai_customers_waiting']} initial="max_over_time(kedai_customers_waiting)" prompt="Find the most customers waiting in the last 10 minutes." goal={{ usesFunction: ['max_over_time'], resultType: 'vector', resultCount: 2 }} hints={['The function wants a window. Add [10m] after the name, inside the brackets.']} solution="max_over_time(kedai_customers_waiting[10m])" success="12 at nasi lemak, 4 at roti canai. Range in, one number out." />

<Hint>`expected type range vector` in plain words: give it a window, like `[10m]`.</Hint>
</Card>
