<Card id="hook" type="hook">
`rate()` gives five lines: each stall at each outlet. The boss wants one line per stall. What now?

<Interactive name="Choice" options={[{ label: 'Add the outlets together for each stall', correct: true, why: 'Yes. Keep the stall label, add up the rest.' }, { label: 'Read all five and add them in your head', why: 'Fine for five lines. Not for five hundred.' }, { label: 'Delete the outlet label from the app', why: 'You would lose the outlet view forever. Add up in the query instead.' }]} />
</Card>

<Card id="try-sum" type="try">
**<Term id="aggregation">sum</Term>** adds series together. Start with one total for the whole shop.

<Interactive name="PromQLPlayground" scenario="o2-kedai" metrics={['kedai_orders_total']} initial="rate(kedai_orders_total[5m])" prompt="Wrap it all in sum( ), then Run." goal={{ usesFunction: ['sum'], labelNames: [], resultEquals: [{ labels: {}, value: 2 }] }} hints={['Type sum( at the start and ) at the end.']} solution="sum(rate(kedai_orders_total[5m]))" success="2 orders per second, the whole shop." />
</Card>

<Card id="predict" type="predict">
Now `sum by (stall) (…)`. It keeps only the stall label. How many lines come back?

<Interactive name="Choice" options={[{ label: '3: nasi lemak, roti canai, cendol', correct: true, why: 'Yes. One line per stall.' }, { label: '5', why: 'by (stall) adds the outlets of each stall together.' }, { label: '1', why: 'That is plain sum(). by (stall) keeps one line per stall.' }]} />
</Card>

<Card id="win" type="win">
You can now add series up with `sum by` and keep the labels you need.
</Card>
