<Card id="try-build" type="try">
Build the rule. Page someone when a target is really down. Not for a short blip.

<Interactive name="AlertRuleBuilder" scenario="o3-target-down" alert="InstanceDown" exprs={[{ expr: 'up == 0' }, { expr: 'up == 1', why: 'up == 1 is true when the target is fine.' }]} fors={['0s', '1m', '5m']} labels={[{ labels: {} }, { labels: { severity: 'page' } }]} annotations={[{ annotations: { summary: 'Something is down' } }, { annotations: { summary: '{{ $labels.instance }} is down' } }]} goal={{ firingAt: ['20m'], quietAt: ['7m'], noFlap: true, firingLabels: { instance: 'shop-1' }, labels: { severity: 'page' }, annotationUses: ['$labels.instance'] }} solution={{ expr: 0, for: 2, labels: 1, annotations: 1 }} hints={['The db-1 blip lasts 3 minutes. Wait longer than that.', 'Pick severity: page, and a message that names the instance.']} success="Shop-1 rings the bell. The db-1 blip stays quiet." />

<Hint>Amber ⏳ is pending: waiting. Red 🔔 is firing: the bell rings.</Hint>
</Card>

<Card id="deeper" type="deeper">
`keep_firing_for: 5m` keeps the bell ringing a little after the problem ends. It stops on-off-on noise. In a message, `{{ $labels.instance }}` is the target and `{{ $value }}` is the number.
