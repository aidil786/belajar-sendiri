Pick the right kind of panel for each question.

<Card id="try-query" type="try">
Write a Stat panel's query: one number, all shop requests per second.

<Interactive name="PromQLPlayground" scenario="o2-shop-requests" initial={'rate(http_requests_total{job="shop"}[5m])'} goal={{ resultCount: 1, labelNames: [], usesFunction: ['sum', 'rate'], typed: 'job="shop"' }} hints={['Wrap the whole thing in sum( … ).']} solution={'sum(rate(http_requests_total{job="shop"}[5m]))'} success="One number for one big Stat panel." />

<Hint>`sum( … )` with no `by` adds every row into one.</Hint>
</Card>

<Card id="check-json" type="check">
<Interactive name="SpotLines" prompt="Tap the line that holds the panel's query." lines={[{ text: '{' }, { text: '  "type": "stat",' }, { text: '  "title": "Targets up",' }, { text: '  "gridPos": { "x": 0, "y": 0, "w": 6, "h": 6 },' }, { text: '  "targets": [{ "refId": "A", "expr": "sum(up)" }]', target: true }, { text: '}' }]} success="Yes: expr holds the PromQL. Grafana sends it to Prometheus." />

Grafana saves every dashboard as JSON. Keep that file in Git, like code.
</Card>
