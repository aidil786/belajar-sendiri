<Card id="see-burn" type="see">
Bahagikan nisbah ralat dengan bajet (0.001). Itulah burn rate.

<Interactive name="PromQLPlayground" scenario="o3-fast-burn" at="80m" initial="job:shop_error_ratio:rate1h" goal={{ resultCount: 1, typed: '/\\s*0\\.001' }} hints={['Tambah / 0.001 di hujung.']} solution="job:shop_error_ratio:rate1h / 0.001" success="Lebih kurang 19 pada minit 80: bajet sebulan habis dalam lebih kurang sehari setengah." />

**<Term id="burn-rate">Burn rate</Term>** 1 bermaksud bajet cukup tepat sebulan. Lebih besar, lebih laju terbakar.
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'Lebih kurang 2%', correct: true, why: 'Betul. 14.4 × 1 jam ÷ 720 jam dalam 30 hari = 2%.' }, { label: 'Lebih kurang 14%', why: '14.4 ialah kelajuan, bukan bahagian. <Card id="try-build" type="try">
Panggil orang untuk pembakaran besar dari minit 61. Senyap untuk lonjakan 4 minit. Berhenti sejurus selepas dibaiki pada minit 91.

<Interactive name="AlertRuleBuilder" scenario="o3-fast-burn" alert="FastBurn" exprs={[{ label: 'Melebihi SLO, tetingkap 5m', expr: 'job:shop_error_ratio:rate5m > 0.001', why: 'Setiap benjolan kecil bunyikannya, macam lonjakan pada minit 20.' }, { label: 'Burn 14.4, tetingkap 1h sahaja', expr: 'job:shop_error_ratio:rate1h > (14.4 * 0.001)', why: 'Sejam itu ingat bahagian buruk. Ia berbunyi lama selepas dibaiki.' }, { label: 'Burn 14.4, tetingkap 5m sahaja', expr: 'job:shop_error_ratio:rate5m > (14.4 * 0.001)', why: 'Lima minit terlalu pendek. Lonjakan minit 20 bunyikannya.' }, { label: 'Burn 14.4 dalam tetingkap 1h DAN 5m', expr: 'job:shop_error_ratio:rate1h > (14.4 * 0.001) and job:shop_error_ratio:rate5m > (14.4 * 0.001)', graph: 'job:shop_error_ratio:rate1h', threshold: 0.0144 }]} fors={['2m']} labels={[{ labels: { severity: 'page' } }]} goal={{ firingAt: ['80m'], quietAt: ['25m', '50m', '100m'], noFlap: true }} solution={{ expr: 3 }} hints={['Tetingkap panjang buktikan ia penting. Nombor ini datang dari buku kerja SRE Google, untuk SLO 99.9% selama 30 hari. Simpan nisbah ralat setiap tetingkap dengan recording rule, contohnya `job:shop_error_ratio:rate1h`. Jadi amaran kekal pendek dan laju.
