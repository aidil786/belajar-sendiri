**<Term id="runbook">Runbook</Term>** ialah kad baiki di sebelah loceng. Susun bahagiannya mengikut urutan.
</Card>

<Card id="try-link" type="try">
Pautkan runbook dari rule itu. Tambah baris `runbook_url` di bawah `annotations`.

<Interactive name="YamlPlayground" file="rules.yml" initial={'groups:\n  - name: kedai\n    rules:\n      - alert: QueueTooLong\n        expr: kedai_queue_length > 50\n        for: 3m\n        labels:\n          severity: ticket\n        annotations:\n          summary: "Queue at {{ $labels.stall }} is {{ $value }}"\n'} expect={[{ path: 'groups.0.rules.0.annotations.runbook_url', type: 'text', hint: 'Di bawah summary, inden sama: runbook_url: https://wiki.example.com/runbooks/queue-too-long' }, { path: 'groups.0.rules.0.annotations.summary', type: 'text', hint: 'Kekalkan baris summary.' }]} solution={'groups:\n  - name: kedai\n    rules:\n      - alert: QueueTooLong\n        expr: kedai_queue_length > 50\n        for: 3m\n        labels:\n          severity: ticket\n        annotations:\n          summary: "Queue at {{ $labels.stall }} is {{ $value }}"\n          runbook_url: https://wiki.example.com/runbooks/queue-too-long\n'} hint="Salin inden baris summary." success="Setiap loceng kini tunjuk kad baikinya." />

<Hint>`runbook_url` sebaris dengan `summary`: sepuluh ruang ke dalam.</Hint>
</Card>

<Card id="deeper" type="deeper">
Simpan runbook dalam Git, di sebelah rule. Selepas setiap insiden, baiki langkah yang mengelirukan anda. Belum ada runbook? Mungkin amaran itu belum sedia untuk panggil sesiapa.
