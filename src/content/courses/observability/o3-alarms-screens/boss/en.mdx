<Card id="try-inhibit" type="try">
Room 3: when the whole shop is down, mute the ticket bells it causes. Add a `target_matchers` line.

<Interactive name="YamlPlayground" file="alertmanager.yml" initial={'route:\n  receiver: team-chat\n  group_by: [alertname, job]\nreceivers:\n  - name: team-chat\ninhibit_rules:\n  - source_matchers: [alertname="ShopDown"]\n    equal: [job]\n'} expect={[{ path: 'inhibit_rules.0.target_matchers', type: 'list', includes: 'severity="ticket"', hint: 'Under source_matchers: target_matchers: [severity="ticket"]' }, { path: 'inhibit_rules.0.source_matchers', type: 'list', includes: 'alertname="ShopDown"', hint: 'Keep the source_matchers line.' }]} solution={'route:\n  receiver: team-chat\n  group_by: [alertname, job]\nreceivers:\n  - name: team-chat\ninhibit_rules:\n  - source_matchers: [alertname="ShopDown"]\n    target_matchers: [severity="ticket"]\n    equal: [job]\n'} hint="Same indent as equal: four spaces." success="Room 3 cleared!
