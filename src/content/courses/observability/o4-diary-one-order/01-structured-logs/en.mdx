<Card id="see-json" type="see">
```json
{"level":"error","msg":"payment timeout","order_id":"A1041","duration_ms":3000}
```

A **<Term id="structured-log">structured log</Term>** writes named fields. Which field finds every problem?

<Interactive name="Choice" compact options={[{ label: 'level', correct: true, why: 'Yes. level="error" finds every error, whatever msg says.' }, { label: 'msg', why: 'Messages change wording. Fields stay the same.' }, { label: 'duration_ms', why: 'That tells how slow, not whether it broke.' }]} />
</Card>

<Card id="try-build" type="try">
Build one diary line for a failed payment. Tap the pieces in order.

<Interactive name="CommandBuilder" pieces={[{ text: '{"level":"error",', means: 'how bad it is' }, { text: '"msg":"payment timeout",', means: 'what happened, in words' }, { text: '"order_id":"A1041",', means: 'which order: now you can find it' }, { text: '"duration_ms":3000}', means: 'how long it waited' }]} decoys={[{ text: '"card_number":"4111 1111 1111 1111",', means: 'never: card numbers must not go in logs' }]} success="A line a computer can filter, with no secrets in it." />

<Hint>Start with the level. Leave out anything secret.</Hint>
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: 'You miss the web team\'s lines', correct: true, why: 'Yes. Just quietly missing lines, which is worse.' }]} />
</Card>

<Card id="check-swipe" type="check">
Swipe right if the field is fine to log. Swipe left if it should stay out.

<Interactive name="SwipeJudge" cards={[{ text: 'order_id', good: true, why: 'It helps you find one order.' }, { text: 'password', good: false, why: 'Never. Logs are read by many people and tools.' }, { text: 'trace_id', good: true, why: 'It links the line to the order\'s trace.' }, { text: 'card_number', good: false, why: 'Never. Payment data must stay out of logs.' }, { text: 'duration_ms', good: true, why: 'Timings help find slow steps.' }]} />
</Card>

<Card id="deeper" type="deeper">
logfmt is another structured style: `level=error msg="payment timeout" order_id=A1041`. In containers, write logs to standard output. The platform collects them for you.

<Interactive name="Mission" id="obs-o4-l01-real" steps={[{ id: 'run', text: 'Print one JSON diary line from a throwaway container.', command: 'docker run --name diary-try alpine:3.22 echo \'{"level":"info","msg":"shop open"}\'' }, { id: 'logs', text: 'Docker kept the line. Read it back.', command: 'docker logs diary-try' }, { id: 'clean', text: 'Clean up.', command: 'docker rm diary-try' }]} success="That is how container logs start their journey." />
</Card>
