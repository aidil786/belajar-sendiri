<Card id="see-collector" type="see">
<Interactive name="Transcript" title="bash" label="otelcol-contrib validate on a config whose traces pipeline names the exporter otlp: Error, references exporter otlp which is not configured." lines={[{ cmd: 'otelcol-contrib validate --config=config.yaml' }, { out: 'Error: service::pipelines::traces: references exporter "otlp" which is not configured', color: 'red' }]} />

The pipeline names an exporter that isn't set up above. The **<Term id="otel-collector">Collector</Term>** is the sorting office: receivers in, exporters out, pipelines join them.
</Card>
