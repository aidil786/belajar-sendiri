<Card id="see-collector" type="see">
<Interactive name="Transcript" title="bash" label="otelcol-contrib validate pada config yang pipeline traces sebut exporter otlp: Error, references exporter otlp which is not configured." lines={[{ cmd: 'otelcol-contrib validate --config=config.yaml' }, { out: 'Error: service::pipelines::traces: references exporter "otlp" which is not configured', color: 'red' }]} />

Pipeline itu sebut exporter yang tak disediakan di atas. **<Term id="otel-collector">Collector</Term>** ialah pejabat sortir: receiver masuk, exporter keluar, pipeline sambungkannya.
</Card>

<Card id="try-fix" type="try">
Baiki pipeline itu. Ia patut hantar trace ke exporter `debug` yang disediakan di atas.

<Interactive name="YamlPlayground" file="config.yaml" initial={'receivers:\n  otlp:\n    protocols:\n      grpc:\n        endpoint: 0.0.0.0:4317\n      http:\n        endpoint: 0.0.0.0:4318\nexporters:\n  debug:\n    verbosity: detailed\nservice:\n  pipelines:\n    traces:\n      receivers: [otlp]\n      exporters: [otlp]\n'} expect={[{ path: 'service.pipelines.traces.exporters', type: 'list', includes: 'debug', hint: 'Baris terakhir patut sebut debug, exporter pada baris 9.' }, { path: 'service.pipelines.traces.receivers', type: 'list', includes: 'otlp', hint: 'Kekalkan otlp sebagai receiver: ia disediakan pada baris 2.' }, { path: 'exporters.debug', type: 'map', hint: 'Kekalkan blok exporter debug.' }]} solution={'receivers:\n  otlp:\n    protocols:\n      grpc:\n        endpoint: 0.0.0.0:4317\n      http:\n        endpoint: 0.0.0.0:4318\nexporters:\n  debug:\n    verbosity: detailed\nservice:\n  pipelines:\n    traces:\n      receivers: [otlp]\n      exporters: [debug]\n'} hint="Receiver dan exporter ialah senarai berbeza. Cuma baris terakhir yang salah." success="Fail itu lulus validate Collector sebenar." />

<Hint>`otlp` ialah receiver di sini. Exporter itu bernama `debug`.</Hint>
</Card>

<Card id="deeper" type="deeper">
OpenTelemetry juga setuju tentang nama, dipanggil semantic conventions: `http.request.method`, `http.route`, `service.name`. Gunakannya, supaya setiap alat faham data anda. Latihan sebenar: semak config anda sendiri.
