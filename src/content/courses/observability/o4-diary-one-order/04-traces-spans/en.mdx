<Card id="see-trace" type="see">
<Interactive name="TimelineTap" events={[{ when: '0 ms', title: 'POST /order starts', text: 'kedai-api gets the order. A trace is the whole order. Each step is a **<Term id="trace-span">span</Term>**, with a start and an end. Tap through it.
</Card>

<Card id="see-real" type="see">
<Interactive name="SpotLines" prompt="This is the real Collector's debug output for that order. Both spans share one **<Term id="trace-id">trace ID</Term>**: the order number.
</Card>

<Card id="predict" type="predict">

<Interactive name="Choice" options={[{ label: "Inside pay card: kedai-pay's own spans", correct: true, why: 'Yes. <Card id="check-kind" type="check">
<Interactive name="SortCards" buckets={[{ id: 'server', label: 'Kind: Server' }, { id: 'client', label: 'Kind: Client' }]} items={[{ label: 'kedai-api receives POST /order', bucket: 'server', why: 'It answers a request: Server.' }, { label: 'kedai-api calls kedai-pay', bucket: 'client', why: 'It makes a request: Client.' }, { label: 'kedai-pay receives that call', bucket: 'server', why: 'The other end of the call: Server.' }, { label: 'kedai-pay sends SQL to the database', bucket: 'client', why: 'It asks the database: Client.' }]} success="Every call has two ends: a Client span and a Server span." />

The real output said `Kind: Server` and `Kind: Client`. Sort these spans.
</Card>

<Card id="win" type="win">
You can now read a trace and find the slow span.
</Card>
