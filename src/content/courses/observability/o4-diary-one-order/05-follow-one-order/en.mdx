<Card id="try-build" type="try">
Build the `traceparent` header. Tap the pieces in order.

<Interactive name="CommandBuilder" pieces={[{ text: 'traceparent:', means: 'the W3C header name' }, { text: '00-', means: 'version 00' }, { text: '3c9a51e0b7d24f6e9a18c2d4e6f80b15-', means: 'the trace ID: the order number' }, { text: 'd2e3f40516273849-', means: "the caller's span: who is asking" }, { text: '01', means: 'flags: 01 means sampled, keep this trace' }]} decoys={[{ text: 'order_id=A1041-', means: 'a log field, not part of this header' }]} success="That is a real W3C traceparent header." />

<Hint>Version, trace ID, parent span, flags. Dashes between them.</Hint>
</Card>

<Card id="deeper" type="deeper">
You rarely write `traceparent` by hand. OpenTelemetry's instrumentation for HTTP clients and servers adds and reads it for you. Still check every hop. One service that drops the header splits the trace in two.
</Card>
