<Card id="predict" type="predict">
Prometheus does not keep exemplars by default. Which flag turns them on?

<Interactive name="Choice" options={[{ label: '--enable-feature=exemplar-storage', correct: true, why: 'Yes. It keeps recent exemplars in a fixed-size buffer in memory.' }, { label: '--web.enable-otlp-receiver', why: 'That lets Prometheus take metrics over OTLP. A different job.' }, { label: '--storage.tsdb.retention.time', why: 'That sets how long samples are kept on disk.' }]} />
</Card>

<Card id="win" type="win">
You can now jump from a graph to one order's trace and logs.
</Card>

<Card id="deeper" type="deeper">
In Grafana, the Prometheus data source can link an exemplar's `trace_id` to your trace store. A Loki data source can turn `trace_id` in a log line into a link too. Then the jump is one click, both ways.
</Card>
