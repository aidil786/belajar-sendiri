<Card id="see-swipe" type="see">
Swipe right for a blameless sentence. Swipe left for a blaming one.

<Interactive name="SwipeJudge" prose cards={[{ text: 'The 17:30 change dropped an index, and no check caught it.', good: true, why: 'It names what the system allowed.' }, { text: 'Ben ran the change wrong.', good: false, why: 'Ask what made it easy to run it wrong.' }, { text: 'The runbook had no step for slow queries.', good: true, why: 'A gap in the system you can fix.' }, { text: 'Mei should have known.', good: false, why: 'Should-have-known fixes nothing next time.' }]} />

A **<Term id="blameless-postmortem">blameless postmortem</Term>** asks what made the mistake easy. Never who to punish.
</Card>

<Card id="see-parts" type="see">
<Interactive name="OrderList" items={['Summary: one paragraph', 'Impact: who felt it, for how long', 'Timeline: what happened when', 'Causes: what let it happen', 'Action items: owner and date']} label="Top of the postmortem first" success="Story first, lessons last." />

Put the parts of the write-up in order.
</Card>

<Card id="predict" type="predict">
Which action item will really get done?

<Interactive name="Choice" options={[{ label: 'Add a CI check that blocks changes that drop an index. Owner: Ben. Due: 15 Nov.', correct: true, why: 'Yes. <Card id="check-draft" type="check">
<Interactive name="SpotLines" prompt="A draft postmortem. Tap every line that blames a person." lines={[{ text: 'Impact: 28 minutes, about 5% of orders failed.' }, { text: 'Cause: Ben was careless with the 17:30 change.', target: true }, { text: 'Cause: no test checks that indexes stay.' }, { text: 'Note: Mei should have spotted it sooner.', target: true }, { text: 'Went well: tracing found the slow query in 4 minutes.' }]} success="Rewrite those two as system gaps, and the team learns." />

Find the blame, then imagine the system fix behind it.
</Card>

<Card id="win" type="win">
You can now write a blameless postmortem with real action items.
</Card>

<Card id="deeper" type="deeper">
Write one when customers felt it, data was lost, or on-call stepped in. Share it widely: other teams have the same gaps. Celebrate the people who spoke up first.
</Card>
