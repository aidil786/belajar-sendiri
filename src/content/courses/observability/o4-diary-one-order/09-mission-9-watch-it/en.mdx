<Card id="see-compose" type="see">
node-exporter has no `ports` line. How does Prometheus reach it?

<Interactive name="Choice" options={[{ label: 'On the Compose network, by its name: node-exporter:9100', correct: true, why: 'Yes. Services in one Compose file share a network and find each other by name.' }, { label: 'Through your laptop on port 9100', why: 'Only ports you publish reach your laptop. This one stays inside.' }, { label: 'It cannot', why: 'It can: Compose gives them a shared network.' }]} />

```yaml
services:
  prometheus:
    image: quay.io/prometheus/prometheus:v3.13.5
    volumes:
      - ./prometheus:/etc/prometheus:ro
    ports: ["9090:9090"]
  node-exporter:
    image: quay.io/prometheus/node-exporter:v1.12.1
  grafana:
    image: grafana/grafana:13.2.5
    volumes:
      - ./grafana/provisioning:/etc/grafana/provisioning:ro
      - ./grafana/dashboards:/var/lib/grafana/dashboards:ro
    ports: ["3000:3000"]
```

<Card id="see-grafana" type="see">
Grafana runs in its own container. Why does the data source say `http://prometheus:9090`, not `localhost`?

<Interactive name="Choice" options={[{ label: "Inside Grafana's container, localhost is Grafana itself", correct: true, why: 'Yes. Use the service name: Compose turns it into the right address.' }, { label: 'localhost is not allowed in YAML', why: 'It is allowed. It just points at the wrong place here.' }, { label: 'Port 9090 only works with a name', why: 'The port is fine. The host is the problem.' }]} />

```yaml
# grafana/provisioning/datasources/prometheus.yaml
apiVersion: 1
datasources:
  - name: Prometheus
    type: prometheus
    uid: prometheus
    url: http://prometheus:9090
    access: proxy
    isDefault: true
```

```yaml
# grafana/provisioning/dashboards/kedai.yaml
apiVersion: 1
providers:
  - name: kedai
    folder: Kedai Kancil
    type: file
    options:
      path: /var/lib/grafana/dashboards
```
</Card>
