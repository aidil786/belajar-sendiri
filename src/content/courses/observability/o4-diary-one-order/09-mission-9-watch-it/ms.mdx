<Card id="see-compose" type="see">
node-exporter tiada baris `ports`. Macam mana Prometheus sampai kepadanya?

<Interactive name="Choice" options={[{ label: 'Melalui rangkaian Compose, ikut nama: node-exporter:9100', correct: true, why: 'Betul.
```yaml
services:
  prometheus:
    image: quay.io/prometheus/prometheus:v3.13.5
    volumes:
      - ./prometheus:/etc/prometheus:ro
    ports: ["9090:9090"]
  node-exporter:
    image: quay.io/prometheus/node-exporter:v1.12.1
  grafana:
    image: grafana/grafana:13.2.5
    volumes:
      - ./grafana/provisioning:/etc/grafana/provisioning:ro
      - ./grafana/dashboards:/var/lib/grafana/dashboards:ro
    ports: ["3000:3000"]
```

<Card id="see-grafana" type="see">
Grafana berjalan dalam container sendiri. Kenapa sumber data tulis `http://prometheus:9090`, bukan `localhost`?

<Interactive name="Choice" options={[{ label: 'Dalam container Grafana, localhost ialah Grafana sendiri', correct: true, why: 'Betul. Guna nama servis: Compose tukarnya kepada alamat yang betul.' }, { label: 'localhost tak dibenarkan dalam YAML', why: 'Ia dibenarkan. Cuma ia tunjuk ke tempat yang salah di sini.' }, { label: 'Port 9090 hanya berfungsi dengan nama', why: 'Port itu elok. Hos itulah masalahnya.' }]} />

```yaml
# grafana/provisioning/datasources/prometheus.yaml
apiVersion: 1
datasources:
  - name: Prometheus
    type: prometheus
    uid: prometheus
    url: http://prometheus:9090
    access: proxy
    isDefault: true
```

```yaml
# grafana/provisioning/dashboards/kedai.yaml
apiVersion: 1
providers:
  - name: kedai
    folder: Kedai Kancil
    type: file
    options:
      path: /var/lib/grafana/dashboards
```
</Card>
